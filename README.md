# J-NOX

**Just-enough Nucleus, Open eXtensions.** 기능안전을 목표로 하는 경량 실시간 마이크로커널과, 서비스·드라이버를 독립 실행 영역에서 확장하는 운영체제 프로젝트.

첫 기준선은 **기획 초안 0.1**이다. 자동차 적용에서 ISO 26262 ASIL D 안전 목표를 지원할 수 있는 구성과 ISO/SAE 21434에 따른 사이버보안 개발을 목표로 한다. 첫 적용 시스템, 보드, 안전 상태 및 정량 시간 한계는 확정 전이다.
