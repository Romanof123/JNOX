# Native X11 hostname (#464, #448)

CHG-345 and IMP-345 cover the packaged node identity interface used by standalone native C applications under REQ-020 and DES-005. The measured endpoint is the read-only native SVC 198 used by uname and gethostname. Xtrans GetHostname consumes that service in the X11 local transport. Socket message delivery and Xauthority credential verification are outside this measurement.

libX11 1.8.10 compiles Xtrans 1.4.0 into xim_trans.c. Xtransint.h selects NEED_UTSNAME on _POSIX_SOURCE. Xtrans.c TRANS(GetHostname) extracts nodename. Apply xtrans-1.4.0-uname.patch with patch -p1 in a private copy of the staged X.Org include directory, then place that directory first for the target build. This propagates a failed uname and protects callers that ignore the result from inspecting an uninitialized buffer. libxcb 1.17.0 xcb_auth.c uses gethostname for FamilyLocal. libXau 1.0.11 consumes Xauthority records.

Package ordinary FIFO/RR native ELFs with --nodename LABEL. All slots read the same kernel-owned value. One 1–63 byte ASCII label with alphanumeric ends and interior letters, digits or hyphens is accepted. The packager records it in metadata. Service 198 takes a writable address and exact size of 325, and returns the five NUL-terminated 65-byte fields sysname, nodename, release, version and machine. The running kernel supplies its Cargo package version/name and AArch64 platform. Absence of the option returns native ENODATA (61) and clears the valid destination. Invalid record length returns EINVAL and invalid user memory returns EFAULT. gethostname reports ENAMETOOLONG and leaves a short destination untouched.

For the serial gate, compile probe.c with the graphics OS overlay and library. Boot a pair of identical probe ELFs in ordinary FIFO/RR slots with --nodename guest-a, --arg guest-a and --peer-arg guest-a; require two kernel-reported zero exits. Repeat with guest-b to distinguish package identity from a constant. Boot with no --nodename and --arg absent to verify ENODATA. Check that empty, oversized, leading-hyphen and trailing-hyphen labels fail packaging. Rebuild the original libX11 translation unit and retain its compiler output. The measured checks and subsequent compiler boundary appear in evidence/README.md.

한국어: 커널 이미지에 명시한 노드 이름을 모든 일반 FIFO/RR 프로세스가 공유한다. 설정하지 않았을 때 두 API 모두 ENODATA 오류를 반환한다. X 인증 쿠키와 피어 자격 증명은 별도 기능이다.

Run identity/gate.py from a clean source checkout with --lab pointing to the shared lock directory, --out to a fresh build location, --runtime to the staged graphics runtime with the Wayland OS profile, --xtrans-include to the pinned Xtrans 1.4.0 include directory, and --x11-build to the libX11 tree configured at the #463 milestone. The gate records the checkout commit and rejects dirty tracked sources. It checks three native boots before resuming the original compiler. For the Unix-only continuation run identity/x11-unix.py with the same --lab, --configured pointing to that libX11 build, --identity-run to the completed identity gate directory, and another fresh --out. The observed compiler failures and full artifact digests are preserved in evidence/.
