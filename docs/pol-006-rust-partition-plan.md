# POL-006 일반 Rust 시간 파티션 작업

[English](pol-006-rust-partition-plan.en.md) · [#99](https://github.com/Romanof123/JNOX/issues/99) · CHG-046 · 예정 IMP-044 · 예정 EVD-044

## 가상 구성과 작업

단일 Cortex-A72 EL1 코어, QEMU virt/GICv2/TCG, 128 MiB에서 실행한다. 콜드 부팅별 에뮬레이터·옵션·ELF·해시를 고정한다. CNTPCT와 CNTFRQ(F), 공통 기준 E, q=F/20틱(50 ms)을 쓰며 F가 1000으로 나누어떨어져야 한다. 기존 어셈블리 시험의 4슬롯·2프레임 근거는 별도 보존한다. [EVD-010](evidence/evd-010.md) · [기존 디스패처](../kernel/src/partition.rs)

| 표 | q 단위, 끝점 제외 | 목적 |
| --- | --- | --- |
| P, 4q 프레임 | A [0,2), B [2,3), 유휴 [3,4) | 기존 창 배치에 일반 작업을 적용해 비교한다. |
| Q, 5q 프레임 | B [0,1), 유휴 [1,2), A [2,4), B [4,5) | 첫 소유자를 바꾸고 프레임 경계 양쪽에 B를 둔다. 문맥을 유지해도 창은 개별 집계한다. |

실행별 표를 고정하고 세 프레임 전체와 네 번째 프레임 첫 디스패치를 관측한다. 시작 전에 정수 오프셋, 빈틈·중복 없는 순서, 양의 길이, 소유자, 카운터 산술 범위를 검사한다. 두 표에서 동일한 일반 Rust 작업과 각각의 EL1 스택을 쓴다. A는 IRQ를 허용하고 양보 없이 순환 정수 누산기와 반복 횟수를 갱신한다. B는 차단 상태로 시작해 최초 명시적 유휴 창 진입 때 준비 상태가 된 뒤 별도 결정적 누산기를 계속 갱신한다. 유휴 문맥도 분리한다. 두 표 모두 B의 첫 창에서는 차단되어 유휴를 선택한다. 명시적 유휴 창에서 준비되더라도 실행하지 않는다. 창 종료 시 미완료 작업의 문맥을 보존하고 다음 자기 창에서 재개한다. 남은 시간을 다른 작업에 빌려주지 않는다. 실제 진행량과 선점·재개 스택, 레지스터·PC를 ELF와 예외 복귀 기록에 대조한다.

## 경계 시간과 복구

E와 프레임·오프셋으로 절대 비교 시각을 계산한다. 독립 판정기는 원시 카운터로 경계 −1/0/+1틱과 순환 시점의 소유자를 재구성한다. 동일 틱에서는 준비 상태를 먼저 반영하고 현재 반개구간에서 선택하며 명시적 유휴는 유지한다. 목표 d, 실제 IRQ 진입 i, 중단된 작업·PC, 디스패치와 복귀 대상, 복귀 후 첫 독립 문맥 관측 x를 구별한다. 동일 단조 카운터와 F, 사건 순서, 측정 불확실성을 보존하고 별도 예외 기록과 대응시킨다. 정상 조건은 d ≤ i ≤ x, 불확실성을 포함해 x−d ≤ F/1000(1 ms), 올바른 창·문맥과 각 실행 가능 창에서의 양의 실제 진행이다. 같은 소유자가 이어져도 복귀 후 관측한다. 가상 시험 한계 1 ms는 최소 창의 1/50로 가장 짧은 창에 명목 49 ms가 남는다. 측정 누락·귀속 불명·한계를 걸친 불확실성은 합격할 수 없다.

경계를 넘어 실제 수행한 시간은 마스킹 여부와 관계없이 나가는 작업의 초과 실행으로 기록한다. IRQ와 디스패처 비용은 분리하고 불확실한 문맥 경계는 보수적 범위로 남긴다. 유휴·작업·커널·전환 불확실성은 경과 구간에 한 번씩 집계한다. IRQ 진입 시 E와 현재 카운터로 실제 창을 다시 구하고 복귀 직전 재확인한다. 차단·유휴 창에는 유휴를 선택하고 다음 미래 절대 경계를 설정한다. 건너간 모든 경계·누락 창·잃은 서비스 시간을 기록한다. 창 연장·기준 이동·보상 실행·재생은 금지한다. 자기 창을 모두 사용하는 것은 허용된다. IRQ 마스킹 중 소프트웨어는 즉시 회수할 수 없고 무한 마스킹에는 유한 전환 한계가 없다. 복구 성공과 별도로 실행 가능 창 누락 또는 시간 한계 초과를 실패 판정한다.

## 사례와 독립 증거

각 표를 정상 실행한 뒤 별도 부팅에서 A 첫 창 종료 d 전에 IRQ를 막고 d+q+q/4에 해제한다. 실제 마스킹 시간과 서비스 손실을 측정한다. P는 명시적 유휴에 진입해 원래 순환 경계까지 유지한다. Q는 마지막 B 창 누락을 기록하고 순환 후 B의 남은 창에서 실행한다. 이후 원래 E 기준으로 보호 창 두 개 전체를 관측한다. 정상 시간 판정 실패, 귀속·누락·복구를 독립 확인해야 결함 관측이 성공한다. 전체 창을 넘기지 않고 1 ms를 조금 초과하는 별도 지연을 주입한다. 판정기는 F/1000틱과 한 틱 초과, 소유자 교환, 기준 이동, 잘못된 재개 PC, 복귀 관측 누락·잘린 기록을 구별해야 한다. 호스트에서는 앞 프레임을 기준으로 한 0 경계를 포함해 각 경계 −1/0/+1틱을 검사하고 길이 0·중복·빈틈·알 수 없는 소유자를 거부한다. 원시 카운터와 실제 진행량을 쓰고 사후 시각 대입을 금한다.

독립 검증자는 표와 결함 사례별 첫 콜드 부팅 결과, 구성·리비전·ELF 해시와 역어셈블리, 원시 사건·스택 범위·독립 예외 복귀 기록을 보존한다. 캡처 버퍼 용량을 미리 정하고 채점 후 UART를 전송한다. 구현과 증거 연결은 실행 후 진행한다. REQ-002/005/023 → DES-003/012 → VER-002/005/023. 시간 창 무결성과 메모리 파티션은 별도로 검증한다. 전용 스택을 써도 EL1 권한과 주소 공간을 공유한다. 메모리 보호, 고장 격리, 물리 지연, 제품 안전 상태·FTTI의 근거는 별도로 필요하다. 제품 표·마스킹 상한·보드 간섭과 해당 승인은 [#21](https://github.com/Romanof123/JNOX/issues/21)에 남는다.
