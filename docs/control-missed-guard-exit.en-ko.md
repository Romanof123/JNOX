# Restore the control decision guard before final SVC / 최종 SVC 전 제어 판정 구간 복원

Defect [#217](https://github.com/Romanof123/JNOX/issues/217), tracked under [#94](https://github.com/Romanof123/JNOX/issues/94) and [#21](https://github.com/Romanof123/JNOX/issues/21). Baseline `ca0b3dd3f87f0f459449271d957af1eb8e77d2cd`. REQ-002/003/005/023 → DES-003/006/012 → VER-002/003/005/023. [Control worker and IRQ/SVC handlers](../kernel/src/control_runtime.rs) · [ADR-001](safety-parameters.en.md).

## Worker invariant

A periodic IRQ can arrive after the worker's first missed-index check restores DAIF and before its second check sets the IRQ mask. When the phase index skipped, the IRQ handler disables the timer, inhibits the workload, records the missed index and resumes the worker. This branch does not rearm the comparator. The worker's decision closure then sees that index. In the baseline it calls the nonreturning `final_check` while the outer guard is active. The inner guard saves an already-set I bit, finishes the actual freshness check and restores that inner DAIF. SVC #2 is reached with the outer guard's mask still set. Its duration/end record and restoration cannot execute. The claim concerns this retiring worker and its guard accounting. Cross-task interrupt suppression or an observed field failure has not been established.

Return the decision to run `final_check` as an ordinary boolean from the closure. The existing guard takes its ending counter sample, accounts the interval and restores the incoming DAIF. The existing final-check routine then consumes the live index once under its own guard, records its completion, marks stopping and performs SVC #2. The worker remains the sole consumer. Between that guard exit and the final check the worker performs no state update, yield or frame switch; the skipped-index IRQ has already disarmed the only workload interrupt. The existing early check already makes the same handoff. Preserve both normal missed-index reads, the post-decision SVC redirect, real freshness check, timing, debit and GPIO semantics. [#213](https://github.com/Romanof123/JNOX/pull/213) combined this issue with a separate optimization. Its 0/8 A0 complete healthy results and held timing status remain separately attributed.

## Independent acceptance

Freeze both ELFs and select the same semantic observation points from each disassembly. Pin QEMU AArch64 virt/GICv2 with one Cortex-A72, 128 MiB, original control image, counter, admission and logging settings. Use controlled in-memory scheduler-state cases as diagnostic observations, reporting any missing capture. Store immutable raw PC, SP, DAIF, frame, IRQ/SVC and actual guard-accounting observations for each build.

1. Test both parent and candidate with a valid missed index pending **after the early check and before the second check** on the ordinary worker stack. Start the decision with I clear. At the real SVC #2 instruction inspect the worker's current DAIF or the immediately saved SPSR, never handler-entry PSTATE. Baseline must reproduce I set and an unclosed outer guard. Candidate must restore all incoming DAIF bits, close/account the outer and final guard, consume the same index once, perform the actual final check, log the same target and stop. Verify each actual closing update to `LONGEST_MASKED` against its max rule using the sampled begin/end, and marker entry/exit pairs on the marker image. A shorter interval may leave the previous maximum unchanged. Also check a pre-masked diagnostic input preserves its original I bit. Do not manufacture an observed interval amount. Record linked instructions and host control boundaries.
2. Set the matching missed index in the saved-state control after the normal decision but before phase completion SVC. Both versions must use the handler's existing saved-frame redirect to `final_check`, retain the control worker's stack and finish once. Include ordinary no-miss behavior. Report these three scenarios separately from naturally occurring cold boots. No new benchmark or observer code may run inside the measured kernel.
3. Compare linked images for control-rm and control-dm under stock healthy, descriptor A0, marker, cold, and operational/characterize-off nominal/anchor selectors; compare data, entry points and PT_LOAD payloads. In each policy use one ordinary default-clock A0 cold boot, one operational missing-bounds boot per A1/A2 and one deterministic OFF-only boot per A1/A2. Validate in order: A0, nominal refusal, anchor refusal, nominal OFF, anchor OFF. Preserve original first failures, real permit and PL061 readback; missing bounds must still give mask 4095 and no worker. The cold fixture needs its declared valid mode input. Smoke each remaining changed stock/marker/cold image and keep its outcomes. Keep compilation, boots and review sequential.
4. A passing directed restore fix requires both changed and preserved execution paths above and no new safety/containment behavior in the comparison controls. Score A0 healthy performance separately under ADR-001, including 5 ms completion/decision spacing and 25/5/30 ms fault-response criteria where an actual ON state and fault exist. Restoring DAIF establishes neither a healthy permit sequence nor physical/product WCET or FTTI.

## 제어 작업 불변식 및 검증

첫 누락 검사에서 DAIF를 복원한 뒤 두 번째 검사가 IRQ를 가리기 전에 늦은 주기 IRQ가 들어올 수 있다. 위상을 건너뛴 IRQ 경로는 타이머를 끄고 출력을 차단한 뒤 실제 누락 인덱스를 기록하고 작업자를 복귀시킨다. 이 경로는 비교기를 다시 설정하지 않는다. 기준 구현에서 두 번째 검사는 보호 구간 안에서 복귀하지 않는 최종 검사를 호출한다. 내부 구간은 이미 I가 설정된 DAIF를 저장·복원한다. 작업자는 바깥 구간의 종료 카운터 측정과 DAIF 복원 전에 SVC #2를 실행한다. 이 결함의 관측 대상은 종료하는 작업자의 상태와 해당 마스킹 회계다.

두 번째 구간은 최종 검사 필요 여부를 반환해 원래 종료 측정·회계·DAIF 복원을 마친다. 이어서 기존 최종 검사 함수가 독립 보호 구간에서 실제 누락 인덱스를 한 번 소비하고 신선도 검사, 완료 기록, 정지 표시 및 SVC #2를 수행한다. 두 구간 사이에 작업자가 상태를 갱신하거나 양보하지 않으며, 누락을 만든 유일한 작업 IRQ는 이미 해제됐다. 정상 경로의 첫 검사, 판정 후 누락에 대한 SVC 재진입, 원래 과금·GPIO·시간 기준은 유지한다. #213의 정상 A0 0/8과 보류 판정은 별도다.

양쪽 ELF와 링크 주소를 고정하고 같은 작업자 상태를 비교한다. 첫 검사를 통과한 뒤 두 번째 검사에 유효 누락을 제공한 경우 기준판의 I 설정·바깥 구간 미종료와 후보의 원래 DAIF 복원·실제 종료 회계, 누락의 단일 소비와 완료를 확인한다. 실제 SVC 직전 PSTATE 또는 해당 SPSR을 사용한다. 각 종료 회계의 최대값 규칙, 마커 이미지의 구간 입·출력, 처음부터 I가 설정된 대조도 확인한다. 정상 판정 후 SVC 전 누락에서는 두 이미지 모두 같은 작업 스택에서 기존 최종 검사로 재진입해야 한다. 누락 없는 경우도 분리한다. 저장 상태 검사는 일반 부팅의 자연 발생 빈도나 기한 증거로 셈하지 않는다.

각 정책의 기존 이미지와 적재 바이트를 대조한다. RM 이후 DM에서 A0 기본, A1/A2 운영 거부, A1/A2 결정적 OFF 순서로 최초 실행을 보존하고, 달라진 stock·marker·cold 구성도 실제 유효 입력으로 확인한다. 누락 마스크 4095, 운영 작업 0건, 독립 출력 판독을 확인한다. 정상 A0의 시간, 실제 출력 ON 이후의 25/5/30 ms, 실기 WCET와 FTTI는 원래 기준과 별도 분모로 보고한다. 부팅·빌드·검토는 한 번에 하나만 진행한다.
