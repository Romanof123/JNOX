## What the 20 first launches established / 첫 실행 20건의 관측

At 62.5 MHz the inclusive opening limit is 62,500 counter ticks; a slot is 3,125,000 ticks. Ten matched v1 launches and ten v2 launches used distinct guests. In each arm two R refusals preceded operational frames and timer arming. Eight matched v1 W/S runs stopped at the first late Rust marker; the separate original v1 cohort also had 0/8 normal completions. In v2 CBS S/trace alone passed (first marker E+57,262, 4 A and 4 B grants, horizon 10). No W run established sustained neighbor service. Six v2 runs observed A’s first marker late (E+63,392–75,826). Aligned W/plain had a different failure: publication was sampled at E+71,644 with generation 1, before any visible 5/6 ledger rows, cutoff arm, selection or worker. Preserve this as a committed, undispatched failure; the original capture cannot independently establish the debit operands. Both archived late v1 runs remain separate with an earlier opening failure. No revised late case ran.

| v2 same-run intervals, ticks | E→IRQ | IRQ→precommit | Pre→post commit | Commit→cutoff arm | Commit→pre-ERET |
| --- | ---: | ---: | ---: | ---: | ---: |
| aligned W/plain, no dispatch | 29146 | 30556 | 11942 | absent | absent |
| CBS W/plain, late marker | 17929 | 23627 | 6707 | 10031 | 12356 |
| CBS S/trace, completed | 21600 | 17240 | 4955 | 8135 | 10735 |

Across all eight v2 runs the inner idle preparation was 47,137–62,699 ticks with at least 2,997,995 ticks left until E afterward. Seven matched config-event-to-first-marker intervals shortened by 9,897–26,165 ticks; the eighth has no v2 worker observation. This comparison excludes unobserved v1 boot-to-config time. Phase durations bracket multiple operations, including instrumentation; none measures the cost of a particular copy. These are observations, not safe execution bounds.

## Proposed source change and independent gate

1. **One reserved ledger bank switch.** Retain the original epoch and real idle preparation. In the present source the IRQ takes the whole prepared record, constructs both frame snapshots, validates the pristine ledger, moves prepared.next into live Jobs and returns a Decision by value. It then emits two sets of q/d and demand rows before arming, selection/return-plan logging and worker dispatch. Reserve two fixed Jobs banks with one authoritative bank index and a one-use generation. Before E prepare the full checked next backend state *in its destination bank*. Preserve a separate immutable first-decision record of both clients’ releases, q/d before/after, demand, action, owner, initial frame metadata, expected count/accumulator, checked goal, end and cutoff. No heap allocation, live ready change, frame transfer, timer shift, or speculative grant. Account boot-to-E, idle preparation/masking and storage, including both banks and immutable witness bytes. If setup misses E, retain the failed setup and stop.
2. **Live authority at the boundary.** With IRQ serialization, read the actual comparator/source/CTL/IAR, time, current idle and saved return, E/slot, generation and unconsumed proposal token. Revalidate both actual frame addresses/bounds and the same saved CPU identity/register fields checked by v2, both actual progress records against their pristine ledgers, ready/demand/pending state, policy and manifest, and allocation invariants. Precompute constant expected values; compare live fields in place once instead of materializing repeated aggregate snapshots. Prevalidated fields may be trusted only for sealed storage: no mutable aliases or intervening writer; otherwise revalidate directly. Keep original before-commit time cutoff; a stale token or failed check leaves bank, frame ownership and accounting untouched. Never consume two proposals or make a blocked/exited client runnable.
3. **Commit vs actual return.** In the sole IRQ writer publish one generation-tagged bank index as the authoritative transition. No whole Jobs/Decision copy, no extra arbitration, no separate unchecked mirror ledger. Consume the one-use token consistently with that publication. Ordered counter samples bracket it; read back the live generation/index and owner, retain the before/post times and result in a preallocated compact record. If the post-sample exceeds the limit, record published generation, actual q/d/debit state identifiable from the sealed record plus readback, and no selected frame/no worker. Fail-stop without undo, fresh publication or inferred service. A pre-publication timeout must instead record unchanged generation. If valid, establish the active grant, actual frame owner, goal/action/generation and original absolute cutoff with hardware readback. Preserve live progress/first-marker and saved-frame checks; require the **actual worker marker** by E+62,500. A timely bank switch is insufficient. Keep checked upper service = vector stop sample minus pre-ERET sample; count entitlement once, and measure actual grant residency separately.
4. **Reduce writes, retain provenance.** On the live path keep a bounded compact event with validity bits for each reached stage, referenced frozen decision ID, live bank/generation readback, register readbacks, actual IRQ, pre/post samples, frame/ELR and actual return-plan order. Capture the original compare programming/readback times when those operations occur, and preserve the existing assembly return recorder. Decode descriptive q/d, releases and inactive-client fields from the sealed decision only *after* the first trap or terminal stop (also on pre-worker failure). Label these values prepared/committed by evidence; do not report delayed formatting times as earlier row 5/6 observations. An absent stage stays absent. Version the event schema and replay parser, preserve v1/v2 decoding, and reject an uncommitted or mismatched bank. Missing readback, record overflow or a truncated capture cannot qualify. Independently recompute the expected transition and compare actual worker/return and post-trap ledger. Include journal writes, readback and fail paths in time and size accounting; no cold worker warm-up or phase exemption.
5. **Bound the change.** Use the revised handoff only for healthy W/S slot 0. Afterward the published bank owns ordinary mutable Jobs, while the distinct first-decision witness remains sealed for replay. Every later boundary uses the existing full live arbitration, SVC block/wake, exit, ownership and cutoff handling. R must refuse before preparation, operational frame or compare. Keep the v1 synchronous late branch outside this change; its clean future qualification remains open. If later work changes that branch, freeze a separate clean diagnostic against the same timer and spill criteria.
6. **First-capture comparison.** Freeze baseline 51567ba and candidate with toolchain, selectors, ELF hashes, counter, native-Linux paths and cohort order. Use the ten previous case positions per source: both policies × W/S × plain/external IRQ trace plus two R refusals, default clock, alternating v2/new pair order, total 20 new first launches, 15 s each. Do not replace the existing matched or original v1 records. Preserve failures before launch, timeout, missing records and first guard reason. Compare full boot/idle/IRQ/commit/cutoff/return/marker and subsequent actual grants per case; correlate independent ELF/ERET, saved frames, both clients’ progress and ledger. W requires complete 34-slot neighbor allocation; S requires four real grants and exit per owner through horizon 10. Retain all thresholds and the 8/8 normal gate. Exercise stale/reused token, wrong bank/frame, bad progress/return, threshold equality/+1, pre/post-commit timeout, lost latch/readback and attempted grant after failure as separately identified controls. An isolated fast boot, source-level bounded operation count or reduced journal volume is not a latency guarantee. No product or board verdict is assigned. REQ-002/005/023 → DES-003/012 → VER-002/005/023.

## 한국어 설계 및 검증 범위

62.5 MHz에서 개방 한계는 62,500틱이다. 같은 명세로 각각 처음 부팅한 v1/v2 10건씩을 비교했다. 각 두 R은 시작 전 거부됐다. 원래 v1과 별도의 비교용 v1은 정상 완료 각 0/8이다. v2는 CBS S/추적만 첫 표식 E+57,262, A/B 각 4회로 완료했다. 여섯 건은 A의 실제 표식이 늦었다. 정렬 W/일반은 E+71,644에 세대 1 커밋 후 작업 복귀 전 실패했다. 기존 기록에 없는 실제 수요·차감 필드는 소급하지 않는다. 전체 W 이웃 서비스는 입증되지 않았다. 위 표의 경계 시각은 같은 실행끼리만 비교한다. v2 유휴 준비 내부는 47,137~62,699틱, 준비 뒤 E까지 최소 2,997,995틱이 남았다. 7개 비교쌍의 구성 기록→작업 표식은 단축됐지만 v1 부팅 전체의 비교와 특정 복사 비용은 관측할 수 없다.

1. 기존 v2는 경계 IRQ에서 준비 구조를 꺼내 프레임 스냅샷을 다시 만들고 Jobs 전체 교체·Decision 전달·여러 기술 행을 기록한다. 두 고정 원장 중 비활성 저장소에 유휴 시간 동안 다음 상태를 직접 준비한다. 별도 불변 기록에 양 작업의 전후 q/d·수요·소유자·프레임·진행·목표·컷오프를 보존한다. E·타이머·실제 준비 상태를 앞당기지 않는다. 두 저장소·기록 크기와 부팅·유휴 마스킹 비용을 집계하고 E를 놓치면 중단한다.
2. 실제 IRQ에서 타이머와 IAR·CTL·비교값·시각, 유휴 복귀, 최초 슬롯·세대·미사용 토큰, 두 프레임과 기존 레지스터 검사, 양 작업의 실제 진행·원장·준비·미완료·정책을 확인한다. 기대 상수만 미리 계산하고 실측 필드는 현장에서 한 번씩 대조한다. 접근이 봉인되지 않은 값은 재검증한다. 커밋 전 실패는 기존 원장·프레임·차감을 유지한다.
3. IRQ 직렬화 안에서 세대가 붙은 활성 원장 인덱스 하나를 게시한다. Jobs/Decision 전체 복사 없이 실제 전후 표본·세대·소유자 되읽기를 남긴다. 커밋 후 한계 초과는 게시된 원장 및 **작업 미선택·미실행**을 기록한 뒤 실패 정지한다. 재시도·취소·실행량 추정은 금지한다. 정상일 때만 실제 작업 메타데이터·프레임 인계와 원래 컷오프 설정/되읽기, 기존 복귀 및 진행 검사를 수행한다. 실제 Rust 표식의 1 ms 한계와 보수적 실행 시간 상한은 유지한다.
4. 실제 경로는 단계별 유효 비트·결정 ID·실제 세대·타이머·프레임·ELR·전후 시각·복귀 순서를 유한 RAM에 기록한다. 첫 트랩 또는 실패 정지 뒤 불변 기록과 실측 커밋을 결합해 기술 필드를 전개한다. 준비값과 실측값을 구분하고 나중 출력으로 이전 시각의 5/6행을 만들어내지 않는다. 도달하지 않은 단계는 미관측이다. 버전별 판정기와 원래 예외 복귀 기록, 실패 경로·되읽기 비용을 유지한다.
5. 정상 W/S 슬롯 0만 변경한다. 이후에는 활성 원장의 기존 스케줄러·차단·재개·종료·컷오프를 그대로 사용한다. R은 준비 전 거부한다. 기존 v1 지연 사례는 별도이고 제때 열린 뒤의 지연 진단은 미완료다. 지연 분기를 수정하면 별도 진단을 동결한다.
6. 51567ba와 새 후보 각각 정상 W/S 일반·추적 8회 및 R 2회, 기본 시계·Linux 저장소에서 순서를 교차해 새 최초 실행 총 20회를 고정한다. 회당 15초, 재시도 치환 없음. 부팅~첫 표식 및 이후 양 작업의 실행·원장·프레임·독립 ERET를 비교한다. W 34슬롯 이웃 서비스, S 각 4회와 종료·10슬롯, 정상 8/8 원 기준을 유지한다. 오래된/재사용 토큰, 원장·프레임·진행 불일치, 한계/1틱 초과, 커밋 전후 실패·되읽기 누락은 별도 대조한다. 현재 실행·보드·제품 승인은 미확정이다.

## Implemented UART schema / 구현 UART 형식

Use the existing virt reservation selectors with aligned-wake, aligned-saturated, cbs-wake or cbs-saturated. The kernel emits RSRV RAW 3 for these W/S images. Refused and late images retain RSRV RAW 1. Decode a saved UART file with `python tools/reservation_handoff.py path/to/uart.log`. The report preserves the guest terminal result. Decoder success describes structural consistency only. Pair each capture with its build hash, cold launch command and external exception trace as prescribed above.

기존 virt reservation 선택자와 위 네 W/S 앱을 사용한다. 거부 및 지연 앱의 UART 버전은 1이다. 위 명령은 저장한 UART에서 실제 종료 결과를 보존하며, 형식 검사 성공만으로 전체 일정 충족을 판정할 수 없다. 각 파일에 해당 빌드 해시, 최초 부팅 명령과 외부 예외 기록을 연결한다.

| Tag | Time and four payload fields / 시각 및 네 필드 |
|---|---|
|24, slot UINT64_MAX, owner 2|Boot anchor / 부팅 기준. Boot counter sample, original epoch, zero, zero. The row timestamp follows clock setup. 행 시각은 시계 설정 후의 표본이다.|
|24, slot 0|Terminal decode time / 종료 시각. Descriptor ID, stage bits (IRQ 1, precommit 2, commit 4, cutoff readback 8, selected 16), terminal authority word, observed owner.|
|25, 37|Vector entry and end of real source reads / 벡터 진입 및 실제 읽기 종료. 25 gives IAR, CTL, CVAL, original target. 37 gives entry, read end, CVAL, IAR.|
|26, 27|Actual publication brackets / 게시 전후 표본. 26 gives descriptor, origin word, epoch, zero. 27 gives authority readback, bank, generation, owner read through that bank.|
|28|After cutoff programming / 컷오프 설정 후. Requested compare, CTL, readback compare, timer kind.|
|29, 30|Selection sample before exception return / 예외 복귀 전 선택 시각. Frame, ELR, x19, TPIDR; return index, epoch, slot end, descriptor. Actual assembly return and Rust marker remain tags 12 and 10.|
|31, 32|Terminal decode of each sealed decision / 봉인된 결정의 종료 시 해석. Before q,d and after q,d; released units, remaining demand, state, selected action plus one (zero for unselected).|
|33|Terminal storage sizes in bytes / 저장 크기(바이트). Jobs, optional destination bank, optional sealed witness, fixed receipt.|
|34, 35|Terminal decode of each initial frame witness / 초기 프레임 봉인값. Address, PC, SPSR, TPIDR; x19, update count, accumulator, common selected goal.|
|36|Idle preparation ready sample / 유휴 준비 완료 시각. Mask start, ready, original epoch, zero. IRQ unmask follows the sample.|

Descriptor IDs 1–4 identify aligned W/S then CBS W/S. The sole writer switches the authority word from 0 to 3. Bits encode bank in bit 0 and generation above it. Tags 31–35 carry the terminal decode timestamp. Tags 31/32 describe a debit only when actual publication/readback identifies the committed bank. An absent selection or return stays unobserved. Counter brackets include instrumentation and the ready sample precedes the final unmask. Whole-path time and independent ERET still require fresh captures.

결정 ID 1~4는 aligned W/S, CBS W/S 순서다. 단일 작성자가 권한 단어를 0에서 3으로 게시한다. 하위 1비트는 뱅크, 상위 비트는 세대다. 31~35행은 종료 시각에 해석한다. 31/32행의 차감은 실제 게시 및 되읽기로 뱅크가 확인된 경우에만 성립한다. 선택·복귀 기록이 없으면 미관측으로 둔다. 계측 비용을 포함하며 36행은 인터럽트 마스크 해제 직전의 표본이다. 전체 경로와 독립 ERET 확인은 신규 실행에 남는다.

The original offline decoder rejected a complete RAW 3 capture because it counted both tag 24 roles as one. Retain that first result with its decoder revision. The corrected decoder checks the boot anchor against clock setup and reports actual stage bits on complete failure streams. Only an explicit pre-anchor setup abort with empty stages may omit the anchor. RAW 1 summarizes the archived terminal payload including refusals. An incomplete UART cannot establish a guest result. The normalized regression input preserves the row order and fields of the aligned-saturated traced failure (status 2, reason 5).

초판 판독기는 완전한 RAW 3 기록의 24행 두 역할을 하나로 세어 거부했다. 첫 결과와 당시 리비전을 보존한다. 수정판은 부팅 기준과 시계 설정을 대조하고 실패로 종료된 기록에서도 관측한 단계를 보고한다. 부팅 기준 이전 중단은 빈 단계와 명시적인 설정 실패일 때만 인정한다. RAW 1은 거부를 포함한 종료값을 요약한다. 종료가 잘린 UART로 게스트 결과를 판정할 수 없다. 회귀 입력에는 aligned-saturated 추적 실패의 행 순서와 수치를 보존했다.
