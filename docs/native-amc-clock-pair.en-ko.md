## Public ABI / 공개 인터페이스

* Package flag `--amc-clock-page` (at most once, only with `--policy amc`); raw build `JNOX_AMC_CLOCK_PAGE=1`, absent by default, reject other values and out-of-profile use. Manifest records boolean, ABI version and page VA; capture the actual linked per-slot backing PAs/roots independently. No change to manifest task descriptors, clock IDs, syscall 6, nanosleep or existing binaries' behavior.
* Public C SDK `<jnox/clock_pair.h>`: `struct jnox_clock_pair { uint64_t monotonic_ns, process_cpu_ns; uint32_t backend, error; };` and `struct jnox_clock_pair jnox_clock_sample(void);`. Rust crate root `pub fn clock_sample() -> Result<ClockPair, ClockError>` with public unsigned 64-bit nanoseconds and `ClockPairBackend::{Page,Syscall}`; use the C implementation through its repr(C) ABI. Backend 1 = one page/counter sample, 2 = two ordered syscall samples, 0 = error. On C failure return both numbers zero and positive errno. No change to errno on successful helper reads. Return by value avoids an extra caller-supplied destination-validation ABI.
* Discovery `JNOX_CALL_CLOCK_PAGE=20`, existing native SVC convention, no arguments, returns VA 0x01400000 only on an enabled AMC package, otherwise a negative unsupported-service result. Old kernels can return ENOSYS or ENOTSUP. SDK discovers lazily and caches only in generation-private writable storage; an unknown/unsupported result takes the ordinary syscall fallback. No dereference of an unnegotiated VA. On fallback read process CPU (ID 2) then monotonic (ID 1) with syscall 6; expose backend 2 and document the two sample instants. Preserve errors including an unavailable process clock. Unsupported/corrupt page format never authorizes reading another address.

선택은 AMC 패키지의 명시적 플래그로 제한한다. C·Rust 함수는 단조 ns, 세대별 CPU ns와 실제 백엔드를 반환한다. 조회 20은 활성화한 패키지에서만 VA를 제공한다. 기본 패키지와 구형 커널에서는 세대 전용 캐시 후 기존 호출 6을 CPU→단조 순으로 사용하고 두 표본의 시각 차이를 공개한다. 기존 clock_gettime과 오류 규약을 보존한다.

## Mapping, counter and publication / 매핑·카운터·게시

One 4 KiB physically distinct, zero-initialized normal-memory page per installed slot. Same VA in each TTBR0, EL0 readable, EL0 writes forbidden, UXN/PXN; only a privileged alias writes. Keep it outside user load/stack/notification regions. Expose no peer data, physical addresses, task pointers or programmable timer controls. On the enabled single-A72 profile set CNTKCTL_EL1.EL0PCTEN for the physical count, keeping EL0 timer register access disabled, synchronize before user entry. Validate the configured CPU/counter domain and nonzero CNTFRQ. The partition mode already demonstrates counter-only access; the weighted notification mapping is shared and has different contents. [Partition setup](../kernel/src/native_cyclic.rs) · [MMU](../kernel/src/native_el0_mmu.rs)

Version 1 consists of eight naturally aligned little-endian u64 words at offsets 0..56: sequence, ABI version (1), slot ID, accepted generation ID, F, monotonic-clock origin, settled CPU ticks, final return counter R. Remaining bytes zero. Origin is CLOCK_DOMAIN.0 used by syscall 6; the release-grid epoch is a distinct value. R is the *same operand* used to arm this grant and settle the next exception. Publish CPU already charged to this generation before R. For observed g, reject g<R or g<origin and checked-add overflow. Compute floor((g−origin)×10⁹/F) and floor((settled+g−R)×10⁹/F) using wide intermediate arithmetic; check u64 result ranges.

On CPU0 with IRQ masked, invalidate the outgoing snapshot before exposing any mutable state. For every actual EL0 return, mark the slot sequence odd before payload changes, enforce store ordering, write the fields including the assembly's actual R and release-publish the next even sequence. Restore validation, cutoff check and calendar programming must precede admission of the return. A rejected preparation never exposes a new valid interval. Document/disassemble the final R-to-ERET and entry-to-sample brackets, including publication overhead. Counter and budget accounting use the same R even if an IRQ is already pending when the guest resumes. On discard/exit revoke the snapshot. Reinitialize backing bytes and SDK BSS only after the old generation can never execute again. Never reuse an even sequence for a resumable reader; if increment would wrap, permanently disable fast reads for that generation. Sequence zero is unavailable.

Reader: at most two fast attempts. Acquire-load a nonzero even sequence, load payload using aligned single-copy atomic reads, execute ISB then one MRS CNTPCT_EL0, issue the required read barrier before re-reading the sequence with acquire semantics. Return the pair only if sequences match, format and generation identity are consistent and conversions succeed. A preempted attempt observes the sequence change on resumption; never combine an old R with another interval. For persistent inconsistency, exhausted sequence or unsupported metadata, use syscall fallback; arithmetic overflow in both implementations returns EOVERFLOW. One successful uninterrupted fast attempt performs one counter read and zero clock SVCs. Report failed attempts separately if observed. All bounded-read and publication operations must be implementable without dynamic allocation.

각 슬롯은 같은 VA에 서로 다른 물리 페이지를 매핑한다. EL0는 읽기 전용, 실행 금지이며 물리 카운터 읽기만 허용한다. 사용자 타이머 설정 권한은 부여하지 않는다. 실제 최종 복귀 카운터 R, 이미 차감한 CPU틱, 호출 6의 단조 원점과 주파수를 동일 단위로 게시한다. IRQ 마스크 상태에서 홀수 무효화→순서 보장→필드/R 기록→짝수 release 게시를 수행한다. 읽기는 acquire·ISB·단일 MRS·재검사용 읽기 장벽으로 구성한다. 세대·순서가 바뀌면 재시도는 최대 두 번, 이후 기존 시계 호출로 복구한다. 되감기·오버플로·시퀀스 순환이나 복귀 거절이 거짓 유효 구간을 만들면 실패다.

## Frozen separate cohort / 별도 최초 실행

Before launch seal the combined toolchain/source, kernel and ordered ELF hashes, decoded configs, backend selection, disassembly, exact QEMU/argv, raw UART/RAM/external trace destinations and 120 s cold timeout. Single virt CPU0/Cortex-A72/GICv2, TCG default clock, 128 MiB, F=62,500,000, Q=3,125,000. Build the existing four slot ELFs with one source change at the paired sampling call to use the helper, leaving sensor ring, batch sizes, 8 ms stamp retention, sample cadence, inputs and products unchanged. Save backend counts separately from the sealed product ABI. Use the same quartet across all new enabled/disabled positions. Keep the original first ELFs, parser and evidence independently addressable. [Existing clients and configs](../examples/native-amc/README.md)

Control configuration: slot 0 LO priority 1 C_LO=C_HI=3, D=3,T=4, offset 0, two generations. Its first ring-reading generation streams for 70 ms of its own CPU; second publishes eight readings and exits. Slot 1 LO priority 4 C_LO=C_HI=1,D=2,T=4, offset 1, one 20 ms ring stream. Both perform the bracket check at start and completion; slot 0 additionally performs it at its ordinary batch polling cadence. Check deadline and independent ring sums; tag every bracket by generation and join captured returns/entries. Prove backend distinctions using callsites/disassembly, marker/backend counters and retained exceptions; normal fast positions may issue discovery once per generation, but require page-backed clock pairs and no steady-state clock syscall at their sampling sites. Do not require a naturally interrupted seqlock read; check odd/changed/repeated sequence, wrap, checked conversions and fallback/error semantics with deterministic SDK controls. An unavailable counter sample or lost event leaves its claim unobserved.

For each timed transition report programmed budget compare, actual entry cause and time i, commit c, first HI-owned post-return observation x, own service charge/spill, roots, private checkpoints, all deadline margins and evidence loss. Cross-check actual i against raw IAR/PPI, same-process trace in traced runs, time-page fields and independent interval replay. Both new CPU-bound positions per workload must satisfy its existing bounds. A synchronous clock read, exit or other event winning the race remains a real synchronous observation. A successful fresh PPI interval would establish that one configuration on QEMU; a missing PPI remains a first failure. Historical host delays, hardware WCET, FTTI and physical product approval remain unresolved.

최초 실행 순서는 활성 normal-hi 일반·추적, 활성 staggered 일반·추적, 비활성 normal-hi 추적, 별도 활성 호환성 대조다. 기존 업무량과 표본 주기는 그대로 두고 읽기 경로만 교체한다. 실제 HI1 PPI30의 진입 i·커밋 c·앱 관측 x를 기존 b2/b5 기준과 비교한다. 호환 대조는 두 슬롯의 전용 페이지와 실제 선점·새 세대를 대조하며 기존 SVC로 각 시계의 상하한을 독립 확인한다. 결과는 관측된 현재 가상 배포에만 적용하고 예전 실패를 덮어쓰거나 원인을 소급하지 않는다.
