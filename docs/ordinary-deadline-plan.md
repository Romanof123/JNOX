# POL-005 · Ordinary EDF and sampled LLF virtual jobs / 일반 EDF·표본 LLF 가상 작업

CHG-051 · intended IMP-048 · planned EVD-048 · REQ/VER-002/005/023 · DES-003/012. [#113](https://github.com/Romanof123/JNOX/issues/113) · [EVD-005](evidence/evd-005.en.md) · [EVD-015](evidence/evd-015.en.md) · [#21 release cases](scheduling-release-cases.en.md)

## Frozen design

One QEMU virt Cortex-A72, GICv2, TCG, one preemptible CPU. Select policy and a static slice of (unique ID, linked Rust entry, release r, absolute deadline d, positive estimated CPU cost c). Each ordinary task gets a private stack and returns via the completion trampoline. For these finite cases admit up to three independent single-shot jobs, in table order A,B,C; no blocking, migration, self-suspension or voluntary yields. Capacity exhaustion, duplicates, absent entries, zero cost, d≤r, inconsistent grid or arithmetic overflow reject before release. Freeze Q=frequency/10 physical counts, exactly 100 ms; reject inexact frequency conversion. Set one future epoch S before launch. Map each integer model tick k to absolute counter S+kQ using checked multiplication/addition. Releases at each grid are queued before selection. Record nominal release, actual observation, deadline and completion. Retain stock EVD-005/015 entry points.

Admission is a conditional, zero-overhead finite **model** result. Before launching run the selected sampled policy with completion at declared CPU cost, actual release table and tie order, and reject predicted deadline misses. For independent preemptive EDF additionally check all intervals bounded by release/deadline endpoints: sum costs of jobs released within and due by the interval end ≤ interval length. Deadline equality passes. Keep overload injection explicit and outside admitted workload. Live-bench timing includes all measured interference and overhead. Product admission needs substantiated cost, dispatch, IRQ and blocking bounds.

| Selected case | Job triples (r,d,c) in Q units | Hand replay |
|---|---|---|
| EDF | A(0,8,2), B(0,12,8), C(1,4,1) | At 0 EDF chooses A; LLF would choose B (slacks 6 and 4). At 1 C displaces A. Declared-demand EDF completes C at 2, A at 3, B at 11. In the real workload require A live across arrival, actual C completion followed by restoration of A, then B, and each completion by its absolute deadline. |
| Sampled LLF | A(0,8,1), B(0,10,8); separate diagnostic adds C(7,8,3) | Initial LLF slacks 7 and 2 select B; EDF would choose A. Through tick 5 B runs; tie 2/2 retains B. At 6 A has 1 versus B's 2, displaces B without arrival. In nominal model A completes at 7 and B at 9. In the live diagnostic A must finish between grid 6 and 7 so B genuinely resumes before C arrives. At 7 C has −2 and displaces B; verify restoration following C's return. The augmented table is infeasible (3 units due in 1) and normal admission must reject it. Run it only in the named diagnostic mode with the rejection preserved. |

Use bounded CPU loops with visible progress in ordinary entries. Freeze exact loop configuration, ELF, timer/clock mode and all run horizons before independent replay. Choose A's EDF work to survive the first grid and LLF A's work to finish strictly between grids 6 and 7. Require B live and executing at ticks 5, 6 and immediately before 7 in the LLF diagnostic as applicable (at 6 it is the outgoing incumbent). Record actual completion against each deadline, including an early completion if measured. Use a separate finite overrun control of the nominal table that keeps an ordinary worker running past its estimated service and then returns it. Require a recorded estimate-exhaustion indication, positive subsequent owner service and exactly one true completion. Keep overload diagnostic admission, model overrun and actual deadline miss as distinct verdicts.

**Arithmetic and observations.** Model time at an observed event is floor((counter−S)/Q), with same-tick ordering retained. Charge elapsed model ticks once to the actual incumbent; a live job's remaining estimate clamps at 1 until explicit completion as in deadline_policy.rs. Compare EDF deadlines unsigned and LLF slack d−k−remaining in signed i128. Incumbent wins equal keys; among queued equals select earliest enqueued. Verify with replay controls including equal queued competitors, same-tick repeated selection, negative slack and one-count-late completion. Track uncapped modeled consumption separately to detect exhaustion and overrun. Raw owner service is measured in counter counts from dispatch to actual exception entry, separately from scheduling gaps and timestamp uncertainty. Idle and scheduler time receive no worker charge. Record nominal/actual compare, IRQ ID, before/after sample brackets and individual service, queue, ranks, owner, frame/SP and saved/selected ELR. Compare independent exception order and the linked ordinary task's private stack and progress witnesses on preemption and resumption.

Absolute sampling is anchored at S. Each scored timer observation must lie in [S+kQ,S+(k+1)Q); record lateness. Reject skipped grids in scored runs, keep actual incumbent service and never invent intervening decisions. Allow at most one involuntary owner change per grid index; completion/idle dispatches are counted separately and may immediately select a waiting task. For sample indices in (a,b] the maximum involuntary switches is b−a. For an arbitrary physical interval count actual distinct observed grid indices in it, allowing delayed delivery near a neighboring sample; the logical bound alone does not prove minimum physical dwell. Report actual adjacent switch times, minimum observed dwell and observed maximum timer lateness. Retain independent first cold plain and diagnostic observations, including failures, raw counter frequency and capture bounds, queue reconstructions, arithmetic controls and ELF/configuration hashes. These finite schedules supply no measured product WCET or hardware latency guarantee.

## 한국어 동결 기준

단일 QEMU virt Cortex-A72/GICv2/TCG에서 정책과 정적 작업 표(고유 ID, 링크된 Rust 진입점, 릴리스 r, 절대 마감 d, 양의 CPU 추정량 c)를 선택한다. 최대 세 개의 독립 단발 작업은 개별 스택과 정상 복귀 트램펄린을 사용한다. 차단·자체 대기·이주·양보는 없다. 용량 초과·중복·진입점 누락·0 비용·d≤r·그리드 불일치·산술 오버플로는 릴리스 전에 거부한다. Q=주파수/10이 정확히 100 ms여야 한다. 미리 정한 미래 기준 S에서 k번째 절대 시각 S+kQ를 검사 산술로 구한다. 같은 그리드의 도착을 선언 순서로 모두 등록한 뒤 선택하며 명목 릴리스·실제 관측·마감·완료를 남긴다. 기존 두 시험 진입점을 보존한다.

입장 판정은 오버헤드 0인 유한 모델에 한정한다. 선택한 표본 정책·동률 규칙·표 입력으로 CPU 추정량 소진 시 완료를 모의하고 예측 마감 위반을 거부한다. EDF는 릴리스·마감 시각을 양 끝으로 하는 각 구간에서 그 안에 릴리스되어 끝까지 마감인 작업 비용 합이 구간 길이 이하인지도 검사한다. 마감 일치는 통과한다. 제품 수용에는 실행·디스패치·IRQ·차단 상한 근거가 필요하다.

- EDF는 위 표의 A(0,8,2), B(0,12,8), C(1,4,1)를 사용한다. 최초 EDF는 A, 동일 입력의 LLF는 여유 6/4이므로 B이다. 1에서 C가 A를 선점한다. 모델 완료는 C=2,A=3,B=11이다. 실제로 A가 첫 도착까지 진행하고 C 종료 뒤 A의 중단 PC로 복귀하며 뒤이어 B를 선택하고 각 절대 마감을 지켜야 한다.
- LLF 기본 표는 A(0,8,1), B(0,10,8)이다. 여유 7/2로 B를 선택하고 5에서 2/2 동률로 유지, 6에서 1/2로 새 도착 없이 A가 선점한다. 기본 모델은 A=7,B=9에 완료한다. 별도 과부하 진단 C(7,8,3)는 한 단위 내 세 단위가 필요하므로 정상 수용에서 거부한 기록을 유지한다. 진단에서 A가 6과 7 사이에 실제 종료하고 B가 재개된 뒤 7에서 여유 −2인 C가 B를 선점하고 종료 뒤 B를 복원한다.
- 유한 CPU 루프·진행 증거·ELF·클록·종료 한계를 재현 전에 동결한다. 별도 과소 추정 시험에서는 소진 시점, 그 후 양의 실제 실행, 정상 완료 정확히 한 번을 요구한다. 작업별 실제 완료와 마감 비교를 기록하며 과부하 수용 거부·추정량 초과·실제 마감 위반을 각각 판정한다.
- 관측 카운터에서 모델 시각 floor((counter−S)/Q)를 계산한다. 동일 틱 순서를 보존하고 지난 모델 틱은 당시 실행자에게 한 번만 부과한다. 실제 완료까지 잔여 추정량은 최소 1이고 누적 소비는 별도로 제한 없이 추적한다. EDF는 부호 없는 절대 마감, LLF는 signed i128의 d−k−잔량으로 비교한다. 동률은 실행자 유지, 대기자끼리는 먼저 들어온 순서이다. 대기자 동률·같은 틱 재선택·음수 여유·한 카운트 마감 초과를 독립 재생한다. 실제 디스패치부터 예외 진입까지 원시 서비스와 계측 오차·스케줄러 구간을 구별하고 idle·선택 비용을 작업에 부과하지 않는다. 목표와 실제 비교값·IRQ·계측 전후·큐·순위·서비스·프레임/SP·ELR을 남기고 링크된 일반 작업 PC·스택·진행 증거를 독립 대조한다.
- 실제 관측은 [S+kQ,S+(k+1)Q) 안이어야 한다. 누락 그리드는 실패이며 가상 선점을 추가하지 않는다. 그리드당 비자발 선점은 최대 한 번으로 모델 인덱스 (a,b]에서는 b−a 이하이다. 완료·idle 디스패치는 별도이며 즉시 선택할 수 있다. 실제 시간 구간은 그 안에서 관측한 서로 다른 그리드 수로 제한한다. 지연이 있는 물리 시각에서 연속 스위치 간격·최소 실측 간격·최대 관측 지연을 보고한다. 일반·진단 최초 콜드 실행과 실패, 원시 주파수·계측 범위·독립 재구성·해시를 남긴다. 해당 유한 가상 작업 외의 제품 WCET와 실보드 지연은 별도 검증 대상이다.
