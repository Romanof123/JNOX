# Retained native P/Q frames (#233)

The optional retained-v1 profile keeps all 104 words twice for independent byte comparison. Assembly saves the real trap directly into a unique aligned bank entry. It switches SP back to the private stack before calling Rust. The existing observe_trap assignment makes the only runtime copy, into a unique persistent resume entry. Each dispatch returns that exact immutable resume entry or the owner's actual initial entry. Assembly records its actual restore base and establishes the next trap SP before scratch registers are restored. Offline replay compares distinct save and resume storage byte for byte, checks the architectural exception trace, selected pointer, owner history and the final stopped bank. An ERET event corroborates PC and transfer; it cannot independently observe every physical CPU register.

retained-v1 uses two 15-entry trap/resume banks, three initial entries and 15 address witnesses plus an eight-byte cursor. All are bounded by 13 Q windows plus two drains. Existing tags 21/22/23 and timer origins remain. Journal header version 3 identifies elided tags 24/25. Version 2 is unchanged. Phase timestamps may accompany either format. Opening-to-first-user acceptance stays frequency/1000 inclusive. Run the same user image, table, input, clock and probe for each comparison. No acceptance conclusion follows from source changes.

선택형 retained-v1에서는 실제 예외 저장 주소와 복원 주소를 따로 기록한다. 어셈블리가 세대별 전용 공간에 원래 레지스터를 직접 저장하고 Rust 호출 전에 커널 스택을 복구한다. 기존 저장 대입은 독립된 복원 공간으로 한 번만 수행한다. 초기 프레임과 종료 구간을 포함해 오프라인에서 두 공간의 104개 워드와 소유자별 마지막 저장 주소를 대조한다. 최초 사용자 관측의 기준 시각과 1ms 판정, P/Q 입력, 가중 스케줄러 및 기존 디코딩은 유지한다. 성능은 후속 실측 대상으로 둔다.
