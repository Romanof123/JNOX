# Pi 4 directed wake workload and SW v1 export

[한국어](pi4-smp-workload.md) · [CHG-070 plan](pi4-smp.en.md)

Build the dedicated image from kernel/ with `JNOX_BOARD=pi4 JNOX_PROFILE=smp JNOX_APP=directed-wake cargo build --release --locked -j1`, no Cargo benchmark features. Freeze the ELF, linked disassembly/map, raw image and package hashes, firmware and options before launch. Use the plan's four-core raspi4b machine with CPU-indexed exception/return trace, a new process and output directory per cold launch, a 30-second host ceiling and one second of terminal quiet. Retain partial output and failures. Startup, MMU, full-IAR EOI and CPU1 release belong to the BSP. The workload uses private guarded stacks and shared Normal memory. Only CPU0 exports after CPU1's final SVC quiesces it. An unresponsive peer permits a local failure line only.

Roles 0/1/2 are producer on CPU0, background and receiver on CPU1. Initial receiver blocks via SVC 1 before background starts. CPU0 waits for one published background milestone then at least one further chunk of 16, computes and release-publishes the generation and sum, and issues one directed SGI. Only the IRQ can claim blocked→ready. Receiver's own continuation consumes ready→active once, doubles the sum, publishes its acknowledgement and blocks for the next generation or exits. The interrupted background frame is reselected. A generation-stable full chunk after return is required before the next send. After the second such milestone CPU1 executes SVC 2, masks IRQ, publishes quiescence and parks. Worker phases have finite local counter watchdogs; CPU0's final peer-failure wait is also bounded. Watchdogs are harness limits.

**Serial schema.** ASCII decimal, LF. HEADER has version, per-core capacity (32) and actual frame size. STACK has role, low, exclusive high and guard status. CORE has CPU index, reserved count, drops, workload failure code, eight boot and eight GIC words. Boot words are MPIDR, entry EL, current EL, TTBR0, TCR, MAIR, SCTLR and CPUECTLR (use BSP encoding). GIC words are TYPER, local ITARGETSR, IGROUPR0, distributor CTLR, CPU CTLR, PMR, SGI priority and ISENABLER0. ROW has CPU, local committed sequence (starts at 1), kind, generation, local CNTPCT tick and five unsigned operands. Unused trailing operands are zero. END has guest protocol success, final acknowledged generation, last result and last background count. This footer alone does not qualify a capture.

| Kind | Operands in wire order |
|---|---|
| 1 | raw MPIDR, raw CurrentEL, CNTFRQ, local counter sample, frame bytes |
| 2, 8, 10, 12, 14, 15 | role, frame address, ELR, interrupted/selected SP above frame, published background count. Respectively initial selection, IRQ save, IRQ selection, receiver SVC save, background selection, final background SVC save. |
| 3 | executing role, inline probe PC, actual SP, value, raw MPIDR. Producer value is sum, receiver value is doubled result (zero at initial entry), background value counts increments. |
| 4 | sum, earlier progress, later progress, 0, 0 (mailbox published before SGIR) |
| 5 | local before/after send-call ticks, actual SGIR word, discovered target bit mask, sum |
| 6, 7 | sum, doubled value, 0, 0, 0 (producer acknowledgement observation or receiver consumption) |
| 9 | full IAR, source CPU-interface ID, mailbox sum, blocked state, ready state |
| 11 | original IAR after BSP EOI/barrier, selected role, 0, 0, 0 |
| 13 | SVC immediate 1, new state (4g), 0, 0, 0; g=3 denotes receiver exit |

**Independent score.** Per-core order is authoritative; use generation and release/acquire handshakes across cores. Check both affinities, identity, non-overlapping ELF stacks, guards, exactly contiguous committed rows and zero drops. Verify each SGIR targets CPU1 only (Group 1, ID 1), and each IAR signals ID 1 from the discovered CPU0 GIC interface; match each EOI to that entire IAR. BSP's GIC-interface ID may differ from MPIDR Aff0. Require one blocked→ready claim, one receiver work sample and one acknowledgement per generation, with 136→272 then 392→784. Match each IRQ ELR to the linked background loop and CPU-tagged exception trace. Check the selected receiver frame against its earlier SVC save and the reselected background frame/PC/SP against its IRQ save. Require in-context receiver and resumed background samples on the right stacks, linked probe sites and strictly advancing progress. The SVC 1 row for g=3 is exit; the final SVC 2 never returns. Missing/out-of-order records, bad state/stack/affinity, incomplete timeout and unsolicited IRQ fail even with correct totals. Decode times on each CPU at its own frequency; SGIR-call brackets include software overhead. A cross-core latency requires separate common-epoch or bounded-offset evidence. No capture or board result accompanies this source.
