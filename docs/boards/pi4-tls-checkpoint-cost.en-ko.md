세 순번 모두 CPU0의 실제 IRQ와 동일 PC 복귀가 확인됐다. 표의 인덱스와 합은 새 리스에서 처음 기록한 체크포인트 값이다. 전역은 검증 함수가 반환한 포인터를 스택에서 다시 읽었고, 클러스터는 검증 함수 진입부에서 복귀했다. 파티션은 산술 함수에서 막 돌아와 다음 체크포인트의 인수를 읽던 중이었다. 세 경우 모두 4,096회 체크포인트, 위 다이제스트 및 최종 합을 달성했다. #279의 엄격한 루프 판정은 짧은 작업 3/6, 스트림 6/6이다. #204의 종료 저널 개선 때 짧은 작업 여섯 개가 모두 먼저 끝난 기록도 보존한다.

## Accessor and failure semantics / 접근 함수 및 실패 처리

Change the word-only consumers in `kernel/src/pi4_migration_local.rs`. Prefer a scalar checked-word result for digest update and final digest read. Specialize the known M identity only if needed to remove the return buffer in linked code. Keep a shared identity check where feasible. On every access read both live TPIDR_EL0 and TPIDRRO_EL0, compare to the expected activation's exact permanent object and immutable token, and take the existing failure path (0x34) before dereferencing on either mismatch. Retain invalid activation handling (0x33). At each sparse observation sample and validate the actual register values afresh and publish both observed values. Preserve M, P0, opening P1 and replacement P1, their distinct objects/tokens, initial state and exclusive lease. The existing relaxed atomic digest load, rotate-left seven, XOR with index, wrapping sum addition and relaxed store stay in checkpoint order. The terminal SVC reads that same word.

Keep all generation acquires, arithmetic/prefix checks, checkpoint counts, sparse sampling and publication order, milestone release, CPU-local lease checks, frame/SGI handling, timers, clocks, interrupt masking and workload limits. Keep the named short and CRC loops, X21 binding, and existing linked-body eligibility rule. Exclude timing changes, added delays, artificial work, deferred checks and changes to M's arithmetic.

다이제스트 갱신과 최종 읽기는 검증된 단일 워드 참조만 받는다. 링크 결과에 필요할 때만 M의 고정 활성화를 특수화한다. 매 접근에서 실제 두 레지스터를 읽고 해당 활성화의 정확한 정적 객체 주소와 토큰을 모두 검사한다. 불일치 시 역참조 전에 기존 0x34, 잘못된 활성화는 0x33으로 처리한다. 희소 기록에서는 두 값을 그 자리에서 다시 읽어 검증한 관측값을 공개한다. 네 활성화의 독립 상태와 리스, relaxed 원자적 읽기·7비트 회전·인덱스 XOR·합의 순환 덧셈·저장 및 종료 SVC를 유지한다. 세대 acquire, 접두값 검증, 기록 횟수와 공개 순서, 마일스톤 release, CPU·프레임·SGI, 마스크·시계·작업량과 X21을 보존한다. 산술 루프 인라인화·범위 확대, 인위적 지연 및 계측 이연은 제외한다.

## Linked comparison / 링크된 명령 비교

Before examining candidate output, freeze the comparison endpoints and inputs. For each of the three policies and both workloads build paired release images from the actual integration parent and that same tree plus the isolated accessor change, using identical compiler, target, configuration, features, linker and commands. If #281 lands first, both sides must include that exact accepted handoff implementation. Otherwise keep #281 outside this pair. Repeat the pair and behavioral gates on the actual integration tree if it changes. Record source trees/diff, tool versions, commands, ELF/raw SHA-256, symbol maps and full disassembly. Extract loaded instruction bytes from the ELF and independently match them to the raw image. Publish the original #279 provenance separately.

For each pair trace from M's linked task entry through one ordinary interior block on an established lease (for example the third block, stable generation, no sparse row), from the before-block acquire through the checkpoint and back to the next iteration. Select the path from source-defined inputs and actual branch conditions. Count executed instructions on this path including callees, calls/returns and stack reads/writes. Show addresses, opcodes, both register checks and digest load/store data flow. Report residual activation dispatch, any new spills/branches and differences in short/stream or policy code. Report symbol sizes for M, checkpoint and all affected helpers (mark inlined/merged bodies), whole .text bytes and raw image bytes for each pair. Prove the three-word indirect result stores and the caller's corresponding pointer reload disappear on M's common checkpoint in every targeted image. Moving them into another callee fails this criterion. Report net path cost even if it increases. A missing baseline pattern or ambiguous mapping leaves the claimed reduction unestablished. Static instruction counts and image sizes support only machine-code claims.

후보 결과를 열기 전에 세 정책·두 작업 각각의 비교 입력과 경계를 고정한다. 실제 통합 부모와 여기에 접근 함수 변경만 적용한 트리를 같은 도구·옵션으로 짝지어 빌드한다. #281이 먼저 통합되면 두 쪽 모두 같은 버전을 포함한다. 통합 소스가 달라지면 비교와 동작 검증을 다시 한다. 원본 #279는 따로 식별한다. 트리·도구·명령·ELF와 이미지 해시·심볼·전체 역어셈블을 보존하고 ELF 명령 바이트를 이미지와 독립 대조한다. 안정 리스에서 희소 기록이 없는 내부 블록을 입력 조건으로 선정하고, 시작 acquire부터 체크포인트를 거쳐 다음 반복까지 호출 내부를 포함한 실행 명령·호출·반환·스택 접근을 센다. 두 레지스터 검사, 다이제스트 흐름, 잔존 분기·스필, 관련 함수 크기와 전체 .text·이미지 바이트를 공개한다. 모든 대상에서 세 워드 반환 버퍼와 호출자의 포인터 재로드 제거가 확인되어야 한다. 비용 증가나 기준 패턴 부재도 그대로 기록한다.
