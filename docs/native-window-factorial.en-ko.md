For its four consecutive cold starts use row (r+s) mod 4 of [ABDC, BCAD, CDBA, DACB], reading left to right. Position is 16r+4b+j+1 for zero-based j. Freeze all 80 position IDs before launch. Each stratum has five local four-cell blocks. The fifth repeats a row; disclose the imbalance. Do not pool clocks or tables.

## Primary endpoint and independent checks / 주 평가와 독립 검증

At 62.5 MHz the observed opening-to-first-user interval must be <=62,500 ticks for **every** ordinary window. Signed margin = 62,500 minus (first user tick minus nominal opening). Score all 10 P and 13 Q windows including Q extension, separately verify two bounded exit drains 41 and 42 per boot. Expected 920 windows and 160 exits across 80 boots. Report scheduled, captured, structurally valid, missing, failed-boot and missed-window denominators, including per-cell/per-clock/per-table counts. Any missing evidence is unverified and prevents a pass for that boot/cell; a timing miss remains a miss even with structural success. Present all margins, generation 2 and later extrema, raw paired results and order.

Use ordinary replay stamps only. For generations >=2 record opening to prior closing IRQ entry, prior entry to current selection, selection to return sample, return sample to first user read, and their sum. The entry closing the current generation belongs to the next transition. Generation 1 has no prior IRQ; mark the two IRQ components unavailable, retain opening/selection/return/user stamps. First-user read and return sample bracket execution; no exact instruction crossing. No estimated observer subtraction. Within a complete round/table/clock/generation compare y = opening-to-user ticks: B-A and D-C (cursor), C-A and D-B (retention), (D-C)-(B-A) (interaction). Report each same-block contrast and missing operands; no cross-clock differences or substitution of historical controls. Default variation and five blocks limit generalization.

Independent verification consumes frozen source, linked ELFs, package manifest, UART, RAM, interrupt/ERET trace and immutable position sheet. Reconstruct ownership, release/readiness, same-PID Q selections, absolute compare, isolation, worker progress and both exits. In ABI v2 decode record 25 saved words and record 24 restored words, comparing each selected owner's entire 104-word value to its own previous save or specified initial frame. In ABI v3 verify trap/sequence addresses, compare the raw 832-byte trap and resume slots at interruption, compare actual restore operand and all restored words with the selected owner's prior save/initial frame, validate final backing RAM. Verify trace against return PC. Compare across kernels by generation, owner and invariants; differing timer ticks, PCs or dynamic register contents need no byte equality across boots. Publish independent per-boot structural and timing statuses even when replay exits nonzero. No hardware, WCET, host-cause, overall release or aggregate scheduling acceptance claim follows.

## 한국어 실행 약속

#238 안정판을 부모로 고정하고 #251의 커서 구현을 그대로 선택할 수 있게 한다. A는 기존 탐색·복사, B는 커서·복사, C는 기존 탐색·프레임 보존, D는 커서·프레임 보존이다. P/Q별 네 패키지 모두 위상 계측을 끈다. 실제 ELF에서 선택 경로와 벡터를 확인하고 사용자 ELF와 프로브 해시를 맞춘다.

위 식으로 실행 전 80개 위치를 확정하고 단일 레인에서 한 번씩 콜드 부팅한다. 각 표·클록에서 같은 라운드 네 결과만 짝지어 비교한다. 다섯 번째 순서의 반복을 표시한다. 빌드 실패, 미실행, 시간 초과, 누락, 구조 실패, 마감 초과를 최초 위치와 원본 자료에 연결해 외부 검증표에도 모두 공개한다. 후속 성공으로 대체하지 않는다.

원래 한도는 모든 일반 창에서 62,500틱이다. P 10개와 Q 확장 포함 13개, 각 부팅의 종료 41·42를 검증한다. 2세대부터 직전 IRQ 진입, 현재 선택, 반환 표본, 사용자 최초 관측까지 나누고 첫 세대의 없는 IRQ 값은 비워 둔다. 각 ABI 방식으로 동일 부팅의 소유자별 104워드 전체를 복원 검증한다. 두 클록을 별도로 보고하며, 마감·구조·누락을 구별하고 실제 하드웨어 보장이나 릴리스 전체 판정으로 확대하지 않는다.
