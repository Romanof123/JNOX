Use main as first parent and merge the feature. For trace/links.csv preserve main's deduplicated graph and add each feature-only CHG-088 affects edge to REQ-002, 005, 008, 014, 020 and 023 once. Compare parsed triples to that expected union. Run `python3 tools/scheduling_evidence.py` and retain its output. Review all other conflict resolutions against both parents, including frozen limits, capture strictness and historical receipts. 병합 부모·트리·충돌 해소 차이를 기록하고 중복 없는 본선 그래프에 기능 브랜치의 실제 간선 여섯 개를 반영한다.

2. **Binary comparison / 바이너리 대조.** Pin the unchanged #183 guest af952e34cea8fbe0aef5c7b4cb1f945a2884fff5 and the actual merged candidate. Rebuild actual main and candidate selectors affected by the merge using their original release recipes. Include all five historical EL1 selectors with the per-selector environment and Cargo arguments in [#183 compatibility](evidence/weighted-el1-compat-183.json). For every genuinely changed loaded main profile freeze its original boot, decoder, clock, criteria and position before launch. 비교 기준 세 가지는 원본 보관본, 동일 도구로 재빌드한 #183, 실제 병합 후보다. 본선과 적재 내용이 달라진 구성마다 기존 시험을 별도로 등록한다.

Never substitute a later launch. 최초 순서와 허용값을 고정하고 부분 기록·실패·미실행을 각각 표시한다.
