# Native applications under a bounded scheduling extension / 제한형 스케줄링 확장과 네이티브 앱

Prospective engineering deployment for [#21](https://github.com/Romanof123/JNOX/issues/21) POL-018 and [#1](https://github.com/Romanof123/JNOX/issues/1), based on main `6a86dac`. An operator packages private EL0 programs and a data-only nomination rule for CPU0. The independently reserved program has its own protected windows. The original [linked jobs #221/#223](extension-normal-jobs.md), [stalled-evaluator controls](m4-bounded-extension.en.md) and [release case](scheduling-release-cases.en.md) retain their original evidence and criteria.

CPU0용 독립 EL0 앱과 후보 추천 규칙을 운영자가 패키징한다. 예약 앱의 실행 구간은 커널이 보호한다. 이 문서는 가상 플랫폼에서 수행할 배포 설계이며 기존 연결 작업, 평가기 정지 실험과 제품 출시 기준의 판정을 유지한다.

## Package contract / 패키지 계약

```sh
python3 tools/build_native_el0.py --out ext-three --policy extension \
  --elf voltage.elf --peer-elf temperature.elf --peer-elf alarms.elf \
  --extension-program rule.txt
```

Require three native ELF slots in this order. Slot 0 is reserved, slots 1 and 2 delegated. Pin all to CPU0, generation respectively 7, 11, 17 for this immutable package lifetime. Publish the ordered ELF digests, argv, generation map, canonical operation list and digest in the manifest. One UTF-8 file contains one instruction per line with ASCII tokens separated by whitespace. Ignore blank lines. Labels are zero-based instruction numbers. The complete language is `ready ID YES NO`, `jump TARGET`, `propose ID GENERATION CPU TICKS`, and `yield`. Integers are unsigned ASCII decimal. Task proposal IDs fit u32, generation and ticks u64, CPU and instruction operands u8. Validate 1..16 operations, all targets including unreachable ones in range, and ready-test IDs 0..2. A representable nomination is data for the trusted gate, including an ineligible CPU or stale generation. Reject unknown tokens, extra operands, overflow, missing peers, mixed policy settings and program options outside this mode before boot. Raw build configuration must enforce the same typed constraints, emit immutable Rust operations and bind the manifest to the data actually compiled. No supplied instruction can address memory or call native code. Existing ELF RX/W^X, private stack/argv, MMU root and syscall validation apply unchanged.

세 ELF는 예약 0번과 위임 1·2번이며 모두 CPU0에 고정한다. 패키지 수명 동안 세대는 각각 7·11·17이다. 매니페스트에 슬롯 순서대로 ELF 해시·argv·세대와 정규화한 명령열·해시를 남긴다. 위 네 명령을 줄마다 하나씩 적으며 빈 줄을 제외한 0부터의 명령 번호로 분기한다. 부호 없는 십진 ASCII 인자, 명령 수 1~16, 도달 불가 분기를 포함한 목적지와 ready ID를 CLI와 원시 빌드 양쪽에서 검사한다. 표현 가능한 오래된 세대나 CPU 요청의 거절 여부는 신뢰 게이트가 결정한다. 형식 오류·잘못된 조합은 부팅 전에 거부한다. 확장 데이터에는 주소 접근이나 코드 실행 권한이 없고 앱에는 기존 ELF 보호·전용 스택과 주소 공간을 적용한다.

## Counter and dispatch / 카운터와 디스패치

Use the existing Extension::decide, interpreter and group gate. On the named single-core virt Cortex-A72, default-clock QEMU, 128 MiB, take F from CNTFRQ, Q=floor(F/10), and establish one checked future epoch after mappings and timer setup. Q must support positive ordered quarter and half thresholds. Cell k starts at S=epoch+kQ. Reservation is exactly k mod 3 = 2; fuel is five fetched instructions, maximum grant one cell, watchdog two cells inclusive. These numerical settings come from the existing [bounded reference](m4-bounded-extension.en.md). Admit all live slots at the epoch. At each delegated boundary snapshot genuine readiness, identities, affinity and remaining grant. Evaluate a copy on the interruptible private EL1 evaluator stack. Only a completed matching-cell reply published strictly before S+floor(Q/4) can commit the copy and advance its heartbeat. At that compare PPI30 takes the reply or cancels the transaction; late results cannot mutate the next cell. With an absent reply use unchanged trusted state and last observed heartbeat for bounded fallback, never execute an unchecked nomination. Preserve distinction between a missed publication and inclusive watchdog expiry since last progress. Each reserved boundary bypasses evaluation, heartbeat publication and delegated fallback.

Fallback selects the lowest eligible delegate on CPU0. If the relevant set is empty use real EL1 idle. A sleeping or exited reserved slot leaves its window idle. Use actual normal sleep targets and signed exits, and preserve the full process frame and private root. A future sleep, yield or exit surrenders the remaining grant until the next cell; no new grant inside that cell. A wake makes a slot eligible at the next matching opening, including equality when due at that opening. An ordinary nonblocking syscall may continue the current grant only while it is still valid at the return decision. Arm the earliest outstanding evaluation, service or wake compare. Service ends at S+Q. On a late entry classify the actual counter cell, discard obsolete grants and replies and record skipped boundaries; never debit or attest execution of a missed cell. Stop when all processes exit, cancel the timer and pending evaluator transaction. Idle while live sleepers remain. Counter calculations and source/return frame ownership must be checked before programming or restoring.

기존 인터프리터와 게이트를 사용한다. 미래의 공통 epoch, 실제 F와 Q=floor(F/10), 예약 k mod 3=2, 연료 5, 최대 한 셀, 마지막 진전 후 두 셀째부터 watchdog 만료라는 기존 수치를 적용한다. 위임 경계에서 실제 상태를 복사해 인터럽트 가능한 별도 EL1 스택에서 평가한다. S+floor(Q/4) 전에 게시한 해당 셀의 완성 응답만 상태와 하트비트를 갱신한다. PPI30에서 미게시 거래를 취소하고 기존 상태로 폴백하며, 늦은 응답과 watchdog 만료를 구별한다. 예약 경계는 평가를 건너뛴다. 폴백은 적격 위임 ID 중 최솟값을 고른다. 예약 앱이 없거나 적격 집합이 비면 실제 유휴 문맥을 실행한다. 미래 수면·양보·종료 시 셀 잔여분은 유휴이며 깨어난 앱은 시각이 일치하는 경우를 포함해 다음 적격 경계에서 경쟁한다. 일반 호출도 복귀 직전 경계를 확인한다. 타이머는 평가·서비스·깨움 중 가장 이른 비교값에 맞춘다. 지연 시 지난 구간은 기록하고 허위 서비스 없이 현재 셀로 진행한다. 프레임과 주소 공간을 복원하고 전원 종료 시 비교기와 평가 거래를 취소한다.

## Frozen runs / 사전 고정 실행

Use ordinary SDK ELFs with private result variables and signed exit statuses. Voltage sums two independent batches [3300,3296] and [3304], yielding between batches; expected cumulative values 6596, 9900, exit 30. Temperature sums [18,23,21] one reading per invocation of its loop body, yielding between readings; expect 18,41,62 and exit 31. Alarms scans the byte ramp 0..255 for values >=240, 4096 complete ramps per batch for three batches. Yield between batches, expect 65536,131072,196608 and exit 32. Use C for voltage and alarms and a separately linked Rust temperature app. Each computes and stores its own result before the yield or final exit. All start ready. No interprocess mailbox or application-specific kernel callback is required.

| Package program (semicolon here denotes a new line) | Expected delegated decision while both ready |
|---|---|
| ready 2 1 2; propose 2 17 0 1; yield | Accepted 2 in two steps; after 2 exits, yielded fallback to 1 in two steps |
| propose 2 16 0 1 | Stale generation rejected in one step, fallback 1 |
| propose 2 17 1 1 | CPU outside mask rejected in one step, fallback 1 |
| jump 0 | Fuel exhausted at five steps, fallback 1 |

Same three ELF digests and products in all four packages. For the named finite inputs expect each batch to finish within a grant; record any overrun as a failed prediction. In the accepted-nomination run expected owners for cells 0..7 are 2,2,0,2,1,0,1,1. For each other run expect 1,1,0,1,2,0,2,2. Separately keep a delegate live for a fourth batch via normal argv (alarms four batches, final 262144), on the same accepted program. Reserved owner has exited by cell 8: require real idle throughout cell 8 while the last delegate remains live and finishes in cell 9. For a sleep control, select an ordinary reserved-app argv mode that requests an absolute monotonic sleep 400 ms into its future after its first batch. At its next reserved opening it must still sleep; score subsequent eligibility against the actual requested target, preserving the same two results. Malformed branch destinations and a fourth ELF must fail packaging. Preserve original stalled-heartbeat evidence; do not force a late IRQ or splice an old stall into a new first run.

세 프로그램은 각각 전용 결과를 기록한다. 전압 앱의 누적값은 6596·9900(종료 30), 온도는 18·41·62(31), 경보는 65536·131072·196608(32)이다. 배치 사이에 일반 SDK 양보를 사용한다. 위 표의 정상 추천·오래된 세대·잘못된 CPU·연료 소진 네 패키지에서 동일 ELF와 전체 결과를 판정한다. 셀 0~7 소유자 예측과 실제 완료를 비교하고 한 승인 안에 끝나지 않은 배치는 예측 실패로 남긴다. 추가 네 번째 경보 배치에서는 예약 앱 종료 후 셀 8 전체가 유휴이고 마지막 위임 작업이 셀 9에서 끝나야 한다. 예약 앱의 별도 인자 모드에서는 첫 배치 후 실제 절대시각으로 400ms 수면하고 다음 예약 경계를 비운 뒤 실제 목표시각에 따라 재개한다. 범위를 벗어난 분기와 네 번째 ELF는 거부한다. 타이머 지연을 주입하지 않는다.

## Evidence and authority / 증거와 승인 범위

Freeze source/package/QEMU identity, hashes, argv, decoded program and counter settings before independent plain and fresh externally traced boots. For each serviced cell compare observed evaluation deadline/IRQ, reply or cancellation, fuel/heartbeat, gate operands/reason, grant, actual selected EL0 first instruction (or actual idle landing), counter and PPI30 cutoff. Require selected first work before S+floor(Q/2), and for each operational end compare service IRQ in [S+Q,S+Q+floor(Q/4)); early surrender still has a real idle tail. Record timer cancel on terminal exit separately. Correlate actual task PC/SP/root, saved/returned continuation, private progress/results and signed exit with the frozen ELF. A UART nomination or pre-ERET sample alone cannot establish first work. Keep first failures, trace loss and unobserved paths explicit. The package, thresholds and outputs qualify only the named virtual deployment after observation. Product authority still supplies adopted rules, protected workloads and arrival envelope, acceptable detection/fallback limits and useful progress, target hardware, hazard analysis and release approval.

최초 일반 부팅과 독립 외부 추적 부팅 전에 패키지·ELF·QEMU·규칙과 시계를 고정한다. 각 셀의 실제 평가 IRQ·게시/취소·연료·하트비트·게이트·승인과 EL0 첫 실행 또는 유휴 진입을 비교한다. 첫 작업은 S+floor(Q/2) 전, 서비스 종료 IRQ는 [S+Q,S+Q+floor(Q/4))이며 마지막 종료에 의한 취소는 별도로 기록한다. PC/SP/루트와 복원 문맥, 앱별 전체 결과·종료값을 독립 대조한다. 최초 실패·추적 손실·미관측 경로를 남긴다. 제품 규칙과 부하, 허용 시간·진전, 물리 보드, 위험 분석과 출시는 해당 제품 책임자가 결정한다.
