# First native AArch64 process · Startup and exit

[한국어](native-el0-startup.md) · CHG-087 · #8 · REQ-001/014/020 · Prospective engineering case

One independently linked static C executable crosses from a privileged virt kernel into AArch64 EL0 on a single Cortex-A72. Its C startup reads the initial user stack, calls main and submits main's return value to the native exit service. This profile carries one original computation. The read-only filesystem, successful standard-stream writes, parent wait/reap, general process creation and IPC remain open. #21 gates IPC implementation in #24. [Native C acceptance](posix-profile.en.md) · [Filesystem plan](filesystem-plan.en.md)

**Image and execution.** Select virt, native, startup-probe and zero benchmark features. Build `examples/portability/native_startup_probe.c` with the unchanged CHG-086 SDK startup, wrappers and linker. Package the exact SHA-256 of this ELF. Validate the native v1 allocated ABI note in the read-only segment against the selected personality and use the CHG-085 load plan. Copy only file bytes and zero remaining pages, including BSS. Map disjoint user RX, RO, RW in [0x00400000,0x00800000) and an NX user stack in [0x01001000,0x01011000) with adjacent guards. Kernel, page tables, backing aliases, UART and GIC are privileged. Freeze a 128 MiB, one-vCPU virt GICv2 configuration. Its timer/GIC are quiescent for this bootstrap; existing scheduler profiles own their IRQ paths.

**Initial stack and result.** At SP=0x01010fb0, 16-byte aligned, place argc=3 followed by pointers to `/bin/native_startup_probe`, `8`, `13`, then two zero words. The first zero terminates argv. The strings start at SP+48, SP+74 and SP+76; the final byte pads the 80-byte tail. SDK startup consumes argc and argv. The C program checks its arguments, initialized writable bias 8 and two initially zero writable totals. Read coefficients 2 and 1 from read-only data and parse the two decimal arguments. Preserve 16 and 13 in the totals and add the initialized bias, yielding 37. The program attempts `write(1,"37\n",3)` and requires libc return −1 / errno 38. Its function result reaches the SDK exit SVC. This boot implements exit alone. Native non-exit IDs return raw −38; an unsupported write emits zero application stdout bytes. Privileged UART reports the actual process status.

**Independent verdict.** Freeze source commit, build flags, compiler/linker versions, exact input and kernel ELFs and hashes, disassemblies, symbols and command line. On the first cold launch preserve UART, exact QEMU configuration/version, same-process exception trace and stopped memory on either terminal outcome. Reconstruct (1) ELF identity, loaded segments, stage-1 permissions/attributes and initial stack, (2) EL1 to EL0t ERET to the exact SDK entry, (3) the real write SVC with x8=4 and its user pointer, length and payload, raw −38 and return to its saved user PC, and (4) exit SVC with x8=1, actual x0=37 and no further user return. Require ESR_EL1.EC=0x15 and immediate 0x4a01, VBAR_EL1+0x400 lower-AArch64 synchronous slot, actual handler CurrentEL=4 (EL1) and SPSR_EL1.M=0 (EL0t) on both entries. Check final C symbols and retained stack arguments independently. Record failed or ambiguous observations. The per-profile result covers entry, memory and exit only. [Arm exception model](https://developer.arm.com/-/media/Arm%20Developer%20Community/PDF/Learn%20the%20Architecture/Exception%20model.pdf) · [Verification plan](verification-plan.en.md)

The exported `jnox_native_el0_image` holds the complete native ELF. The little-endian `jnox_native_el0_journal` starts with 16 u64 words: version, state (1 prepared, 2 entering, 3 exited, 4 failed), failure code, image length, entry, initial SP, stack base/top, committed events, raw signed exit, status-valid bit, stdout byte count, setup CurrentEL, SCTLR_EL1, TTBR0_EL1, argc. Next come eight available rows of 16 u64 words: index, vector offset, CurrentEL, ESR, SPSR, ELR, SP_EL0, x8, x0, x1, x2, raw result (zero on exit), disposition (1 return, 2 exit), VBAR, TTBR0, FAR. Read only committed rows. Interpret FAR only for exceptions where the architecture defines it. The diagnosed status remains visible even if it differs from 37.

After dependencies are integrated, on Linux or WSL run `python3 tools/build_native_el0.py --out NEW_DIRECTORY` for a fresh package. The C migration pilot still requires real file service and stdout/stderr under the target libc; the unchanged Linux ELF and native Rust SDK retain separate acceptance.
