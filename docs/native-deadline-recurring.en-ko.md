# Native deadline jobs and a recurring service ELF / 네이티브 마감 작업과 반복 서비스 ELF

[#319](https://github.com/Romanof123/JNOX/issues/319) · CHG-128 · POL-005. Prospective baseline a9144773d08bded0e0346c134a288732b37bf7a4. One operator-selected service receives the processor at designated cells while two independent compute jobs use remaining supply under EDF or sampled LLF. Target for the acceptance workload is one Cortex-A72 QEMU virt CPU, GICv2, 128 MiB and default clock. Product loads and board timing remain with [#21](https://github.com/Romanof123/JNOX/issues/21). [Native LLF evidence](evidence/evd-121.en.md) · [Linked recurring predecessor](deadline-recurring-plan.en-ko.md)

## Operator interface / 실행 인터페이스

Build ordinary independent ELF files with the native SDK. Supply the service ELF and an increasing comma-separated list of distinct reserved cell indices, together with an explicit positive integer switch ceiling. Example using POLICY=edf or llf:

~~~sh
python3 tools/build_native_el0.py --out run-POLICY --policy POLICY --elf checksum.elf --job 0,12,1 --peer-elf histogram.elf --peer-job 0,13,4 --deadline-service-elf service.elf --deadline-service-cells 1,3 --deadline-switch-cap 6
~~~

These three options are required together for this mode. Accept any nonempty ordered subset of 0..15, including adjacent cells, with the existing two ordinary one-shot job tuples; validate demand against remaining supply. Require the ordinary ELF loader, process isolation and SDK startup for the service (slot 2, no deadline tuple). Reject field overflow, missing/duplicate/unsorted/out-of-range cells, extra peer/third job or incompatible profiles at both package and raw build interfaces. Retain normal EDF/LLF when all three options are absent. Emit the service hash, selected cells, cap, policy and tuples in manifest and boot evidence. Never identify or dispatch a workload by its sample ELF name or expected arithmetic answer.

운영자가 지정한 독립 ELF와 0~15 중 예약할 칸 목록을 받아 커널에서 기존 로더로 세 번째 주소 공간에 적재한다. 예약되지 않은 칸은 두 일반 작업이 공유한다. 예제 이외의 서비스와 달력에도 같은 규칙을 적용한다.

## Service ABI and calendar / 서비스 호출과 시간표

Use existing checked Q=CNTFRQ/10 (100 ms), future epoch S and 16 cells [S+kQ,S+(k+1)Q). Pass the canonical comma-separated calendar string as service argv[1] using the native startup ABI, without requiring any clock syscall. Service enters main once at its first activation, ordinal zero. Provide a public C SDK call jnox_deadline_service_wait_next() returning the zero-based ordinal of the next activation when actually resumed. Choose and publish a collision-free SVC number and signature in the SDK. Only the current service may call this operation, once per nonfinal activation. It parks the full frame, changes the owner to idle, retains the remainder of the reserved cell, and resumes after the call only at the next configured activation. Final activation exits via ordinary process exit, then idle owns any remaining reserved time. Boundary processing must continue until both jobs exited, all service activations completed and the final reserved cell ended. Never restart the service image between activations. Include an actual idle owner and an armed absolute comparator while waiting.

Each activation requires a timely wait or final exit strictly before its scheduled end. Enforce one such transition per activation. A premature service exit, final wait, unexpected syscall, fault, panic, unrelated interrupt, deadline arithmetic error, skipped mandatory sample or overrun invalidates the scored position. An ABI/mode violation must stop before another owner-changing return. Distinguish prelaunch admission from runtime failure. No service work, output generation or expected-value comparison belongs in the kernel. At a due grid IRQ compute the delivered cell once, account actual ownership, program the next strictly future absolute grid, and permit at most one changing IRQ return per observed cell. Never fabricate a missed service dispatch or receipt. Check both the selection and actual return timestamp against the claimed cell; a return crossing a cell before user execution invalidates timing. No catch-up sequence. Re-evaluate EDF or signed LLF on job-supplied cells using existing tie rules. Charge modeled work only to the incumbent in eligible cells; record actual counter occupancy and handler gaps separately.

서비스는 최초 한 번만 main으로 진입하며 argv[1]의 달력을 읽는다. 중간 활성화에서는 공개 SDK 대기로 다음 순번을 받고 마지막에는 정상 종료한다. 일찍 끝난 예약 칸은 유휴로 유지한다. 각 경계에서 실제 관측 칸과 복귀 시각을 기록하며 누락된 실행을 소급하지 않는다. 실제 서비스의 계산과 결과 저장은 독립 ELF에서 수행한다.

## Admission and switch-frequency accounting / 수용과 전환 빈도

Subtract reserved cells in every release/deadline interval and independently simulate the selected policy on residual supply. Check absolute endpoints before the first operational timer arm or EL0 restore. Model completion at a deadline is acceptable; measure actual exit separately. In this restricted recurring profile both regular jobs may only compute then exit once; the service may perform one wait/exit per activation. Constrain the syscall dispatcher accordingly. Other modes retain their existing syscall semantics.

Count each handled exception returning to a different owner (idle, A, B or service), including the first IRQ return from idle and a wait/exit return to idle. Same-frame/same-owner returns add zero. A terminal park adds zero. Timestamp transitions consistently at the common entry-handling sample; also record actual arm, sample and return brackets, so this entry-indexed bound is distinguishable from user service and physical switch latency. On successful paths any half-open Q-tick interval intersects at most two grid cells. Each can contribute one owner-changing timer entry and, if reserved, at most one service wait/exit entry. The two compute-job exits add at most two more. Thus 2+2+2=6 is a conservative universal admission bound over supported calendars. It need not be tight for an individual calendar. Cap 5 is refused even if an observed run peaks lower. Enforce the per-cell premises at runtime. A wait/exit sampled outside its activation fails before owner change; an early or duplicate IRQ cannot add another change. Record every IRQ and SVC, including nonchanging and nonreturning ones, with timestamps, source owner, action, target and saved/restored ELR/SP. Independently replay all sliding windows, including exact-Q boundary exclusions.

한 Q 너비의 이동 창에는 최대 두 격자 칸이 포함된다(일부만 겹치는 칸 포함). 칸당 타이머 전환 1회와 서비스 대기 또는 종료 전환 1회까지, 일반 작업 둘의 종료까지 합하면 보수적 상한은 6이다. 동일 소유자 복귀·최종 정지와 유휴로 실제 전환한 경우를 구별한다. 이 수치는 예외 처리 표본 기준이며 물리 스위치 지연과 구별해 보고한다.

## Frozen jobs and first positions / 고정 작업과 최초 실행

A is examples/native-llf/checksum.c. Expect 16 private blocks, sum 8,355,840 and exit 17. B is examples/native-weighted-rust/Cargo.toml built without extended-input. Expect private progress 67,108,864, nine bins equal to 262,144 times (1,8,28,56,70,56,28,8,1) and exit 197. Both compute without syscalls until exit. EDF initially selects A, LLF initially selects B for the example calendar. Check both actual exit deadlines.

Use a separately built ordinary C service example. It parses the calendar using startup arguments, processes one privately stored 64-element array per activation and publishes its ordinal, scheduled cell, input range, count and sum of squares in process-private memory. Activation i processes 64i+1 through 64i+64 inclusive. Read the actual input in an inspectable reducer, wait after each nonfinal publication, verify the returned ordinal, and exit 41 after the final publication. The two sample receipts are 89,440 and 617,824. Alternate cell positions change the service-reported indices without rebuilding any application. Independently verify outputs and inspect the EL0 service PC/SP, private mapping and real wait/exit entry. For at least one service activation in each nominal run require a live regular job interrupted, restored at its saved PC/SP and showing subsequent productive progress to completion. Do not infer an external observation for a plain run.

Independently reconstruct selection, full-cell reservation, exit/wait order, counter windows and private outputs. Record separately the outcomes of ordinary EDF and LLF compatibility commands without the new options. Provide host controls for adjacent and terminal cells, refusal, late/duplicate IRQ and unsupported syscall paths.

정상 일반·추적 4회, 같은 세 ELF를 다른 달력에 배치하는 일반 실행 1회, 정책별 두 종류의 사전 거부 4회를 각각 보존한다. 개인 메모리의 계산 결과, 서비스 대기 복귀, 원래 작업의 중단 지점 복원, 유휴 잔여 구간과 모든 이동 창을 독립 재생한다. 기존 EDF·LLF 호환성과 실보드·제품 채택 판정은 각 범위에 맞게 별도로 기록한다.
