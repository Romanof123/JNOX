# Independent interrupt load on the protected permit bench / 허가 채널 독립 인터럽트 부하

[IPC-010 qualification #389](https://github.com/Romanof123/JNOX/issues/389) uses the single-vCPU Cortex-A72 virt/GICv2 target. The fixed scheduler owns CNTP and PPI30. For a separate opt-in engineering position, enable the EL1 virtual timer CNTV and its distinct level-sensitive PPI27. QEMU wires the two generic timer outputs to separate GIC inputs. Archive the actual emulator identity and machine arguments. [QEMU virt timer wiring](https://github.com/qemu/qemu/blob/v8.2.0/hw/arm/virt.c#L753-L773)

In the optional qualification package, arm up to 32 independent timer deliveries. The first CVAL is one millisecond after the first virtual counter sample; each later CVAL is five milliseconds after a new virtual counter sample in the preceding handler (durations round up to ticks). Disable before EOI, program only the next deadline, and return through the ordinary interrupted user or idle frame. No catch-up bursts or deliberate masked delays. An early terminal stop retains the actual arm/delivery counts. A full-stream claim requires 32 matching acknowledgements and completed handler records. Compare the same declared ordinary ELF workload, policy and phase with this option disabled and enabled. Retain each first result.

Capture physical-counter brackets around virtual-counter samples, requested and readback CVAL, CTL, raw IAR, physical entry and post-EOI stamps, and the interrupted owner or idle. Keep domains distinct. For an outstanding controller absolute wait, sample its nominal target before real loan and permit syscall bodies. When the physical target falls inside a continuously IRQ-masked body, the interval from target to the final masked sample is a measured lower bound on residual blocking in that particular body. Use the qualification return stamps and actual readiness/dispatch evidence separately. An empty overlap set supplies no blocking estimate. Report missing samples, late deliveries, source uncertainty and array overflow. Neither observed maxima nor an unexplained IRQ delay supply a universal blocking bound, WCET, physical target approval or admission.

단일 CPU virt/GICv2에서 스케줄러의 CNTP/PPI30과 별도로 선택한 CNTV/PPI27을 사용한다. 첫 비교값은 현재 가상 카운터에서 1 ms 뒤, 이후는 직전 핸들러의 새 표본에서 5 ms 뒤이며 올림하여 예약한다. 최대 32회, 누락된 시각의 몰아 실행 없이 실제 전달만 센다. 종료 시 미전달 예약과 실제 개수를 보존한다. 동일 ELF·정책·위상의 부하 비활성/활성 최초 결과를 각각 보존한다.

가상 카운터와 물리 카운터 표본의 구간, CVAL 설정·읽기, CTL, 실제 IAR, 진입·EOI 완료와 원래 실행 주체를 남긴다. 제어기 기상 목표가 실제 IRQ 차단 상태인 대여 또는 허가 시스템콜 본문 안에 들어왔을 때만 목표 이후 마지막 차단 표본까지를 해당 관측의 잔여 차단 하한으로 사용한다. 관측이 없거나 버퍼가 넘치면 그 한계를 기록한다. 실측 최댓값은 WCET·포괄적 차단 상한이나 물리 장치 안전 승인을 제공하지 않는다.
