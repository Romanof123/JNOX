# Mask-constrained native SMP migration on Pi 4 / Pi 4 네이티브 SMP 마이그레이션

Prospective Systems intake on `7baa7ab06eb5881062feb7691e16899d7cf2fe7e`, #21 POL-013 / #47. The current #355 native owner is fixed; the older MG workloads migrate kernel-linked tasks. Preserve EVD-106 short 3/6 and stream 6/6, EVD-108 short 2/6 and stream 6/6, and EVD-146's unresolved strict overlap and traced ownership. This design adds runnable global and logical-cluster selectors for ordinary independent ELFs. [Original criteria](scheduling-policies.en.md) · [MG controls](boards/pi4-smp-migration.en.md) · [Native baseline](pi4-native-smp-applications.en-ko.md)

기존 #355는 고정 코어 사용자 ELF를 실행하고 MG는 커널 링크 작업을 이동한다. 이번 대상은 전용 주소 공간을 가진 일반 ELF의 실제 이동이다. 기존 짧은 루프 실패 및 시간 불확실성은 기존 판정대로 유지한다.

## Public contract / 사용자 계약

Extend the normal Pi 4 package with `--policy smp-global|smp-clustered --online-cpus 2|3` (contiguous CPU IDs from zero), ordered existing ELF/priority/release-cell/CPU-mask parameters for 2–3 processes. Global effective mask = requested mask. Clustered requires a complete ordered partition, e.g. `--cluster-masks 3,4 --cluster 0 --peer-cluster 0 --peer-cluster 0`; each effective mask = request intersect its assigned cluster. A request may contain bits in other online clusters, but no effective claim can use them. Reject unknown/offline bits, empty intersections, missing/overlapping cluster coverage, duplicate clusters, bad indices/cardinality, malformed ELFs or time arithmetic overflow before first user return. Global rejects cluster options. Preserve argv, private memory, clock, absolute sleep, yield, signed exit and the separate existing fixed selector. No affinity-changing syscall required. Raw build and CLI bind identical normalized masks, cluster table, hashes, argv and releases.

온라인 CPU 2~3개와 프로세스 2~3개의 마스크·우선순위·릴리스 셀을 선언한다. 클러스터는 온라인 집합을 겹침 없이 분할하고 실제 마스크는 요청과 소속 클러스터의 교집합이다. 잘못된 설정은 사용자 실행 전에 거부한다. 기존 고정 정책과 앱 ABI를 유지한다.

## Ownership, time and coherence / 소유권·시간·일관성

CPU0 publishes all jobs due at an anchored E+kQ (Q=floor(F/50)) in one release transaction. Independent absolute sleep expiry uses its original deadline and one wake token. Preserve actual lateness, coalesced releases and skipped cells. Rank by descending priority and FIFO readiness; preserve incumbent queue age through involuntary interruption, renew equal-priority queue order on voluntary yield. Plan the eligible active+ready snapshot with the existing augmenting-path matcher; keep compatible current placements if they realize the same selected priority set and occupancy, then minimize moves with CPU-ID tie break. Use a bounded exhaustive placement tie pass for up to three CPUs. Give yielded jobs no incumbent preference over earlier equals. Publication of a plan conveys intent only. Usable remote preemption requires a targeted reschedule SGI to the current owner; a naturally earlier PPI/SVC can perform the transition. Do not assign a running process remotely based solely on the proposed map. [AffinityDomain](../kernel/src/domain_policy.rs) · [Ownership::plan/claim/retire](../kernel/src/smp_policy.rs)

Serialize ownership, release/wake bits, matching revision and immutable saved-frame slots under a short IRQ-masked inter-core lock with acquire/release. Extend the existing Ownership cfg for native mode. Its plan currently excludes occupied CPUs: use a distinct hypothetical all-eligible affinity snapshot for reschedule requests, then claim only truly ready tasks on actually vacant cores. On real exception the owning CPU reads its last **actual** return R, entry I, local TTBR, GPRs, q0–q31, FPCR/FPSR, both TLS registers, SP, ELR/PSTATE. Retire the exact sequence and add checked I−R once, store the complete frame and publish readiness atomically. Initial idle, failed pre-ERET validation and kernel scheduling have zero process charge. Separate provisional claims from delivered grants, and cancel a stale undelivered claim without a fictitious interval. Concurrent plans cannot revoke an accepted lease without acknowledgement from its CPU. Record send, actual interrupt and EOI independently. A stale/duplicate SGI rechecks current revision; it cannot duplicate a grant. Never wait for remote acknowledgment while locked. Copy incoming frame into CPU-owned restore storage while locked; end every Rust borrow before unlocking, sending SGI or entering assembly. The local claim remains exclusive through real return and until the next retirement. Use verified lexical guards and UnsafeCell ownership; no shared static mutable references outside the lock, no remote writes to live CPU stacks.

각 인터럽트는 실제 R~I 구간만 현재 리스에 한 번 부과한다. 전역 계획은 요청이며 리스 자체를 이전하지 않는다. 소스 코어가 전체 프레임 저장과 리스 반납을 같은 임계구역에서 공개한 뒤에만 대상 코어가 새 리스를 얻는다. 잠금 상태에서 원격 응답을 기다리지 않고 CPU별 복원 사본을 사용한다. 절대 릴리스와 수면 만료는 재계획으로 이동하지 않는다.

Stage one reuses #355's CPU0/1 startup. Stage two adds CPU2 cold affinity detection and its own spin-table release, exception/idle stacks and guards, frame staging, GICv2 banked PPI/CPU interface, SGI mapping, calibrated counter bracket, release/park acknowledgment and CPU-indexed trace/capture. CPU3 stays parked. Verify firmware spin slot and target mask for CPU2 from the actual BSP. CPU0 publishes all immutable mappings, executable bytes and page tables to PoC before secondary startup; each participating core installs its own EL1 control/VBAR and synchronizes translations and instructions before EL0. Use fixed private root+ASID per process, same shareable kernel mappings and permissions on all roots. At migration perform the existing synchronized local TTBR switch before destination restore, hold source ownership through last user instruction, and order writable private data and frame publication with shareable acquire/release. No ASID reuse, mutable executable aliases, live page rebind or implicit user data sharing. Any future remap requires acknowledged shareable invalidation. Terminal export only after all owners retire, outstanding handoffs drain and every enabled core disables its comparator and acknowledges park. [Native scheduler](../kernel/src/native_pi4_smp.rs) · [MMU](../kernel/src/native_el0_mmu.rs)

3코어 단계에서는 CPU2의 진입·가드 스택·개별 GIC/PPI·SGI·시간 보정 및 정지 승인이 선행 조건이다. 프로세스별 루트와 ASID를 유지하며 목적지에서 TTBR 전환을 완료한 뒤 실행한다. 현재 설계는 실행 중 매핑 변경이나 ASID 재사용을 허용하지 않는다.

## Frozen proposed firsts / 제안 최초 실행

Use unchanged #355 odd/even paired scalar/SIMD clients (N=2²⁵; private sums 1,125,899,906,842,624 / 1,125,899,940,397,056; exits 12/77, distinct live TLS) and original C prime-low (78,498, exit 12). M=odd, H=prime, B=even. Ordered parameters below are (mask,priority,release cell). All use stock raspi4b, existing raw cold boot, unmodified common timer phase, 120 s per first. Capture first plain then first traced for each row. No tuning, retries or replacement positions.

| Case | Ordered descriptors M,H[,B] | Required causal outcome |
|---|---|---|
| Global 2 | (3,2,0),(1,5,1) | M executes on CPU0 until H's release, then migrates live to CPU1 while H runs pinned on CPU0. |
| Global 3 | (7,2,0),(1,5,1),(2,4,0) | M and pinned B are jointly released at E. H displaces M; occupied CPU1 forces M to CPU2. |
| Clustered 3, confinement | same as Global 3, clusters {0,1}/{2}, all assigned cluster 0 | Same contention and raw M mask permits CPU2. CPU2 is free but outside M's cluster. With H and B still ready M waits; resumes only within {0,1}. |
| Clustered 3, allowed move | same except B pinned CPU2 (mask 4) and assigned cluster 1 | B remains on CPU2; H displaces M from CPU0 to CPU1 inside cluster 0. |

Check simultaneous release as one publication with separate legal grants, pinned peer progress, individual private results, all release and charge totals, no lost records and no cross-boundary claim. For each live move join source in-loop preemption and complete outgoing architectural frame, source retirement sequence, destination exclusive claim, correct restored PC/SP/TLS/GPR/SIMD/FP and TTBR/ASID, actual EL0 resumption and later increasing in-loop count on destination. Bind external instruction evidence to independently attributable CPU IDs; ambiguous trace or ordering remains incomplete. If M finishes early, B already exited, high selection is serviced by local PPI before SGI, or a planned route is never actually needed, retain precisely that outcome. Require at least one genuinely delivered remote reschedule causal handoff in global cases for that claim. Record migration request→source stop→destination restore/first observed work with calibration intervals, independent local CPU charge and real peer contention. Use a separately declared matched pin/no-move control for any comparative migration-cost claim. Preserve the existing sleep/yield contract via first plain calendar substitution (global 2, H=existing calendar-report, private result/exit 32) measuring its absolute wake and continuation. Existing #355 partitioned controls retain their original scope.

같은 ELF로 전역 2코어 이동, 전역 3코어 경계 통과, 클러스터 경계 차단, 클러스터 내부 이동을 구별한다. 첫 부팅에서 실제 소스 중단과 대상 실행을 확인하고 중도 완료·핀 작업 조기 종료·SGI 경쟁은 관측 그대로 남긴다. 별도 달력 작업으로 실제 절대 수면·재개를 검사한다. 마이그레이션 비용 비교에는 대응 고정 실행이 필요하다.
