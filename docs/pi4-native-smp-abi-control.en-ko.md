# Pi 4 native SMP ABI control / Pi 4 네이티브 SMP ABI 대조군

Prospective supplement to [#355/#356](pi4-native-smp-applications.en-ko.md), based on `b2c603661bdfe39a6803685e50ccc6ed9064cbd8`. Keep the production selector, vectors, timer phase, SDK startup, private ELF layout and exit unchanged. Build two ordinary C clients with one separately assembled AAPCS64 leaf routine and different linked role constants. Use the existing SDK and native ELF linker script; preserve caller-required registers, original thread pointer and FP environment on return. No SVC, helper call or exception trigger inside the work loop. The assembly routine controls register lifetimes and exports loop boundaries for disassembly. [SDK errno access](../sdk/native-aarch64/io.c) · [Operator replay](../tools/pi4_native_smp_replay.py)

기존 실행 경로에서 일반 C 앱 두 개가 어셈블리 leaf 함수를 호출한다. SDK 시작·종료와 정책, 타이머 위상은 유지한다. 루프에서는 시스템 호출이나 강제 인터럽트를 사용하지 않는다. 호출 전 상태를 복구하고 정상 종료한다.

## Work and live register values / 연산과 레지스터

A sums the first N positive odd integers, B the first N positive even integers, N=33,554,432. Each iteration accumulates one input in a scalar GPR and independently accumulates it in a 64-bit SIMD lane. Keep both sums and count in separate private result words. Require A = N² = 1,125,899,906,842,624 and B = N(N+1) = 1,125,899,940,397,056 in both accumulators, count N for each. Exit 12 and 77 respectively on success; mismatch exits with a distinguishable error. No closed-form substitution in the timed loop.

Inside the labeled loop reserve x19 and both 64-bit lanes of q16 as immutable role signatures. A x19=0x1111222233334444, q16 low/high=(0x101,0x102); B x19=0xaaaabbbbccccdddd, q16=(0x201,0x202). Use a different vector for the actual SIMD sum. With no threads or TLS-dependent calls inside the leaf, set writable TPIDR_EL0 to the address of the role's aligned private two-u64 TLS record **plus a role-specific byte offset**; use disjoint effective user virtual addresses (A and B can otherwise link at the same VA). Bind exact linked address to disassembly and ELF symbols before either run. Set one private word at that address to the role's x19 signature and read it back through the actual TPIDR_EL0 after the loop. Record TPIDRRO_EL0 by MRS at entry and before return, compare both with its published incoming value (zero for this startup); only EL1 can program this register. Preserve the SDK errno convention. For FP control select only defined rounding bits 23:22 (A=01, B=10); set FPSR.QC for A and zero for B. Integer non-saturating SIMD operations preserve those flags. Record hardware readbacks, sentinels and final accumulators in private RAM before restoring the original registers and returning to C.

A와 B가 각각 처음 N개 홀수와 짝수를 스칼라·SIMD로 독립 합산한다. x19와 q16의 두 레인은 역할별 고정값이다. 각 ELF의 쓰기 가능한 전용 TLS 레코드 주소는 서로 다른 VA임을 링크 결과로 확인한다. EL0는 TPIDR_EL0만 설정하고 TPIDRRO_EL0는 진입과 복귀 때 읽어 기동값과 대조한다. FPCR 반올림 비트와 FPSR.QC도 역할별 실제 읽기값을 남긴다.

## Firsts and evidence / 첫 실행과 판정

Freeze the ELF hashes, symbols, exact result layout, counter/loop register assignments and linked instructions before observations. Use the documented normal command with `--board pi4 --policy smp-partitioned --elf odd.elf --peer-elf even.elf --cpu-mask 1 --peer-cpu-mask 2 --priority 2 --peer-priority 2`, both releases cell 0. First cold plain, then first cold external exception trace; same inputs, stock raspi4b Cortex-A72, unchanged host settings and existing 120 s limit. Retain UART, raw journals, RAM, roots, per-core trace identities and exact capture command. Check independently for each position:

1. Both ordinary exits, both private scalar/vector products and counts, all user readbacks, disjoint private backing, distinct TTBR0 roots/ASIDs and the recorded TLS values agree. Validate TLS byte range inside private writable ELF storage; never write TPIDRRO_EL0 from EL0.
2. Each core receives real PPI30 from EL0 with saved PC inside its linked work loop and positive measured service. Bind complete outgoing frame to that row's actual CPU, PID, SP, root, stack and saved ELR/PSTATE. Compare all 31 GPRs, both TLS registers, all 32 full 128-bit vectors, FPCR/FPSR, SP/PC/PSTATE to its prepared same-owner return; check the named constants independently against linked instructions. Join subsequent actual user return/entry timestamps and positive later work with that frame. Confirm private after-loop hardware readbacks; prepared bytes alone do not prove restoration. External trace must bind actual IRQ/ERET to the correct core in the traced position.
3. For simultaneous progress use the existing conservative cross-core calibration and disassembly/progress evidence on **these jobs**, retaining the uncertainty interval. Require positive computable overlap of observed application service and advancing loop work on both cores for a concurrent-work claim. A missing in-loop PPI, incomplete frames, ambiguous cross-core timing, loss or wrong product withholds the corresponding criterion. Record each first outcome even if only some criteria pass. No reruns to replace firsts. Existing prime/plain/overlap/SGI outcomes and physical-board disposition retain their original evidence.

일반 패키지에서 두 작업을 CPU0·CPU1에 각각 고정하고 같은 셀에서 시작한다. 최초 일반 부팅과 외부 예외 추적 부팅을 각각 보존한다. 코어마다 루프 내 실제 PPI30, 전후 전체 프레임, 실제 재실행 및 최종 EL0 읽기값을 연결한다. 보정 오차를 반영한 서비스 중첩과 각 루프의 진척이 확인된 범위만 동시 실행으로 인정한다. 누락·모순 또는 제품값 불일치는 해당 항목에 그대로 기록한다. 이전 실행과 실물 보드 판정은 별도 근거를 유지한다.
