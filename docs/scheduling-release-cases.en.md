## CHG-088 · two native EL0 processes

[English reference workload](ordinary-vruntime-plan.md) · [prior EL1 results](evidence/evd-049.en.md) · [native entry contract](native-el0-startup.en.md)

Prospective single-core AArch64 virt/GICv2 engineering profile. Run the same native SDK ELF twice with weights A=1 and B=2, distinct ASIDs, private saved GPR/FP/TLS frames and physically distinct RW/BSS and stacks at identical user VAs. Use the existing VruntimeScheduler for every actual lease. Check native package identity and allocated ABI note, permissions, owner and stack on entry/return. A read-only horizon flag permits each process to finish its ordinary arithmetic and return through SDK exit. The kernel observes each process's own published result, progress and exit status.

* Share: both remain runnable through 36 actual timer closures. Q=10 ms, H=5Q/4, G=Q/4. Freeze relative Q at dispatch, measure actual service and handler gaps. Require Q≤timer service≤H, gaps≤G, −H≤2A−B≤2H for every prefix, total≥36Q and the original terminal share error bound 2H/(108Q). Exclude and retain the finite tail.
* Wake: B performs work then uses monotonic absolute sleeps three times; A stays runnable. Native SVC 0x4a01 calls 6/7 implement clock_gettime(1,out) and clock_nanosleep(1,1,deadline,NULL) in this profile. Timespec is two signed 64-bit words (seconds, normalized nanoseconds). Validate user buffers, return 0 or raw negative errno and use a checked ceiling conversion for absolute deadlines. Sleep requests target the monotonic read plus 40 ms. Program the earlier deadline/quantum and distinguish a shortened deadline-interrupt lease from a full slice. Only actual timer IRQ expiry wakes B. Record requested time, IRQ entry, accepted wake, selection and resumed B progress. Apply the reference 3Q A-only service and three-to-four full A closure criteria, zero B charge while blocked, bounded floor placement, at most one intervening A lease and H+2G from wake acceptance to B dispatch. Record a missed criterion as such.
* Predeclare first runs for both arms on default TCG and separately identified deterministic TCG. Retain actual ELF/MMU mappings, both backing checksums, counter frequency, complete grants and frame PCs, IRQ IAR/EOI, SVC and independent ERET history. Compare existing startup-probe and EL1 POL-011 selectors against their parents. Product timing, physical isolation approval, unrestricted POSIX clocks and general process/IPC services remain open.

For each wake cycle D is the accepted absolute deadline, I the expiry IRQ entry, W the post-placement acceptance sample, R the assembly pre-ERET sample of B’s first resumed lease (match SELECT, subsequent STOP and external ERET), and S the clock sample returned by B’s first resumed clock SVC and published in its round. SELECT precedes R. Freeze the following simulator engineering limits before capture. Require D≤I≤W≤R≤S, I−D≤G, W−I≤G, R−W≤H+2G, S−R≤G and S−D≤H+5G (25 ms) in every round. Report each interval. Integer nanoseconds n imply an inclusive tick interval epoch+[ceil(nF/10⁹),ceil((n+1)F/10⁹)−1] at frequency F. Intersect with the producing SVC entry through its next kernel return sample. Require a nonempty interval and prove limits using its worst endpoints. An absent causal match or interval crossing a limit leaves the round unqualified. S includes EL0 instructions, SVC entry and kernel clock-read work. Application progress and exit require separate evidence.
