# POL-009 virtual workload limits / 가상 작업 부하 한계

CHG-048 · IMP-046 · [EVD-046 (English)](evidence/evd-046.en.md) · [EVD-046 (한국어)](evidence/evd-046.md) · REQ/VER-002/005/023 · DES-003/012. [#102](https://github.com/Romanof123/JNOX/issues/102) · [#21](https://github.com/Romanof123/JNOX/issues/21) · [EVD-040](evidence/evd-040.en.md)

## Frozen virtual inputs and verdicts

Use QEMU virt, one Cortex-A72, GICv2, TCG and the ordinary private-stack task entry/return path. Record the executable, clock mode, frequency, exact image/options, workload and witness hashes. Let U=floor(CNTFRQ/100) counts, Q=U, P=16U, feedback allotments [4U,6U,8U] top first. Require positive units and checked arithmetic. Each case starts from a fresh boot. Keep the original MLQ/MLFQ workloads selectable.

1. **Terminal state.** Two equal-class MLQ tasks, initially ready in ID order, each blocks once with no wake source. Require two distinct block SVCs, both tasks live and asleep, empty ready queue, no owner, STALL. A separate otherwise identical workload returns both entries through the exit trampoline. Require both exits, zero live tasks, empty queue, no owner, DONE. In each case require timer enable bit zero by actual readback after disable, terminal PC in linked idle and no further dispatch/IRQ/terminal message during a declared one-second host quiet window. Keep the timebase for this window explicit. Idle is never charged. A terminal UART line alone cannot distinguish task states.
2. **Finite saturation.** MLQ declaration order low 0 (class 0), high 1 and 2 (class 2). Both high workers stay runnable, with no yield, block or return through the first eight complete timer quanta. Use a shared predeclared absolute end at least 16Q after the first dispatch starts, followed by ordinary returns. Freeze a bounded iteration or run timeout. Score the first eight timer closures from initial selection. For each row reconstruct high-peer FIFO rotation 1,2 repeatedly, continuous low readiness, positive measured high charge, low service delta and cumulative service exactly zero. Require first low dispatch immediately upon the last high exit, eventual positive low service and normal termination. Early exit, absent peer, lost row or inadequate IRQ count invalidates the case. This observes finite denial of service. Strict priority supplies no guaranteed minimum share under indefinitely ready high work.
3. **Delayed first timer observation.** Three ordinary MLFQ tasks initially ready [0,1,2]. Owner 0 performs CPU work across the delayed first IRQ without SVC, yields or masking IRQ. The frozen alternate timer configuration programs only the first dispatch at start+3P+P/4, retaining nominal due=start+min(4U,P). Record start, nominal due, actual comparator and timer control, IRQ ID, first stop, pre/post totals and next dispatch. The first observation must be the timer IRQ with stop≥programmed compare and stop−start<4P. Reject early/spurious boundaries or missing evidence. The interval crosses exactly three full periods. Later dispatches program start+min(remaining,P−total%P) including exact multiples. Record at least the next ordinary boundary and a later ordinary epoch crossing, with finite worker termination.
4. **Replay.** Reconstruct service stop−start in raw monotonic counts once on the outgoing owner, exclude scheduler and idle, verify sum of per-owner deltas equals total. Before reset apply all elapsed debt through top and middle and quotient/remainder at bottom (exact exhaustion reloads the full bottom balance). Verify this intermediate state or an independently inspectable charge path plus a pre-reset witness. Epoch count is floor(after/P)−floor(before/P). Count one actual reset when positive and zero otherwise. Record the reset invocation count or equivalent independently observable event because final priorities alone cannot distinguish repeated resets. At the first IRQ the queue before boost is [1,2,0]. After boost require unchanged FIFO order, all three live tasks at top with full balance, selected owner 1. Check unchanged ancestry of per-owner service and no retroactive credit, synthetic epochs or repeated charge on the next row. Every selected task must own its saved frame and PC.
5. **Evidence and limits.** Keep first cold ordinary and diagnostic observations per case, including failures. Preserve raw UART, exception order, diagnostic rows, terminal registers/idle PC, ELF symbols and hashes. Bound to four task slots, 16 KiB private stacks, 256 rows including initial/terminal rows. Overflow, wrap, impossible timing, missing records or timeout cannot pass. Retain independent replay plus the original two workload regressions. The deliberate compare delay tests service reconciliation. Default timer latency, field starvation tolerance, execution bounds and board release need product inputs and separate evidence.

## 동결한 가상 입력과 판정

QEMU virt 단일 Cortex-A72, GICv2, TCG와 일반 태스크 전용 스택·복귀 경로를 사용한다. 실행 파일·클록 모드·주파수·옵션·이미지·작업·계측 해시를 기록한다. U=floor(CNTFRQ/100), Q=U, P=16U, 피드백 할당량은 상위부터 [4U,6U,8U] 카운트이다. 양의 단위와 오버플로 검사를 요구한다. 사례별로 새로 부팅하고 기존 두 작업 구성을 유지한다.

1. 같은 클래스 두 MLQ 태스크를 ID 순으로 준비한다. 각각 한 번 차단하며 깨움 원천은 없다. 서로 다른 차단 SVC 두 건, 두 태스크 생존·수면, 빈 큐·소유자 없음과 STALL을 확인한다. 별도 부팅에서 두 태스크가 복귀 트램펄린을 거쳐 종료하면 종료 두 건·생존 0·빈 큐·소유자 없음·DONE을 요구한다. 두 경우 모두 비활성화 뒤 타이머 enable 비트 0 실측, 링크된 idle 안의 PC, 호스트 시간 1초간 추가 디스패치·IRQ·종료 메시지 부재를 확인한다. idle에는 서비스를 부과하지 않는다.
2. MLQ 선언 순서는 하위 0(클래스 0), 상위 1·2(클래스 2)이다. 첫 디스패치 이후 적어도 16Q 뒤의 공통 절대 시각까지 상위 두 태스크를 실행 가능 상태로 두고 정상 복귀시킨다. 반복 또는 실행 시간 한도를 동결한다. 첫 타이머 종료 여덟 건에서 양보·차단·복귀 없이 1·2가 FIFO로 교대하고 매번 상위 실측 서비스가 양수이며 하위의 준비 상태와 누적·증분 서비스 0이 유지되어야 한다. 마지막 상위 종료 직후 하위를 선택하고 하위 양의 서비스와 정상 종료를 확인한다. 조기 종료·상위 부재·행 손실·IRQ 부족은 실패이다. 유한 관측이며 지속 포화 시 하위 최소 지분 보장은 없다.
3. MLFQ 일반 태스크 [0,1,2]를 준비한다. 첫 소유자 0은 SVC·양보·IRQ 마스킹 없이 CPU 작업을 수행한다. 별도 타이머 구성의 첫 명목 기한은 start+min(4U,P), 최초 실제 비교값만 start+3P+P/4이다. 시작·명목 기한·실제 비교값·타이머 제어값·IRQ ID·최초 관측 종료 시각·누적 전후값·후속 선택을 기록한다. 첫 경계가 타이머 IRQ이고 stop≥비교값, stop−start<4P여야 하며 정확히 세 주기를 넘어야 한다. 조기·예상 밖 경계나 증거 누락은 실패이다. 이후 매번 정확한 주기 배수에서도 start+min(remaining,P−total%P)를 사용한다. 다음 일반 경계 및 이후 일반 주기 통과와 유한 종료를 확인한다.
4. 독립 재구성에서 실제 stop−start를 소유자에게 한 번만 부과하고 선택·idle을 제외한다. 태스크별 증분 합이 전체 증분이어야 한다. 리셋 전 상위·중간 잔량을 차감한 뒤 하위 반복분을 몫과 나머지로 처리하며 정확히 소진하면 하위 전체 잔량을 복원한다. 중간 상태 계측 또는 독립 검사 가능한 차감 경로와 리셋 직전 증거를 요구한다. 지난 주기 수는 floor(after/P)−floor(before/P)이며 양수면 실제 리셋 한 번, 0이면 0회여야 한다. 호출 횟수 또는 동등한 관측을 남긴다. 첫 IRQ에서 리셋 전후 큐 [1,2,0], 세 태스크 상위 전체 잔량, 다음 선택 1을 요구한다. 누적 소유자 서비스 보존, 소급 지급·가상 경계·중복 차감 부재와 선택된 태스크의 저장 프레임·PC 소유권을 확인한다.
5. 각 사례의 일반·진단 이미지 최초 콜드 부팅과 실패 기록, UART·예외 순서·진단 행·최종 레지스터·idle PC·ELF 심볼·해시를 보존한다. 최대 4개 태스크, 전용 스택 16 KiB, 초기·종료를 포함한 256행이다. 초과·랩어라운드·불가능한 시각·누락·시간 초과는 합격할 수 없다. 독립 재구성과 기존 두 작업의 회귀 결과를 남긴다. 의도적 비교 지연은 지연 서비스 회계를 평가한다. 기본 타이머 지연, 현장 기아 허용치, 실행 상한과 보드 승인은 별도 제품 입력·증거가 필요하다.
