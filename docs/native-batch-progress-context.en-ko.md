## Recover the saved operand first / 저장된 원본부터 복원

The plain and traced first-arrival-srtf terminal ram.bin files retain the complete interrupted A frame in FRAMES[0]. The ELF symbol is at 0x40210000, offset 65536 from the retained dump base. Decode x0…x30 as 31 consecutive little-endian u64 words; compare ELR at +264 and SP_EL0 at +272 with the original decision rows. Both ELRs are the productive byte load 0x400808. For traced A the saved SP_EL0 is 0x1010f40. [activate](../kernel/src/native_el0.rs) copies the outgoing trap frame to FRAMES only on an owner change; B→A restores that saved A operand. Final A exit takes the terminal path before another activate. Compare the owner sequence, [transfer and finish](../kernel/src/native_batch.rs), and final RAM identity before using the frame.

In batch.elf (SHA-256 a70b319006df9dd001bb346bca23b427a76039949172809d1fbac16b5e8ef73d), W21 starts at one at 0x400a20; 0x400a2c calls batch_reduce, 0x400a38 publishes the running sum at 0x403008, 0x400a3c publishes the completed block number at 0x403010, then 0x400a40 increments W21. Thus inside this reduction the preceding W21−1 stores completed. Terminal private RAM independently gives 32,768 blocks and sum 17,112,760,320. This recovers numerical progress by control-flow inference and all saved integer words. The historical exception stream records ERET to 0x400808, not 31 independently sampled live register values or transient private words. A single reused terminal trap-stack page cannot serve as two time-separated samples.

일반·추적 최초 SRTF 덤프에 남은 FRAMES[0]에서 중단 당시 정수 레지스터 31개를 추출할 수 있다. 저장된 W21은 현재 블록 번호이므로 이미 게시한 블록은 각각 13,721개와 13,619개다. 이 수치는 명령 순서에서 복원한 값이다. 실제 복귀 직전의 별도 프레임 및 당시 앱 메모리 읽기와 구분한다.

## Two new first observations / 새로운 최초 관측 두 건

Freeze exactly one externally observed arrival-SRTF and then one externally observed tie-SJF cold acquisition. Use original packaged kernel SHA-256 089ff0bc0ba855c6ff3cda7dd19af7243ed4af84017917b0ac5316e6f612da3b and ab8257864df4ed0aa9c08fa18c552410b6c504ce88f39dd3054669ccbac00b2b respectively. Preserve archived manifest, ordered app ELFs, arguments, original epoch/release offsets, stock QEMU 6.2 A72 virt/GICv2 CPU0 default 62.5 MHz, original -d int, UART and terminal RAM. Retain first failure or coalesced release. No repeated plain position or mid-run stop. [Frozen cases](native-batch-applications.en-ko.md)

Use the stock TCG plugin's instruction and memory callbacks restricted to exact decoded PCs. The installed binary exports qemu_plugin_register_vcpu_mem_cb, qemu_plugin_get_hwaddr and qemu_plugin_hwaddr_phys_addr. Its plugin ABI supplies memory direction/size/address; it exposes neither memory value nor general register read API. Distinguish equal user VAs by independently verified physical mappings. For the fixed-block loop monitor the actual 32-bit progress store 0x400a3c; for timed A use 0x400960. Verify instruction word and expected private backing page first. Maintain one counter and last address per role, with bounded boundary records; do not log every reduction load or dump every store. A memory callback alone does not publish a numeric store operand. Read the real private word at the *following instruction* on the same vCPU and at the relevant trap/return boundaries. For a count-only fallback label it executed store count and cross-check final progress. Verify 522,240 sum per committed block, treating interruption between sum and progress stores as a separate phase.

For arrival-SRTF, correlate the lower-EL PPI30 with the real saved-frame stack writes and select/return sequence. From pinned disassembly, first save STP x0,x1 at 0x402011c8 yields the real frame-base physical address; at 0x40201290 the stores have completed. Snapshot x0…x30 plus SPSR, ELR and SP_EL0 at that point. Independently obtain the **restore** frame base from the actual load of x0,x1 at 0x402013e8, at the corresponding B-exit→A return. Read its bytes before they can be reused. Match all 31 values individually, SP/PC/PSTATE, mapped owner, ERET at 0x40201480 and actual next EL0 PC in the external trace. Retain actual addresses/word digests and original raw frame bytes. First post-return progress publication must advance the genuine private word; retain the last completed value before PPI, the first after return and terminal totals, with event identities. This compares the complete memory operands consumed by the architectural restore. A register-file read at ERET would be a separate observation.

For the same-process address read, prequalify a bounded read-only bridge on this exact QEMU executable. Its dynamic symbols include qemu_ram_block_by_name, qemu_ram_get_host_addr and qemu_ram_get_used_length; these are build-specific internals. Verify their signatures, RAM block identity, virt physical base, length, access ranges, pinned kernel instruction bytes and known immutable application bytes before accepting reads. Translate callback physical address to an offset in the validated RAM block and synchronously copy only the whitelisted words while that vCPU is executing the callback. Reject MMIO, address overflow, ambiguous mappings, symbol failure and dropped boundary records. No writes, monitor stops, breakpoint stepping or host-timed pmemsave requests in the scored interval. If the bridge cannot be validated, retain store/address and ERET evidence and mark numerical reads and frame comparison unavailable.

For tie-SJF record A's first completed publication, the B/C release decision, actual interrupted PC/owner, publication counts immediately before/after it and the selected ERET. Require prior useful A work for the specific incumbent-retention claim. If all three are already due at first dispatch, report that ordering and initial A count; still capture A's subsequent genuine private progress and complete products plus B/C FIFO order. Cap records per kind at fixed positions (first publication, first relevant release, first post-return publication, terminal), retain counts and explicit overflow, and keep callbacks off unrelated sites. Unexpected PCs, intermediate ordering and unavailable snapshots are outcomes. Neither a coalesced run nor observer timing qualifies a missing causal transition.

두 신규 관측은 원본 arrival-SRTF와 tie-SJF 패키지를 한 번씩 사용한다. 앱의 실제 진행 저장, 트랩 저장, 프레임 복원 주소를 물리 매핑과 대조한다. 검증된 읽기 전용 RAM 경로가 있을 때만 시점별 메모리 값과 레지스터 31개를 비교한다. 복귀 후 다음 진행 게시와 최종 결과도 보존한다. SJF에서 세 작업이 다시 한꺼번에 준비되면 초기 순서와 이후 실제 계산량을 기록하며, 실행 중인 A의 유지 판정은 미관측으로 둔다. 게스트 중단, 타이머 조정, 재시도는 수행하지 않는다.
