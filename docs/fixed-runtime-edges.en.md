# Fixed RR timing edges

[한국어](fixed-runtime-edges.md)

CHG-034 / IMP-032. Planned EVD-032 for #72, REQ-002/005/023 and VER-002/005/023. These criteria precede execution.

Both linked applications use RR with Q = 12,500,000 physical counter ticks and priority 2. In table order C (slot 0) is released at T+Q, A (slot 1) at boot T, and B (slot 2) at T+Q/2. T is the single boot sample. Only A can start. Expected UART lines carry FIXED TIES or FIXED LATE followed in order by START, A START, B RUN, C RUN, A RESUME, A DONE. Each peer returns through the task trampoline. A detects incomplete peer progress after 12Q from its own entry sample and reports FAIL upon regaining execution. Bound host capture separately for a guest that never resumes.

* **fixed-ties**. The initial compare is T+Q/2. Its IRQ must arrive before T+Q, preserve A and program T+Q using A's residual. This absolute compare is simultaneously C's logical release and A's slice expiry. At its IRQ admit C behind B, then rotate A behind C. Dispatch B. B's exit selects C and C's exit restores A's interrupted frame. Require exactly these two timer IRQs. Different IRQ arrival samples from programmed compares are expected.
* **fixed-late**. The linked test A alone temporarily masks IRQ at entry, samples the counter, busy-works for 4Q, samples immediately before clearing the IRQ mask, and synchronizes. Require mask start before T+Q/2, mask duration at least 4Q and below 5Q in the captured guest. Both deadlines are overdue when the pending first compare enters. Admit B then C in deadline order, even though C has the smaller slot. One timer decision dispatches B. No intermediate expiries, rotations or peer service are due during A's masked execution. B and C return in sequence and A resumes. Require exactly one timer IRQ. Excessive host or guest delay invalidates the timing witness.

The application symbol fixed_app_observations contains 16 little-endian u64 words. In order these are SP(A,B,C), A progress, progress sampled by B and C, A start counter, mask start, mask end, B and C entry counters, A resumption counter, phase, failure, and two reserved zeros. Require aligned distinct private stacks, equal positive progress at both peers and greater final progress, chronological samples, phase 3 and failure 0. Ties has zero mask samples. Late peers must first enter after mask end.

Capture ordinary and JNOX_FIXED_TRACE=1 ELFs independently with matching selectors. Preserve ELF symbols/digests, QEMU interrupt PCs, UART, observation memory and stopped idle PC for each. Decode diagnostic rows by the [fixed runtime schema](fixed-runtime.en.md). Check initial/restored ELRs against linked task entries and interrupted A, SP/frame continuity, timer source and readbacks, exit SVCs and disarmed terminal idle. Reconstruct elapsed sample differences per real outgoing owner and compare cumulative service. Until B's first ERET, A receives all accounted service, including late elapsed quanta. At each peer exit the service delta starts at its own dispatch boundary. Normal captures establish actual guest ordering and context evidence, diagnostic captures additionally establish exact scheduler samples/compares and service. An inconsistent boundary, missing witness or extra transition leaves the claim open. This is single-core emulator evidence.
