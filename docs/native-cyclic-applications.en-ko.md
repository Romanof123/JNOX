## Operator interface / 실행 방법

~~~sh
python3 tools/build_native_el0.py --out table-p --policy partition --partition-windows a:100,b:50,idle:50 --elf energy.elf --peer-elf density.elf
python3 tools/build_native_el0.py --out table-q --policy partition --partition-windows b:50,idle:50,a:100,b:50 --elf energy.elf --peer-elf density.elf
~~~

A and B denote primary and peer. A bare lower-case owner token followed by a colon and a positive decimal integer gives its duration in milliseconds. Accept 2..16 windows with each real owner present, optional explicit idle, repeated owners, adjacent same-owner slots and same-owner wrap. Reject malformed or empty fields, duplicates of the option, missing owners, unsupported board, wrong process count, other policies’ knobs, duration/sum/tick/absolute endpoint overflow and a counter frequency F that does not support exact millisecond conversion. Expose the same checks for direct builds. Record ordered input and converted durations; never round them down. Layout and program entry must not depend on application symbols, measurement hooks or sample status codes. Leave prior native policies and linked partition selectors usable.

밀리초 단위의 순서 있는 표를 받아 A·B·명시적 유휴 창을 반복한다. 같은 소유자가 연속하거나 프레임 끝과 처음에 이어져도 경계를 보존한다. 일반 ELF에 관측용 코드나 특정 결과 필드를 요구하지 않는다.

## Execution / 실행 의미

Use the existing CyclicExecutive half-open lookup, cumulative ends, checked frame length and ready mask. Extend its bounded representation narrowly if needed to accept a validated variable-length table. Use the current native loader, two TTBR0 roots, frame save/restore, physical timer/PPI30, SDK absolute sleep and CPU0 kernel idle path. Establish a single future epoch E after ordinary preparation. Both jobs are initially ready. Arm E and wait in idle for the initial real interrupt. Every planned boundary is E plus an integral number of whole frames and the slot offset. Never restart the frame when a task blocks, exits or overruns. Schedule a comparator at the earliest relevant window edge or pending wake. Sample real cause/counter and re-evaluate the current table position at *every* scheduling entry, including a syscall crossing a boundary. At coincident wake and edge apply elapsed releases then resolve the window. A syscall crossing into a later window must never extend or renew the prior owner's allocation. A stale/pending PPI must not close the same boundary twice.

Return to the named task only while it is ready. Yield reconsiders the current owner; a ready sole owner may resume. Sleep until its actual deadline or exit makes the rest of its reserved window idle; a mid-window wake of that owner may resume within its remaining allocation. A different owner's wake can only mark it ready. Never run a peer in spare capacity. When both exit, stop the timer and terminate, with no forced drain outside the table. On late delivery use the current absolute slot, record every skipped boundary (bounded reporting with explicit loss), spill past the intended end and actual interruption; select at most one successor per actual return. Keep the triggering timer value, raw physical sample and actual PC/SP/root, including same-owner boundary and frame wrap. Failure to meet latency remains visible without changing ordinary table semantics. A bounded diagnostic journal may overflow during a long-lived normal application: continue scheduling, report loss and prohibit complete-evidence claims for that capture.

기준 E는 한 번만 정한다. 도착·기상·시스템 호출과 타이머 경계가 겹칠 때 실제 시각으로 현재 창을 다시 계산한다. 차단·종료한 소유자의 남은 구간은 유휴이며 동료에게 빌려주지 않는다. 지연 시 건너뛴 경계와 초과 실행을 원래 시간표로 계산하고 실제 복귀는 한 번만 수행한다.

## Workload and post-return timing / 실작업과 복귀 후 시간

For the named two-app example build independent SDK ELFs. A sums squared bytes and B computes a byte-density histogram on repeated 0..255 byte blocks. A complete A block adds 5,559,680 to a private u64 sum. A complete B block adds (1,8,28,56,70,56,28,8,1) to nine private bins. Each publishes completed-block count; exit 41 and 42 respectively after a completed block once 900 ms has elapsed from its own first user counter sample. Use wide checked counters and retain the final complete results. This wall-time observation interval covers three P (200 ms) and Q (250 ms) frames and the first return in frame four; verify that actual coverage exists. Require both productive workers and both private memory outputs on both tables. A starts first under P and B under Q. Q must observe consecutive B windows across the wrap. The example may accept an ordinary optional startup argument on B requesting one 160 ms absolute monotonic sleep on first entry: run it with P and verify idle in the tail of B's window, execution of ready A in its own window, no early B return and B's eventual product. Keep this control separate from the healthy timing cohort.

Use direct ordered reads of the guest physical counter in the sample applications (ISB; MRS CNTPCT_EL0). Permit only the EL0 physical counter read via the appropriate CNTKCTL_EL1 permission for this mode; timer programming remains privileged. Establish F independently from the guest counter frequency. Each example publishes a bounded append-only private record containing counter, completed count and a checksum/bin witness. Capture an initial sample; observe at short block intervals and append when at least 0.2 ms has elapsed since the previous record. Use integer threshold ceil(F/5000) and capacity 8192 records per process. Record overflow explicitly. Input, iterations and results are application-owned, independent of the dispatcher. Match a sample by absolute counter, actual owner/EL and the surrounding return/entry records; a stale sample from an earlier turn cannot qualify. A sample right after resumption may report the last completed block; require additional positive work within every eligible scored window. The actual user sample is an upper bound on arrival at user code and includes the cost of reaching the sample. Excess sampling delay remains in the measured result.

For each scheduled edge d retain i (first handling timestamp), r (last pre-ERET timestamp), x (first actual target-owned counter observation after that return) and j (next exception entry). Score d ≤ i ≤ r ≤ x < j AND x−d ≤ F/1000. At 62.5 MHz the limit is 62,500 ticks. Document which interval interrupted the selected context and match its PC/SP/TTBR with the exception trace when enabled. For kernel idle use the first actual counter read by the idle loop *after control reaches it*, with its own return or transfer bracket; report EL1 idle timing separately. When the CPU was already idle or the same process remains selected, require a fresh post-return observation for that edge. Keep the original EL0-idle observations under #216/#219 separate. A missing bracket, lost samples, skipped edge or missed limit leaves that edge unqualified. Kernel selection or a pre-ERET number alone cannot supply x.

작업 A는 바이트 제곱합, B는 비트 밀도 히스토그램을 따로 계산한다. 사용자 코드가 자신의 사설 메모리에 직접 읽은 카운터를 남긴다. 모든 건강한 경계에서 명목 경계부터 실제 대상 코드 표본까지 1 ms를 적용한다. 커널 유휴 진입은 EL1에서 별도로 표시한다. 같은 소유자가 이어진 경계도 새로운 복귀 후 표본이 필요하다.

## First positions and retained history / 최초 실행과 기존 판정

Freeze the same two ELFs, journals, argv, QEMU virt Cortex-A72 single CPU, GICv2, 128 MiB and default clock before the first run. Capture P and Q plain and externally traced (four first cold boots) and the separate P sleep control once. Retain first failures. Score each table's first three complete frames and the first dispatch in frame four, through its closing edge, with ordinary execution continuing to both exits. Independently replay policy order, all boundaries, owner/idle choices, wakes, spills, frame restores, core/privilege, timer-to-user/idle samples and private terminal products. Preserve raw UART, RAM, ELF/disassembly, package/source hashes, epoch/frequency, versions, exact commands and external exception log where enabled. Include one existing native policy compatibility path and focused invalid-table controls. Do not induce delayed IRQs in healthy positions.

On the earlier P/Q lineage one original P/default transition to idle took 73,392 ticks and exceeded 62,500. Both revisions of the later paired study exceeded 1 ms in five of five P/default boots and four of five Q/default boots; its deterministic boots passed. A later corrected plain CLI cohort exceeded the limit in three of five P and one of five Q. These remain results for those configurations. Assess product workload, frame, overrun action, physical target and end-to-end worst-case bounds through #21. [Original matrix and linked records](scheduling-release-cases.en.md#L16)

표별 첫 일반·외부추적 부팅과 별도 차단 제어 실행을 보존한다. 기능·산출물·각 경계의 1 ms 충족 여부를 독립적으로 기록한다. 과거 기본 시계에서의 미충족 및 결정론적 모드의 성공을 그대로 유지한다. 실물·제품 최악 보장은 별도 승인 대상이다.
