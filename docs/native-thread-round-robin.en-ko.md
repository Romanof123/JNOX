# Timer-driven round robin within a native process / 네이티브 프로세스 내부의 타이머 기반 RR

[#315](https://github.com/Romanof123/JNOX/issues/315) · CHG-126 / IMP-126 / EVD-126. Prospective design on tested #314 source `3d53da8b72a3f58e44e02d256af815fa3159adb9`. Two CPU-bound parts of one app can share CPU0 even when neither voluntarily yields. They access shared data through one process mapping and preserve separate user stacks, registers and errno cells. [Joinable threads](native-joinable-threads.en-ko.md) · [Existing RR selection](../kernel/src/fixed_policy.rs) · [Thread lifecycle](../kernel/src/native_thread_policy.rs)

같은 앱 안의 두 계산이 양보 호출 없이도 CPU0에서 번갈아 실행된다. 기존 생성·조인·재사용 규약과 공용 주소 공간을 유지하고 각 스레드의 스택·레지스터·errno를 복원한다.

## Deployment / 배포

~~~sh
python3 tools/build_native_el0.py --out thread-rr --elf sensor_pair.elf \
  --threads 2 --policy rr --quantum-ticks 625000
~~~

Accept one ordinary C source or ELF, optional primary arguments, exactly two thread slots, one CPU and one common positive quantum in physical counter ticks (1…i64::MAX). Equal rank is implicit. Raw Cargo uses JNOX_NATIVE_THREADS=2, JNOX_NATIVE_POLICY=rr and JNOX_NATIVE_QUANTUM_TICKS. Record ELF digest, capacity, policy, scope (within one process), quantum and observed CNTFRQ. Reject missing/zero/out-of-range quantum for thread RR, a quantum for cooperative threads, duplicate singletons, peer ELFs, probe, other policy selections, or per-process priorities, weights, jobs, classes and reservations. Preserve --threads 2 alone for cooperative operation. Ordinary --policy rr without --threads retains its existing per-process priority requirements and dispatch path. Keep one slot for the process and two for its threads; route thread RR through the thread vectors/lifecycle rather than activating the fixed process scheduler in parallel. Reuse the existing SDK and native thread services.

일반 단일 ELF 또는 C 소스에서 --threads 2와 rr을 함께 선택한다. 퀀텀은 1부터 i64 최댓값까지의 물리 틱이며 두 스레드는 동순위다. 스레드만 지정하면 종전 협력형, rr만 지정하면 종전 프로세스 RR이다. CLI와 Cargo에서 상충하는 인수와 범위를 검사한다.

## CPU0 selection and accounting / 선택과 정산

Keep the #314 thread lifecycle as sole owner of join claims, handles, zombie/reap, sleep deadlines and its ready FIFO. Reuse the equal-rank RR rule: expire into the tail only when an equal peer is ready; start a fresh Q for the selected new turn. Do not create a parallel queue of process IDs. All selections operate on thread IDs even with unchanged TTBR. At dispatch, stamp near the final restore and calculate a checked nominal slice end. Arm the earliest of the eligible slice end and earliest live sleep target. A slice compare is eligible only while a peer is ready; a lone owner continues without periodic slice IRQs. Its remaining entitlement saturates at zero. If a peer becomes ready after that solo turn has expired, request immediate arbitration. An immediate hardware compare may use the current counter when the logical end is already past. Preserve both values in evidence.

- CREATE publishes the handle and queues a clean worker, preserving the caller's turn and original logical expiry; arm the newly eligible compare before return. The worker may subsequently preempt before the caller's next user instruction. Nonblocking SDK calls, unsuccessful operations and elapsed sleeps preserve the current turn, including its original expiry. A waking equal peer joins the tail; it does not displace an unexpired incumbent. At an elapsed expiry admit due sleepers in target/ID order before requeuing the expired owner. Handle a simultaneous wake/expiry as one decision at the actual observed sample.
- Save the entire interrupted EL0 frame on PPI30, acknowledge/EOI, change thread owner and restore the selected frame (ELR, SP, x0–x30, PSTATE, SIMD/FP, TPIDR_EL0 and TPIDRRO_EL0) with the same process address-space root. Charge the actual incumbent once to the observed entry, retain any overrun beyond the nominal slice, and start the next interval only at dispatch. A same-owner interrupt preserves its turn; split accounting intervals if needed without resetting the quantum. Exclude idle and scheduler gaps from assigned service; report the convention for nonblocking syscall residency. Never replay skipped timer turns as worker service.
- Yield gives up the turn to the ready FIFO. Future sleep, blocking join, worker termination and process exit end the outgoing interval; a later dispatched thread begins a new turn. An already-zombie join returns immediately. Preserve saved acquire/return values across preemption, register-only join handoff, stale-handle checks, slot reuse with a fresh quantum and fresh errno. PPI30 from idle admits due threads without saving a fictitious user frame. Disable an unused compare, stop all timers on process termination, and report arithmetic exhaustion explicitly.

준비 큐·조인·수면·좀비 수명은 기존 스레드 정책이 소유한다. 동료가 준비된 경우에만 퀀텀 만료를 예약하고, 먼저 도래하는 수면 기한도 함께 고려한다. 동률의 깨어난 작업은 뒤에 넣고, 만료 전이면 실행자를 유지한다. 같은 시점에는 깨움을 먼저 반영하고 만료된 실행자를 뒤로 보낸다. 지연된 IRQ는 관측 시각까지 실제 실행자에게 한 번만 정산한다. 프로세스 루트가 같아도 전체 스레드 문맥을 교환한다.

## Frozen ordinary workload and first positions / 고정 작업과 최초 실행

Build one C ELF using public pthread_create/join. Before create, main initializes two 4,096-byte ramps in process-owned writable memory: main reads x[i]=i mod 256, worker reads y[i]=(17i+3) mod 256. Creator computes a u64 sum over **16,384** complete x blocks; worker computes sixteen u64 high-nibble bins over **16,384** complete y blocks. Use volatile reads and externally inspectable completed-block counts, update a count only after publishing the block's results, and keep each reduction in a named non-inlined routine. No time reads, yields, sleeps, polling flags or other syscalls in either reduction. Main starts the worker before entering its routine, joins after completing its own blocks and validates the worker's shared descriptor pointer. Require both block counts 16,384, main sum 8,556,380,160, all sixteen bins 4,194,304 and process exit 17. No thread reads the other thread's live output before join. This fixed 64 MiB per thread is a finite input, not a guaranteed execution duration.

Freeze ELF hashes/disassembly, input, argv, controls, capacity, default QEMU version/command and independent ext4 acquisition before any scored launch. Use virt/GICv2, one Cortex-A72, 128 MiB, TCG default clock and Q=625,000 counter ticks (10 ms at 62.5 MHz; record the actual frequency). Run the RR pair plain then externally exception-traced cold; repeat the identical ELF cooperatively. For RR require two consecutive involuntary changes main→worker→main while both remain runnable, saved PCs inside the two productive routines, resumed PCs/SPs in their respective stacks and subsequent advancing private counters/full results. For cooperative require main completes its reduction before worker first enters after join blocks. If either reduction finishes before the scored switches or a PC lands outside useful work, preserve that first and its limits. Classify measured quantum intervals, delivery lateness and per-thread service separately from the correct selection and products.

Include separate short controls: one peer exits early leaving the surviving main doing finite work for several nominal quanta (no further slice-only switches); main blocked on join while the worker sleeps to a genuine SDK absolute deadline (all idle, timer wake, resumed syscall, result handoff); a wake before incumbent expiry and a solo-expired wake/creation with a ready peer; valid yield, stale handle after reuse and errno across asynchronous switches. A no_std Rust control may use the #314 public C ABI and a static shared result. Retain nonthread process RR and #314 cooperative controls under their original contracts. Use deterministic host inputs for equal-time, late sampling and arithmetic edges. Do not inject delay into deployed timers.

Record old/new TID and generation, reason/origin (EL0, idle or SVC), prior/post FIFO and states, sleep deadline, logical expiry and actual compare, start/stop/pre-restore counter, measured elapsed and totals, nominal/overdue ticks, per-thread saved/restored PC/SP and errno locator, TTBR, join result and dropped rows. Retain external exception and actual user-return evidence; pre-ERET is only a lower bound on user entry. Preserve partial observations and original #314 findings. Results qualify the deployed virtual-machine configuration only.

C 앱의 두 스레드는 각각 4,096바이트 배열을 16,384회 계산하며 루프에 시스템 호출이 없다. 메인 합계 8,556,380,160, 작업자 빈 16개 각각 4,194,304와 조인 포인터를 독립 확인한다. 같은 ELF를 RR·협력형으로 일반/외부 추적 최초 부팅한다. 실제 두 연속 타이머 전환과 복귀 PC·SP, 이후 진척·최종 결과를 대조한다. 별도 사례로 동료 종료 후 단독 실행, 전체 유휴 중 절대 대기·깨움·조인을 검증한다. 관측되지 않은 경계나 실물 보드 타이밍은 미확인으로 남긴다.
