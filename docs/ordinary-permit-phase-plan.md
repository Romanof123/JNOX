# CHG-055 · Phase of ordinary permit publication / 일반 허가 게시의 위상

[#94](https://github.com/Romanof123/JNOX/issues/94) · intended IMP-054 · [ADR-001](safety-parameters.en.md) · [FS-M3-01](pol-004-m3-control-plan.md) · [CHG-053](control-service-plan.md)

## English

**Design decision.** Retain the 10 ms absolute RM/DM sender release grid and its 10 ms job deadline. Anchor only the ordinary worker’s publication target to its first actual publication in the fresh generation. A timer interrupt may wake this worker but cannot publish its permit. This is a bounded attempt to eliminate release-phase drift, with no promise that software can hit an exact device-visible tick. Keep the existing descriptor candidate as a separately identified baseline; stay inhibited whenever timing or provenance is insufficient.

**Why change the source.** In the 24 default-clock CHG-053 cold boots only descriptor DM 14/15 met every service and phase criterion. Both accepted seven permits, had no fault latch, and stayed OFF. At 62.5 MHz the first two issue ticks differed by 589967 and 582002 (short by 35033 and 42998 ticks), while the separate command arrived 1 and 7 ticks past the 937500-tick stimulus. The current worker samples at or after each nominal release +0.5 ms, then calls send, traces, enqueues and invokes delivery inline. A timestamp selected before these operations cannot identify the committed publication tick. First-period cold latency can vary independently of later latency. The data support testing the anchor change; they establish neither sender headroom nor unavoidable latency. The decoder correction leaves the observed outcomes intact. [Descriptor study](https://github.com/Romanof123/JNOX/pull/122) · [Marker study](https://github.com/Romanof123/JNOX/pull/124) · [Frozen sender](https://github.com/Romanof123/JNOX/blob/1f45010cd277ba1f1bffb90aa6e240e0848eb782/kernel/src/control_runtime.rs)

1. **Events and ownership.** Cold boot OFF, empty bounded record, fresh generation, one ordinary sender, strictly consecutive sequence. Prepare payload privately. Once per scheduled send, the worker takes a fresh ordered issue sample I, fills the issue field from I, publishes the fully initialized record by one commit store, waits for completion and takes sample U. Preserve ordered raw ticks and barriers in the linked ELF. The committed publication P lies in [I,U]; I is an actual sample, not proof of the instant of the store. For the qualifying first anchor require I=U, definite visibility and exactly one matching record, then A=I. For each later index k target A+k·625000 (checked integer arithmetic, F divisible for exact offsets). Score both actual issue gap and publication. With independent event intervals [L1,U1],[L2,U2], the gap is bounded by [L2−U1,U2−L1]; it proves exact equality only when wholly contained in the singleton required gap. An earlier poll, a post-store-only sample, exact timer compare or host log cannot certify it. Report early, late and straddling brackets separately. Failed observation never causes another store or re-anchors the generation.
2. **Receiver and command.** Move consumption out of the sender call stack. At an ordinary control activation, independent receiver code acquire-loads the committed sequence/payload, records actual before/after ticks, validates generation, order and age since I, applies expiry before simultaneous arrival, then publishes the accepted delivery record. No backdated delivery or advance on a duplicate read. Late delivery must leave both permits fresh at rearm. Separately the existing supervisor owns one explicit command stimulus intended at A+15 ms. It must receive two distinct accepted permits in the live generation; the second does not itself create a command. Instrument the external-to-controller command ingress (supervisor commit and independent receiver observation) with same-clock bounds. Score actual arrival at +15 ms, not the control task's later consumption. If visibility occurs earlier than an independently timestamped consume, do not substitute the latter for ingress. Freeze which ingress observation can classify the exact tick before launch; an unresolved bracket is unqualified. The general ADR allows a separate command while both are fresh; +15 ms is the frozen positive case, +20 ms the separate expired-first negative. Record an off-nominal command without inventing a product rejection tolerance. The test supervisor withholds positive authorization on uncertainty. Never synthesize an enable, clear a timing fault or bypass rearm. Independent PL061 transition/readback remains mandatory.
3. **Headroom and bounded waiting.** Before admitting the configuration fix dispatch, wake, mask/IRQ, instrumentation, receiver and publication worst bounds and guard using recorded same-clock intervals and analytic assumptions. Let Rk be the original release, T the anchored target and Dk=Rk+10 ms. Require Rk≤T<Dk and worst completion ≤Dk; if the latest possible ready/prepare instant exceeds T, mark infeasible. Reserve CPU for bounded final sampling, commit and restoration/SVC within the 750 µs sender cap across *all* slices. Charge setup, enqueue, wait programming, wake IRQ, restore and observer to the responsible budgets or system interference exactly once. Sleeping consumes elapsed response time; spinning and IRQ-masked work consume CPU and can interfere with control. Use one checked timed continuation of the same ordinary worker, with IRQs enabled while waiting and a predeclared final polling limit bounded by remaining service, masked-time and deadline margins. Keep control compare priority and original absolute epoch if multiple timer deadlines coincide. No wait or retry past the first qualifying opportunity. If already too late record actual timing, one missed index, preserve pending IRQs and inhibit the test. Enforce unchanged control 250 µs, IRQ 0.5 ms, phase 1 ms, check spacing and job finish each 5 ms, sender finish 10 ms. Check consecutive overhead and command path interference; unused budget in a previous job cannot fund the next.
4. **Feasibility and controls.** Even when ready on time, an IRQ, counter read granularity or multi-tick store bracket can make exact equality unobservable. If available platform ordering/measurement cannot produce a defensible singleton, report the exact case unqualified and retain interval evidence. No release-triggered timestamp stamping, hardware-issued permit, alternate command schedule, widened acceptance window, warm-up, selective retries, or output-on experiment on an ambiguous pair. An independently timestamped device/external stimulus or revised time contract would require new upstream approval and a separately attributed test. Preserve input-gate invalidation, expired/old/future generation data handling and existing fail-inhibit. Test missing second permit, early command (discard; require a new one), exact expiry/arrival tie, command at +20 ms, one-tick early/late issue or command, multi-tick bracket, missed wake, ordinary budget overrun and a second write. Evidence must expose these failures. Score fault→detect ≤25 ms, detect→device OFF ≤5 ms and total ≤30 ms only after independent ON, normal delivery and actual atomic fault injection.
5. **Separate experiments.** Freeze A0 as the existing descriptor, A1 as a measurement/ownership-only arm (identical receiver, visibility probes and command fixture, nominal publication targets), A2 as A1 with first-publication anchoring alone. Any new command-pacing change is A3, compared only with A2; keep sender arbitration unchanged. First run matched A0/A1 and A1/A2 pairs for RM and DM in both AB/BA orders (16 default-clock cold boots) on native Linux storage, first launch retained. Use the same per-policy artifact for each repeat, hashes/argv, actual ELR/ERET, counter frequency/resolution, raw rows and scoped PL061 evidence. Score first and later issues, releases, charged service, delivery, command ingress and rising edge per run. Preserve all denominators, including infeasible and uncertain runs. Run deterministic instruction counting as a separately identified functional experiment (one A1/A2 pair per policy); no substitution for default-clock time. An isolated command correction or full fault replay follows its own freeze. No EVD, product timing or approval is assigned by this plan.

## 한국어

**설계 결정.** 일반 RM/DM 송신 작업의 절대 10 ms 릴리스와 10 ms 마감을 유지한다. 새 세대의 첫 **실제 게시**만 이후 발행 목표의 기준 A로 삼는다. 타이머는 같은 작업을 깨우고 허가는 일반 송신자만 게시한다. 24회 중 DM 기술자 14·15만 모든 시간 기준을 충족했다. 7건씩 수용했지만 첫 발행 간격은 정확한 625000틱보다 각각 35033·42998틱 짧았고 독립 명령은 기준보다 1·7틱 늦었다. 두 실행 모두 래치 없이 OFF였다. 현재 송신 경로는 릴리스+0.5 ms 목표에서 실제 시각을 읽은 후 기록·큐 삽입·동기식 전달을 수행한다. 발행 전 표본만으로 게시 완료 시각을 확정할 수 없다. [ADR-001](safety-parameters.md) · [#122](https://github.com/Romanof123/JNOX/pull/122) · [#124](https://github.com/Romanof123/JNOX/pull/124)

1. OFF·빈 단일 레코드·새 세대로 시작한다. 일반 송신자가 페이로드를 준비하고 순서화한 실제 발행 시각 I를 필드에 넣어 단 한 번 게시하고, 저장 완료 뒤 U를 읽는다. 게시 시점은 [I,U]다. I=U이고 실제 가시성과 유일한 순번을 확인해야 첫 기준 A를 확정한다. k번째 목표는 A+k×625000틱이다. 두 사건 간격의 하한 L2−U1과 상한 U2−L1 전체가 정확한 요구값일 때만 입증한다. 단측 표본·목표·사후 시각·재게시·재시도·기준 이동은 허용하지 않는다. 빠름·늦음·경계 불명은 구분한다.
2. 송신자 스택 밖의 일반 제어 위상에서 수신자가 게시 완료 순번·페이로드를 획득해 실제 전달 구간을 기록하고 세대·연속성·나이를 검증한다. 만료 동시에는 만료 우선이며 같은 레코드 재독은 상태를 진행시키지 않는다. 두 신선 허가와 별도 감독자 명령이 필요하다. 감독자의 한 번뿐인 게시, 제어기 외부 명령 입력의 실제 수신 구간 및 나중의 소비를 독립 기록한다. +15 ms는 동결된 성공 자극, +20 ms는 첫 허가 만료 대조다. 일반 ADR의 신선 상태 재무장과 구분한다. 시각 불확실 또는 승인 미충족이면 시험 출력은 OFF로 유지하며 래치 우회 없이 독립 PL061 전이를 확인한다.
3. 원래 릴리스 Rk≤목표 T<Rk+10 ms와 최악 완료 마감, 준비·복귀·IRQ·마스킹·게시·수신·계측 상한을 사전에 검사한다. 최악 준비가 T 이후이면 수용하지 않는다. 대기 중 IRQ 허용, 같은 작업의 한 번만 가능한 타이머 재개와 예산 안의 짧은 최종 폴링을 사용한다. 잠든 시간은 응답 시간에, 바쁜 대기와 마스킹은 실행/간섭에 반영한다. 모든 송신 슬라이스 합계 750 µs, 제어 250 µs, IRQ 0.5 ms, 위상 1 ms, 판정 간격·작업 마감 5 ms와 송신 마감 10 ms를 유지한다. 깨우기·IRQ·복귀 비용을 한 번씩 귀속한다. 타이머 충돌 시 원래 제어 우선순위·기준을 보존한다. 늦은 경우 실제 누락을 기록하고 차단한다.
4. 준비 여유가 있어도 인터럽트·해상도·저장 구간 때문에 단일 틱 입증이 불가능할 수 있다. 그러면 미입증으로 남기며 허용 오차·대체 시각·재시도로 승인하지 않는다. 하드웨어 발행이나 명령 계약 변경은 별도 승인 대상이다. 두 번째 허가 누락, 조기 명령 폐기, 만료·도착 동시, +20 ms 명령, 한 틱 빠름/늦음, 다중 틱 구간, 깨우기 누락·예산 초과·중복 게시를 대조한다. 독립 ON 관측과 실제 고장 주입 후에만 25/5/30 ms 구간을 평가한다.
5. A0 기존 기술자, A1 동일 명목 목표로 수신 소유권·계측과 명령 자극만 도입, A2는 A1에서 게시 기준만 변경한다. 명령 페이싱 수정은 별도 A3다. 기본 시계에서 A0/A1·A1/A2를 RM/DM별 AB/BA로 비교해 16회 콜드 실행한다. 결정적 명령 계수는 각 정책당 A1/A2 한 쌍으로 별도 판정한다. 네이티브 Linux 저장소와 첫 실행·실패·해시·원시 카운터·복귀·장치 증거를 유지한다. 상한 미정·불확실·실패도 분모에 포함한다. 제품 판정과 구현·검증 근거는 미완료다.

## Refused admission and inhibited characterization / 수용 거부와 출력 차단 계측

**Scope and accounting.** Under [#129](https://github.com/Romanof123/JNOX/pull/129) engineering may characterize the virtual A1/A2 paths while the PL061 output is forcibly inhibited. Sample maxima from QEMU cannot supply qualified WCET, wake, IRQ or mask bounds. For every intended operational attempt, freeze the manifest and evaluate admission first. Missing qualified costs produce an immutable refused-admission record identifying the missing inputs, policy, arm and trial index; no operational job is launched. Preserve the original 16 default-clock trial positions and four deterministic trial positions with their respective clock labels; record passes, failures, refusals and uncertain outcomes explicitly. A characterization is a separate record and cannot replace a refused position, enter the positive numerator, or retrospectively qualify the same ELF. A genuine arithmetic impossibility, invalid configuration or unusable counter also prevents any dependent diagnostic from running; report a planned but unexecuted position.

**Predeclared characterization cohort.** On native Linux storage use A1/A2 only, RM and DM, AB/BA per policy (eight default-clock cold attempts). Separately run one deterministic A1/A2 pair per policy (four attempts). Prefix records with characterization, policy, clock, pair and ordinal, and link any corresponding refusal. Freeze hashes, default affinity/clock and order before launch. Keep first failures and missing data; no best-run substitution. Start OFF in a separate simulator-only image/entry with a hard OFF policy at the actuator interface: every enable request is recorded as hypothetical and cannot write ON, including through supervisor, diagnostic or fallback paths. An independent device-side observer verifies initial OFF before workers start, observes every transition/write attempt and samples terminal OFF. Verify observer coverage with a separately identified synthetic trace containing a transient ON. Initial/final samples alone cannot exclude a transient; lost observer coverage invalidates the characterization. A real ON, clamp failure or unexplained readback is a containment failure: stop immediately, request/verify OFF and retain the full record. No runtime knob, rearm command or subsequent successful sample can lift this inhibit.

**Execute and stop.** On this independent inhibited entry, missing cost bounds may permit collection of measurements only under the existing finite workload/horizon and host timeout. Run the actual ordinary worker, one bounded continuation and at most one real publication per scheduled opportunity; A1 retains nominal targets and A2 needs a classifiable first anchor. A separate receiver observes and validates committed records and a separately owned supervisor supplies the one-shot command through its measured ingress. Do not substitute the sender's log for either. Stop a dependent A2 series on an unclassifiable first anchor; preserve the bracket and unexecuted indices. Record original release, readiness, sleep programming, wake/IRQ and mask brackets, context return, each charged CPU slice, actual issue/commit brackets, receiver acceptance/rejection, command ingress/consumption and actuator observation on the same counter. Sum all sender slices including bounded waiting work, report elapsed sleeping and system interference separately, and retain measured values against the unchanged 750 µs/10 ms sender, 250 µs control, 0.5 ms IRQ, 1 ms phase and 5 ms control limits. A breached operational threshold, skipped phase, missed wake, unexpected owner, expired permit or ambiguous critical timing takes its designated stop/expiry/inhibit path with actual time and pending IRQ evidence. Do not continue past a prescribed stop to collect another attempt. Report hypothetical eligibility only where all observed data support it, with uncertainties and missing bounds attached. All characterization attempts remain operationally unqualified, including apparent exact matches. No healthy rearm, ON→OFF loss response, transferable WCET or product timing approval is established here.

**범위와 분모.** 엔지니어링 권한은 PL061 출력을 강제로 끈 QEMU 전용 A1/A2 계측에 한정한다. QEMU의 관측 최댓값은 검증된 WCET·깨우기·IRQ·마스킹 상한을 제공하지 않는다. 원래 기본 시계 16개와 결정적 시계 4개 자리마다 먼저 정해진 입력으로 수용 판정하고, 상한이 없으면 누락 항목·정책·구성·순번을 적은 거부 기록을 고정한다. 거부된 운영 작업은 시작하지 않는다. 성공·실패·거부·불확실을 모두 원래 시계별 분모에 남긴다. 별도 계측 기록은 이 거부를 대체하거나 정상 성공 수에 들어갈 수 없다. 잘못된 구성·산술 불가능·사용 불가능한 카운터가 진단에도 영향을 주면 해당 진단 자리를 미실행으로 기록한다.

**대상과 출력 차단.** A1/A2, RM/DM별 AB/BA로 기본 시계 8회, 결정적 시계는 정책별 한 쌍씩 4회를 별도로 선언한다. Linux 기본 파일시스템, 이미지 해시·시계·순서·관련 거부 기록을 고정한다. 최초 실패와 누락을 보존한다. 전용 시뮬레이터 이미지의 출력 인터페이스는 모든 ON 요청을 가정상 사건으로만 기록한다. 감독자·진단·대체 경로·재무장 명령으로 차단을 해제할 수 없다. 독립 장치 관측기가 작업 전 OFF, 모든 쓰기 시도와 전이, 마지막 OFF를 확인한다. 일시적 ON을 넣은 별도 합성 기록으로 관측 판정기를 확인한다. 처음과 끝 OFF만으로 중간 상태를 보장하지 않으며 관측 누락은 무효다. 실제 ON·차단 실패·설명되지 않는 읽기값은 즉시 중단하고 OFF 요청·확인과 원본 기록을 남긴다.

**실행과 종료.** 비용 상한만 없을 때에는 유한 관측 구간·호스트 타임아웃 안에서 실제 일반 송신자의 한 번의 제한된 재개와 기회별 최대 한 번의 게시를 측정한다. A1은 명목 목표, A2는 입증된 첫 게시 기준을 사용한다. 기준을 판정할 수 없으면 그 구간과 미실행 인덱스를 남기고 의존 계열을 중단한다. 수신자는 실제 게시 기록을 독립 검증하고 감독자 명령의 입력·소비를 별도로 관측한다. 같은 카운터로 실제 릴리스·대기·깨우기·IRQ·마스킹·복귀·슬라이스별 과금·게시·수신·명령·출력을 기록한다. 송신 750 µs/10 ms, 제어 250 µs, IRQ 0.5 ms, 위상 1 ms, 제어 5 ms 한계는 유지한다. 잠든 시간과 시스템 간섭을 분리한다. 위반·위상 누락·깨우기 실패·소유자 오류·허가 만료·중요 시각 불확실은 기존 중단·만료·차단 절차와 실제 대기 IRQ 증거를 보존한다. 가정상 적격성은 해당 표본 범위에서만 보고한다. 정확한 틱을 관측해도 운영 적격, 정상 재무장, ON→OFF 고장 응답 또는 제품 시간 승인이 되지 않는다.
