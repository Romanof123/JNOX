# 고정 우선순위 런타임 비용 측정 설계

한국어 · [English](fixed-cost.en.md)

#90, CHG-043, IMP-041, [EVD-041](evidence/evd-041.md). 동일한 virt 단일 CPU FIFO/RR 앱에서 비용 계측 및 스케줄러 추적을 각각 켜거나 끈 네 조합을 비교한다. 조합당 콜드 부트 3회와 모든 실패 기록을 보존한다. 소스 차이, 도구 버전, 선택자, ELF 및 해시, nm -S, readelf -lW/-SW, size -A, 실행 인수, UART, 예외 로그, QMP 유휴 PC와 원시 RAM을 남긴다. 이미지별 파일 크기, 할당 섹션, PT_LOAD 파일/메모리 크기, 심볼과 스택 예약량을 구분한다. 16 KiB 스택 다섯 개 중 하나는 미사용이며 부트 스택은 측정 범위 밖이다.

Rust 핸들러 진입 후, 과금과 선택을 포함하는 Fixed::event 전후, 타이머 설정과 다음 프레임 선택 후에 ISB/MRS CNTPCT_EL0/ISB 순서로 읽는다. 명령별 및 동일/교체 프레임별 표본 수와 최댓값을 계산한다. 나노초는 경과 틱 × 10억 / CNTFRQ_EL0이다. 벡터 진입, 어셈블리 저장과 복원, 함수 프롤로그와 에필로그, ERET는 제외한다. 외부 구간에는 IRQ 승인 또는 SVC 해독 및 활성화된 추적 기록이 들어간다. 부팅 시 연속 판독 차이도 보존한다. 판독 비용을 일괄 차감하지 않는다. 기록 쓰기와 캐시 변화는 다음 이벤트 시각에 영향을 줄 수 있다. 비계측 이미지는 정적 크기와 동작 대조군이다.

최초 프레임 생성 전 사용 슬롯과 유휴 스택을 한 번만 0xA5로 채우고 초기 프레임은 0으로 지운 뒤 구성한다. 정지 시 가장 낮은 변경 주소로 사용 흔적을 계산한다. 같은 값 재기록과 SP만 이동한 공간은 놓칠 수 있으며 초기 프레임도 포함한다. 앱 스택 3개와 유휴 스택, 미사용 BSS 보존, 양의 주파수, 중첩 구간 순서, 비어 있지 않은 기록, 넘침 0, 두 앱의 IRQ 교체 및 종료, FIFO 양보·수면 및 동일 프레임 복귀를 요구한다. 공개 실행기의 UART 판정과 단일 CPU 유휴 PC도 확인한다. 수치 한도, WCET, 실기 시간 또는 안전 인증을 주장하지 않는다.

Linux/WSL의 실행 명령은 [영문 실행 예시](fixed-cost.en.md#capture-on-linux-or-wsl)를 따른다. 비활성 선택자는 환경에서 제거한다. 스택 81,920바이트와 기록 7,208바이트를 심볼에서 대조한다. PT_LOAD 물리 구간은 virt RAM(시작 0x40000000) 안에서 서로 겹치지 않아야 하며 파일 길이는 메모리 길이 이하여야 한다. 섹션과 패딩 변화를 기록하고 추가 스택 예약이 없는지 확인한다.
