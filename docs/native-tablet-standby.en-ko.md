# CHG-343 · Tablet ownership after compositor failure / 합성기 고장 후 태블릿 소유권

REQ-015 and REQ-024, DES-009 and DES-013, VER-015 and VER-024. This integration covers the native QEMU virt display lease, compositor fault isolation and control continuity in issue #457. IMP-343 implements the combined path. Acceptance measurements are pending.

## Lease and reset / 소유권과 리셋

Only the initialized display lease holder can acquire or read the tablet through SVC 197. A primary assertion retires the owner and closes its broker connections. Before launching slot 2, masked EL1 invalidates buffered input, resets the device and reads back status zero and both QueueReady bits clear. Only that acknowledgement permits clearing the DMA backing. A quarantined tablet or a failed reset or interrupt mask check prevents spare launch. An absent tablet exposes only the keyboard. Clean primary exit dismisses the spare. Spare exit or failure ends the lease. Each process owns its own Wayland connection, pointer resources and implicit grab. The surviving client drops old pressed and focus state on EOF.

초기화된 디스플레이 소유자만 SVC 197로 태블릿을 획득하고 읽을 수 있다. 주 합성기가 예외로 종료되면 커널은 연결을 닫고 대기 중인 입력을 폐기한다. 장치 상태가 0이고 두 큐의 QueueReady가 모두 0임을 읽은 후에만 DMA 메모리를 비운다. 리셋 또는 IRQ 마스킹을 확인할 수 없거나 장치가 격리되면 예비 합성기를 기동하지 않는다. 주 합성기가 정상 종료하면 예비 슬롯을 해제한다. 예비 합성기까지 종료되면 소유권은 소멸한다. 클라이언트는 EOF에서 포인터 포커스와 눌림 상태를 폐기하고 새 연결에서 포인터를 다시 요청한다.

## Serial gate / 순차 검증

Build the five-role package from the repository root on Linux or WSL. Use a fresh output directory. The optional Cargo feature enables the deliberate compositor exception in this test executable. Both compositor slots use the same ELF. The package includes separate client, broker and controller processes. On the same image without a virtual tablet, the client uses the advertised keyboard to drive repaint and recovery. / Linux 또는 WSL에서 새 출력 디렉터리를 지정한다. 시험용 Cargo 기능은 합성기 예외 주입을 활성화한다. 같은 이미지를 태블릿 없이 부팅하면 앱은 좌석이 알린 키보드로 화면 갱신과 복구를 진행한다.

sh verification/wayland/build-tablet-recovery.sh /tmp/jnox-tablet-recovery
(cd /tmp/jnox-tablet-recovery && sha256sum -c SHA256SUMS)

Add `--pointer-tablet`, replace the client argument with `--peer-arg reconnect-pointer`, and keep the primary and spare compositor restart roles. Attach `-global virtio-mmio.force-legacy=false -device virtio-tablet-device`. Resolve each private witness with its slot's linked TTBR0 root. Check one real down and zero ups on the client wire, one palette change and its frame callback. Send the #449 UART assertion byte while QEMU's left button is held. 3. Wait for the survivor's second mapped frame, fresh pointer binding and slot 2 acquisition. Before injecting new input, capture the replacement's wire journal, pixel image and client counters. Both press and release counts must start at zero. Run `python3 tools/native_tablet_qmp.py SOCKET KERNEL NEW_SPARE_DIR --epoch spare-click --points 80 70 0 0`. The first packet physically releases the held QEMU button. Require its DMA completion but no unmatched Wayland button release and no redraw caused by that release. Require a fresh enter at surface-local (64,46), one down/up pair, one palette change and a matching external frame. Finish with UART q, or induce a second assertion for spare-exhaustion coverage. A QMP acknowledgement alone does not establish guest delivery.

Compare the two rows of `jnox_tablet_generations[2][7]`: owner+1, acquisition tick, raw event sequence at acquisition, retirement tick, final sequence, remaining software events discarded and terminal phase. Require primary retirement before spare acquisition, consecutive sequence boundaries and a fresh spare queue. Exercise status timeout and nonzero QueueReady with the reset protocol's faulty transport controls; verify the reclaim callback is never invoked and the lease refuses the spare. #449의 5개 슬롯 FIFO 패키지에 태블릿을 추가하고 클라이언트 인자를 `reconnect-pointer`로 바꾼다. 첫 프레임에 QMP로 이동과 누름만 보내고, 앱의 색 변경을 확인한 후 버튼을 누른 채 주 합성기에 예외를 유발한다. 예비 합성기의 새 연결·프레임·큐를 확인한 후 기존 버튼을 물리적으로 뗀다. 이 해제는 DMA에 도착해야 하지만 새 클라이언트에 짝 없는 해제 이벤트나 화면 변경을 만들어서는 안 된다. 새 위치로 이동한 후 누름과 해제를 보내 로컬 좌표, 포커스, 색 변경, 외부 화면을 대조한다. 정상 종료, 두 번째 고장, 리셋 확인 실패, 장치 없음, 태블릿 없는 기존 설정을 독립적으로 검증한다. 소유권 세대, 소켓 메시지, 실제 DMA 데이터, 제어 앱의 4,096개 완료 시각을 함께 보존한다. 가상 장치 시험과 리셋 모델 시험의 결과를 구분한다.
