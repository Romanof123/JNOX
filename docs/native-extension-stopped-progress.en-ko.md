## Revised source-built comparator after the first preflight / 최초 사전 검증 이후 소스 기반 대조군

The [first preflight](evidence/native-extension-stop-first-preflight.en-ko.md) produced six builds, rejected both ordinary-to-fixture comparisons and ran zero guests. The inline Rust operand changed actual instructions in the timer and settlement paths. Supersede that implementation with the following fixed source entry. Preserve the original 12 + 12 ordinary releases, the linked controls and both rejected firsts. The eight fault/control positions and their timing criteria remain as specified above.

**One interface.** In the native extension profile, after a successful masked `tx.begin()` on the private evaluator stack, call exactly one AAPCS64 assembly function `jnox_extension_evaluator_enter(cell: u64)` with the copied transaction cell in x0. Make the Rust declaration and call identical in every member of a position. The external call permits memory effects. Both implementations start with the ordinary IRQ unmask and ISB. The ordinary source returns immediately; it has no bench selector, selector reference or loop. The fixture source reads its own aligned two-word immutable table, compares x0 without writing flags (caller-saved scratch registers), then returns or enters the named single-instruction self-branch. It touches no stack, callee-saved register, transaction, timer or interrupt controller. Both enter with IRQ masked and may return unmasked. Keep evaluation, re-mask/ISB, publication, stack-switch/abort and PPI consumer in their existing trusted paths. An interruption before the loop has its own observed PC and cannot score as interruption at the loop.

**One compilation per position.** Use the current application packager, its frozen ELF/argv inputs, kernel Cargo target/profile, build script and normal linker script. Remove the old fixture-only Rust operand, cfg and embedded table from the trusted compilation. For the extension profile alone, build the named external function from one checked-in AArch64 assembler source with three fixed variants, ordinary/dormant/active. Pass the selector only to assembly generation from the frozen position enum (A 1,3 or B 9,MAX; dormant MAX,MAX). The narrow cohort command installs a final-link driver for the kernel target. At the single Cargo link invocation, give the real pinned linker the same ordered emitted Rust object files, libraries, flags and script three times, appending one named assembler object per link and selecting the corresponding output file. The driver returns the ordinary result to Cargo. Archive the exact response files, object/library bytes or replayable content-addressed inputs, command lines, assembly bytes, linker identity and all three ELF maps while temporary inputs exist. Ordinary standalone packaging links just the ordinary source. No finished ELF is an input to construction; no kernel write, debugger or arbitrary patch-site option is involved.

**Byte boundary.** Give the source entry the same fixed aligned RX extent in all variants (e.g. 64 bytes, checked by the assembler, padded after an unconditional return or loop). The linker puts the optional 16-byte selector in its own RO input/output section after shared read-only data and before the existing writable alignment; ordinary has no selector section or symbol. Retain the original linker script for other profiles. Inspect actual loaded intervals; reject displaced shared symbols or changes to a shared instruction, branch target, literal, data byte, mapping or permissions within a position. Seal ordinary receipts and position-specific equivalence gates before the existing eight fixture firsts. Record all failures and unavailable evidence. A qualified ordinary release or matched-object proof alone does not establish live injected recovery, actual late publication, hardware timing or family release.

**단일 진입점.** 개인 평가기 스택에서 IRQ를 막은 상태로 실제 거래 사본을 만든 뒤, 모든 구성의 동일한 Rust 코드가 x0에 해당 셀을 담아 고정된 AAPCS64 함수 하나를 호출한다. 일반·벤치 어셈블리 모두 같은 IRQ 허용과 ISB로 시작한다. 일반 함수는 바로 복귀하고 선택표나 루프를 포함하지 않는다. 벤치 함수만 읽기 전용 두 셀과 비교해 복귀하거나 자기 분기한다. 스택·플래그·보존 레지스터·거래·타이머는 변경하지 않는다. 기존 평가·재마스킹·게시·IRQ 복구 경로를 유지하고, 루프 전 중단은 루프 중단으로 판정하지 않는다.

**빌드와 바이트 검증.** 최초 6개 빌드와 두 사전 검증 실패, 게스트 0회 및 기존 일반 부팅 12+12회를 보존한다. 이전 Rust 조건부 후크와 테이블을 제거한다. 각 위치에서 기존 패키저와 Cargo가 신뢰 커널을 한 번 컴파일한다. 최종 링크 드라이버는 동일한 오브젝트·라이브러리·스크립트·옵션 순서에 버전 관리되는 단일 진입 함수의 일반/휴면/활성 어셈블리 오브젝트만 각각 추가한다. 실제 링커 입력·해시·지도·명령을 임시 파일 소멸 전 보관한다. 완성 ELF 수정은 허용하지 않는다. 다른 프로파일에는 기존 링크를 적용한다. 세 함수의 정렬된 RX 크기를 고정하고 선택표는 공유 RO 뒤의 독립 영역에만 둔다. 같은 위치에서 모든 공유 명령·데이터·주소·권한·컴파일러 입력의 동일성을 독립 검증하고 일반 단독 빌드도 재현한다. 휴면/활성 적재 차이는 선택표로만 제한한다.

**새 기준선.** 역사적 A 재현과 B의 동일 입력·이전 소스 재빌드, 최초의 패닉 줄 기록과 타이머 명령 차이를 그대로 남긴다. 새 공통 호출이 들어간 일반 커널은 별도 기준선이다. 이전 바이너리 동등성이나 지연 수치를 승계하지 않는다. 원래 6개 일반 구성의 일반·외부 추적 12회, 공유 거래·변이 및 연결형 일반/정지 대조군을 기존 기준으로 독립 재검증한다. 역사적 B가 없으므로 B 일반도 현재 B의 순서·제품·시간 기준으로 일반/추적 최초 1회씩 추가한다. A 재사용은 입력과 바이트가 같을 때만 허용한다. 위치별 동등성 및 기준선 영수증 봉인 후 기존 8개 벤치 최초 취득을 진행한다. 실시간 복구·늦은 게시·보드 지연·제품군 출시 판정은 각각 해당 증거가 필요하다.
