Freeze the launch, toolchain, compiler/linker flags, map, symbol ranges, section bytes, disassembly and selector contents before capture. Identify the hook block and its return into the original evaluate path. 통합 증거의 세 ELF 원본과 규칙·도구·옵션·해시를 고정한다. 기존 명령은 다섯 번 인출하면 종료하므로 일반 커널은 원본 그대로 보존한다. 벤치 전용 빌드에서만 실제 거래 시작과 IRQ 허용·ISB 직후, 평가와 게시 전에 지정 셀이 자기 자신으로 분기한다. 이 루프는 평가기 스택과 기존 타이머 상태를 그대로 사용한다. 휴면 대조군은 빈 선택표를 쓴다. 각 쌍의 실행 코드 바이트와 일반 빌드의 적재 바이트를 대조한다. 일반 코드와 벤치 코드 사이에는 후크 밖의 동일 심벌·오프셋을 가리키는 개별 재배치 피연산자만 허용한다. 인라인 코드까지 대조하고 설명되지 않은 차이는 보류한다.

Establish the ordered stack-switch, cutoff exception, `.Lidle_irq`/extension abort to the caller stack, single genuine acknowledgment, production consume, next nominal compare and chosen return/idle path from vector disassembly and bounded trace. * Reconcile every opening snapshot, ready mask, last heartbeat, publication stamp, cancellation, fuel, reason, eligible owner, grant, counter, compare and service end against the cell schedule. 각 고장 셀의 실제 D 설정, 타이머 허용, IAR 30, 진입 카운터, 예외 PC·PSTATE·중단 전 SP를 연결한다. 외부 추적에서 EL1h, I=0, 루프 PC, 해당 ELF 전용 스택 범위와 실제 마지막 TTBR0/ASID를 확인하고 페이지 테이블을 독립적으로 순회한다. 인터럽트 후 원래 호출자 스택 복귀, 단일 승인, 실제 소비 및 다음 명목 비교값과 앱 복귀 또는 유휴까지 추적한다. 거래 사본 폐기와 하트비트 불변, 예약 우회, 종료 시 타이머 취소를 확인한다. 중복·오래된 응답 거부의 근거는 공유 로직 대조군이다. 이 루프에서는 뒤늦은 게시가 발생하지 않는다. 실제 늦은 게시를 주장하려면 별도 사전 정의한 관측이 필요하다.

표의 모든 셀에서 실제 첫 작업 또는 마감 후 유휴 진입이 S+Q/2 전이고 운영 종료 IRQ가 [S+Q,S+Q+Q/4) 안인지 확인한다. 앱별 복원 PC·SP·루트, 사유 메모리의 각 누적값 및 종료 코드를 대조한다. 소스·명령·입력·해시·역어셈블리·레지스터·원시 추적·페이지 순회·거래 행과 개별 판정을 보관한다. 반례는 실패, 핵심 관측 누락은 미검증으로 기록한다. 모든 대조·고장군이 충족된 경우에만 해당 가상 환경의 주입 고장 복구를 인정한다. 실제 고장 빈도, 보드 지연 및 제품 출시는 별도 사항이다.
