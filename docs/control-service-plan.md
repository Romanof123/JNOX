# CHG-053 · Ordinary control service and first dispatch / 일반 제어 서비스와 최초 디스패치

[#94](https://github.com/Romanof123/JNOX/issues/94) · [#111 / EVD-050 v2](https://github.com/Romanof123/JNOX/pull/111) · [FS-M3-01 / CHG-044](pol-004-m3-control-plan.md) · [CHG-049 cold-start design](https://github.com/Romanof123/JNOX/issues/109)

## English

**Decision proposed for the virtual bench.** Diagnose the measured service interval first. In EVD-050 v2 all 128 native-Linux-filesystem default-clock boots overspent the 15,625-tick control cap; first overspends were 15,992–42,570 ticks at 62.5 MHz. The first latch was service in 93 and phase time in 35. All latched before permit 1; all had seven rejected permits. First issue gaps were 522,071–605,466 ticks against exactly 625,000. The fw_cfg repair admitted 96/96 requested diagnostic modes. These are separate observations. The earlier 128-run sentinel cohort remains separately attributable.

**Accounting and implementation hypothesis.** The archived b9db104 RM diagnostic ELF is freestanding release, optimized for size (Cargo opt-level s). Its control symbol is 0x40203120, size 0x2b8. Disassembly shows repeated DAIF save/mask/restore, UDIV at 0x402032a4, call to check at 0x402032b4 and SVCs at 0x4020338c/0x402033d0. The select path stamps slice_start before returning the frame; account charges through exception entry. Restoration and entry overhead therefore contribute to charged service. Check completion and SVC entry are distinct. Compare an actual stock image's symbols separately. In the first individual.json record, phase 0 target/IRQ/check completion/phase-return were 226881/238286/297998/301187; its first overspend was 37908 ticks. This row alone cannot separate dispatch or translation latency from intrinsic evaluation. [Frozen source](https://github.com/Romanof123/JNOX/tree/b9db1043588fcb78cb44aae00fdd028199754538/kernel/src)

1. **Baseline and measurement.** Use the archived ordinary healthy stock bytes (e0f0ce6 v2) and hash-matched source build as control. Version and hash any different baseline before pairing. Preserve row 6 slices, row 8 debit, rows 21/10 decision and phase completion, actual ELR/ERET sequence and outcome. Add a diagnostic-only arm with preallocated raw records: absolute release/IRQ vector, selection, final return path, first worker instruction, decision start/end, SVC and next handler entry. Record ordered same-counter brackets, actual masked regions and interrupted PCs. Attribute pre-worker delay, restore/entry, worker computation, masked duration and trace writes separately, reconciling the full unchanged debit across preemptions. Record first phase, later first-of-job phases and same-job continuations separately. Instrumented deltas are observations of that image; preserve uninstrumented results. No dummy first dispatch or warm-up.
2. **Ordinary intervention.** On a separate uninstrumented source arm carry the immutable release index, absolute phase targets and step in a private bounded per-job descriptor initialized at ordinary release; replace the worker’s repeated release reconstruction/divide with checked loads. Preserve job generation and same-worker continuation, check missed work under the existing synchronization, do not lengthen an IRQ-masked region, preserve fresh issue/decision timestamps, expiry priority, synchronous latch/device actions, readback, independent counters and fail-inhibit. Include descriptor setup and any shifted cost in release-to-decision/job bounds and whole-system accounting. Verify initialized descriptors across consecutive jobs and new cold starts. Compare this one source change at opt-level s against the baseline. Independently compare opt-level 3 vs s on identical unmodified source with all other flags fixed. Inspect compiler invocations, source/ELF hashes, generated instructions and section footprints; code size alone supplies no timing verdict. Do not combine optimization and source changes in the first comparison. Consider deferring nonessential formatting only in a later isolated arm, retaining raw event time/order, bounded storage and all acceptance evidence.
3. **Small discriminating study.** Default clock, native Linux /tmp for every runtime path, original QEMU/CPU/options and cold timeout. Pair RM and DM separately; two counterbalanced cold pairs per policy per comparison (baseline vs markers, baseline vs descriptor, baseline vs compiler). This is 24 cold boots before optional follow-up. Keep logging configuration identical within each pair; run a separately paired external IRQ/ERET trace for attribution if the original arm lacks it. Retain first failures, hashes, argv, clock frequency, host paths and raw data, including no-launch and truncation. Use common boot-relative phase indices without pooling unrelated clocks. If improvement disappears without instrumentation, report that dependence. Promote only a frozen candidate to independent full workload replay. Maintain 0.5 ms IRQ, 1 ms phase, 250 µs charged service, real ≤5 ms decision spacing and ≤5 ms job finish, 25/5/30 ms fault intervals, late/demand forced failures and separate exact worst-phase/tie controls. Distinguish a short-run service improvement, a qualified job, and the complete healthy output sequence.
4. **Independent permit obligation.** Sender nominal release at 10 ms does not establish exact issue spacing. On a separate arm only, use the approved exact-injector initialization and record actual issue, delivery and publication before transferring sole generation/sequence ownership to the ordinary sender. Score ordinary sender issue spacing separately. Equality requires recorded same-clock ticks exactly 625000 apart at this F, with adequate resolution/provenance; preserve independent delivery, command and device observation. Never replace actual issue with a target, retrospective store time or rounding. If exact timing cannot be observed, record unqualified and return any proposed tolerance or alternate issuance contract to Functional Safety; no product tolerance follows. No healthy pass or loss response follows merely from removing the service fault.

## 한국어

EVD-050 v2의 기본 시계 128회 모두 62.5 MHz에서 제어 서비스 상한 15,625틱을 넘었다. 첫 초과값은 15,992–42,570틱이며 최초 래치 원인은 서비스 93회, 위상 시간 35회였다. 첫 허가 전 차단되어 7개 허가가 모두 거부됐다. 첫 실제 발행 간격은 522,071–605,466틱으로 요구값 625,000틱에 미달했다. fw_cfg 진단 모드 초기화 96/96 성공과 이전 sentinel 집단 128건은 별도 결과다.

보관한 b9db104 RM 진단 ELF는 크기 최적화 s의 release 빌드다. control(0x40203120, 0x2b8바이트)에는 반복 DAIF 저장·마스킹·복원, UDIV, check 호출과 두 SVC가 있다. 선택기가 복귀 전부터 예외 진입까지 과금하므로 작업 계산 외 비용이 들어간다. 첫 원시 실행의 위상 0 목표/IRQ/판정 완료/위상 완료는 226881/238286/297998/301187, 첫 초과는 37908틱이었다. 이 기록만으로 최초 디스패치와 실제 판정 비용을 분리할 수 없다.

1. 원래 e0f0ce6 stock ELF와 해시가 일치하는 빌드를 기준으로 삼는다. 별도 계측 구성에서 같은 카운터로 IRQ·선택·복귀 경로·작업 첫 명령·판정 시작/끝·SVC·다음 핸들러와 마스킹 구간, 중단 PC를 기록한다. 외부 ELR/ERET와 대조하고 사건 6/8/21/10 및 기존 과금 전체를 보존한다. 최초 위상·후속 작업 첫 위상·같은 작업 재개를 분리한다. 워밍업이나 첫 작업 면제는 없다.
2. 일반 소스 변경은 릴리스 때 작업별 불변 인덱스·절대 목표·step을 길이가 제한된 전용 기술자에 저장해 작업 내 반복 계산·나눗셈을 대체하는 한 가지로 제한한다. 세대·작업 경계 초기화, 기존 동기화와 누락 검사, 마스킹 길이, 실제 시각, 만료 우선, 즉시 래치·출력 및 독립 읽기를 유지한다. 릴리스로 이동한 비용도 전체 시간과 마감에 반영한다. 이 변경은 s에서 비교하고, 별도로 변경 없는 동일 소스를 s와 3으로 비교한다. 도구 명령·ELF·코드·크기를 보존한다. 필수 사건의 기록은 유지하며 부수적인 출력 정리는 후속 별도 실험으로만 검토한다.
3. 기본 시계와 원 QEMU 설정·시간제한을 고정하고 모든 실행 경로를 Linux /tmp에 둔다. 계측·기술자·컴파일러 세 비교마다 RM/DM 각각 순서를 교차한 콜드 두 쌍, 총 24회를 우선 수행한다. 쌍별 로깅은 같게 하고 필요하면 별도 쌍으로 외부 예외 추적을 수집한다. 최초 실패·누락·메타데이터를 보존한다. IRQ 0.5 ms, 위상 1 ms, 과금 250 µs, 실제 판정 간격·작업 종료 각 5 ms, 고장 25/5/30 ms를 유지한다. 지연·과수요 실패 대조와 최악 위상·동시 만료 별도 시험을 유지한다. 소표본 개선으로 정상 출력이나 전체 검증을 승인하지 않는다.
4. 발행 간격은 독립 요건이다. 별도 구성에서 승인된 정확 시점 주입기로 실제 발행·전달·게시를 관측한 뒤 일반 송신자에 세대·순번을 단독 인계한다. 일반 송신자의 발행 증거도 별도로 평가한다. 정확한 10 ms에는 이 카운터에서 실측 625000틱과 충분한 해상도·출처가 필요하다. 목표값·사후 저장 시각·반올림은 사용할 수 없다. 불확실하면 미입증으로 남기고 허용 오차나 계약 변경은 기능안전 결정에 맡긴다. EVD-042/050 원본과 판정을 유지하며 제품 승인·구현·독립 검증은 미완료다.
## IMP-051 descriptor comparison arm / 작업 기술자 비교군

CHG-053 uses the release IRQ's existing counter-derived index and absolute release. Only a healthy periodic control job can select the descriptor variant. After the overlap check and before enqueue, it initializes five words in the control worker's fresh private exception frame. AArch64 entry arguments x0 through x4 carry the first index and target, second index and target, and step. The first target is the actual nominal release computed in the IRQ as epoch + floor((entry - epoch) / step) × step. That product is at most entry - epoch. The second target uses checked addition. The consecutive indices must describe an even first phase within the observation horizon. The ordinary worker takes those values by value and selects the current pair by indexing a two-entry array. Rust preserves live arguments across calls according to AAPCS64. SVC 1 preserves the same worker frame and stack for phase two. On a skipped release the existing missed-work path performs its final live check; it never consumes an uninitialized descriptor. The sender, decision, device and failure paths retain their existing code and timing criteria.

For the native Linux comparison, check out the candidate in a native /tmp directory, enter its kernel directory, clear unrelated JNOX selectors and use the pinned release configuration (opt-level s). Use a different native target directory per pair member. Example for RM:

```sh
export JNOX_BOARD=virt JNOX_PROFILE=periodic JNOX_APP=control-rm JNOX_CONTROL_CASE=healthy
unset JNOX_CONTROL_COLD JNOX_CONTROL_MARKERS JNOX_CONTROL_DESCRIPTOR
CARGO_TARGET_DIR=/tmp/jnox-rm-stock cargo build --locked --release
JNOX_CONTROL_DESCRIPTOR=1 CARGO_TARGET_DIR=/tmp/jnox-rm-descriptor cargo build --locked --release
```

Repeat with control-dm and separate DM directories. Manifest the source tree, explicit selector values, compiler invocations, sorted environment relevant to Cargo, ELF SHA-256, symbols, disassembly and section sizes. The selector is unset for stock or exactly 1 for the descriptor. The descriptor arm requires both the cold and marker selectors to be unset. The default build retains the zero-argument control entry and its original reconstruction path. Verify the stock binary against its archived hash; label any source build that differs. The descriptor arm emits the existing UART format, so its identity must come from the frozen ELF and launch manifest.

Descriptor construction executes with IRQs masked during the actual release. Row 34 includes that work, and the elapsed release-to-check and release-to-job-finish intervals include it. Compare the full handler and masking intervals, not just the worker's rows 6 and 8. The existing 250 µs debit, 0.5 ms IRQ envelope, 1 ms decision envelope and 5 ms spacing/deadline remain in force. Independent QA must determine whether any masked interval increased, confirm argument-register and resume behavior in the actual ELF, verify consecutive and cold-start generations, and reconcile accounting before claiming improvement. No source-only WCET or unchanged masking bound is established.

제어 작업을 실제로 릴리스하는 IRQ가 중첩 검사를 통과한 뒤 전용 예외 프레임의 x0~x4에 두 위상의 인덱스·절대 목표와 시간 단위를 한 번 기록한다. 두 번째 목표는 오버플로를 검사해 더하며 두 인덱스가 관측 범위 안에서 연속인지 확인한다. 일반 작업은 이 값을 인자로 받아 두 번째 위상까지 같은 작업과 스택에서 사용한다. 놓친 위상은 기존 경로에서 현재 시각으로 최종 평가한다.

위 명령에서 기본 비교군은 JNOX_CONTROL_DESCRIPTOR를 해제하고, 작업 기술자 비교군은 1로 설정한다. 두 비교군 모두 healthy, 기본 시계, 동일한 opt-level s를 사용한다. DM은 JNOX_APP=control-dm과 별도의 /tmp 경로를 쓴다. 기술자 구성에서는 콜드 및 마커 선택자를 모두 해제한다. 실제 ELF 해시·디스어셈블리·실행 명세로 비교군을 식별한다. 기술자 작성 비용은 IRQ 내에서 발생하므로 행 34, 릴리스부터 판정·종료까지의 시간과 마스킹 구간을 함께 비교한다. 행 6·8의 작업 과금만으로 비용 절감이나 마스킹 상한을 판단할 수 없다. 기존 한계를 그대로 적용하고 연속 작업과 콜드 부팅에서 재개 동작을 독립 검증한다.

| Kind | t, a, b (physical counter ticks / 원시 카운터 틱) |

| 1 | Original slice_start, selected task, selected ELR / 과금 시작·태스크·선택 ELR |
| 2 / 3 | Stock IRQ / SVC vector stamp, interrupted ELR, handler sample / 기존 벡터 표본·중단 ELR·핸들러 표본 |
| 4 | Restore-start, late restore sample, return ELR / 복귀 시작·복귀 후반 표본·복귀 ELR |
| 5 / 10 | Fresh entry / post-SVC continuation sample, zero or preceding phase index, zero / 신규 진입 또는 SVC 후 재개 표본·이전 위상 또는 0·0 |

| 8 | Actual decision, actual completion, phase index (stock row 21) / 실제 판정 시작·종료·위상 |

The vector sample follows the vector branch, frame allocation, scratch save and ISB. The first restore sample follows the callback return and SP switch. The late restore sample precedes its own store, GPR/LR restores, SP adjustment, CLREX and ERET. Fresh worker entry starts with ISB then MRS; neither that sample nor the continuation's ISB/MRS timestamps ERET. An arbitrary IRQ resume returns directly to the interrupted PC and may lack an immediate worker sample. Match individual ELR/ERET events against disassembly. Kind 2/3's handler sample includes copying the preceding restore marker. Release targets/entries remain in rows 2/3/4; check completion and SVC entry are distinct. / 벡터 표본 전에는 분기·프레임 확보·레지스터 저장·ISB가 있다. 복귀 시작은 콜백 반환·SP 전환 뒤이고, 후반 표본 뒤에는 저장·레지스터 복원·SP 조정·CLREX·ERET가 있다. 신규 진입과 SVC 후 ISB 다음 MRS가 표본을 얻는다. 임의 IRQ 재개에는 즉시 작업 표본이 없을 수 있다. 실제 ELR/ERET와 역어셈블리를 대조한다. 2/3행의 핸들러 표본에는 이전 복귀 마커 저장이 포함된다. 절대 목표·진입은 기존 2/3/4행에 남으며 판정 종료와 SVC 진입은 구분한다.

The decoder reconciles each charged slice and debit against stock rows 6/8, including splits at preemption. Actual phase indices identify phase zero, later first-of-job and same-job continuation. Disjoint ticks isolate measured in-slice journal writes, restoration, restore-tail to worker sample, check and remaining charged time. Control-mask brackets overlap those totals.
