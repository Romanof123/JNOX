# EVD-052 · Independent control-service marker replay and malformed-input checks

[CHG-053 / IMP-052](../control-service-plan.md) · [#124](https://github.com/Romanof123/JNOX/pull/124) · [EVD-051](evd-051.en.md) · [JSON](evd-052.json) · [ZIP](evd-052-marker-replay.zip)

The original and repaired decoders agreed with the independent interval and phase joins on four genuine EVD-051 RAM journals covering 104 phases. The original RAM/UART decoder reproduced its archived outputs. Disjoint cost totals matched for every service slice. The repaired decoder also checked ordered external IRQ/SVC and ERET events. Boot 02 marker 9 recorded start 273778, end 275568 and phase 0, a 1,790-tick decision interval. The independent addendum withdrew the earlier claim that the original decoder mislabeled genuine phases.

The repaired path rejected mirrored reversed endpoints, wrong phase, omitted or duplicated data, corrupted PC and terminal exception data. The archive retains per-journal commands, outputs, controls and exit statuses. The marker integration accepted baseline, descriptor, cold and marker arms individually. It rejected cold+descriptor, descriptor+marker and cold+marker. Integrated control images matched reference layout and instructions. Differences of 9–12 loadable bytes were confined to source-line metadata.

All six integrated control guests across two source heads reached terminal output. Operational qualification was 0/6. Descriptor-head RM and DM failed actual delivery and rearm issue spacing, respectively. Marker-head RM and DM marker boots failed actual delivery and the phase envelope, respectively. One fixed-epoch no-probe cold boot on each head confirmed its startup mode, but the ordinary scorer did not recognize event 48. Each case was a single default-clock observation. Instruction equality does not establish healthy timing or physical equivalence.

**The original strict audit verdict was HOLD.** At ab14de0 the audit exited 1 for a dangling POL-004 implementation, IMP-052. This record supplies the exercised implementation and partial verification links. The resulting evidence tree awaits a separate strict audit.
