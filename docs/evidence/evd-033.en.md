# EVD-033 · Periodic releases under rate-monotonic and deadline-monotonic priorities

[한국어](evd-033.md) · [Acceptance design](../pol-004-exact-periodic.md#english)

The first observer invocation rejected the unsupported `--capture-dir` option and exited 2 before QEMU started. Using the supported launcher, the first and only guest boot passed. The observer captured all 111 expected UART bytes and stopped QEMU after its quiet window. The guest ran on one emulated Cortex-A72 with GICv2 and 128 MiB.

A had period 10 and relative deadline 9. B had period 12 and relative deadline 4. B was enqueued first. At tick 0, RM selected A then B, while DM selected B then A. Both policies dispatched A again at tick 10 and B at tick 12. In each 14-IRQ epoch, the first IRQ was followed by two completions, and the 11th and 13th IRQs by one each. The terminal IRQ parked after the guest checked all eight completions and empty job queues.

QEMU recorded 28 IRQs from controller ELR `0x40201260` and eight SVC #1 exceptions with syndrome `0x56000001`. The trace directly records the worker and controller return PCs. The frozen guest checks interrupt ID 30, timer-control low bits 5, worker marker SPs A/B `0x402070c0` / `0x4020b0c0` and saved worker frame addresses `0x40206d80` / `0x4020ad80`. These addresses come from the executed checks and ELF disassembly. The controller saved address `0x4020ed70` is derived from its stack layout. The capture supplies no per-event SP dump, board latency or WCET.

The JSON includes extraction and offline replay commands, exact UART and exception logs, observer output, validator and frozen ELF disassembly. [Independent evidence and replay](evd-033.json)

All ten QEMU boots passed (seven combined and three baseline). The selector checks produced four expected rejections, and 126 Rust and 32 Python host tests passed.
