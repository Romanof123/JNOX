# EVD-135 · 네이티브 계층형 CPU 예산과 유휴 타이머 지연

CHG-135 / IMP-135 / POL-016 / [#333](../native-hierarchical-applications.en-ko.md) / [#334](https://github.com/Romanof123/JNOX/pull/334)

`b276a2ed8e9715fc6ced057b84681d77ccead755`

단일 Cortex-A72 QEMU virt/GICv2 기본 시계에서 최초 콜드 부팅 10건 중 8건만 시간 기준을 충족했다. 전체 시간 판정은 실패다. 포화 일반 부팅의 유휴 PPI30 진입은 비교 시각보다 4,201,556틱, 교환 일반 부팅은 6,487,068틱 늦어 각각 상한 1,953,125틱을 넘었다. 둘 다 유휴에서 히스토그램으로 복귀했고 유휴 차감은 0이었다. 일반 부팅에는 실제 IRQ 신호·WFI·ERET의 독립 시각 및 호스트 스케줄 기록이 없어 지연 원인을 분리할 수 없다.

10건 모두 예산·부채 원장 1,275행을 누락 없이 재생했고 각 앱의 사설 결과와 종료값을 확인했다. CRC는 134,217,728바이트에서 2,124,873,618/종료 237, 히스토그램은 536,870,912바이트/종료 70, 에너지는 1,073,741,824표본에서 5,864,240,971,776/종료 179였다. 보고 앱은 기한 3회, 마스크 7, 종료 7을 기록했다. 단일 CRC 일반·추적 각각 11회 유휴 타이머 보충 후 같은 PC·SP·페이지 루트로 복귀했다. 결정 간격은 모두 125,000,000틱 이내였고 점유 초과 합계는 실행별 N × 1,953,125틱 이내였다(N은 경로 예산으로 제한된 연속 실행 구간의 만료 IRQ 횟수).

별도의 기존 링크형 EL1 일반·반복 대조군 네 건과 기본 네이티브 CRC 대조군이 통과했다. 계층형 네이티브 패키지는 선택형 공학 구성이다. POL-016 시간 승인은 미결이며 두 최초 실패를 #339에서 추적한다.
