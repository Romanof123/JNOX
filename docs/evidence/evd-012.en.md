# EVD-012 · Cooperative FCFS retains the running task at a timer wake

[한국어](evd-012.md)

While A (ID 1) was running, the timer made B (ID 0) ready. The first independent guest returned from that IRQ to the same instruction in A at `0x40201290`. A yielded to B and resumed when B blocked. The wake operation returned to A. A exited to B, which then exited to the event dispatcher. The five SVC immediates from the same guest were 2, 3, 4, 1 and 1.

The capacity-two queue accepted 1 and 2 and rejected excess event 4. Handler 1 appended 3. Handlers 2 and 3 ran next. The observer received 13 lines and 163 bytes. After recording the first verdict the verifier inspected exception return addresses. Queue rejection and non-nesting follow from executed guest checks and the linked call path.

All 33 host tests passed and three malformed UART controls were rejected. Integration separately booted all features selecting cooperative dispatch and the previous partition profile. Physical timing, handler WCET and an approved service-time ceiling require further evidence.
