# EVD-042 v2 · 시작·경계 변경 후 FS-M3-01 런타임 재현

[English](evd-042-v2.en.md) · [EVD-042](evd-042.md) · [#94](https://github.com/Romanof123/JNOX/issues/94)

**부분 통과.** 단일 가상 Cortex-A72의 QEMU 6.2.0에서 기본 시험 구성 23개 중 완전한 실행 14개가 적격 판정을 받았다. 진단 10개는 같은 ELF에 별도 클록 모드를 적용했다. 최초 실행 명령은 암묵적으로 NIC를 켰고 efi-virtio.rom이 없어 게스트 시작 전에 실패했다. 실제 실행은 미사용 NIC를 껐다. 첫 RM 정상 인계 게스트는 호스트 읽기 오류로 출력이 끊겨 종료 표시와 종료 상태가 없었다. 별도 콜드 재실행이 통과했으며 두 시도 모두 보존했다.

| 기본 시험 | 관측 결과 |
|---|---|
| 기본 클록, 두 정책의 정상·손실·지연·수요(8개) | 모두 활성화 전에 억제됐다. 위상 0 IRQ 지연은 허용치 31,250틱 대비 111,771~123,682틱이었으며 이후 위상이 누락됐다. 호스트 스케줄링 또는 로그 기록에 원인을 귀속할 수 없다. |
| 결정론적 정상·손실 인계(4개) | 두 정책 모두 적격이었다. 190,111·815,111틱에 허가를 발행하고 1,127,611틱에 명령을 발행했다. RM 손실의 활성 읽기 구간은 1,252,671~1,252,672틱, 인계는 1,252,676틱이었다. 두 손실 실행 모두 닫힘·래치·OFF 읽기는 2,065,123·3,440,142·3,440,170틱이었다. 보수적 구간은 22.000304/0.000448/22.000752 ms로 25/5/30 ms 한계 이내였다. |
| 결정론적 최악 위상(1개) | 발행·수용·닫힘은 1,408,830틱이었다. 위상 6은 발행 후 20 ms보다 한 틱 이른 2,658,829틱에서 완료했고 위상 7은 정확히 312,500틱 뒤인 2,971,329틱에서 완료했다. 검출·억제·전체 상한은 1,562,499/5/1,562,504틱이었다. |
| 결정론적 동률(1개) | 만료와 네 번째 발행을 2,658,830틱에 관측했다. 입력 저장은 명령 순서상 래치 뒤지만 관측 상한이 2,658,831틱이었다. 거부는 2,658,837틱, OFF 읽기는 2,658,840틱이었다. 동일 틱 입력은 미충족이다. |
| 나머지 결정론적 RM 스크립트(9개) | 시작·억제·종료 상태가 기대값과 일치했다. 복구만 닫힘과 래치 이후 다시 활성화됐다. |

기본 클록 인계 진단 4개는 인계 전 실패했다. 결정론적 명령 계수에서 일반 정상 실행 2개는 통과했다. 지연 대조군은 서비스 초과 없이 위상 12에서 늦은 IRQ 하나를 분리했다(RM/DM 39,063/39,064틱). 수요 대조군은 IRQ 한계 안에서 실행당 활성화 14회의 초과를 분리했다(최대 19,548틱, 상한 15,625틱). 네 음성 대조군 모두 타이밍 래치와 레지스터 1→0 전이를 보였다.

단독 CLI는 위상을 건너뛴 완전한 추적 12개에서 IndexError를 냈다. 또한 래치 뒤 발행도 전달돼야 한다고 보아 결정론적 음성 대조군 4개를 잘못 거부했다. 독립 판정 근거는 원시 사건 기록이다. 가상 PL061 읽기와 로컬 송신은 전기적 응답, 안전 IPC 전송, 보드 타이밍이나 일반 해석적 수용을 검증하지 않는다.
