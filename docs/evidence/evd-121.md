# EVD-121 · 유한 네이티브 작업의 격자형 LLF

CHG-121 / IMP-121 / POL-005 / [#306](../native-llf-applications.en-ko.md) / [#307](https://github.com/Romanof123/JNOX/pull/307)

`af022d69bf2ad5a62798e163ea72d2daa07be0a5`

최초 순번 7개를 보존했다. 두 작업이 모두 준비된 상태에서 LLF는 격자 0에서 히스토그램 B를 골랐고, 격자 1의 여유 시간 4/4 동률에서는 B를 유지했으며 격자 2의 3/4 역전에서 체크섬 A로 전환했다. 그 사이 시스템 호출이나 신규 공개는 없었다. EDF는 A부터 실행했다. 최초 외부 추적에서 B는 PC `0x400040`에서 중단돼 같은 PC와 SP `0x1010fa0`로 복귀했다. 전환 전후의 전용 메모리 표본으로 진행량을 확인했다. 일반 실행에는 종료 시점 RAM만 남았다. A는 16블록 합 8,355,840(종료 17), B는 131,072블록과 16개 빈 각각 33,554,432(종료 29)를 기록했다. 512 MiB B는 LLF와 EDF의 일반·추적 모두 실제 마감을 놓쳤다.

별도로 고정한 보조 LLF 부팅 2회는 최초 A와 기존 64 MiB Rust 비트 개수 히스토그램을 사용했다. 두 실행에서 순위 역전을 확인했고 두 앱 모두 마감 전에 끝났다. B는 표본 67,108,864개와 빈 9개 전체를 검산해 197로 종료했고 A는 17로 종료했다. B는 일반에서 마감보다 29,004,015틱, 추적에서 28,778,340틱 빨랐다. 보조 일반 실행에는 종료 시점 RAM만 남았다.

단독 장기 B는 부호 있는 여유 시간이 −1이 된 후에도 완료까지 실행됐다. 단독 단기 A는 마감을 지켰고 과수요 패키지는 EL0 진입 전에 거부됐다. 호스트 시험은 163개를 통과했다. 과거 #298 및 연결형 EDF·LLF 근거, 실물 타이밍과 통합 부하 검증은 별도 범위다.
