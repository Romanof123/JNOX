# EVD-045 v1 · 일반 Rust 비주기 서버의 타이밍과 서비스

[English](evd-045-v1.en.md) · [EVD-045](evd-045.md)

**부분 통과. 최초 기본 클록 부팅 10건은 모두 중재 전에 실패했다.** 첫 IRQ 지연은 130,150~366,557틱(2.0824~5.864912 ms)으로 62,500틱 상한을 넘었다. 이 실행에서는 제출, 실행권 부여, 작업 완료 및 마스킹이 없었다. 별도 결정론적 실행에서 정상 스케줄 5개가 완료됐고 결함 대조군 2개는 청구 후 미완료 작업을 보존했다.

기본 클록 일반 선택자는 A·B 각각 PS, DS, SS2, SS1이고, 나머지 두 이미지는 A/SS2-late와 B/DS-late다. 10건 모두 슬롯 전체가 지나기 전에 IRQ 0에서 게스트 판정 1로 멈췄다. 별도 icount shift=0 진단의 최초 정상 캡처 5건은 UART를 전송하던 중 호스트 15초 제한이 만료됐다. 최초 결함 진단 2건은 완료됐다. 이후 Linux 로컬 UART로 새로 콜드 부팅해 7개 완전한 기록을 확보했다. 원본 시도 24건을 모두 보존했다.

| 완료된 진단 | 실제 서버 실행 슬롯 | 청구 / 작업 완료 단위 |
|---|---|---|
| A, 폴링 | 4, 5, 8, 9 | 4 / 4 |
| A, 지연 가능 | 1, 3, 4, 5 | 4 / 4 |
| A, 산발적 서버, 크레딧 항목 2개 | 1, 3, 5, 7 | 4 / 4 |
| A, 산발적 서버, 크레딧 항목 1개 | 1, 3, 7, 8 | 4 / 4 |
| B, 산발적 서버, 크레딧 항목 1개 | 0, 1, 5, 7, 11, 12 | 6 / 6 |

FIFO 요청 ID 순서는 A에서 1/2/2/3, B에서 1/1/1/1/2/2였다. A/SS1의 단일 크레딧 항목은 슬롯 3에서 병합되어 슬롯 7에 2단위가 만기됐다. 완료한 정상 진단마다 높은 우선순위의 주기 작업은 슬롯 2/6/10/14를 차지했고 명목 릴리스부터 완료까지 258~260틱이 걸렸다. IRQ 지연은 0틱, 어셈블리 복귀 표본까지 준비 최댓값은 94틱(1.504 µs)이었다. QEMU는 ERET 목적지를 기록하지만 마지막 복원 명령별 시각은 제공하지 않는다. B/PS, B/DS, B/SS2의 정상 결정론적 스케줄은 이 진단에 포함되지 않았다.

실행권 부여 시 이산 할당량 1단위를 청구하고 작업의 256단계 체크섬 및 완료 SVC를 거쳐야 완료 처리한다. 두 지연 대조군은 128단계 뒤 목표보다 4,687,500틱(75 ms), 즉 슬롯 한 개 이상 늦은 IRQ에서 중단됐다. A/SS2는 슬롯 2에서 미완료 1단위, B/DS는 슬롯 1에서 4단위를 보존했다. 두 경우 모두 청구 1단위, 완료 0단위였으며 후속 중재는 없었다.

단일 가상 A72에서 유한한 입력 패턴 두 개를 관측했다. 동시 요청 ID 최대 4개, 미완료 총량 최대 6단위 및 요청당 1~4단위는 입력 제한이다. 실행 결과만으로 IRQ 1 ms, 준비 5 ms와 남은 서비스 허용량 45 ms의 상한 근거를 확보할 수 없다. 기본 클록 타이밍, 실제 M3 간섭, 실물 보드 WCET와 제품 수용은 미확정이다.
