# EVD-009 · Timer preemption of running RM and DM jobs

[한국어](evd-009.md)

**RM immediately resumed the interrupted A. DM let the shorter-deadline B finish, then resumed A at the exact interrupted instruction.**

Before reading the implementation a fresh verifier booted one single-core Cortex-A72 QEMU guest and recorded 178 UART bytes and observer exit 0. The same run contained 18 IRQs and 14 SVC #1 completions. Both IRQ 14 and IRQ 17 interrupted the ADD in A at `0x402012b0`. Three host-only controls rejected a missing marker, reversed order and trailing data.

The guest checked private stacks, register witnesses and work progress. The external exception trace captured interrupted and resumed PCs. Physical latency, WCET and system schedulability require separate evidence. A WSL Git metadata lookup failed before launch. Windows Git supplied the revision.

Integration separately booted the legacy periodic-only configuration (111 UART bytes) and the all-features configuration selecting CBS (112 bytes) on this revision. Both observers passed.
