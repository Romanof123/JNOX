# EVD-105 · Equal-priority FIFO handoff on one PI mutex

CHG-105 · IMP-105 · POL-014 · [#275](https://github.com/Romanof123/JNOX/issues/275) · [#277](https://github.com/Romanof123/JNOX/pull/277).

Task 0 owns X at base priority 2. Workers 1 and 2 at priority 7 attempt X in opposite orders in two epochs of the same ELF. The shared lock release selects the grantee. Each worker appends its digit after its saved acquire returns. The prospective journal sequences are 4→41→412 and 4→42→421.

[6f2f903](https://github.com/Romanof123/JNOX/blob/6f2f903623031fee8d81a4413569a8dd74ca0bd4/kernel/src/ordinary_mutex_fifo.rs) · [#275](../ordinary-mutex-fifo-plan.en-ko.md)

Both first QEMU virt boots qualified both epochs (4/4). Plain and traced each recorded 30 journal entries and 30 restores. Independent replay followed the blocked frames through owner donation and restoration, FIFO grant and acquire return, then the protected writes 4→41→412 and 4→42→421. In the traced boot, 30 ordered ERET targets and 28 SVC exception link addresses matched the frozen instructions and recorded frames.

On each transcript the checker rejected all three constructed changes: a fixed-ID grant in the reversed epoch, an acquire restore before grant, and a wrong intermediate value with the correct final value. The original scorer separately qualified ordinary PI plain, PI traced, ceiling plain and ceiling traced (4/4). All eight host mutex tests passed, including the reversed arrival check with fixed IDs. The build rejected the Pi 4 FIFO selector and an unknown mutex app.

These observations cover one PI lock on a single emulated CPU. The timed-chain work in #236, physical maximum blocking, product ceilings and nesting limits, and policy-family release remain separately gated.

The first independent host checker assumed the journal sequence restarted in each epoch. The verifier corrected the checker to follow the continuous J1–J30 sequence and replayed the unchanged first captures. Both original guest runs supplied the verdict. The integration preflight ELF and the first guest ELF differed only in symbol and string tables among the ELF sections. PM compared both complete PT_LOAD entries and found identical addresses, layout, permissions and bytes. The .text, .rodata and .data sections also matched.
