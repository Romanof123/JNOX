# 비주기 서버 호스트 판정기의 보관 기록 재생

[#120](https://github.com/Romanof123/JNOX/pull/120) · [7e0f913](https://github.com/Romanof123/JNOX/tree/7e0f913882342c2d6cba2cbfe38be290f15a2d2f) · [JSON / SHA-256](evd-045-host-replay.json) · [EVD-045 v1](evd-045-v1.md) · [EVD-045 v2](evd-045-v2.md)

동결된 판정기에 원본 UART, 같은 실행의 예외 로그, ELF 및 메타데이터를 함께 제공한 CLI 호출 44건이다. 빌드 인덱스와 환경을 각 이미지에 대조했다. 작업 완료 21건, 지정된 지연 결함 관측 8건, 중재 전 억제 10건, 불완전한 원본 icount 기록 5건이었다. v1 기본 시계의 지연 이미지 2개는 주입 전에 억제됐다.

| 집단 | 완료 | 지정 지연 | 억제 | 불완전 |
|---|---:|---:|---:|---:|
| v1 default | 0 | 0 | 10 | 0 |
| v1 diagnostic (icount) | 0 | 2 | 0 | 5 |
| v1 diagnostic-complete (icount) | 5 | 2 | 0 | 0 |
| v2 default | 8 | 2 | 0 | 0 |
| v2 diagnostic (icount) | 8 | 2 | 0 | 0 |

호스트 대조 26건은 모두 예상 결과와 일치했다. 23건에서 손상된 원장·소유권·서비스·반환 순서 또는 입력 식별 불일치를 거절했다. UART 단독 및 ELF 추가 재생은 제한된 범위에서 완료였다. 잘못 명명한 실행도 중재 전까지 관측이 동일하면 억제로 남는다. 실행 케이스는 호출자가 지정한다. 외부 ERET 기록은 순서와 주소를, 게스트 카운터는 시간 순서를 제공한다. 이 호스트 재생은 게스트 재실행·물리 보드 시간 검증을 포함하지 않는다. 기본 시계 집단 사이의 차이 원인은 미확정이다.
