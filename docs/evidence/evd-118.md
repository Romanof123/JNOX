# EVD-118 · 네이티브 주기 작업의 RM·DM 실행

CHG-118 / IMP-118 / POL-004 / [#300](../native-periodic-applications.en-ko.md) / [#301](https://github.com/Romanof123/JNOX/pull/301)

같은 C·Rust ELF 쌍에서 RM은 C를, DM은 Rust를 먼저 실행했고 종료값은 각각 17과 29였다. 소스 `4a0c17a7025d663d90b67535ccc27b594277ec08`의 최초 일반 QEMU 부팅은 62.5 MHz 타이머를 사용했다. 과거 #94 결과, 제품 작업량 가정, 실물 보드 검증은 별도로 추적한다.

최초 순번 18개 중 DM 초과 작업에서는 마감 사건을 관측한 시계 시스템 호출(원인 5)에서 B1을 선택했다. A의 프레임을 유지해 PC `0x4001a0`, SP `0x1010f40`으로 복귀했다. 최초 초과 작업 RM에서는 A1·B1이, DM에서는 A1만 마감을 놓쳤다. 수면 중 쌓인 작업 3세대가 취소됐다. 이 대조의 일반 부팅에서는 g0~g2, 외부 추적 부팅에서는 g0~g3가 마감을 놓쳤다.

별도로 고정한 최초 부팅 4회는 32 MiB A1 작업을 사용했으며 독립적으로 확인한 CRC는 `0xfa914cb6`였다. DM에서 B1과 B2는 A1이 crc_ramp 내부 PC `0x4001ec`, SP `0x1010f50`에서 계산하는 동안 실제 EL0 타이머 IRQ로 선점했다. 외부 IRQ·ERET 추적에서 같은 프레임으로 A가 복귀함을 확인했다. B1 완료는 DM 일반·추적에서 각각 마감보다 2,466,751·2,231,856틱 빨랐다. RM 일반·추적에서는 각각 7,744,212·8,914,655틱 늦었다. 고정 작업에서 RM 일반은 A1/B1/B2, RM 추적은 A1/A2/B1/B2, DM 일반은 A1, DM 추적은 A1/A2가 마감을 놓쳤다. 고정 작업 추적에서는 A3가 취소됐다.

호스트 정책 검사 152개가 모두 통과했고 잘못된 패키지 11개는 거부됐다. 부모 및 후보 소스 모두 네이티브 시작 대조는 37, EDF 대조는 43으로 종료했다. 기존 연결형 RM·DM의 기본 손실 관측기는 두 소스 모두 원래 실제 전달 판정의 미충족을 보고했다.

## 최초 후보 판정

소스 `4a0c17a7025d663d90b67535ccc27b594277ec08`는 같은 카운터 시각의 완료 전에 관측을 처리할 경우 실제로 없던 겹침이나 취소를 기록할 수 있어 릴리스 검토에서 보류됐다. 최초 잘못된 패키지 11개 중 몇 건은 일반 선택자 오류까지만 도달했다. 별도 표적 대조에서는 실제 ELF를 사용한 CLI 검사 17개와 직접 Cargo 진단 10개를 수행했다. 과거 연결형 RM 대조 ELF 두 개는 덮어쓰였으며 최초 해시·UART 캡처·로그·종료 상태는 보존됐다.

## 수정된 동일 시각 처리 순서

수정 소스 `770c19b`는 `fbbae9e`의 동일 카운터 시각 규칙을 따른다. 세대를 명시적으로 추적하는 독립 판정기로 공개·완료·겹침·마감 미준수·취소·실행 소유자 상태 1,664개를 대조했다. RM·DM의 동순위 사건 순서 96개, 슬롯 순열 6개, 중복 횟수 4종, 대기와 종료, 실제 소유자 변경 및 더 늦은 완료를 확인했다. 같은 판정기는 최초 소스에서 실패하고 수정 소스에서 통과했다. 순차 호스트 검사 161개에는 생성형 검사 두 묶음이 포함된다. 게스트 22회를 새로 부팅해 기준 RM·DM 순서와 순위 역전, 고정 작업의 실제 IRQ와 루프 내부 복귀, 앱 계산 결과를 대조했다. 시작 및 EDF 대조는 기준·후보에서 각각 37·43으로 종료했다. 기존 연결형 손실 대조 관측은 별도로 유지한다.
