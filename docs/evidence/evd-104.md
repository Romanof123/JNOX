# EVD-104 · EDF와 표본 LLF의 서비스 반복 예약 두 번

CHG-104 · IMP-104 · POL-005 · [이슈 #273](https://github.com/Romanof123/JNOX/issues/273) · [PR #274](https://github.com/Romanof123/JNOX/pull/274).

`4ecce4b0f3afdd1a676bcffb81fae33acf4b1d6d`의 단일 CPU QEMU 최초 실행 12건이 모두 예상한 종료 지점에 도달했다. 각 정책에서 정상 승인, 소유자 전환 한도 거부, 공급 부족 거부를 일반·추적 모드로 각각 실행했다.

승인된 4건 모두 16개 셀 중 1번과 9번을 예약했다. 서비스는 서로 다른 두 입력 묶음을 계산해 89,440과 617,824를 반환했다. 작업 A는 중단된 프레임으로 두 번 복귀했으며 첫 복귀와 두 번째 중단 사이, 두 번째 복귀 이후에도 연산이 진행됐다. 각 실행에서 격자 IRQ 11회와 작업 완료 SVC 2회가 발생했고, 다른 소유자로 실제 복귀한 횟수는 6회였다. 정렬된 셀과 임의의 Q폭 이동 구간에서 각각 최대 예외 진입 3회, 소유자 전환 2회를 관측했다. 이동 구간의 이론 상한은 두 지표 모두 4회였다.

4건은 공급 승인을 통과한 뒤 전환 한도 3을 거부했고, 공급이 빠듯한 작업표 4건은 예약 후 남는 슬롯이 부족해 거부했다. 8건 모두 작업 시작 전 거부했다. 기존 마감 구성 24개를 모두 부팅해 최초 종료 상태와 UART 행 종류·순서가 일치함을 확인했다. 24개 실행 코드 섹션은 일치했고, 전체 ELF와 적재 이미지 해시는 모두 달랐다. 실기 시간 특성과 반복 간섭을 받는 제품 작업의 승인 범위는 아직 확정하지 않았다.
