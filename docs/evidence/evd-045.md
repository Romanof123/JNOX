# EVD-045 · 일반 Rust 비주기 서버의 타이밍과 서비스

[English](evd-045.en.md) · [#101](https://github.com/Romanof123/JNOX/issues/101) · [PR #108](https://github.com/Romanof123/JNOX/pull/108)

**통합 기본 클록 실행은 일반 스케줄 8개를 모두 완료했다.** 의도적으로 지연시킨 대조군 2개는 각각 1단위를 청구하고 완료 처리 없이 정지했다. 이전 단독 기본 클록 실행에서는 10개 이미지 모두 첫 IRQ에서 중재 전에 정지했다. 통합 재현에서 두 계열의 사례별 ELF와 QEMU 해시가 일치했다. 타이밍 차이의 원인은 미해결이다. [v2](evd-045-v2.md) · [v1](evd-045-v1.md) · [근거 색인](evd-045.json)

이미지 비교 34건에서 독립 이미지의 PT_LOAD 배치·적재 바이트·.text가 모두 일치했다. 비교 대상은 서버 통합 전 멀티레벨 이미지 12개, 통합 후 동일 구성 12개, 통합 비주기 서버 이미지 10개였다. 독립 기본 클록 최초 실행에서는 일반 작업 8개와 지연 대조군 2개 모두 첫 IRQ에서 부과량 0으로 멈췄다. 통합 기본 클록에서는 일반 작업 8개가 모두 완료됐고 두 지연 대조군은 각각 1단위를 부과한 뒤 완료 처리 없이 멈췄다. 별도 결정론적 명령 계수 실행에서도 일반 작업 8개가 완료되고 지연 대조군 2개가 의도한 지점에서 멈췄다. 독립 기본 클록 캡처는 WSL DrvFS, 통합 기본 클록 캡처는 Linux /tmp에 기록했다. 타이밍 차이의 원인은 미확정이다. 증거를 추가하기 전 동결 소스의 감사에서는 `IMP-045`와 `IMP-046`의 증거 연결 누락이 보고됐다.
