# EVD-045 · 일반 Rust 비주기 서버의 타이밍과 서비스

[English](evd-045.en.md) · [#101](https://github.com/Romanof123/JNOX/issues/101) · [PR #108](https://github.com/Romanof123/JNOX/pull/108)

**통합 기본 클록 실행은 일반 스케줄 8개를 모두 완료했다.** 의도적으로 지연시킨 대조군 2개는 각각 1단위를 청구하고 완료 처리 없이 정지했다. 이전 단독 기본 클록 실행에서는 10개 이미지 모두 첫 IRQ에서 중재 전에 정지했다. 통합 재현에서 두 계열의 사례별 ELF와 QEMU 해시가 일치했다. 타이밍 차이의 원인은 미해결이다. [v2](evd-045-v2.md) · [v1](evd-045-v1.md) · [근거 색인](evd-045.json)
