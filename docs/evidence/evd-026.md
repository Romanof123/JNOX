# EVD-026 · 제한된 스케줄러 확장의 선택과 대체 처리

[English](evd-026.en.md) · [승인 기준](../m4-bounded-extension.md) · [#59](https://github.com/Romanof123/JNOX/issues/59)

한 차례 콜드 부팅에서 아홉 슬롯을 기록했다. 평가 두 단계 뒤 제안이 승인되어 태스크 2가 실행됐다. UART는 마스크 위반, 오래된 제안, 평가 연료 소진, 워치독에 따른 대체 처리와 실행 대상이 없는 유휴 슬롯, 예약 슬롯 세 개를 기록했다. 게스트 저널은 서비스 인터럽트 아홉 건과 평가 인터럽트 여섯 건 모두에 PPI30을 기록했다. QEMU의 일반 IRQ 추적으로 PC를 대조했다. 인터럽트 ID는 게스트 저널에서 읽은 값이며, 저널에 인터럽트 소스를 제어하는 별도 필드는 없다.

이 기록의 범위는 해당 가상 부팅이다. 실물 보드 타이밍과 제품 기능 안전은 별도 검증 대상이다. ELF SHA-256 `2c20aa2f12ae6083bfcbd29828522118cf3e790024c69981d4c0810a9bb1d29d`. [검증 소스](https://github.com/Romanof123/JNOX/commit/92d62b30b89abdefebb1d0fdf268b8a3cfd30526) · [검증 결과와 원시 기록](evd-026.json)
