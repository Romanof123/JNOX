# EVD-123 · Private native process arguments

CHG-123 / IMP-123 / [#310](../native-process-arguments.en-ko.md) / [#311](https://github.com/Romanof123/JNOX/pull/311) / [#12](https://github.com/Romanof123/JNOX/issues/12)

`1c45bee0cb37e13f1a53f8dab902bd0e7e9fec94`

Six packages each had a plain boot, a separate stock capture/replay and a separate externally stopped boot on one QEMU virt Cortex-A72. All six stock replays passed. At actual _start the external observer compared all 11 active private vectors, pointers, terminators and padding. The two cooperative instances of the same C ELF used distinct physical stack pages at the same virtual SP. Across yields, the primary summed 16 samples to 376 and exited 17; the peer found min 64 and max 95 in 32 samples and exited 29.

FIFO selected C slot 1 first with a 128-byte tail, and in the three-slot package selected Rust slot 2 first with a 112-byte tail. Rust preserved the 14-byte UTF-8 label `-동쪽 센서`, summed 16 samples to 3,960 and exited 43. The primary retained its 96-byte tail. The ordinary default and startup probe each matched all 80 original stack bytes from preimplementation boots, with argc 1 and 3 and exits 0 and 37 respectively.

The original standalone host unit harness failed to compile with E0308. On `fffbb31d46c88670dd82485be4fdea1171b3a78b`, an explicit slice type in test-only code corrected the harness and all three tests passed. The guest observations apply to the original source. The recorded change is scoped to native arguments and startup for the named virtual machine.
