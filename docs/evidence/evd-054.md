# EVD-054 · 송신자 허가 발행의 최초 가상 실행

[CHG-055 / IMP-054](../ordinary-permit-phase-runtime.md) · [#131](https://github.com/Romanof123/JNOX/pull/131) · [c382eb3](https://github.com/Romanof123/JNOX/tree/c382eb3c42955324b87ffff3b72d862b10bc8c7c) · [JSON](evd-054.json) · [ZIP](evd-054-first.zip)

정해진 순서의 32개 위치를 한 번씩 실행해 모두 CONTROL END와 원시 UART·에뮬레이터 기록을 남겼다. A0는 기술자 기준, A1은 명목 시각 발행, A2는 첫 실제 발행에 기준을 둔 구성이다. 서로 다른 시계 및 OFF 특성 측정의 분모를 구분했다. Windows Rust 1.95.0에서 이미지 10개를 만들었고 잘못된 설정 8개는 빌드에서 거절됐다.

| 실험 | A0 | A1 | A2 |
|---|---|---|---|
| 기본 시계 운영 | 4/4 결함, 수락 0 | 8/8 거절 | 4/4 거절 |
| 명령 계수 시계 운영 | 배정 없음 | 2/2 거절 | 2/2 거절 |
| 기본 시계 OFF | 배정 없음 | 4/4 조기 중단 | 4/4 조기 중단 |
| 명령 계수 시계 OFF | 배정 없음 | 2/2 완료 | 2/2 완료 |

**운영 적격 0/20.** A1/A2 16건은 적격 입력 누락 마스크 4095를 기록했다. GIC를 구성하고 타이머를 비활성화한 뒤 수용 전 단계에서 거절해 운영 비교기 설정·인터럽트·예외 복귀·작업 실행이 없었다. A0 4건은 결함을 기록했고 발행한 허가를 하나도 수락하지 않았다. A0의 이전 참조와 비교하면 양 정책 모두 명령어와 주소, 쓰기 가능한 적재 세그먼트는 같고 읽기 전용 세그먼트에서 Rust 소스 줄 번호가 달랐다.

기본 시계 OFF 8건은 첫 발행 전에 중단했다. 서비스 예산 사유 3이 7건, 제어 위상 사유 7이 1건이었다. 결정적 OFF 4건은 각각 허가 7건을 발행·전달·수락해 합계 28건을 기록했다. 각 발행 시점 괄호의 양 끝이 같았고 첫 발행 간격은 정확히 625,000틱이었다. 서로 다른 허가 두 건을 수락한 뒤 별도 감독자가 기준+937,500틱에 명령 한 건을 게시했고 제어 작업이 수신했다. 가상 적격 판정 뒤에도 OFF였고 실제 출력 활성화는 없었다. 각 결정적 부팅에서 SVC 3 이후 타이머 복귀가 저장된 송신자 ELR과 일치했고 외부 ERET 74건은 복귀 직전 PC 기록 순서와 일치했다. 기본 OFF에서는 각 2건이었다.

PL061 에뮬레이터는 리셋 출력 0→0을 기록했다. OFF 12건 중 11건에서 오프셋 4에 0 쓰기 두 번, 기본 DM 21-1에서 세 번이었다. 방향 설정은 각 한 번, 출력 읽기는 모두 0이었다. 외부 기록에는 게스트 카운터 타임스탬프가 없어 같은 시계에서의 포괄 구간은 검증되지 않았다. 실보드 핀·ON 에지·원자적 결함 주입이 없어 25/5/30 ms 상실 대응을 측정할 수 없다. 실제 마스킹·복귀 꼬리·간섭 상한과 적대적 입력·결함 재생도 미검증이다.

원본 관측기의 scheduler.irq는 진입 시각에서 요청 인덱스를 빼는 잘못된 계산이었다. 교정 결과는 행 3의 요청 인덱스에 대응하는 가장 최근 선행 행 2의 절대 비교값을 뺀다. 원본 출력과 교정 결과를 모두 보존했다. 결정적 OFF의 서비스·응답·위상·간격·교정 IRQ 수치는 해당 실행의 상한 안이었다. 시스템 적격성이나 분석적 최악시간 판정을 부여하지 않는다.

통합 소스에서 고정된 32개 조건을 재실행했다. 운용 조건 20건 중 적격은 0건이었다. A0 세 건에서 각각 허가 7개를 수락했지만 첫 발행 간격이 짧았다. 최초 EVD-054의 32건은 별도 집단이다. [EVD-054 · #131](evd-054-integration.md)

허용된 릴리스 이미지 21개 모두 통합 참조와 로더 입력이 일치했고 전체 ELF 해시는 각각 달랐다. 음성 구성 44개는 모두 선택자에서 거절됐다. 총 65개 빌드에서 새 게스트 부팅은 0회였다. [위상·비례 배분 통합 대상 비교](evd-054-targeted.md)
