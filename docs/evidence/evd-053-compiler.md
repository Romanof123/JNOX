# EVD-053 · 예약 컴파일러 최적화 비교

[CHG-064](../reservation-compiler-profile-plan.md) · [#145](https://github.com/Romanof123/JNOX/pull/145) · [EVD-053 v3](evd-053-v3.en.md) · [JSON](evd-053-compiler.json) · [ZIP](evd-053-compiler.zip)

일반 부팅은 크기 최적화(S) 8건 중 1건, O2 8건 중 0건이 완료됐다. 두 설정 모두 과부하 2건씩을 거절했다. 기존 크기 최적화와 1 ms 경계 검사를 유지한다.

동일 커널에서 선택자 6종을 두 설정으로 빌드했다. S 이미지 여섯 개는 기존 ELF 해시를 재현했다. 최초 하네스는 Python의 hashlib.file_digest 미지원으로 Cargo 실행 전에 중단됐고 최초 오류와 호환 드라이버를 보존했다. 신규 게스트 20건을 열 쌍으로 번갈아 한 번씩 실행했다. 과거 소형 인계 v3 4/8, 당시 대응 v2 5/8, 별도의 과거 v2 1/8 및 두 v1 집단 각각 0/8은 이 집단과 구별한다.

| 조건 | S | O2 | O2−S IRQ→사전 커밋 / 소스 읽기 끝→사전 커밋 (틱) |
|---|---|---|---|
| 정렬 깨움 일반 | 2/5 | 2/5 | −3490 / −1047 |
| CBS 깨움 추적 | 2/5 | 2/5 | +3673 / +4532 |
| 정렬 포화 추적 | 2/2 | 2/5 | +6163 / +6522 |
| CBS 포화 일반 | 2/5 | 2/5 | +12995 / +9597 |
| 정렬 깨움 추적 | 2/5 | 2/5 | +4910 / +5047 |
| CBS 깨움 일반 | 2/5 | 2/5 | +4325 / +4837 |
| 정렬 포화 일반 | 2/5 | 2/5 | −2661 / −602 |
| CBS 포화 추적 | 0/0 | 2/5 | +6418 / +5404 |

0/0인 S CBS 포화 추적은 10슬롯에 도달해 A/B 각각 4회 실행했고 첫 작업자 표식은 E+58,439틱이었다. S 정렬 포화 추적의 2/2는 첫 실제 표식 E+67,380틱으로 62,500틱 한도를 초과했다. 2/5는 선택 전 검사 중단이며, 영수증이 없는 이후 단계는 미관측이다. 양쪽 모두 첫 표식이 있는 쌍은 없었다. 과부하 4건은 수요 9/8을 타이머 설정·작업자 실행 전에 거절했다. 외부 예외·복귀 기록은 추적 조건에만 있다.

두 사전 커밋 구간에서 O2는 각각 같은 2쌍에서 짧고 6쌍에서 길었다. 각 조건은 표본 한 번으로 QEMU 콜드 번역, 호스트 스케줄링 및 계측을 포함한다. O2의 매핑 RAM 증가는 거절 이미지 1,672바이트, 일반 이미지 4,624–4,664바이트였다. 일반 이미지에는 704바이트 뱅크·증빙·영수증, 추적 저장소 65,536바이트, 16 KiB 작업 스택 3개와 부트 스택 1개가 포함된다. 실물 스택 최대 사용량·타이밍·배포 적격은 미확인이다.

원래 디코더는 20건 중 16건을 거절했다. 수정 디코더와 독립 분석기는 20건 모두의 종료 피연산자에 합의했다. 실행 귀속 변조 5건과 태그 24 역할 변조 5건을 거절했다. 보존된 터미널 프레임과 호스트 프로세스 종료 상태 124를 구분한다. 각 ELF의 역어셈블리, 풋프린트, 최초 부팅과 실패 원본, 검증 스크립트 및 명령을 아래 절차로 복원한다.
