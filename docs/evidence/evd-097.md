# EVD-097 · 절대 마감 기준 협력형 FIFO 수용

`CHG-097` · `IMP-097` · `POL-001` · [#250](https://github.com/Romanof123/JNOX/issues/250) · [#253](https://github.com/Romanof123/JNOX/pull/253).

최초 소스 667c288에서 게스트 79워드, 블록 합 52·132, 동료 값 0→20을 확인했다. 그러나 비어 있지 않은 구간에서 시각 20의 마감 거부 뒤 15의 요청이 수용됐다. 기존 협력형 게스트 2개가 완료했고 각 적재 영역은 144바이트 증가했다. 기존 마감 구성 8개의 적재 바이트는 기존 기준선과 같았다. 최초 일반 실행은 게스트 진입 전 런처에서 실패했다. 이어진 실제 실행을 보고서에서 구분했다.
