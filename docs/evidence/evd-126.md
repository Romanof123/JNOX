# EVD-126 · 한 네이티브 프로세스 안의 라운드로빈

CHG-126 / IMP-126 / POL-002 / [#315](../native-thread-round-robin.en-ko.md) / [#316](https://github.com/Romanof123/JNOX/pull/316)

`9df9437b626da3bcaa4151f3db1370e7db24ae13`

단일 CPU QEMU virt에서 최초 콜드 부팅 13회와 Rust 보조 부팅 2회가 예상 상태로 종료했다. 최초 RR 일반·추적은 자발적 양보 없이 각각 비자발적 전환 22회를 기록했고 누락은 0이었다. 외부 추적에서 PPI 30 승인 22건을 확인했다. 메인이 0x400328에서 중단되고 새 작업자는 0x400024에서 시작했다. 다음 IRQ는 작업자의 0x400384를 중단해 메인의 0x400328로 복귀했고 세 번째 IRQ는 작업자의 0x400384로 복귀했다. 외부 ERET PC는 선택된 모든 PC와 일치했다. SP(0x1010f60·0x1008fc0), 별도 errno 셀과 공통 주소 공간 루트는 게스트 행에서 확인했다.

두 스레드는 각각 16,384블록(각 64 MiB)을 처리했다. 종료 RAM에서 체크섬 8,556,380,160, 16개 빈 각각 4,194,304, 조인 디스크립터 0x402000을 확인했다. RR 두 부팅은 17로 종료했다. 같은 ELF의 협력형에서는 메인이 계산을 마치고 조인에서 차단된 뒤에야 작업자가 처음 실행됐다. 두 협력형 부팅도 같은 산출물과 종료값 17을 기록했다. 전환마다 중간 블록 수를 직접 측정하지는 않았다.

추적 만료 지연은 62.5 MHz에서 3,715~10,264틱이었다. 설정값 625,000틱은 10 ms다. 정산 구간은 직전 복원 전 표본부터 예외 진입까지이며 비차단 핸들러 시간·유휴·스케줄러 공백은 제외한다. 복원 전 표본은 사용자 실행 시작 시각의 하한이다. 정확한 ERET 시각, 비동기 전체 레지스터 표식, 실물 타이밍과 멀티코어는 미측정이다. 동일 틱과 오버플로는 호스트 모델에서 확인했다. 이 패킷에는 독립 CLI 거부 조합 검증이 없다.
