# EVD-045 v2 · Ordinary Rust aperiodic server integration replay

[한국어](evd-045-v2.md) · [EVD-045](evd-045.en.md) · [#101](https://github.com/Romanof123/JNOX/issues/101)

**The integrated default-clock run completed all eight ordinary schedules.** Both deliberate late controls stopped after charging one unit and retiring none. The earlier standalone default-clock series stopped all ten images at their first IRQ before arbitration. The integration replay matched the per-case ELF and QEMU hashes across both series. The reason for the timing difference is unresolved.

| Corpus | Clock and capture location | Outcomes |
|---|---|---|
| Standalone v1 | Default, UART and exceptions on WSL DrvFS | 0/8 ordinary completions. Both late images also stopped at startup with no charge. |
| Integrated v2 | Default, UART and exceptions on Linux /tmp | 8/8 ordinary completions; 2/2 intended late inhibitions. |
| Integrated v2 | Deterministic instruction counting | 8/8 ordinary completions; 2/2 intended late inhibitions. |

Each integrated normal run recorded 17 IRQs and completed the higher-priority periodic work in slots 2/6/10/14. The actual normal server slot sequences below matched in both integrated clock modes. Pattern A retired four units and B retired six. Each retirement matched a completion SVC and 256 worker steps. The credit ledger, frame returns and actual FIFO identities were replayed per unit.

| Server | A slots | B slots |
|---|---|---|
| Polling | 4,5,8,9 | 0,1,4,5,8,9 |
| Deferrable | 1,3,4,5 | 0,1,4,5,8,9 |
| Sporadic, two credit entries | 1,3,5,7 | 0,1,4,5,8,9 |
| Sporadic, one credit entry | 1,3,7,8 | 0,1,5,7,11,12 |

At 62.5 MHz the largest IRQ lateness across the eight normal default runs was 27,922 ticks (0.446752 ms), against 62,500 allowed. Preparation through the return sample peaked at 86,006 ticks (1.376096 ms), against 312,500 allowed. Each A/SS2 late control preserved one pending unit; each B/DS late control preserved four. None retired its charged unit.

The integration gate replayed 30 raw streams, including the original ten standalone default runs. The original checker assumed a default-clock stream must be a first-IRQ failure and rejected all ten newly captured default outcomes. The revised replay branched on observed IRQs, arbitration and guest verdict and preserved those original scoring failures. Different UART/exception storage paths are documented; they do not establish causation.

The combined #107/#108 kernel tree was `a097b300e0ffb2803b88e0fe02e5d88f0a2dec2b`. All ten AP and twelve ML configurations matched their corresponding standalone PT_LOAD ranges, bytes and .text. These finite observations do not justify future default-clock timing, release admission, board WCET or actual M3 interference. The 45 ms service allowance remains a required budget, with no demonstrated worst-case bound.
