Original source 4465fb72 failed both admitted first boots. The equal peer completed before the timer was delivered; the target never entered. Both one-tick-tighter inputs refused. The public idle-only acquisition preserved partial originals, with separate same-ELF RAM diagnostics. [Corrected source assessment](strict-class-first-service-corrected.en-ko.md) on 0a10dde8 captured all four first guests: both admitted cases took a genuine IRQ to the lower-class target, then resumed the unfinished peer at the saved PC. First target entry elapsed 4,108,876 and 4,091,980 counts respectively, below the conditional 24,000,000 ceiling. Effective whole-window allowances used were 64,043 and 62,938 counts. A deadline of 23,999,999 refused before workers, leaving the runtime witness zero. Only this finite declared load on the virtual target was verified. The original and corrected archives have separate identities.
