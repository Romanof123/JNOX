# EVD-029 · 하드 CBS의 차단과 기상

[English](evd-029.en.md) · [승인 기준](../m2-cbs-wake.md) · [#65](https://github.com/Romanof123/JNOX/issues/65)

최초 호출은 ELF 경로를 찾지 못해 부팅 전에 중단됐다. 실제로 처음 부팅된 게스트는 슬롯 0~24까지 도달한 뒤 5초 UART 관측 기한이 만료됐다. 독립 재현 결과는 확보한 행과 예외에서 일치했다. 슬롯 25~33과 최종 UART 표시가 누락되어 이 게스트 시험은 실패했다. [부팅 전 기록](evd-029-initial.json) · [첫 게스트, 34행 중 25행](evd-029-partial.json)

호스트 관측 기한을 15초로 연장한 뒤 동일한 ELF를 한 번 콜드 부팅해 34개 슬롯을 모두 기록했다. 독립 재현에서 모든 실행권 배정과 예외·복귀 PC 사건 78건이 일치했다. A는 슬롯 0·4·8·14·22에서 SVC로 대기하고 4·8·14·22·23에서 실행을 재개했다. 이웃 B는 슬롯 1·5·9·13·17·21·25·29·33에서 총 아홉 번 실행권을 받았다. 유휴 슬롯은 17개였다. 이 단일 가상 CPU 시험의 검증 범위는 해당 구간의 실행권 배정 순서다. 물리적 인터럽트 지연과 제품 간섭은 보드 측정 대상이다. [통과한 게스트와 재현 기록](evd-029.json)

동일 커널 리비전에서 Rust 테스트 120개와 Python 테스트 28개가 통과했다. 단일 구성 26개와 조합 구성 4개에서 게스트를 추가로 30회 순차 부팅했다. [회귀 기록](evd-027-029-regressions.json)

최종 관찰기에서 Python 테스트와 주기·CBS 직접 수집 실행이 통과했다. 우선순위 프로파일은 독립 스키마 재생에서 같은 직접 실행 경로를 확인했다.
