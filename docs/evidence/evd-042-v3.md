# EVD-042 v3 · FS-M3-01 정확 경계와 판정기 복구

[English](evd-042-v3.en.md) · [EVD-042](evd-042.md) · [#109](https://github.com/Romanof123/JNOX/issues/109)

**부분 통과.** 기본 구성 23개 중 첫 콜드 실행에서 14개가 적격이었다. 호스트 읽기 실패 뒤 별도 콜드 재시도로 적격 구성은 15개가 됐다. 결정론적 명령 계수에서 두 정확 경계가 모두 적격이었다. 기본 클록의 일반 사례 8개는 모두 미충족이었다. 진단 구성 10개는 별도 집계했다.

독립 검증자는 ELF 23개의 해시를 빌드 색인과 대조했다. 기본 23개·진단 10개 구성에 대해 QEMU 6.2.0, 단일 Cortex-A72, GICv2, TCG, 메모리 128 MiB에서 게스트 실행을 34회 시도했다. 구성 조회 오류 한 건은 게스트 시작 전에 발생했다. DM 인계 손실의 첫 실행은 호스트 읽기 오류(errno 61)로 끊겼다. 불완전 캡처와 재구성한 인수는 보존됐으나 시작·종료 시각과 프로세스 종료 상태는 기록되지 않았다.

| 작업 | 관측 결과 |
|---|---|
| 기본 시험, 기본 클록 RM/DM 정상·손실·지연·수요 | 0/8 적격. 단축되거나 시각이 어긋난 위상 기록과 장치 상태를 보존했다. |
| 기본 시험, 결정론적 RM/DM 일반 인계 정상·손실 | 최초 3/4 적격, 콜드 재시도 포함 4/4 적격. |
| 기본 시험, 결정론적 RM 상태·경계 스크립트 | 최악·동률을 포함해 11/11 적격. |
| 진단, 결정론적 일반 작업 | 정상 2/2, 지연·수요 4/4 적격. 네 음성 대조군 모두 래치 전 수용, 이후 발행의 순차 거부, 레지스터 하강 전이 1회와 최종 억제를 보였다. |
| 진단, 기본 클록 인계 | 0/4 적격. |

62.5 MHz에서 RM 동률 사례의 세 번째 허가 게시·전달은 1,408,831틱이었다. 정확히 1,250,000틱 뒤 종료 판정, 래치 구간, 네 번째 발행 및 입력 게시 구간의 표본이 모두 2,658,831틱이었다. 주소 0x40200638~0x4020066c의 명령 순서는 래치 저장 후 네 번째 발행 표본과 게시 저장을 수행함을 보인다. 수신기는 2,658,838틱에 네 번째 허가를 거부했고 PL061에서 2,658,841틱과 마지막 2,658,844틱에 OFF를 읽었다. 최악 사례에서 판정은 발행 후 1,249,999틱에 완료됐고 다음 판정은 정확히 312,500틱 뒤에 이뤄졌다.

판정기는 파일 누락, 손상, 잘림 및 불완전한 호스트 읽기 표본에 대해 구조화된 결과를 반환했다. 기존 회귀 시험 3건이 통과했고 변조한 결정론적 음성 대조 입력 8개를 거부했다. 이 호스트 검사는 래치 전 수용과 이후 발행 거부를 구분한다.

장치 관측은 게스트 안에서 가상 PL061을 읽은 결과다. 두 정책 모두 일반 실행 전체 적격성은 미확정이다. 외부 전기 신호, 안전 IPC 전송, 제품 타이밍과 최악 간섭은 검증 범위 밖이다. 기본 클록 실패 원인은 미확정이며 별도 #109 콜드 시작 실험이 남아 있다.
