# EVD-124 · Fixed-input native EDF interruption and return

CHG-124 / IMP-124 / POL-005 / [#312](../native-edf-block-input.en-ko.md) / [#298](https://github.com/Romanof123/JNOX/issues/298) / [Operator recipe](../../examples/native-edf/README.md)

`424a63fbce01189c9be054107e4e6e42ec5ad965`

Both first boots on one Cortex-A72 QEMU virt CPU ran A→C→A→B. The external trace showed PPI 30 interrupting the byte load at `0x4001e8` in batch_reduce. After C exited, ERET returned A to that PC with SP_EL0 `0x1010f40`. Both journals matched the saved and restored native frame `0x402141c0`. Saved X21 and disassembly identified 12,937 completed blocks at interruption in plain and 13,120 in traced. Later private reads showed further progress.

Both boots completed all three jobs before their individual deadlines, with no skipped grids or dropped rows. A reduced 32,768 blocks of 4 KiB (128 MiB) to 17,112,760,320. B completed 128 blocks with 32,768 in each of 16 bins. C completed eight blocks and counted 2,048 exceedances. Exit statuses were 17, 29 and 43.

Four controls used the same A ELF. One block produced 522,240 and exit 17. Inputs 65537 and 2x each yielded zero progress and sum, exit 105. With no extra arguments the original timed mode completed 17,608 blocks, sum 9,195,601,920 and exit 17. This supplies the outstanding #298 fixed-input functional witness on the named emulator. Both earlier #299 externally traced clock-helper returns retain their original partial verdicts.
