# EVD-034 · Service and response across 16 EEVDF wakes

[한국어](evd-034.md) · [Predeclared contract](../m4-eevdf-wake-design.md) · [11 originals and hashes](evd-034.json)

An independent verifier reconstructed 128 timer IRQs, 16 blocking SVC #1 calls from C and 127 changes of owner from one QEMU virt cold boot. A and B remained runnable on one virtual Cortex-A72. A/B/C had fixed weights 2/2/1 and one-unit requested slices. C blocked after each of its first 16 grants and became runnable after 1, 2, 3 and 4 intervening completed grants cyclically.

| Observation | Result |
|---|---|
| A/B/C grants | 55 / 54 / 19 |
| Peak absolute service error across every prefix | 1.1 / 1.6 / 2.2 quanta respectively against a limit of 20 per task |
| Intervening grants from wake to first work | 3, 2, 5, 4 repeated four times. Nearest-rank p50/p95/p99/max were 3/5/5/5 against a maximum of 6 |
| Counter delay from wake to first work | p50 2,235,564 counts. p95, p99 and maximum each 3,718,362. At 62.5 MHz the maximum was 59.493792 ms or 5.9493792 quanta against a limit of 8 (625,000 counts per quantum) |

The verifier compared every service prefix against accumulated runnable weight fractions and linked each SVC frame to its restored PC and first task-code counter sample. This distribution describes one run at fixed settings. Weight and slice changes were exercised in [EVD-023](evd-023.en.md). Repeated wakes combined with changing settings, board latency and product limits remain open.

## Offline replay

From the repository root, restore the originals with the following Python 3 code, then run `python evd-034-replay/verify.py`. Compare its JSON output with the preserved `summary.json`. The `raw/` directory contains observation memory, exception trace, UART, QMP, launch and exit records. The top level contains the verifier, summary, symbols, C-worker disassembly and boot log.

```python
import base64, hashlib, io, json, zipfile
from pathlib import Path

record = json.loads(Path("docs/evidence/evd-034.json").read_text())
blob = base64.b64decode(record["zip_base64"], validate=True)
assert hashlib.sha256(blob).hexdigest() == record["zip_sha256"]
dest = Path("evd-034-replay")
dest.mkdir(exist_ok=False)
with zipfile.ZipFile(io.BytesIO(blob)) as archive:
    assert set(archive.namelist()) == set(record["files"])
    for name, spec in record["files"].items():
        data = archive.read(name)
        assert len(data) == spec["size"]
        assert hashlib.sha256(data).hexdigest() == spec["sha256"]
        path = dest / name
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_bytes(data)
```
