# EVD-033 · 주기 단조 및 마감 단조 우선순위에서의 주기 작업 릴리스

[English](evd-033.en.md) · [승인 기준](../pol-004-exact-periodic.md#한국어)

첫 관측기 호출은 지원하지 않는 `--capture-dir` 옵션을 거부해 QEMU 시작 전에 종료 코드 2를 반환했다. 지원되는 실행 경로로 시작한 첫 번째이자 유일한 게스트 부팅은 통과했다. 관측기는 예상한 UART 111바이트 전체를 캡처하고 무출력 대기 구간 뒤 QEMU를 종료했다. 게스트는 가상 Cortex-A72 한 개, GICv2, 메모리 128 MiB에서 실행됐다.

A의 주기는 10, 상대 마감은 9였고 B의 주기는 12, 상대 마감은 4였다. B를 먼저 큐에 넣었다. 0틱에서 RM은 A 다음 B를, DM은 B 다음 A를 선택했다. 두 정책 모두 10틱에 A, 12틱에 B를 다시 실행했다. IRQ 14회로 구성된 각 구간에서 첫 IRQ 뒤 두 작업이 완료됐고 11번째와 13번째 IRQ 뒤에는 각각 하나가 완료됐다. 마지막 IRQ에서 게스트는 완료 8회와 빈 작업 큐를 확인한 뒤 정지했다.

QEMU는 제어기 ELR `0x40201260`에서 발생한 IRQ 28회와 신드롬 `0x56000001`인 SVC #1 8회를 기록했다. 작업과 제어기의 복귀 PC는 예외 기록에 직접 남았다. 검증한 게스트는 인터럽트 ID 30, 타이머 제어 하위 비트 5, 작업 진입 표시의 SP A/B `0x402070c0` / `0x4020b0c0` 및 저장 프레임 주소 `0x40206d80` / `0x4020ad80`을 검사한다. 이 주소는 실행된 검사와 ELF 역어셈블리에서 확인했다. 제어기 저장 주소 `0x4020ed70`은 스택 배치로 계산했다. 사건별 SP 덤프, 실물 보드 지연 및 WCET는 이 기록에 포함되지 않는다.

JSON에는 추출 및 오프라인 재현 명령, 원본 UART와 예외 기록, 관측기 출력, 검증기와 ELF 역어셈블리가 들어 있다. [독립 근거와 재현 기록](evd-033.json)

QEMU 부팅 10회(통합 7회, 기준 3회)가 모두 통과했다. 선택기 검사에서 예상한 4건을 거부했고 호스트 검사 Rust 126건과 Python 32건이 통과했다. 기존 periodic·periodic-preempt·EEVDF 바이너리는 변경됐으며, 세 프로파일 각각의 UART 바이트와 심볼 기준 예외 순서는 기준 실행과 일치했다. [통합 회귀 검사 기록](evd-034-regressions.json)
