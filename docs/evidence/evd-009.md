# EVD-009 · 실행 중인 RM·DM 작업의 선점

[English](evd-009.en.md)

**RM은 타이머에 중단된 A를 즉시 재개했다. DM은 기한이 짧은 B를 먼저 완료한 뒤 A를 같은 명령에서 재개했다.**

독립 검증팀은 구현을 열기 전에 단일 코어 Cortex-A72 QEMU 게스트를 한 번 부팅했다. UART 178바이트와 종료 코드 0을 먼저 기록했다. 같은 실행에서 IRQ 18회와 SVC #1 14회를 확인했다. 14번째와 17번째 IRQ는 모두 A의 덧셈 명령 `0x402012b0`에서 발생했다. 누락·순서 반전·추가 바이트를 넣은 호스트 대조군 3개를 모두 거부했다.

게스트는 전용 스택, 레지스터, 실행 진척을 검사했다. 외부 예외 로그에는 중단·복귀 주소가 남는다. 실제 보드 지연, WCET, 일반적인 스케줄 가능성은 별도 검증 항목이다. 최초 WSL Git 조회는 게스트 실행 전에 실패하여 Windows Git으로 소스 리비전을 확인했다.

통합팀은 같은 리비전에서 기존 periodic-bench만 켠 구성(111바이트)과 전체 기능을 켠 CBS 구성(112바이트)을 차례로 부팅했다. 두 관찰기 모두 성공했다.
