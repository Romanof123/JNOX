# EVD-014 · Pi 4 모델의 물리 타이머 선점과 정확한 복귀

[English](evd-014.en.md)

Pi 4 커널 원시 이미지를 raspi4b 모델에서 실행했다. LOW의 덧셈 명령 `0x812bc`에서 IRQ가 발생해 벡터 `0x80a80`을 거쳐 HIGH 진입점 `0x8134c`으로 복귀했다. HIGH의 `0x81388`에 있는 SVC #1이 `0x80a00` 벡터를 거쳐 LOW의 같은 `0x812bc`로 돌아갔다. 게스트 내부에서 PPI 30과 프레임·스택·진척을 확인했다. 외부 예외 로그는 중단·복귀 주소를 확인한다.

독립 검증팀은 첫 게스트에서 UART 103바이트, 마지막 LF 이후 1초 무출력, 관찰기 종료 코드 0을 기록했다. 셸 인수 준비 오류 1건은 관찰기 실행 전에 발생했다. 호스트 대조군 5개를 모두 거부했다. 두 클린 빌드에서 원시 이미지와 ELF 해시가 일치했다. 통합팀은 SD용 파일 묶음의 스케줄러 이미지와 기존 직렬 이미지, virt 스케줄러를 차례로 부팅했다. 지원 밖 Pi 기능 조합 5개를 빌드에서 거부했다. [UART / IRQ / SVC](evd-014.json) · [SD / SHA-256](evd-014-package.json)

검증 환경은 QEMU 11.1.3, 2 GiB raspi4b 모델, 코어 0이다. 실보드에서는 보안 펌웨어 스텁이 비보안 PPI를 위임해야 한다. 실제 전원 인가 2회, 보드 예외 추적, 실시간 지연과 SMP 검증은 별도로 남아 있다. [IMP-014](../boards/pi4-timer.md) · [#34](https://github.com/Romanof123/JNOX/issues/34)
