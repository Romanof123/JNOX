# EVD-055 · 일반 Rust 작업의 시드별 복권 선택과 실측 스트라이드 서비스

[CHG-057 / IMP-055](../ordinary-proportional-plan.md) · [#136](https://github.com/Romanof123/JNOX/pull/136) · [#54](https://github.com/Romanof123/JNOX/issues/54) · [#79](https://github.com/Romanof123/JNOX/issues/79) · [JSON](evd-055.json) · [ZIP](evd-055-first-three.zip)

단일 Cortex-A72 QEMU TCG 기본 시계에서 독립 프로세스로 최초 콜드 부팅 3회가 모두 완료됐다. A/B/C의 가중치는 1/2/4였다. 표의 서비스는 각 실행 구간에서 관측한 완전한 틱을 소유자별로 더한 값이다. 62.5 MHz 카운터에서 복권 틱은 625,000카운트(10 ms), 스트라이드 틱은 2,500,000카운트(40 ms)다.

| 사례 | A/B/C 실행권 | A/B/C 서비스(틱) | IRQ/SVC/ERET | UART 행 |
|---|---|---|---|---:|
| lottery1 | 10/8/14 | 10/8/14 | 33/0/33 | 394 |
| lottery2 | 5/11/16 | 5/11/16 | 33/0/33 | 394 |
| stride | 6/6/4 | 6/12/8 | 11/6/17 | 197 |

콜드 시드 1과 2에서 스케줄러가 실제 적격 선택마다 유지한 SplitMix64 상태, 원시 단어, 티켓, 반개구간과 실제 소유자를 독립 재생했다. 합계 7장의 티켓 중 0은 A, 1–2는 B, 3–6은 C다. 이 두 실행에서 각 선택에 단어 하나가 사용됐다. 초기 적격 집합이 비어 있을 때 유휴 프레임으로 복귀했고, 이때 난수 상태가 유지됐다는 것은 이후 상태의 연속성에서 추론했다. 유한 시드·실행 구간의 결과다.

스트라이드는 A/B 8회 선택 후 C를 합류시켰다. 행 11은 기존 A/B 패스 720,720/720,720, 준비 마스크 3→7을 기록했다. C는 기존 최소 패스에서 시작했다. 앞뒤 8회 선택은 각각 ABABABAB와 ABCCABCC였고 서비스 증가량은 4/8/0과 2/4/8이었다. A는 한 틱 뒤 SVC로 양보했고 B와 C는 두 틱 단위 타이머 선점을 받았다. 독립 재생은 유휴 진입을 포함한 실제 ERET, IRQ/SVC 순서·PC를 전용 작업 프레임·저장된 복귀 주소와 대조했다.

세 게스트 모두 최초 실패 기록의 다섯 필드가 0이었다. 작업 진행·스택·카운터·GIC 값은 게스트 기록이다. 외부 예외 로그는 전환 순서와 PC를 확인하지만 명령별 CPU 서비스나 계측 구간 밖의 복귀 비용을 독립 측정하지 않는다. lottery-miss와 stride-delay는 이번에 실행하지 않았다. 과거 네 IRQ 뒤 실패의 원인(#79), 통제된 지연 차감, 실물 보드 간섭과 제품 시간 보장은 미확정이다.
