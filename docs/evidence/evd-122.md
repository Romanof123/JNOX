# EVD-122 · 네이티브 고정 클래스 및 피드백 큐

CHG-122 / IMP-122 / POL-009 / [#308](../native-multilevel-applications.en-ko.md) / [#309](https://github.com/Romanof123/JNOX/pull/309)

`0ed120045885a75eae2429384bcc6204937f15cc`

단일 Cortex-A72 QEMU virt의 62.5 MHz 시계에서 최초 실행 9개가 완료됐다. 고정 MLQ와 피드백 MLFQ의 일반·추적 부팅 4회에서 보고 앱이 깨어난 12회 모두 CRC에서 보고 앱으로 전환했다. 대기 중 CRC 계산이 진행됐고 보고 앱은 매회 경보 256건씩 합계 768건을 확인한 뒤 53으로 종료했다. 세 슬롯 고정 큐에서는 상위 두 슬롯이 0→1→0으로 시작했고 둘 다 종료한 뒤에야 하위 보고 앱이 실행됐다. 피드백 주 실행 2회는 각각 승격 경계 6개를 통과했다.

누적 서비스 대조에서 슬롯 0은 첫 승격 전에 305번째 양보에서 강등됐다. 동급·누적·단독 양보 실행은 각각 최초 512행을 보존했고 이후 전이 15,939·15,905·15,886건은 누락돼 채점에서 제외했다. 각 실행의 별도 종료 시점 전용 RAM에서 16,384블록, 67,108,864바이트, 경보 4,194,304건과 종료값 59를 확인했다. 모든 앱이 잠든 세 구간에서는 서비스 부과와 승격이 없었다.

호스트 시험 165개가 통과했고 잘못된 CLI 11건과 직접 Cargo 설정 10건이 거부됐다. 게스트 채점 행에서 자연적으로 비교값이 정확히 겹친 사건이나 한 번에 여러 단계를 넘은 지연 정산은 관측되지 않았다. 추적 부팅의 복귀 PC는 전환을 뒷받침하며 ERET 직전 카운터는 첫 명령 시각의 하한이다. 이 관측은 선택한 가상 설정에 적용된다. 실물 응답 시간과 제품 전반의 상한은 미확정이다.
