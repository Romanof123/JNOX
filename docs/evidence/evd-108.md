#283의 짧은 작업은 2/6 통과했다(partitioned 1회차, clustered 2회차). 나머지 4회는 엄격한 루프 범위 밖에서 M을 복귀시켰다. 스트림은 6/6 통과했다. global의 짧은 작업은 두 회차 모두 루프 범위 밖에서 복귀했다. 나머지 미통과 순번은 partitioned 2회차와 clustered 1회차였다. 앞선 #279에서는 짧은 작업 3/6, 스트림 6/6을 통과했다.

각 정책의 일반 세 번째 블록 경로에서 링크된 기계 명령 수는 짧은 작업 250개에서 245개로, 스트림 16,490개에서 16,485개로 줄었다. 해당 경로의 호출·복귀·조건 분기 수는 같았다. 6개 바이너리 각각에서 스칼라 접근 함수 입력 검사 13개(정상 4개, 잘못된 포인터 4개, 잘못된 토큰 4개, 유효하지 않은 활성화 1개)를 모두 통과했다. 원본 기록 12회의 독립 재판독도 모두 통과했다. 별도 인계 브랜치 #281은 보류 상태다.

여섯 이미지 쌍 모두 링크 경로 비용 검사를 통과했다. 각 세 번째 블록 경로에서 SP 직접 읽기 1회와 실행 명령 5개가 줄었다. 각 쌍의 양쪽 모두 .text는 20,468바이트, 원시 이미지는 53,448바이트였다. 링크된 접근 함수 검사 78개에서 정상 반환 또는 거부 결과가 기대값과 일치했다. 판독기는 과거 순번 30개를 재판독했다. 후보 최초 부팅 12회 모두 저장된 IRQ PC와 외부 ERET PC가 일치했고 프레임/SP/X21 연속성과 최종 계산값을 확인했다. global의 M은 CPU1에서, 고정 정책의 M은 CPU0에서 재개했다. 경과 시간과 실물 보드 성능은 측정하지 않았다. 메인라인 통합은 릴리스 검토를 기다린다.
