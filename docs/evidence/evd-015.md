# EVD-015 · 실행 중 여유 시간 역전과 고정 경계 선점

[English](evd-015.en.md)

동일한 A·B에서 EDF는 A, LLF는 B를 먼저 실행했다. LLF는 시각 5의 동점에서 B를 유지했다. 6에서는 새 도착 없이 A가 B를 선점하고, A가 끝나자 B가 원래 명령으로 복귀했다. 7에는 여유가 −2인 C가 B를 선점하고 완료 후 B가 다시 같은 중단 지점으로 돌아갔다. EDF에서도 C의 더 이른 기한이 A를 선점했다.

첫 관찰기의 종료 코드는 0이었다. 계측기가 마지막 UART를 전달하기 전에 vCPU를 정지해 마지막 0.1초간 실행 중 무출력 여부는 판정할 수 없었다. 별도 독립 검증자가 동일 ELF로 새 게스트를 실행했다. 두 번째 실행은 346바이트 수신 후 0.1초간 무출력을 확인하고, 호스트가 종료를 요청한 시점에 QMP로 실행 중임을 확인했다. 이 게스트의 IRQ 8회와 완료 SVC 6회를 대조했다. 62.5 MHz 게스트 카운터의 6,250,000카운트 간격마다 설정한 절대 구간 안에서 8회 모두 IRQ가 관찰됐다. [First](evd-015-first.json) · [UART / QMP / IRQ](evd-015.json)

독립 호스트 모델은 11,520개 작업 조합을 대조했고 전체 호스트 시험 48개가 통과했다. 단독·조합 커널 회귀 구성 4개의 게스트 부팅도 통과했다. 논리 작업량과 완료 시각은 시험 입력이다. 이 결과로 다른 작업 부하의 스케줄 가능성이나 실보드 최악 지연을 확정할 수 없다. [QEMU](evd-015-regressions.json)
