# EVD-032 · 동순위 도착·RR 만료 일치와 지연 IRQ

[English](evd-032.en.md) · [사전 합격 기준](../fixed-runtime-edges.md) · [원본 49개 및 SHA-256](evd-032.json)

독립 검증자는 일반 이미지 두 개와 계측 이미지 두 개의 최초 콜드 부팅을 각각 통과로 판정했다. QEMU virt, Cortex-A72 한 코어, TCG, GICv2, RAM 128 MiB에서 RR 양자 Q는 12,500,000 카운트였다. 같은 우선순위의 A(슬롯 1), B(2), C(0)의 공개 시각은 각각 부팅 표본 T, T+Q/2, T+Q였다. 네 부팅 모두 A 시작 → B → C → A 재개 → A 종료 순서, 각 작업의 16바이트 정렬 전용 스택, 종료 SVC #1 세 번, 마지막 idle PC를 확인했다. B와 C가 읽은 A 진행량은 같았고 A는 재개 후 진행했다.

| 사례 | 일반 이미지 | 계측 이미지에서 독립 재구성한 결과 (62.5 MHz 카운트) |
|---|---|---|
| 도착·만료 일치 | IRQ 2회. 첫 IRQ에서 A의 중단 PC로 즉시 복귀했다. | T=46,436. 첫 비교 6,296,436, 실제 IRQ 6,465,401. A가 잔여 양자를 유지하고 다음 비교를 12,546,436으로 설정했다. C 공개와 A 만료의 논리 시각이 일치했고 실제 IRQ는 12,682,109였다. B 다음 C, 이어서 A의 저장 프레임으로 복귀했다. 슬롯 0/1/2의 총 서비스는 143,102 / 12,763,436 / 155,056이다. |
| 지연 IRQ | A가 카운트 116,318~50,116,320 사이 IRQ를 마스킹했다(50,000,002). 이후 IRQ 1회로 B를 선택했다. | T=45,246. 마스크 130,463~50,130,463(정확히 4Q). 첫 비교 6,295,246은 50,266,925에 처리됐다. A에게 50,221,679를 차감하고 한 번의 결정으로 공개 기한 순서 B→C를 보존했다. 그동안 B·C에 대한 차감이나 중간 회전은 없었다. 슬롯 0/1/2 총 서비스는 129,405 / 50,360,267 / 152,356이다. |

일반 이미지는 UART·작업 관찰 메모리·외부 예외/복귀·정지 PC로 평가했다. 계측 이미지에는 각각 6행/5행이 있었고 넘침은 0이었다. 외부 ELR·복귀 PC를 행과 대조하고 나가는 소유자별 인접 카운트 차를 누적했다. IRQ 행의 INTID는 30, ISB 후 제어 판독값은 활성 비교에서 1, 마지막 idle에서 0이었다. 실보드 최악 지연, 전체 스케줄러 프로파일 승인과 제품 안전 승인은 이 기록의 범위 밖이다.

## 오프라인 재현

저장소 루트에서 아래 Python 3 코드를 실행하면 49개 파일의 길이와 SHA-256을 확인하며 새 디렉터리에 복원한다. 이어 `python evd-032-replay/validator.py`를 실행한다. 검증자는 같은 디렉터리의 `verification.json`을 다시 생성한다. 원본은 JSON 묶음에 보존된다.

```python
import base64, hashlib, json
from pathlib import Path

archive = json.loads(Path("docs/evidence/evd-032.json").read_text())
root = Path("evd-032-replay")
root.mkdir(exist_ok=False)
for name, entry in archive["files"].items():
    data = base64.b64decode(entry["base64"], validate=True)
    assert len(data) == entry["bytes"]
    assert hashlib.sha256(data).hexdigest() == entry["sha256"]
    target = root / name
    target.parent.mkdir(parents=True, exist_ok=True)
    target.write_bytes(data)
```

파일 지도에서 `ties/`, `late/`는 일반 이미지, `ties-trace/`, `late-trace/`는 계측 이미지다. 각 디렉터리에는 `boot.txt`, `rc`, `elf.sha256`, `symbols.txt`가 있다. `raw/`에는 UART, 16워드 관찰 메모리, IRQ/SVC 트레이스, 레지스터, QMP, 실행 인자 및 종료 기록이 있고 계측용에는 `trace.bin`이 추가된다. 루트의 `validator.py`는 오프라인 판정기, `verification.json`은 디코딩 결과, `run.sh`는 원래 WSL 경로와 기존 ELF를 사용하는 캡처 명령이다.
