# EVD-100 · 한 그리드 주기의 모든 카운터 구간에서 소유자 전환 상한

`CHG-100` · `IMP-100` · `POL-005` · [#260](https://github.com/Romanof123/JNOX/issues/260) · [#261](https://github.com/Romanof123/JNOX/pull/261).

소스 4c62e02의 최초 QEMU 게스트 8건이 통과했다. 원래 수용되는 두 작업에서 한도 3은 기동 전에 거부했고 EDF·표본 LLF 모두 4에서 허용했다. 정상 실행의 실제 경로는 유휴→A→서비스→A→B였다. 한 번의 전체 실행에서 실제 복귀한 소유자 전환은 4회, 길이 Q의 임의 구간에서 최대 2회였고 해석 상한은 4회다. 기존 마감 게스트 16개의 종결을 확인했다. 실행 코드·적재 레이아웃이 같았고 적재된 읽기 전용 데이터의 Rust 줄 번호만 달랐다. 별도의 유한 모델로 일정 14,648건과 완전한 정수 시간창 953,766건을 대조했다. IRQ당 지정된 셀 및 작업당 1회 이하 완료가 전제다. 실기 시간·제품 간섭 승인은 열려 있다.
