# EVD-042 · FS-M3-01 가상 런타임 검증 기록

[English](evd-042.en.md) · [#94](https://github.com/Romanof123/JNOX/issues/94) · [검증 기록 색인](evd-042.json)

**현재 판정은 v2 부분 통과다.** 정확 최악 위상, 결정론적 인계 4개와 상태 스크립트 9개를 포함해 기본 구성 14개가 적격이었다. 기본 클록 8개는 활성화 전 억제됐고 동률 입력은 관측 상한이 한 틱 늦었다. 별도 진단 10개 중 명령 계수 실행으로 지연·수요 초과를 분리했다. 단독 CLI는 예외 12건과 잘못된 거부 4건을 보였다. #94 전체, 실물 응답 및 안전 IPC 전송은 미확정이다. [EVD-042 v2](evd-042-v2.md)

최초 검증의 부분 통과 판정은 유지된다. v1에서는 정확 경계 두 건이 모두 미충족이었다. [EVD-042 v1](evd-042-v1.md)
