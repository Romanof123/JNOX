# EVD-042 · FS-M3-01 가상 런타임 검증 기록

[English](evd-042.en.md) · [#94](https://github.com/Romanof123/JNOX/issues/94) · [검증 기록 색인](evd-042.json)

**부분 통과.** 기본 구성 23개 중 첫 콜드 실행에서 14개가 적격이었다. 호스트 읽기 실패 뒤 별도 콜드 재시도로 적격 구성은 15개가 됐다. 결정론적 명령 계수에서 두 정확 경계가 모두 적격이었다. 기본 클록의 일반 사례 8개는 모두 미충족이었다. 진단 구성 10개는 별도 집계했다. [EVD-042 v3](evd-042-v3.md)

이전 독립 판정과 원본 캡처 · [v2](evd-042-v2.md) · [v1](evd-042-v1.md)

실물 보드 응답, 안전 IPC 전송 및 #94 전체 적격성은 미확정이다. [#109](https://github.com/Romanof123/JNOX/issues/109)

통합 점검에서는 결정론적 주 시험 5건과 진단 2건이 적격이었다. 기본 클록 RM 정상 사례는 종료 표식까지 도달했으며 예상대로 목표 시각 검사에서 부적격이었다. 설정 오류 1건은 게스트 실행 전에 발생했다. 별도의 호스트 읽기 오류로 첫 RM 최악 위상 캡처가 종료 표식 전에 중단됐고 새로 부팅한 재시도는 적격이었다. 기존 구성 회귀 부팅 5건이 통과했고 무효 빌드 조합 4건은 거부됐다.

통합 이미지 23개의 기계어와 세그먼트 배치는 원본과 일치했다. 각 페이로드에서는 패닉 소스 줄 번호를 나타내는 3바이트가 달라졌다. 정적 PT_LOAD 메모리는 최소 부팅 16,667바이트, 일반 RM 정상 116,724바이트, 스크립트 RM 동일 틱 118,880바이트였다. 이 수치는 링크된 메모리 예약량이다. [통합 회귀 및 메모리 크기 기록](evd-042-regressions.json)
