# EVD-042 · FS-M3-01 가상 런타임 검증 기록

[English](evd-042.en.md) · [#94](https://github.com/Romanof123/JNOX/issues/94) · [검증 기록 색인](evd-042.json)

**현재 판정은 v1 부분 통과다.** 최초 독립 검증은 단일 코어 QEMU virt에서 서로 다른 ELF 이미지 23개를 다뤘다. 결정론적 RM·DM 정상/손실 인계 네 건이 통과했고, 결정론적 RM 스크립트 아홉 건은 기대한 상태 전이를 재현했다. 기본 클록 여덟 건은 활성화 전에 억제됐다. 결정론적 RM 두 건은 최악 간격 및 발행·만료 동시 사건에 지정된 틱을 놓쳤다. #94 전체 적격성은 미확정이다. [v1 사례별 결과](evd-042-v1.md) · [원시 캡처 23건과 재현 방법](evd-042-v1.json) · [v1 소스](https://github.com/Romanof123/JNOX/commit/d17ce2d36c7c9bc4db40dc60fccec4f0ebfc8d29)

인계에는 로컬 Rust 송신 작업을 사용했고 게스트가 가상 PL061 레지스터를 읽었다. 실물 보드 응답, 안전 IPC 전송과 실측 실행 예산 근거에는 별도 검증이 필요하다. 후속 후보의 시작 및 경계 변경은 독립 런타임 판정을 기다린다. [후속 후보 소스](https://github.com/Romanof123/JNOX/commit/e0f0ce623aa170a8daff600515b0c76e0b20405f)
