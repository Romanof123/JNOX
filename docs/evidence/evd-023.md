# EVD-023 · EEVDF 실행 자격과 기상 지연

[English](evd-023.en.md) · [승인 기준](../m4-eevdf.md) · [#56](https://github.com/Romanof123/JNOX/issues/56)

검증자는 슬라이스와 가중치 변경을 포함한 디스패치 12회를 재현했다. 62.5 MHz 가상 카운터에서 한 퀀텀은 625,000카운트였다. 두 기상 시점부터 첫 작업까지 각각 2,843,013카운트(45.488208 ms)와 3,643,095카운트(58.289520 ms)가 걸렸다. 예외 추적에는 IRQ 순서가 기록됐다. PPI30 식별은 게스트 타이머 검사와 해당 소스로 교차 확인했다. 이 게스트 검증에서는 호스트 대조 시험을 실행하지 않았다.

이 기록의 범위는 해당 가상 부팅이다. 실물 보드 타이밍과 제품 기능 안전은 별도 검증 대상이다. ELF SHA-256 `68aea143810e99bfe45e088b19acc0ef2e7496cb56c7e43b4c9177f96e1d6881`. [검증 소스](https://github.com/Romanof123/JNOX/commit/92d62b30b89abdefebb1d0fdf268b8a3cfd30526) · [검증 결과와 원시 기록](evd-023.json)

동결된 소스에서 Rust 테스트 120개, Python 테스트 28개와 순차 게스트 부팅 14회가 통과했다. [회귀 결과](evd-023-026-regressions.json)
