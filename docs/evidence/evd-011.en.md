# EVD-011 · First serial boot on the Pi 4 model

[한국어](evd-011.md)

A fresh verifier launched the raw image on the QEMU 11.1.3 raspi4b model with 2 GiB RAM and TCG. The first guest emitted both boot markers in exactly 29 bytes, followed by one second of silence. After recording the verdict, the verifier compared the 0x80000 entry and load address against firmware settings and linked MMIO instructions. Host controls rejected CRLF, a trailing byte and an ELF supplied as a raw image.

The separate first observer status file contained only a newline. Its terminal PASS path implies exit 0, and the outer wrapper recorded 0. Integration separately booted the staged offline payload, observed all 29 bytes and directly captured the second observer exit code 0.

Two clean target directories produced identical ELF and raw hashes. The raw payload occupies 429 bytes. Online and offline packaging reproduced the same pinned firmware file set and SHA256SUMS. Controls rejected an occupied output directory and corrupted firmware. The board model loads the raw payload directly. Physical microSD, EEPROM, firmware and electrical UART behavior, timer IRQs, SMP and product timing await hardware evidence.
