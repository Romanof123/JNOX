# CHG-071 · 예약 단계 v3 최초 실행

[CHG-071](../reservation-stage-attribution-plan.md) · [#153](https://github.com/Romanof123/JNOX/pull/153) · [Source](https://github.com/Romanof123/JNOX/tree/df8fde7f5241a722724f06b073ea3fb53e701659) · [JSON](reservation-stage-v3-first.json) · [ZIP](reservation-stage-v3-first.zip) · [v1](reservation-stage-first.md) · [v2](reservation-stage-v2-first.md)

정렬 깨움(W, 일반) 6건 중 3건, 포화 CBS(S, 외부 추적) 6건 중 2건이 완료됐다. 기준 이미지 B는 완료된 부팅이 없었다. 경계 한도는 62,500틱(1 ms)으로 유지했다.

열두 순번을 모두 보존했다. 2/5는 선택 전 경계 중단 4건, 2/2는 실제 작업자 표식 지연 3건이다. 완료된 W는 슬롯 34·실행권 18회, S는 슬롯 10·실행권 8회에 도달했다. 각 게스트는 15초 제한까지 유지됐다. 터미널 UART와 실제 종료 판정은 순번별 원본에 있다. 외부 IRQ/SVC/ERET 대조는 S에만 있다.

두 B의 전체 ELF 해시는 과거 파일과 달랐으나 적재 세그먼트의 헤더와 바이트는 과거·신규 부모 참조와 일치했다. 두 E에서는 IAR 저장 뒤 CBNZ로 일반 DSB 또는 표본 DSB/ISB/MRS(0x402013e8/ec/f0) 중 하나를 선택한다. 표본 경로는 다른 장벽을 건너뛴다. F에서는 두 번째 프레임 검사 성공 후 목적지 뱅크 접근 전에 ISB/MRS(0x40201968/6c)에 도달하는 링크 경로를 확인했다. B의 정적 CNTPCT 명령은 26개, E/F는 각각 27개다.

아래 표는 영수증 마스크, 종료 슬롯/소유자/상태/사유, 가드 피연산자, IRQ와 기준 시각 차이, 읽기·측정점 전후·전체 구간, 첫 작업자 표식과 실행권 수를 담는다. 시간 단위는 같은 부팅의 62.5 MHz 카운터 틱이며 —는 미관측이다.

두 번의 W/E 관측에서 뒤 구간은 전체의 85.8%, 83.0%였고 S/E에서는 82.7%, 82.6%였다. W/F의 앞 구간은 87.1%, 86.0%, S/F는 85.7%, 86.8%였다. 네 비교 모두 B로 옮겨 해석할 범위·도달 조건을 충족하지 못했다. 서로 다른 부팅의 카운터를 빼거나 누락값을 채우지 않았다. 물리 보드 시간, 스택 최대 사용량과 전체 프로필 적격 여부는 확인되지 않았다.

공개 ZIP은 텍스트 파일 22개에서 절대 홈 경로의 계정 부분만 `capture-user`로 대체했다. 원본 아카이브는 비공개로 보존했다. JSON은 각 파일과 두 ZIP의 원본·공개 크기 및 SHA-256을 기록한다. 공개 고정 입력과 명령 메타데이터에서 인수 순서와 수치를 유지했다. 게스트 스트림, ELF 및 역어셈블리는 원본 바이트와 동일하다.

```sh
python3 -m zipfile -e reservation-stage-v3-first.zip v3
python3 -c "import hashlib,json,pathlib; p=pathlib.Path('v3'); j=json.loads(pathlib.Path('reservation-stage-v3-first.json').read_text()); assert all(hashlib.sha256((p/n).read_bytes()).hexdigest()==h for n,h in j['public_member_sha256'].items())"
```
