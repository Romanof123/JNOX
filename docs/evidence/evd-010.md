# EVD-010 · 두 프레임에 걸친 정적 시간 분할

[English](evd-010.en.md)

양보하지 않는 A가 할당 시간을 넘겼을 때 커널이 CPU를 회수했다. 첫 프레임에서는 B가 준비되지 않아 유휴 스레드가 실행됐다. B가 준비된 뒤에도 명시적 유휴 구간이 끝날 때까지 유휴 스레드가 CPU를 유지했다. 다음 프레임에서는 A가 중단된 주소로 복귀했고, B가 자신의 시간 구간에서 실행됐다.

최초 독립 부팅에서 UART 135바이트, 관찰기 종료 코드 0, 예외 6회를 기록했다. 검증팀은 첫 판정을 기록한 다음 같은 실행의 예외 복귀 주소를 확인했다. 표의 시점은 소스와 ELF의 절대 타이머 설정에서 산출했다. 레지스터·스택 검사는 게스트 안에서 수행했다. 이 기록의 범위는 단일 코어 기능 동작이다. 보드 지연 및 메모리 격리는 별도 항목이다.

별도 호스트 시험 30개가 통과했다. 독립 오라클은 소유자·길이를 조합한 729개 테이블에서 준비 마스크 4개와 프레임 3번을 확인했다. UART 순서 오류·추가·잘림은 거부했고 CRLF는 허용했다. 통합팀의 별도 회귀 부팅은 RR(171바이트)과 전체 기능 선택 시 partition(135바이트)이 각각 통과했다.
