# EVD-012 · 협력형 FCFS에서 실행 중인 작업의 CPU 유지

[English](evd-012.en.md)

A(ID 1)가 실행되는 도중 타이머가 B(ID 0)를 준비 큐에 넣었다. 첫 독립 게스트에서 타이머 IRQ는 A의 같은 명령 `0x40201290`으로 복귀했다. A가 양보한 뒤 B가 실행됐고 B가 대기하자 A가 재개됐다. A가 B를 깨운 호출도 A로 돌아왔다. A가 종료한 뒤 B가 재개됐고 B가 종료한 뒤 이벤트 처리가 시작됐다. 같은 실행에서 SVC 명령은 순서대로 2, 3, 4, 1, 1이었다.

용량 2인 큐에 1, 2를 넣고 초과 이벤트 4를 거부했다. 1의 처리기가 3을 등록한 뒤 2, 3 순으로 실행됐다. UART는 13줄 163바이트였다. 검증팀은 첫 판정 후 예외 복귀 주소를 대조했다. 이벤트 큐의 거부와 비중첩 호출은 실행 중인 게스트 검사·링크 코드로 확인했다.

호스트 시험 33개 통과, UART 대조군 3개 거부. 통합팀은 전체 기능을 켠 협력형 구성과 기존 시간 분할 구성을 순서대로 부팅했다. 실제 보드 선점·지연, 처리기 WCET 및 승인된 최대 실행 시간은 별도 검증 항목이다.
