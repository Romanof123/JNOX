# EVD-031 · 라즈베리 파이 4 모델에서의 고정 우선순위 런타임

[English](evd-031.en.md) · [#71](https://github.com/Romanof123/JNOX/issues/71)

독립 검증자는 QEMU 11.1.3의 raspi4b 모델에서 각 원시 커널 이미지를 두 번씩 콜드 부팅했다. 일반 부팅 네 번은 모두 첫 시도에 통과했다. FIFO 부팅마다 SVC 7회와 IRQ 2회가 기록됐다. B는 0틱 수면으로 양보한 뒤 준비 상태를 유지했고, HIGH가 A를 선점하고 종료하자 A가 B보다 먼저 재개됐다. 이후 B는 수면과 기상을 거쳤고, 거부된 수면 요청 뒤에도 계속 실행해 종료했다. RR 부팅마다 IRQ 3회와 SVC 3회가 기록됐고, 실행 순서는 A/HIGH/A/B/A/B/idle로 재구성됐다. 작업 식별 근거는 UART, 링크된 명령어, 예외·복귀 PC다.

별도 디버거 재현에서 CNTFRQ_EL0는 62,500,000 Hz였고 설정된 RR 퀀텀은 200 ms였다. A/B/HIGH의 스택 슬롯은 FIFO에서 0/1/2, RR에서 0/2/1이었으며 슬롯 크기는 16 KiB였다. 두 재현 모두 유휴 PC `0x8125c`, SP `0x98120`에서 끝났다. 일반 예외 기록에는 사건별 카운터, 작업 SP, 인터럽트 ID와 타이머 레지스터 표본이 없다. RR의 정확한 잔여 실행 시간과 실물 타이밍은 이번 측정 범위 밖이다.

모델은 kernel8.img를 직접 로드했다. 오프라인 패키지에는 버전을 고정한 펌웨어, 장치 트리, 오버레이와 부팅 설정을 담았다. 실물 펌웨어 부팅, 직렬 포트 동작, 보드 타이밍과 제품 안전에는 별도 근거가 필요하다.
