# EVD-040 · 일반 Rust 작업의 MLQ·MLFQ 실행

[English](evd-040.en.md) · [사전 합격 기준](../ordinary-multilevel.md) · [독립 원본·재현 자료](evd-040.json)

CHG-042 / IMP-040 / POL-009. 일반 및 계측 이미지로 MLQ·MLFQ를 각각 처음 한 번씩 콜드 부팅했다. 네 실행 모두 단일 Cortex-A72 QEMU virt, GICv2, TCG에서 통과했다. 일반 부팅의 UART·무출력 관찰 구간·예외 기록이 보존돼 있다. 계측 부팅에서 최초 선택을 포함하여 MLQ 15회와 MLFQ 42회의 결정을 독립 재구성했다.

**MLQ.** 세 작업 모두 처음부터 준비 상태였다. 클래스 2의 작업 1·2가 10회 타이머 IRQ에서 교대로 실행되는 동안 클래스 0의 작업 0은 큐에 남아 서비스가 0이었다. 11행과 12행에서 상위 작업이 차례로 종료한 뒤 작업 0이 디스패치·양보·종료했다. 작업 0/1/2의 최종 서비스는 296,589 / 3,936,504 / 4,443,824 카운트였다. 상위 부하는 유한했다. 계속 포화된 클래스 아래에서 최소 서비스 비율을 보장하는 기록은 아니다.

**MLFQ.** 62.5 MHz에서 상·중·하 할당량은 각각 2,500,000 / 3,750,000 / 5,000,000 카운트, 전체 부스트 간격은 실제 소유자 서비스 10,000,000 카운트였다. 클라이언트의 1행 양보 후 잔여량은 1,709,995였다. 4행에서 937,664를 남기고 차단됐고 5행에서 대화형 작업이 깨워도 보존됐다. 6행 양보 후 175,889를 남겼으며 8행 IRQ의 차감 284,419로 강등되어 초과분 108,530이 중간 단계에 차감됐다. CPU 작업은 18행에서 최하위에 도달했다.

10행 부스트는 [클라이언트, 대화형, CPU] 순서를 보존해 클라이언트에 즉시 복귀했다. 20·29행에는 [CPU, 대화형]에서 CPU가 선택됐다. 29행은 깨움 SVC 중 부스트 경계를 넘었다. 세 작업 모두 종료했으며 클라이언트/CPU/대화형 최종 서비스는 2,748,419 / 20,437,544 / 15,726,117이었다.

**관찰 범위.** 진단 자료의 나가는 프레임 14/41개는 각각 소유자별 16 KiB 스택 내 정렬된 832바이트 영역에 있었다. 검증자는 복귀 PC와 저장 프레임을 외부 예외 순서·링크 심벌에 대조했다. QMP 종단 PC는 MLQ `0x4020125c`, MLFQ `0x40201a5c`로 idle 내부였다. 빈 큐 경로에서 타이머 제어에 0을 쓰는 명령을 확인했지만 종단 레지스터 판독은 없었다. 실패한 깨움은 이미 준비됐거나 종료한 클라이언트를 대상으로 했다. 빈 테이블 시작·모두 차단·무효 설정/범위 밖 ID·강제 랩·버퍼 실패·복수 부스트 병합은 실행하지 않았다. 제품 부하·지연 한계·실보드 판정은 별도다.

## 오프라인 재현

저장소 루트에서 아래 Python 3 코드를 실행한 뒤 `python ml-replay/verify.py`로 두 계측 기록을 재구성한다. 아카이브에 네 부팅의 ELF 해시·원본 실행 로그, UART, 예외, 계측 메모리, 레지스터, 심벌, 디스어셈블리, 작업 표 및 독립 검증 결과가 있다.

```python
import base64, hashlib, io, json, zipfile
from pathlib import Path

record = json.loads(Path("docs/evidence/evd-040.json").read_text())
blob = base64.b64decode(record["zip_base64"], validate=True)
assert hashlib.sha256(blob).hexdigest() == record["zip_sha256"]
root = Path("ml-replay")
root.mkdir(exist_ok=False)
with zipfile.ZipFile(io.BytesIO(blob)) as archive:
    assert set(archive.namelist()) == set(record["files"])
    for name, spec in record["files"].items():
        data = archive.read(name)
        assert len(data) == spec["size"]
        assert hashlib.sha256(data).hexdigest() == spec["sha256"]
        target = root / name
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_bytes(data)
```
