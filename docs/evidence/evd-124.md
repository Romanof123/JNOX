# EVD-124 · 고정 입력 네이티브 EDF의 선점과 복귀

CHG-124 / IMP-124 / POL-005 / [#312](../native-edf-block-input.en-ko.md) / [#298](https://github.com/Romanof123/JNOX/issues/298) / [Operator recipe](../../examples/native-edf/README.md)

`424a63fbce01189c9be054107e4e6e42ec5ad965`

단일 Cortex-A72 QEMU virt에서 두 최초 부팅은 모두 A→C→A→B로 실행됐다. 외부 추적에서 PPI 30이 batch_reduce의 바이트 읽기 PC `0x4001e8`를 선점했다. C 종료 뒤 ERET는 A의 SP_EL0 `0x1010f40`와 같은 PC로 복귀했다. 두 저널에서 저장·복원된 네이티브 프레임 `0x402141c0`이 일치했다. 저장된 X21과 링크된 명령으로 계산한 선점 시점 완료량은 일반 12,937블록, 추적 13,120블록이었다. 이후 전용 메모리에서 추가 진행을 확인했다.

두 부팅 모두 세 작업이 각자의 마감 전에 끝났고 누락 격자와 손실 행은 없었다. A는 4 KiB 블록 32,768개(128 MiB)를 합산해 17,112,760,320을 냈고, B는 128블록에 16개 빈 각각 32,768, C는 8블록에서 초과값 2,048개를 기록했다. 종료값은 17·29·43이었다.

동일한 A ELF로 대조 4회를 실행했다. 1블록은 합 522,240·종료 17, 잘못된 입력 65537과 2x는 각각 진행량·합 0과 종료 105였다. 무인수 기존 시간 모드는 17,608블록과 합 9,195,601,920으로 17을 반환했다. 이 결과로 지정 에뮬레이터의 #298 고정 입력 기능 증거를 확보했다. 앞선 #299에서 외부 추적으로 시계 함수 복귀를 관측한 두 사례는 기존 부분 판정을 유지한다.
