# EVD-046 · MLQ saturation and MLFQ delayed boost

[한국어](evd-046.md) · [Acceptance plan](../multilevel-limits-plan.md) · [#102](https://github.com/Romanof123/JNOX/issues/102) · [#107](https://github.com/Romanof123/JNOX/pull/107)

**PASS for the six finite workloads.** Each selector completed one ordinary and one diagnostic cold boot on QEMU with default virtual time. All twelve first guests passed. A WSL Git worktree check failed before launch; Windows Git confirmed the source and clean tree. Ordinary images provide task output, exception order and idle evidence. **Blocked and exited.** Each diagnostic captured two task-owned SVCs. The final live/asleep masks were 3/15 after blocking and 0/15 after exit. Unused slots count as asleep. Both plain and diagnostic variants reached linked idle with the timer enable bit clear. Diagnostic frame pointers and saved return PCs matched the task’s private 16 KiB stack and QEMU exception returns. Distinct frames and queue history identify owners sharing worker code.

**Finite saturation.** For the opening eight timer events, high-class peers 1 and 2 alternated and each closed interval charged positive service. The ready low-class owner 0 waited until the last high-class exit. It then ran for 865,755 counts.

**Delayed boost.** Owner 0 began at 70,876. The nominal deadline was 2,570,876; the armed compare read back 32,570,876. The timer PPI stopped the interval at 32,744,052, charging all 32,673,176 elapsed counts to owner 0. Before reset it was at bottom rank 0 with 3,576,824 remaining. One reset covered three boost periods, preserved ready order [1,2,0] and gave all three top rank 2 with 2,500,000 remaining each. Owner 1 resumed. Its next compare matched the ordinary nominal deadline of 35,263,215 and its stop at 35,392,778 charged 2,629,563 counts. Later period crossings also replayed.

The finite run establishes no minimum low-class share under indefinitely sustained high-class saturation. Deployed class and boost settings, workload latency limits, physical timing and product qualification require separate evidence.

All 34 image comparisons matched the standalone PT_LOAD layouts, loaded bytes and .text. The comparisons covered 12 multilevel images before integration with the servers, the same 12 configurations after integration, and 10 integrated aperiodic images. In the first standalone default-clock series, all eight ordinary schedules and both late controls stopped at the first IRQ with zero charge. The integrated default-clock series completed 8/8 ordinary schedules. Both injected late controls stopped after charging one unit and retiring none. Deterministic instruction counting gave the same eight completions and two intended stops in its own series. The standalone default captures used WSL DrvFS and the integrated default captures used Linux /tmp. The cause of the timing difference remains unresolved.
