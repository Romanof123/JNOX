# EVD-141 · 제한형 CPU0 추천 규칙과 보호된 네이티브 예약

CHG-141 / IMP-141 / POL-018 / [#345](https://github.com/Romanof123/JNOX/issues/345) / [#346](https://github.com/Romanof123/JNOX/pull/346)

[Deployment / 배포](../native-extension-applications.en-ko.md) · [#59](https://github.com/Romanof123/JNOX/issues/59)

5c378fa6085f9958ffe3bb0cdacb77eae5fb7a3d에서 고정한 여섯 구성의 일반·외부 추적 최초 부팅 12건이 모두 완료됐다. 채택 및 양보 대체의 소유자 순서는 22021011, 오류 세대 16·CPU 1·다섯 번 명령 인출 후 자기 점프 대체는 11012022였다. 연장 실행 2202201131에서 예약 앱 종료 뒤 셀 8은 유휴였다. 400 ms 수면 실행 220213110에서 슬롯 0은 예약 셀 5 동안 잠들고 요청 시각 뒤 예약 셀 8에서 복귀했다. 숫자 3은 EL1 유휴다. 사설 RAM에서 전압 누계 6596/9900(종료 30), 온도 18/41/62(31), 경보 65536/131072/196608(32), 네 번째 배치 경보 262144를 확인했다.

62.5 MHz, Q=6,250,000틱에서 102개 셀의 실제 작업 후 SVC 또는 유휴 진입을 기준으로 한 최초 작업 상한은 최대 1,782,891틱(한도 3,125,000)이었다. 위임 게시 74건 모두 S+Q/4 전이었고 운영 셀 90개를 종료한 실제 PPI30의 최대 지연은 20,093틱이었다. 최종 종료 시 비교기 취소는 별도로 관측했다. 최초 저널에 건너뛴 셀, 평가 취소, 유실은 없었다. 추가 레지스터 캡처 6건에서 실제 전용 스택의 IRQ 허용 EL1h 평가기와 실제 EL0 복귀 PC/SP 51쌍을 확인했다.

정상 평가가 차단 시각 전에 끝났으므로 네이티브 평가 중 타이머 인터럽트, 미게시·하트비트 만료에 따른 취소와 대체, 늦은 응답 거부 및 해당 경로의 임의 레지스터 보존은 미관측이다. 셀 시작과 정확히 같은 시각의 기상도 미관측이다. 기존 링크형 정상·정지 평가기 대조 4/4는 자체 범위에서 통과했다(정지 진단 9개 결정, 외부 IRQ PC 15개, 셀 6 대체·7 유휴). 첫 호스트 실행은 모듈을 독립 크레이트로 잘못 컴파일해 실패했고 정식 진입점은 191/191 통과했다. #59 및 POL-018의 제품별 규칙·반응 한도·실물·위험 및 승인 판정은 별도다.
