# EVD-032 · Coincident RR expiry and delayed peer releases

[한국어](evd-032.md) · [Predeclared acceptance criteria](../fixed-runtime-edges.en.md) · [49 originals and SHA-256 digests](evd-032.json)

An independent verifier passed the first cold boot of each of two ordinary and two diagnostic images. The QEMU virt machine used one Cortex-A72 CPU, TCG, GICv2 and 128 MiB. The RR quantum Q was 12,500,000 counts. Equal-priority A (slot 1), B (2) and C (0) became due at boot sample T, T+Q/2 and T+Q respectively. All four boots showed A start → B → C → A resume → A done, distinct aligned task stacks, three exit SVC #1 exceptions and a stopped idle PC. B and C observed identical positive A progress, which increased after A resumed.

| Delayed IRQ | A masked IRQs from 116,318 to 50,116,320 (50,000,002 counts). One IRQ then selected B. | T=45,246. Mask interval 130,463–50,130,463 (exactly 4Q). Ordinary captures establish ordering from UART, application memory, external exceptions/returns and the stopped PC. Diagnostic journals had six and five rows respectively with zero overflow. The verifier matched ELRs and return PCs against the external trace, then summed adjacent samples per outgoing owner. IRQ rows recorded INTID 30. Timer control read back as one at armed compares and zero at terminal idle. Hardware worst-case latency, integrated profile acceptance and product safety approval remain open.

## Offline replay

Run the following Python 3 code from the repository root to restore all 49 originals into a new directory, checking each byte length and SHA-256. Then run `python evd-032-replay/validator.py`. It regenerates `verification.json` in that directory. The archive preserves the original verdict.

```python
import base64, hashlib, json
from pathlib import Path

archive = json.loads(Path("docs/evidence/evd-032.json").read_text())
root = Path("evd-032-replay")
root.mkdir(exist_ok=False)
for name, entry in archive["files"].items():
    data = base64.b64decode(entry["base64"], validate=True)
    assert len(data) == entry["bytes"]
    assert hashlib.sha256(data).hexdigest() == entry["sha256"]
    target = root / name
    target.parent.mkdir(parents=True, exist_ok=True)
    target.write_bytes(data)
```

Capture map: `ties/` and `late/` hold the ordinary images' evidence. `ties-trace/` and `late-trace/` hold diagnostic evidence. Each directory includes `boot.txt`, `rc`, `elf.sha256` and `symbols.txt`. Its `raw/` directory holds UART, the 16-word observation block, IRQ/SVC trace, registers, QMP, launch and exit records. Diagnostic captures also contain `trace.bin`. At the root, `validator.py` is the offline verifier, `verification.json` its decoded result, and `run.sh` the original capture command using existing ELFs and the verifier's WSL paths.
