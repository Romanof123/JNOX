# EVD-003 · Equal-priority FIFO execution

[한국어](evd-003.md) · English

**The AArch64 single-core FIFO bench passed.** On 2026-11-24 the independent verifier recorded the UART verdict before matching exception addresses from the same execution to candidate symbols and instructions. Source `76b88ee7fe4c8ece0eb206bd3ed2126d1b761ff1` produced ELF SHA-256 `b5f87bf6086cf8a33eadb54a7c0b91622bfcaf6a16b29b81ddcdf5c65ab8806d` in one kernel build. [Test contract](../m1-fifo.en.md) · [Source commit](https://github.com/Romanof123/JNOX/commit/76b88ee7fe4c8ece0eb206bd3ed2126d1b761ff1)

| Stage | Observation |
| --- | --- |
| First attempt | The host observer encountered `ENODATA` and stopped QEMU early. The 83 UART bytes reached B's first entry. This attempt was inconclusive. |
| Sequential retry | With the same ELF and machine configuration, the observer used the default WSL temporary directory and launched one fresh guest. All ten UART lines, 142 bytes and the quiet observation window passed. |
| Timer preemption | An IRQ interrupted LOW's non-yielding loop. The emulator recorded LOW's return address as `0x402012bc`. |
| FIFO and voluntary yield | The equal-priority peers A and B had IDs 2 and 1. A became ready first. The sequence was A entry → B entry → A resumption → B resumption. The two yields and two exits produced SVC immediates 2, 2, 1, 1. |
| LOW resumed | The last exception return targeted LOW's originally saved address, `0x402012bc`. The guest checked stack and register witnesses. The verifier inspected the linked image and source for separate stacks and ready-queue operations. |

Three separate host unit tests passed for reverse-ID FIFO and yield, preserving a preempted peer's turn, and rejection of invalid IDs, duplicates and full-queue insertion. The independent verifier also replayed UART captures on the host to check the observer's rejection behavior.

From the repository root, compile the host suite with `rustc +1.95.0 --edition 2024 --test kernel/src/ready_queue.rs -o queue-tests` and run the executable with `--test-threads=1`. The default and earlier `sched-bench` configurations each passed `cargo check`. The profile booted in this round was `fifo-bench`.
