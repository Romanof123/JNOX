## Ordinary guests

The independent verifier observed one cold boot per configuration on QEMU. The interface admits zero to four trusted, statically linked Rust tasks on one CPU. Each has a fixed priority and a separate 16 KiB stack. Idle has a fifth stack. These tests cover the FIFO and RR peer policies.

| Configuration | Observed behavior |
|---|---|
| FIFO | B’s zero sleep yielded to A and kept B ready. When HIGH exited, interrupted A resumed at PC `0x4020127c` ahead of B. B later slept for 25,000,000 ticks, resumed after idle, continued after a rejected overflowing sleep and exited explicitly. |
| RR | For a configured 12,500,000-tick quantum, the verifier reconstructed A/HIGH/A/B/A/B/idle using the task table, UART, stack observations and exception order. Shared loop PCs and the absence of per-event counters limit exact residual and saved-frame attribution in this ordinary capture. |
| Empty | An empty table entered idle directly and all eight observation words remained zero. |
| Delayed | The only task had an initial delay of 6,250,000 ticks. Boot entered idle, an IRQ dispatched slot 0, and explicit exit returned to idle. |

All four captures ended with PC `0x4020125c` and idle SP `0x40218120` during the bounded quiet window. The evidence covers these virtual runs. Physical timing, indefinite idle behavior and product safety require separate evidence. ## Diagnostic guests

The independent verifier replayed 10 FIFO, 7 RR, 1 empty and 3 delayed records. Each record contained 19 words. At 62.5 MHz, A consumed 6,377,034 ticks of its 12,500,000-tick RR quantum before HIGH preempted it. A resumed at counter 9,695,826 with 6,122,966 ticks remaining. Its programmed compare was 15,818,792. Granting a fresh quantum would have set the compare to 22,195,826.

The verifier matched timer IRQs to PPI30, charged service to the interrupted owner, and matched interrupted and selected ELRs and stack pointers against exception order, task progress and stack ranges. All four final idle records showed timer control zero. IRQ delivery and subsequent behavior provide indirect evidence for interrupt completion. Individual GIC EOI writes were outside the capture. Equal-peer arrival after uncontested service, simultaneous release and expiry, multiple late wakes and delays spanning multiple quanta have host-only coverage here. [Diagnostic replay, 19-word records, validator and captures](evd-030.json)

The final source passed 126 Rust tests, 32 Python tests, eight expected configuration rejections and five additional sequential regression boots. The ordinary FIFO ELF occupies 94,192 file bytes and maps 113,608 bytes. The ordinary RR ELF occupies 94,048 file bytes and maps 113,400 bytes. Both contain fixed task and idle stacks in BSS. Dynamic stack high water and physical response-time bounds remain open. Live delayed-IRQ and simultaneous-release cases continue in [#72](https://github.com/Romanof123/JNOX/issues/72).
