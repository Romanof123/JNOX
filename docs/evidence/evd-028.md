# EVD-028 · RM과 DM에서의 주기 작업 초과 실행

[English](evd-028.en.md) · [승인 기준](../m1-periodic-overrun.md) · [#64](https://github.com/Romanof123/JNOX/issues/64)

최초 호출은 래퍼 파일명에 포함된 캐리지 리턴 때문에 게스트 시작 전에 멈췄다. 수정한 호출로 게스트가 한 번 부팅됐다. 검증자는 154행을 해석하고 예외와 복귀를 각각 64회 대조했다. RM에서는 B1이 상대 틱 16, A1이 19에서 마감을 넘겼고, DM에서는 A1만 상대 틱 19에서 마감을 넘겼다. 논리적으로 마감과 완료가 일치하는 사건을 관측한 IRQ는 두 구간에서 각각 107,151카운트와 118,019카운트 늦었다.

카운터는 62.5 MHz였고 한 틱은 3,125,000카운트였다. 마감과 완료의 논리적 일치는 달력 사건의 처리 순서에 따른다. 측정 범위는 가상 CPU 한 개다. 실물 보드 지연, 물리적 마감 시각 일치와 최악 실행 시간에는 별도 근거가 필요하다.

ELF SHA-256 `f1f7bc9d6a67665d6c25469e542bdb5a29cf853372c1c6c54cfc7fcd9590710d`. [검증 소스](https://github.com/Romanof123/JNOX/commit/93c64c853c3d1bf3f6286da59d83d7dc8394f7b9) · [독립 판정과 원시 기록](evd-028.json)

동일 커널 리비전에서 Rust 테스트 120개와 Python 테스트 28개가 통과했다. 단일 구성 26개와 조합 구성 4개에서 게스트를 추가로 30회 순차 부팅했다. [회귀 기록](evd-027-029-regressions.json)

최종 관찰기에서 Python 테스트와 주기·CBS 직접 수집 실행이 통과했다. 우선순위 프로파일은 독립 스키마 재생에서 같은 직접 실행 경로를 확인했다.
