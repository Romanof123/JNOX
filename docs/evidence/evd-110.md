# EVD-110 · 일반 뮤텍스의 시간 제한 연쇄 상속 및 FIFO 통합

CHG-110 / IMP-110 / POL-014 / [#232](../ordinary-mutex-chain.md) / [#236](https://github.com/Romanof123/JNOX/pull/236)

#236 통합 소스 1bc463d에서 최초 부팅 8회(시간 제한 연쇄 상속 2회, FIFO 2회, 기존 PI·천장 대조 4회)가 모두 통과했다.

연쇄 상속 일반·추적 부팅에서 인터럽트 시점의 BASE 진행량은 총 16,384 중 각각 1,414와 2,052였다. 타이머 비교값부터 핸들러까지 각각 8,431틱과 8,440틱이었고, 두 부팅 모두 인터럽트된 PC `0x402014d4`에서 BASE가 재개했다. FIFO 부팅은 각각 같은 우선순위 대기자의 두 도착 순서를 재현했다. 기존 대조 4회도 각 시간 기준을 충족했다. 일반·추적 순으로 PI는 1·7청크, 천장은 74·65청크를 기록했다. 앞선 통합 실험에서는 연쇄 상속 2/2, 기존 대조 2/4가 통과했다. 실물 보드의 차단 시간과 타이밍 검증은 남아 있다.

단일 코어 Cortex-A72 QEMU virt/GICv2의 두 연쇄 상속 부팅에서 PPI30으로 HIGH의 대기가 만료되고 LOW와 BASE의 우선순위가 4에서 2로 복원됐으며 LOW가 Y를 직접 양도받았다. BASE가 4,194,304회 읽기를 끝내고 LOW가 같은 개수와 합계 35,651,584를 게시했다. FIFO 두 부팅은 각각 두 도착 순서에서 보호 기록 412와 421을 남겼다. 호스트 시험 140개와 관련 Python 시험 24개가 통과했고 잘못된 선택자 8개는 빌드에서 거부됐다. 통합 소스 전체 해시는 `1bc463d88e5b69763e1268349a57e10685076020`이다.
