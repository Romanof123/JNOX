# EVD-047 · First-failure observation in the legacy partition fixture

[한국어](evd-047.md) · CHG-050 · IMP-047 · POL-006 · VER-023 · [JSON](evd-047.json) · [ZIP](evd-047-raw.zip)

Plain and diagnostic each reached PASS with six IRQs in one cold boot. The deliberate negative recorded guard 99, observed 0 and expected 1 at the first A marker. The original PART FAIL remains unattributed.

Three boots used QEMU 6.2.0, single Cortex-A72 virt/GICv2 TCG and the default clock. Both positive UARTs show A first, idle first, B ready, A resumed, B first, idle resumed, STOP and PASS. Each trace records six IRQs at vector 0x40200a80 and six exception returns including initial dispatch. Runtime guard 28 checks PPI 30. QEMU records exception class and vector. The linked disassemblies identify the first interrupted A PC as 0x40201278 in both images and the resumed idle PC as 0x40201380 in plain and 0x40201440 in diagnostic.

The negative stopped before any IRQ after one initial return. It emitted one PART DIAG1 followed by PART FAIL. Its upper operand was unavailable, worker A (0), window [0,2), last comparator 6289028 and allocated partition 0. UART stayed stable after terminal in all three boots. All three ELFs matched their respective pre-selector images byte for byte. The diagnostic stop symbol is absent in plain and present in both diagnostic images. The plain .text digest differs from the image that originally emitted PART FAIL after A FIRST and the first IRQ. That capture lacks a guard ID and operands. Product timing and isolation qualification remain open.

The ZIP contains the ELFs, linked disassemblies, UARTs, exception logs, execution options, selector build controls and original failure records. Check each member against the SHA-256 index. To repeat a capture, replace -kernel, -serial and -D paths in its execution.json argv. The shared original manifest also lists separate #104 files.
