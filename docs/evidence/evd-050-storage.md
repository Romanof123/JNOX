# EVD-050 · 관측 파일 저장 경로 교차 실험

[EVD-050](evd-050.md) · [JSON / SHA-256 / archive](evd-050-storage.json) · [#118](https://github.com/Romanof123/JNOX/issues/118) · [#109](https://github.com/Romanof123/JNOX/issues/109)

두 워크로드를 각각 4개 블록에서 4가지 경로 조합으로 콜드 부팅했다(총 32회). A는 UART와 예외 로그를 모두 WSL ext4에, B는 예외 로그만 DrvFs에, C는 UART만 DrvFs에, D는 둘 다 DrvFs에 썼다. 게스트 카운터는 62.5 MHz이며 첫 IRQ 허용치는 RM 0.5 ms, A-PS 1 ms다.

| 층 | 셀 | 첫 IRQ 기준 충족 | 정상 동작 완료 | 게스트 종료 기록 |
|---|---|---:|---:|---:|
| RM | A | 4/4 | 0/4 | 4/4 |
| RM | B | 0/4 | 0/4 | 4/4 |
| RM | C | 4/4 | 0/4 | 3/4 |
| RM | D | 0/4 | 0/4 | 4/4 |
| PS | A | 4/4 | 4/4 | 4/4 |
| PS | B | 0/4 | 0/4 | 4/4 |
| PS | C | 4/4 | 0/4 | 0/4 |
| PS | D | 0/4 | 0/4 | 4/4 |

아래 값은 첫 IRQ 지연(틱)이다. UART 경로를 고정한 16개 비교 모두에서 DrvFs 예외 로그 경로의 지연이 더 컸다. 예외 로그 경로를 고정한 UART 차이의 부호는 일정하지 않았다.

RM 16회에서 승인된 허가는 0건이었다. 1-RM-C에서는 호스트 읽기가 ENODATA로 중단되어 종료 후 원시 추적을 복구했다. 종료 시각·상태와 다음 실행까지의 간격은 알 수 없다. A-PS C의 네 실행은 단계 기록 출력 중 시간 초과됐다. 각각 IRQ 17회, 제출·과금·서버 완료·주기 작업 완료 각 4건이 관측되었다. 블록 순서로 단계 기록은 201, 198, 166, 196개였고 복귀·전체 단계·종료 검증이 미완료였다. A-PS 정상 완료는 A에서만 4회였다.

QEMU 6.2.0의 기본 시계와 파일 백엔드를 사용했다. 호스트 폴링 목표는 10 ms였고 호스트 시각은 게스트 카운터와 별개다. RM 명령은 이전 관측에서 사용한 -no-reboot를 생략하고 -nodefaults를 적용했다. 호스트 활동, TCG 및 파일시스템 내부 효과는 분리되지 않았다. 물리 보드의 지연 한계와 수정된 fw_cfg 경로의 동작은 이 실험의 검증 범위 밖이다.
