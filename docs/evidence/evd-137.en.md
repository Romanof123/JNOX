# EVD-137 · Schedule native applications with lottery or stride

CHG-137 / IMP-137 / POL-010 / [#337](../native-proportional-applications.en-ko.md) / [#338](https://github.com/Romanof123/JNOX/pull/338)

`f107b60fc1cb5bc83767ee98299d7042a3103b7a`

Seven cold first boots used one default-clock 62.5 MHz Cortex-A72 QEMU virt/GICv2 CPU. Each of six policy journals reached final exit with zero drops. The default CRC control exited 237. Both seeds met all 25 sliding 24-grant windows through 48 full closures. Seed 1 totals were 11/14/23 with minima 5/3/11. Seed 2 totals were 8/17/23 with minima 1/7/10. Stable stride passed all 48 exact prefixes. Maximum normalized spread was 634,686 ticks (M=634,686), with 4,412,618/8,809,860/16,996,099 ticks delivered through prefix 48.

Private RAM verified CRC32 2,124,873,618 over 134,217,728 bytes (exit 237), nine histogram bins over 536,870,912 bytes (exit 70), and energy 5,864,240,971,776 over 1,073,741,824 samples (exit 179). The reporter counted 256 hits in each of three rounds, 768 total (exit 53). In both dynamic cases, CRC execution PCs, positive service during each 40 ms sleep and the final product established useful execution. RAM progress counters were not sampled at each wake. SP/PSTATE came from saved frames and external EL0 return PCs from QEMU.

The public packager and raw build both refused owner A receiving five grants against a required six in [24,48), returning 2 and 101 without an executable. All 11 host controls passed. The first offline reader lacked pyelftools and a separate shell quoting error selected a nonexistent capture directory. With the dependency installed, the original captures were scored unchanged. The #54, #79, #200 and #235 records retain their original scope. The failed branch and operands in #79 remain unknown. External product-risk acceptance and physical timing require separate decisions.
