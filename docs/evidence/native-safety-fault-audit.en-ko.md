# Native permit fault coverage / 네이티브 허가 채널 고장 검증

**Keep the #11 native fault-acceptance item open.** On the fused single-vCPU QEMU bench, sender silence met all three observed output budgets and the 5 ms completed-check interval under FIFO and RR. The invalid-traffic and saturation runs left the normal producer gate open. The frozen verification plan calls for closing that gate, invalidating queued valid frames and introducing invalid traffic through a separate downstream test injector. This difference survives at reviewed head `a7aa0a659f239950fa29b3326813cf4b35d846f9`, tree `ac8fcaa090613c583d04139ada18652d4c88ea95`. [VER-019](https://github.com/Romanof123/JNOX/blob/a7aa0a659f239950fa29b3326813cf4b35d846f9/docs/verification-plan.en.md#verdicts-and-evidence) · [CHG-311 contract](https://github.com/Romanof123/JNOX/blob/a7aa0a659f239950fa29b3326813cf4b35d846f9/docs/native-safety-channel.en-ko.md)

**우선순위는 고장 주입 경로다.** 정상 생산자의 게이트를 실제 닫고 대기 중 유효 프레임을 무효화한 뒤, 별도 시험 주입자가 같은 수신 큐에 불량 프레임을 공급해야 한다. 기존 불량 입력·포화 실험은 MARK만 기록한 뒤 정상 생산자가 계속 게시했다. 이 차이는 제어 위상 1 ms 최적화와 독립적으로 고칠 수 있다.

## Three separate fault runs / 세 가지 독립 고장 실행

Each figure is a conservative upper endpoint in ticks at 62,500 ticks/ms. Triples are injection→detection, detection→device readback, and injection→readback. Limits are 1,562,500 / 312,500 / 1,875,000 ticks. The gap limit is 312,500 ticks. The reducer checked enabled state at injection, the latch bracket, the later 1→0 swap/readback bracket, entry order, actual publications/receives and adjacent COMPLETE intervals in raw UART. These are finite observations on wall-clock Cortex-A72 TCG with one virtual CPU.

In fused silence the last receive journal timestamp preceded the beginning of CLOSE by 13,283 FIFO / 19,403 RR ticks. This establishes the observed spacing for “loss after delivery”.
