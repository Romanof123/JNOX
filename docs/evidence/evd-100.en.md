# EVD-100 · Owner changes over every counter window of one grid period

`CHG-100` · `IMP-100` · `POL-005` · [#260](https://github.com/Romanof123/JNOX/issues/260) · [#261](https://github.com/Romanof123/JNOX/pull/261).

Eight first QEMU guests on 4c62e02 passed. With an otherwise admitted two-job supply table, a ceiling of three refused before worker launch. Four admitted under EDF and sampled LLF. Each normal run returned four changed owners across the whole run and at most two in any Q-length counter window; the analytic upper bound was four. The actual path was idle → A → service → A → B. All 16 legacy deadline guests reached the expected terminal. The code and load layouts matched; only Rust line records in loaded read-only data changed. A separate finite oracle checked 14,648 schedules and 953,766 complete integer windows. Conditional on each IRQ being in its assigned grid cell and at most one completion per job. Physical timing and product-interference approval remain open.
