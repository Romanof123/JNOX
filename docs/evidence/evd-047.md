# EVD-047 · 기존 파티션 최초 실패 관측

[English](evd-047.en.md) · CHG-050 · IMP-047 · POL-006 · VER-023 · [JSON](evd-047.json) · [ZIP](evd-047-raw.zip)

일반 이미지와 진단 이미지는 각각 한 번의 콜드 부팅에서 IRQ 6회 후 PASS에 도달했다. 의도적 음성 대조군은 첫 A 마커에서 조건 99, 실제값 0, 기대값 1을 기록했다. 기존 PART FAIL의 원인은 미확정이다.

세 실행은 QEMU 6.2.0, 단일 Cortex-A72 virt/GICv2 TCG, 기본 클록에서 수행됐다. 두 긍정 사례의 UART 순서는 A 최초, 유휴 최초, B 준비, A 재개, B 최초, 유휴 재개, STOP, PASS였다. 두 로그 모두 벡터 0x40200a80에서 IRQ 6회와 최초 디스패치를 포함한 예외 복귀 6회를 기록했다. PPI 30은 커널 조건 28이 검증하며 QEMU는 예외 종류와 벡터를 기록한다. 링크된 디스어셈블리에서 최초 A 중단 PC는 모두 0x40201278이며 유휴 재개 PC는 일반 0x40201380, 진단 0x40201440이다.

음성 사례는 최초 복귀 1회 후 IRQ 전에 멈췄다. PART DIAG1 한 줄과 PART FAIL이 출력됐다. 상한 미지정, 작업 A(0), 창 [0,2), 마지막 비교값 6289028, 할당 파티션 0이다. 세 UART 모두 종료 후 안정적이었다. 세 ELF는 선택기 변경 전의 대응 ELF와 바이트가 일치했다. 일반 이미지에는 진단 정지 심볼이 없고 두 진단 이미지에는 있다. 과거 실패 이미지의 .text 해시는 이번 일반 이미지와 다르다. 당시 A FIRST 후 첫 IRQ까지 기록됐으나 조건 번호와 피연산자가 없다. 제품 타이밍과 격리 승인은 미확정이다.

ZIP에는 각 ELF, 디스어셈블리, UART, 예외 로그, 실행 옵션, 빌드 선택 대조 결과 및 과거 실패 기록이 있다. JSON의 SHA-256으로 각 파일을 확인하고 execution.json의 -kernel, -serial, -D 경로를 로컬 경로로 바꿔 실행할 수 있다. 공유 manifest에는 별도 #104 자료도 나열된다.
