# EVD-021 · 복권 선택과 스트라이드 실제 실행량

[English](evd-021.en.md) · [합격 기준](../m4-proportional.md) · [#54](https://github.com/Romanof123/JNOX/issues/54)

첫 검증자는 원래 80개 선택 순서를 재현한 뒤, 계약의 스트라이드 25 Hz와 구현의 40 Hz가 다르고 IRQ 처리가 늦어져도 예정된 허용량만 계상하는 문제를 발견했다. 최초 80개 구간은 모두 예상 정수 틱 범위 안에 있었고, 고정 이미지 검토에서 이 차이를 찾았다. [첫 관측과 발견 사항](evd-021-initial.json)

다른 검증자는 지연 IRQ 대조군이 추가된 수정 이미지를 처음 부팅했다. 총 81행, IRQ 75회·SVC 6회와 문맥 복귀 주소를 독립 재생했다. 복권은 각 시드 32회에서 A/B/C가 10/8/14회, 5/11/16회 선택됐다. 스트라이드 서비스는 C 합류 전 4/8/0, 기존 작업들의 최소 패스에서 합류한 뒤 2/4/8틱이었다. 마지막 작업의 허용량은 2틱이었고 3틱이 될 때까지 IRQ를 지연시켰다. PPI30이 중단한 PC는 `0x40201310`이었다. 경과량 7,619,345카운트를 스트라이드 틱당 2,500,000카운트로 나눈 실제 3틱을 모두 계상해 가중치 1의 패스가 2,162,160 증가했다. [독립 재생·UART·예외·81행 원본](evd-021.json)
