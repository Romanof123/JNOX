## Reproduction / 재현

Check out the cited commit under /tmp/iv318-f0/src for the original-path byte hashes. Run build.sh with its cd changed to that path. It records the compiler, SDK invocation and all policy arguments. Per-package manifests are under manifests/, per-run launch.json includes the exact QEMU invocation, and session.json lists individual SHA-256 values. run.py uses the project's QMP capture to stop on terminal UART and save linked RAM. For supplemental runs use reconstructed/run.py, which expects packages under ~/iv318-f0/orig/raw and the checkout under ~/iv318-f0/orig/src. Extract the eight reconstructed session tarballs together and run python3 audit.py EXTRACTED_DIRECTORY with aarch64-linux-gnu-nm on PATH. Compile host.rs under raw/ alongside ../src using rustc --edition 2024 --test raw/host.rs -o host and run ./host. Build outside.c using python3 tools/build_native_el0.py --out OUT --source outside.c and capture through native_el0_capture.py --expect-exit 0. No repository or external service was modified.
