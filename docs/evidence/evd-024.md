# EVD-024 · 계층형 스케줄러의 예산 소진과 보충

[English](evd-024.en.md) · [승인 기준](../m4-hierarchy.md) · [#57](https://github.com/Romanof123/JNOX/issues/57)

12개 슬롯에서 리프 실행 순서 1/2/2/3/3/3이 두 번 반복됐다. 준비 마스크는 예산이 남은 자식 0을 제외했다. 부모 0의 예산이 소진됐을 때 실행 준비 상태인 리프 2에는 네 슬롯, 해당 자식에는 두 슬롯이 남아 있었다. 슬롯 6에서 예산을 보충한 뒤 자식 1이 다시 실행됐다. 검증자는 SVC 대기 4회, 유휴 IRQ, 리프 IRQ 12회와 복귀 PC를 대조했다. 쿠키와 IRQ ID 검사의 근거는 게스트의 PASS 표시다.

이 기록의 범위는 해당 가상 부팅이다. 실물 보드 타이밍과 제품 기능 안전은 별도 검증 대상이다. ELF SHA-256 `2e498fd3068aadca24af7c0e5fb955f695c3bc0ee964fd25f05089de37718a38`. [검증 소스](https://github.com/Romanof123/JNOX/commit/92d62b30b89abdefebb1d0fdf268b8a3cfd30526) · [검증 결과와 원시 기록](evd-024.json)
