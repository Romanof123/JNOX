# EVD-050 · QEMU virt 콜드 시작의 쌍대 시간 비교

[English](evd-050.en.md) · [#109](https://github.com/Romanof123/JNOX/issues/109) · [#111](https://github.com/Romanof123/JNOX/pull/111)

**일반 이미지 정상 판정은 0/32, 진단 모드 초기화 성공은 0/96이었다.** 행렬의 128회 모두 종료 표시를 남겼다. 일반 실행의 모든 위상은 IRQ 한계를 충족했지만(832/832), 판정·복귀 한계를 충족한 위상은 830/832였다. 허가 수신, 재무장 명령 또는 장치 ON 전이는 한 번도 관측되지 않았다. 이는 #109의 별도 콜드 시작 실험이다. [EVD-050 v1](evd-050-v1.md) · [근거 색인](evd-050.json)
