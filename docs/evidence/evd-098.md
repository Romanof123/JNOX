# EVD-098 · 네이티브 순환 창 조회와 문맥 보관 방식 4개 조합 비교

`CHG-098` · `IMP-098` · `POL-006` · [#257](https://github.com/Romanof123/JNOX/issues/257) · [#258](https://github.com/Romanof123/JNOX/pull/258).

62,500틱 기준 보류다. 소스 0799f565의 최초 80회 모두 구조를 재생했고 창 920개와 종료 160건(41·42)을 확인했다. 14개 창이 기준을 넘었으며 모두 기본 클록 2세대였다. P의 스캔·복사/커서·복사/스캔·보관/커서·보관 조합은 각 5회 중 4/3/2/4회, Q는 0/0/0/1회였다. icount3 460개 창은 모두 기준을 충족했다. 32번 P 커서·보관은 77,022틱으로 여유 −14,522틱이었다. 원본 필드에서 선택 시점까지 3건, 나머지 11건은 첫 사용자 표본에서 처음 초과했다. 직전 종료 IRQ에서 이미 초과한 사례는 없었다. 관측 구간의 인과관계와 실기 시간은 열려 있다. 최초 기본 판독기는 80건 모두 Python 의존성 오류였고, 같은 원본을 독립 판독기 및 보완한 오프라인 판독기로 재생해 모든 창이 일치했다.
