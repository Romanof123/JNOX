# EVD-126 · Round robin within one native process

CHG-126 / IMP-126 / POL-002 / [#315](../native-thread-round-robin.en-ko.md) / [#316](https://github.com/Romanof123/JNOX/pull/316)

`9df9437b626da3bcaa4151f3db1370e7db24ae13`

Thirteen first cold boots and two Rust supplements reached their expected statuses on single-CPU QEMU virt. Both first RR boots recorded exactly 22 involuntary turns without voluntary yields or dropped rows. The external trace recorded 22 PPI 30 acknowledgments. Main was interrupted at 0x400328, the new worker entered at 0x400024, and the next IRQ interrupted the worker at 0x400384 and restored main at 0x400328. The third IRQ restored the worker at 0x400384. External ERET PCs matched every selected PC. Guest rows supplied SP (0x1010f60 and 0x1008fc0), the separate errno cells and common address-space root.

Both threads processed 16,384 blocks (64 MiB each). Terminal RAM verified checksum 8,556,380,160, sixteen bins of 4,194,304 and joined descriptor 0x402000. Both RR boots exited 17. With the same ELF under cooperative dispatch, the worker first ran when main completed its reduction and blocked in join. Both cooperative runs finished with the same products and exit 17. Intermediate block counts were not sampled independently per turn.

Traced expiry lateness was 3,715–10,264 ticks at 62.5 MHz. The configured 625,000 ticks equal 10 ms. Charge uses exception entry minus the preceding pre-restore sample, excluding nonblocking handler time, idle and scheduler gaps. Pre-restore bounds the start of user execution. Exact ERET timing, exhaustive asynchronous register canaries, physical-board timing and multicore behavior were unmeasured. Exact ties and overflow were host-model cases. This packet contains no independent CLI rejection matrix.
