# EVD-049 · 일반 가중 Rust 작업의 서비스 점유율과 동료 깨움

[JSON](evd-049.json) · [CHG-052 / IMP-049](../ordinary-vruntime-plan.md) · [#116](https://github.com/Romanof123/JNOX/issues/116) · [621c089](https://github.com/Romanof123/JNOX/tree/621c089c7d17f91ed229109a0ed25deb0150dfc1)

QEMU Cortex-A72 virt/GICv2, TCG 단일 가상 CPU에서 커널 4종을 기본 시계와 icount shift=3으로 각각 콜드 부팅했다. 최초 실행 8회 모두 20초 안에 종료 표시에 도달했고 수치·소유권 기준을 충족했다. ELF·UART·QMP와 RAM 캡처에는 네이티브 리눅스 임시 경로를 썼다. 모든 실행에서 예외 로그를 수집했다. 기본 시계에는 호스트 관측 부하가 포함되고 icount는 모의 명령 실행 시간을 나타낸다.

62.5 MHz 카운터에서 Q=625,000, H=781,250, G=156,250, H+2G=1,093,750틱이었다. 연속 준비 상태의 1:2 가중치에서 첫 36개 타이머 구간을 평가하고 작업 종료 구간 2개를 별도로 보존했다. D는 A 서비스의 두 배에서 B 서비스를 뺀 값이다. 모든 접두 구간에서 −H ≤ D ≤ 2H였다.

깨움 사례마다 B가 세 차례 차단되고 A가 B를 깨웠다. 동료 작업의 SVC #2/#3, 대상 1과 반환값 검사를 확인했다. 832바이트 프레임이 각각 전용 16 KiB 스택에 있었고, 저장·복구 ELR 및 프레임 순서는 외부 예외·ERET 기록과 일치했다. 사용 가능한 UART 행은 모두 RAM과 대조했다. 진단 복구 표식 뒤에 마지막 레지스터 복원과 ERET가 실행되므로 표식은 아키텍처 복귀 순간을 직접 측정하지 않는다. 수락은 배치 뒤·선택 전, 실제 작업 시점은 저장된 복귀 주소에서 B가 읽은 카운터다. 유효 대기는 실행 가능할 때 경쟁 작업에 주어진 서비스만 포함한다.

원래 문서의 단독 모듈 컴파일은 E0433으로 실패했다. 독립 검증용 controls.rs는 기존 검사와 추가 소유권 및 704개 분수 격자 사례를 포함해 호스트 검사 9개를 통과했다. 역행한 시각·소유자 불일치·중복 실행권·늦은 IRQ·스택을 벗어난 프레임은 변조 기록으로 거절을 확인했다. 물리 보드, 최악 지연, 장기 제품 부하는 측정하지 않았다.

12번의 깨움에서 수락부터 디스패치까지 625,706–642,419틱, 디스패치부터 B의 첫 복귀 명령까지 44–3,658틱이었다.
