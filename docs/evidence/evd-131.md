# EVD-131 · 비주기 서비스와 백그라운드 앱 실행

CHG-131 / IMP-131 / POL-007 / [#325](../native-aperiodic-applications.en-ko.md) / [#326](https://github.com/Romanof123/JNOX/pull/326)

`67fd4aa10b2916a6cd077f7f601656ea0e0b9470` · [SDK / QEMU](../../examples/native-aperiodic/README.md)

원본 다섯 부팅 모두 예상 배정과 두 앱의 산출물·종료값 41/42가 일치했다. 일반 산발 2크레딧 실행의 124행에서 셀 8 경계보다 278틱 늦게 이전 배경 작업으로 복귀했다. 기존 링크형 a-ss2는 TimeRegression을 처리하지 않아 E0004로 빌드에 실패했다.

수정 후보 2036fe00b65fca5d92714c1bec19affaace46f90에서 같은 두 ELF를 단일 Cortex-A72 QEMU virt 기본 시계로 실행했다. 50 ms 슬롯, 예산 2/5에서 처음 10개 셀 중 서비스 배정은 폴링 {0,5,6}, 지연 {0,3,5,6}, 산발 2크레딧 일반·추적 {0,3,5,8}, 산발 1크레딧 {0,3,8,9}였다. 매번 셀 0에서 잠들고 셀 2에서 실제 기상했다. 다섯 최초 부팅 모두 만료 뒤 수락된 복귀, 건너뛴 셀, 저널 손실이 없었다. 종료 시 사설 RAM에서 서비스 체크섬 32,640, 블록당 제곱합 5,559,680, 배경 작업의 9개 히스토그램 빈을 확인했다. 종료값은 41/42였고 추적 실행의 EL0 복귀 PC 267개가 일치했다.

별도 1 ms 부팅에서 후보 복귀가 각각 0·31·46회 취소됐고 합계 77회 중 40회가 유휴 후보였다. 취소 직후 재시도에서 점유 시간은 0이었다. 새로 차감한 서비스가 셀 전체에 진입하지 못했을 때의 환불은 호스트 검사에서만 확인했다. 수정된 링크형 a-ss2의 긴 실행은 AP END 0 및 4회 차감·4회 정산을 기록했다. #203은 검토 보고서가 없을 때 DENIED 1, 해시가 틀릴 때 빌드 거부를 유지했다. #101·#203의 제품 승인 입력, 실물 M3 간섭·최악 실행시간은 별도 검증 대상이다.
