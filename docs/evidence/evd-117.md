# EVD-117 · 네이티브 앱의 격자 기반 EDF

CHG-117 / IMP-117 / POL-005 / [#298](../native-edf-applications.en-ko.md) / [#299](https://github.com/Romanof123/JNOX/pull/299)

네이티브 ELF 세 개의 예제에서는 격자 1에 긴급 작업이 도착해 배치→긴급→배치→히스토그램 순으로 실행됐다. 소스 `ffc2e3232cf211f6cb7cda8726f853d26e908f19`의 최초 주 게스트는 중단한 배치 작업의 레지스터를 저장·복원하고 앱 세 개 모두 기대 결과를 반환했다. 비교용 LLF 작업과 실물 보드 타이밍은 별도 검증 범위다.

최초 일반 부팅에서 A는 계산 루프 내부 PC `0x4001b4`에서 중단됐다. 최초 외부 추적 부팅, 별도 일반 재실행, 별도로 고정한 보조 추적 부팅에서는 A가 모두 SDK clock_gettime+0x14인 `0x40016c`에서 중단된 뒤 같은 PC로 복귀했다. 외부 추적으로 계산 루프 내부 중단을 포착하는 조건은 미충족이다. 주 작업 세 개는 모두 실제 마감을 지켰다. 의도적으로 마감을 놓치게 한 A 단독 대조는 3,826,506틱 늦게 끝났다.

기존 연결형 EDF·LLF 대조 8건은 음수 여유 시간과 순위 역전을 포함해 모두 통과했다. 네이티브 시작·협력형·FIFO·RR·가중 대조도 통과했다. FIFO·RR·가중 대조에는 더 긴 순차 캡처를 사용했다. 검증자는 정책 시험 147개, 공급 마스크 시험 10개, 잘못된 CLI·원시 설정 조합 18개와 게스트 수용 거부를 기록했다.

의도된 마감 초과는 모델 시계 기준 61.224096 ms였다. 독립 릴리스 검토에서는 이 범위의 출시를 막을 소스 결함을 발견하지 않았다. 외부 추적에서 계산 루프 내부 PC를 확인하는 조건은 #21·#298에 남아 있다.
