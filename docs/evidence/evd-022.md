# EVD-022 · 가중 실행시간과 수면·깨우기

[English](evd-022.en.md) · [합격 기준](../m4-vruntime.md) · [#55](https://github.com/Romanof123/JNOX/issues/55)

첫 부팅의 첫 12회 허용에서 A와 B는 각각 5,655,507 및 11,334,667카운트를 받았다. |2A − B|는 23,653카운트로 사전 허용 오차 5,000,000 이내였다. 이후 B는 A의 세 구간 동안 차단됐다. B가 깨어날 때 가상시간은 11,334,667에서 19,598,044 반 틱으로 올라갔고 기록된 지연은 8,263,377에서 0으로 줄었다. 복구 여섯 구간의 순서는 A,B,B,A,B,B였고 마지막 B의 지연은 −16,375카운트였다.

신규 검증자는 표본으로부터 21번의 선택과 계상값을 각각 재구성했다. QEMU 외부 예외 기록에서 IRQ 주소 21개, 최초 문맥 진입, 이어지는 20개 복귀가 일치했다. 마지막 IRQ 후 CPU는 대기했다. 타이머 시각·전용 스택 주소·작업 진행량은 게스트가 기록한 값이다. 관찰기 종료값은 0이었다. 결과 저장 후 바깥 셸의 마지막 명령에 남은 CR로 셸 종료값 2가 기록됐다. [최초 관측 전체](evd-022.json)

Rust 1.95.0으로 최초 소스와 스트라이드 수정 소스를 각각 빌드한 결과 이 프로파일의 ELF 바이트는 동일했다. SHA-256 `d4dea231a8572c2dc732bccc422201a20383d1c5d14a2baff7cf21f201104203`. 최종 소스에서 Rust 시험 93개, Python 시험 19개, 추가 가상 부팅 11회가 통과했다. 실보드·제품 부하·시간 기준 승인은 별도 추적한다.
