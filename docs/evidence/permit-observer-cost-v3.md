# OFF 전용 관찰 비용 · 세 번째 집단

[#144](https://github.com/Romanof123/JNOX/pull/144) · [CHG-069](../permit-observer-cost-plan.md) · [v1](permit-observer-first-partial.en.md) · [v2](permit-observer-v2-preflight/extra-control-result.json) · [JSON](permit-observer-cost-v3.json) · [ZIP](permit-observer-cost-v3.zip)

첫 실행 16건에서 OFF 전용 관찰을 완료해 인접한 8쌍을 얻었다. PL061 읽기 로그를 제외한 경우 첫 서비스·위상·IRQ 시간 차이의 방향은 일정하지 않았다.

F는 전체 PL061 추적, R은 읽기 이벤트를 제외한 추적이다. 단위는 62.5 MHz 게스트 카운터의 틱이다. 양수는 R이 더 오래 걸렸다는 뜻이다. 위상 지연과 IRQ 지연은 각 부팅의 최초 관측을 사용한다.

| 실행 순서 | 서비스 F / R | 서비스 R−F | 위상 R−F | IRQ R−F |
|---|---:|---:|---:|---:|
| 01-rm-off-1-F / 02-rm-off-1-R | 19672 / 21342 | +1670 | +4130 | +1873 |
| 03-rm-off-1-R / 04-rm-off-1-F | 20354 / 32313 | +11959 | +18967 | +3578 |
| 05-rm-off-2-R / 06-rm-off-2-F | 24228 / 21740 | -2488 | -788 | -957 |
| 07-rm-off-2-F / 08-rm-off-2-R | 18920 / 22761 | +3841 | +6459 | +1642 |
| 09-dm-off-1-F / 10-dm-off-1-R | 22716 / 26994 | +4278 | +1001 | -2354 |
| 11-dm-off-1-R / 12-dm-off-1-F | 23666 / 19835 | -3831 | -4929 | -384 |
| 13-dm-off-2-R / 14-dm-off-2-F | 20727 / 22095 | +1368 | +1377 | -900 |
| 15-dm-off-2-F / 16-dm-off-2-R | 19833 / 21438 | +1605 | +5173 | +692 |

첫 서비스와 위상 지연은 각각 6쌍에서 늘고 2쌍에서 줄었다. 첫 IRQ 지연은 4쌍씩 증가·감소했다. 모두 첫 발행 전에 중지했다. 03번의 최초 결함 코드는 107이고 나머지 15건은 103이다. 각 게스트의 송신 기회 7개는 모두 미시도였다. 고정 입력, 실행별 UART·메커니즘 추적, 결함 피연산자, 보존 매니페스트 및 종료 영수증을 보관했다. 출력 활성화와 명령 전달은 관측되지 않았다. 게스트 행 80/81/82에는 0 쓰기 요청 33건 및 전후의 0 표본이 있다(03번은 3건, 나머지는 각 2건). 이 표본만으로 외부 전이 시각이나 특정 쓰기가 0 판독의 원인이었는지 판정할 수 없다. 외부 장치 이벤트와 게스트 틱 간의 대응은 없고 R은 읽기 기록을 생략한다. 동기화된 장치 지연, 관찰 비용의 인과적 감소, 실물 안전 또는 제품 승인을 판정할 수 없다.

사전 점검은 실시간 감시 벡터, 종료·보존 제어, 원본·스테이징·최종 사본의 정확한 구성 검사를 포함한다. v1은 1/16 실행 후 메커니즘 스트림 대부분이 소실돼 완성된 쌍이 없었다. v2는 예기치 않은 파일을 수락한 사전 검사에서 중단돼 게스트 실행이 없었다. 두 집단은 별도로 보존했다.

공개 메타데이터에서 원본 및 사본 집단 경로 접두부, 운영자 홈 경로 접두부와 호스트 이름을 대체했다. inventory.json은 원본과 공개 파일 각각의 크기·SHA-256, 빈 디렉터리 이름, 합성 심볼릭 링크 대상을 기록한다. 압축 해제 때 링크를 생성하지 않도록 합성 링크는 목록으로 표현한다. 실행별 UART, 메커니즘, 표준 출력·오류와 ELF 4개는 원본 바이트다. 전체 소스는 고정 커밋을 참조한다.

```sh
unzip permit-observer-cost-v3.zip -d v3-record
(cd v3-record && sha256sum -c SHA256SUMS)
```
