# EVD-099 · 폐쇄형 엄격 클래스 작업의 조건부 첫 서비스 상한

`CHG-099` · `IMP-099` · `POL-009` · [#259](https://github.com/Romanof123/JNOX/issues/259) · [#262](https://github.com/Romanof123/JNOX/pull/262).

최초 소스 4465fb72의 일반·추적 수용 게스트 모두 타이머 전달 전에 동급 작업이 종료되어 대상 워커에 진입하지 못했다. 1틱 작은 두 입력은 거부됐다. 유휴 상태 전용 수집기가 남긴 최초 부분 기록과 같은 ELF의 후속 RAM 판독을 나누어 보존했다. [수정 후 최초 검증](strict-class-first-service-corrected.en-ko.md)에서는 0a10dde8의 게스트 4건을 확인했다. 두 수용 사례는 실제 타이머 IRQ로 대상에 진입하고 미완료 동급 작업을 같은 PC에서 재개했다. 대상 첫 진입은 각각 4,108,876틱과 4,091,980틱으로 조건부 상한 24,000,000틱 이내였고, 전체 구간의 여유 비용은 64,043틱·62,938틱이었다. 23,999,999틱 입력은 작업 실행 전에 거부되고 런타임 관측값은 0이었다. 판정 범위는 선언한 유한 부하와 가상 대상이다.
