# EVD-135 · Native hierarchical CPU budgets and idle timer latency

CHG-135 / IMP-135 / POL-016 / [#333](../native-hierarchical-applications.en-ko.md) / [#334](https://github.com/Romanof123/JNOX/pull/334)

`b276a2ed8e9715fc6ced057b84681d77ccead755`

Eight of ten first cold boots on one default-clock Cortex-A72 QEMU virt/GICv2 CPU met timing. The full timing verdict failed. In saturated-plain and swap-plain, PPI30 entry from idle followed the compare by 4,201,556 and 6,487,068 ticks respectively, exceeding 1,953,125. Both returned from idle to histogram with zero idle charge. The plain captures lack independent physical assertion, WFI and ERET timestamps and host scheduling records, leaving causal attribution open.

All ten boots retained their private products and exits, with 1,275 budget and debt rows replayed and zero loss. CRC processed 134,217,728 bytes (CRC 2,124,873,618, exit 237), histogram processed 536,870,912 bytes (exit 70), and energy summed 1,073,741,824 samples (5,864,240,971,776, exit 179). The reporter recorded three deadlines, mask 7 and exit 7. Both single-CRC boots had 11 idle timer refills and restored the interrupted CRC PC, SP and page root. All decision gaps were within 125,000,000 ticks and each occupancy excess sum fit N × 1,953,125 ticks, where N counts uninterrupted quota-limited grant-end IRQs.

Four separate linked EL1 ordinary/recurring controls and the default native CRC control passed. The native hierarchy package is an opt-in engineering configuration. POL-016 timing qualification remains open and #339 tracks both original misses.
