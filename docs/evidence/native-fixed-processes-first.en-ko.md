All extended first captures completed. HIGH requested a 5 ms absolute sleep and counted 32 leap years. The extended C and Rust workers checked all 348,513 and 316,066 primes and returned 25 and 90. Every fixed record was replayed through the exact released Fixed policy, including ready order, prior wake/eligible expiry, next compare, cumulative service and slice balances. A separate elapsed-interval check charged only the previously active owner. ELR/SP pairs for each resumed slot match its saved pair; ordinary timer PCs fell within the separately disassembled compute symbols. In the three-party extended run A's interrupted and restored pair was 0x4001ec / 0x1010fa0. The vector source saves the 832-byte integer/SIMD/FP/status/TLS frame and restores the selected frame. Each slot owns a root table, image, stack and frame; the observed PC/SP and application checks do not sample every individual register.

No ordinary native trial showed equal logical wake and expiry or a late delivery covering two distinct due deadlines. ## Reproduction / 재현

The shell scripts preserve the actual paths, toolchain and command lines of this run. Use a fresh WSL user working directory and evidence root, with Rust 1.95.0 and its aarch64-unknown-none targets, clang/lld, binutils, QEMU and a local git mirror containing the exact public SHA. The first wrapper obtains that revision from /mnt/d/codex/j-nox/.git. Recreate evidence into a NEW destination with fresh runs and inputs directories rather than overwriting this archive. Adjust only machine-specific paths in launcher copies; their recorded digests refer to the originals. Run first.sh, supplemental.sh, extended.sh, controls.sh and offline.sh sequentially. first.sh ends with the recorded unsuccessful standalone host test invocation after all ten native boots; extended.sh uses the corrected harness. Original bounded captures intentionally return timeout status 124 after terminal UART as the guest parks. Extended captured guests are quit after all three/two exit records. See outcomes.json for per-case arithmetic, comparisons and statuses. For offline replay alone, compile replay/main.rs with rustc --edition=2021 --cfg jnox_native_el0 and pass the executable path to check.py. The portable content hashes are in SHA256SUMS. The three native cohort scripts refuse existing trial directories.
