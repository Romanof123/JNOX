# EVD-011 · Pi 4 모델의 첫 직렬 부팅

[English](evd-011.en.md)

독립 검증팀은 QEMU 11.1.3의 raspi4b(2 GiB, TCG)에서 전용 원시 이미지를 처음 실행했다. 정확히 29바이트의 두 부팅 문구를 수신하고 이어진 1초 동안 추가 출력이 없었다. 첫 판정을 기록한 뒤 ELF의 진입점과 적재 주소 0x80000, 부팅 설정과 주변장치 레지스터를 대조했다. CRLF, 추가 바이트, 원시 이미지 대신 ELF를 준 호스트 대조군을 모두 거부했다.

처음에는 관찰기의 독립 종료 코드 파일에 줄바꿈만 남아 마지막 PASS 경로로부터 코드 0을 추론했다. 외부 실행기 종료 코드는 0이었다. 통합팀은 오프라인 패키지 안의 커널로 별도 게스트를 부팅하고 UART 29바이트와 관찰기 종료 코드 0을 직접 기록했다.

서로 다른 빌드 디렉터리에서 ELF와 429바이트 원시 이미지의 해시가 각각 일치했다. 검증된 공식 펌웨어로 온라인·오프라인 FAT 파일 세트와 SHA256SUMS를 재현했다. 기존 출력 경로와 손상된 펌웨어를 거부했다. QEMU는 원시 이미지를 직접 적재한다. 실제 microSD·EEPROM·펌웨어 부팅, 물리 UART 전기 신호, 타이머 IRQ, SMP, 제품 시간 한계는 실보드 검증이 남아 있다.
