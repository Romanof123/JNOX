# IPC-005 first independent verification · 공유 페이지 대여 1차 독립 검증

**PASS for #374’s single-core AArch64 QEMU virt CPU-only FIFO and RR profile.** Eleven first cold boots, ten additional live RAM snapshots within those boots, four original host controls, and two independent host controls passed. Candidate `66d988a0772fac3fd305b83bb123c5d966ea5f23`, tree `e921bdda13ce358b7adb6386f4a1e0fff4b56e72`. Acceptance came from #374, original IPC-005/#24 and `df5260d7048f04dd38ae9499b07b10578826d05b`. The cases and expected outcomes are in `freeze.txt`. QEMU TCG 6.2, Cortex-A72, one vCPU. Physical cross-core coherency, DMA, physical timing and product safety require separate evidence.

C·Rust 송수신은 두 정책에서 핸들·VA·내용·꼬리 0을 일치시켰으며 링 포화 후 동일 쓰기 대여로 재시도했다. 생산자 사망 시 소비자가 이미 읽던 페이지와 게시된 다음 메시지를 보존했고, 소비자 사망 때는 활성 읽기·미게시 쓰기·대기 게시분을 모두 회수했다. 제3자의 네 연산은 −13이었다. 독립 RAM 캡처에서는 같은 물리 페이지의 RW → 미매핑 → RO → 미매핑 → 새 RW 전환, 113바이트 뒤의 초기화 및 재사용 전 전체 초기화를 확인했다.

**MMU and publication.** The decoder walked each private root and all reachable valid AArch64 leaf tables, including privileged identity aliases. No EL0 alias mapped any page-table frame. Each loan slot had only its expected user alias, marked nG, PXN, UXN, AF, inner-shareable; AP bit 7 distinguished read-only. The two-slot checkpoint boots had 18 distinct table frames and the three-slot terminal snapshots had 25. Exact ELF disassembly from the official FIFO image shows the PTE store at 0x40204a64 followed by DSB ISHST, TLBI VAE1IS with ASID+VA, DSB ISH, and ISB. The publication path calls the revocation/tail-clear hook at 0x40203d04, stores the descriptor handle, then publishes tail with STLR at 0x40203d30. Ring front uses LDAR at 0x402038a0 and dequeue releases head at 0x40203b6c. The compiled RR image contains the same ordered instructions. The source and ELF use the same backing PA through all states; only initial clearing and tail clearing change its contents. SDK Rust byte reads and writes are unsafe volatile accesses scoped to a live grant; the wrapper constructs no Rust page references. The uncommitted dirty frame remained physically dirty but unmapped after a supplemental exit; scrubbing is enforced on the next writer grant.

**호스트 대조와 한계.** 독립 호스트 대조는 0, 1, 2⁶⁴−3, 2⁶⁴−2, 2⁶⁴−1에서 시작한 head/tail로 각각 12회 게시·소비해 최대 점유 2, 종료 점유 0을 확인했다. 마지막 세대 후 새 대여는 세 차례 모두 −75였다. 매핑 실패·중복 정리 대조는 호스트에서 실행했다. 일반 앱 실행에서는 자연 종료를 사용했다. 공식 앱이 비어 있는 링을 반복 조회해 일반 스케줄러 저널에 FIFO 2,828개 및 RR 2,611개 누락이 있었다. 전용 매핑 기록은 각 34개 전부 남고, 추가 9회 부팅의 일반 저널에는 누락이 없었다. `results.json`에 복원한 값과 물리 페이지별 해시를 담았다.

**Host controls and trace limits.** Four candidate tests cover wrap/rollback, injection of refused mapping callbacks, generation exhaustion and teardown. Two independent controls traverse five counter origins and retire the final representable generation. Public guest APIs do not seed u64 counters or force kernel mapping failures. The original spinning reader overflowed the general scheduler journal by 2,828 FIFO and 2,611 RR events. The separate loan journal retained all 34 mapping transitions in each. The nine supplementary boots retained all scheduler events. All 11 captured the complete linked physical RAM at exit. This first verification covers the declared deployment; independent release review owns approval.

**Observed footprint.** Two FIFO packages used the same two verifier-app ELF hashes and priorities with different role strings. Enabling the reversed loan route changed GNU size's text/data/BSS totals by +7,519/+168/+32,768 bytes, and the linked ELF file by +15,824 bytes. The route reserves 12,288 bytes for three frames and 8,192 bytes for two process-specific loan L3 tables, alongside the two-entry ring, policy state and fixed diagnostic storage. These are comparison-build measurements.
