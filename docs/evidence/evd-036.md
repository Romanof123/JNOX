# EVD-036 · 협력 이벤트의 순서와 처리 시간

[English](evd-036.en.md) · [사전 계약](../coop-runtime.md) · [원본·심벌·독립 검증기](evd-036.json)

독립 검증자가 QEMU virt 단일 Cortex-A72, TCG, GICv2, 128 MiB에서 두 일반 이미지를 각각 처음 콜드 부팅했다. 두 경우 모두 타이머 IRQ가 소유자 실행을 중단한 뒤 같은 PC로 복귀했다. 중단 PC는 events에서 `0x402013c4`, single에서 `0x402013c8`였다. 응용 메모리에는 양보 전에 타이머가 비활성 상태였다고 기록됐다.

두 실행에서 외부 예외 순서는 IRQ → SVC #0(소유자 양보) → #1(태스크 2 종료) → #1(태스크 0 종료) → #1(소유자 종료)였다. 양보와 첫 종료는 진입 트램펄린 `0x4020124c`로, 다음 종료는 소유자의 저장 PC `0x40201434`로, 마지막 종료는 idle `0x40201258`로 복귀했다. 정지 시 PC는 `0x4020125c`였다. UART의 태스크 2→0 순서와 응용 관찰값도 일치했다.

|---|---|---|
| coop-events | 용량/최대 깊이 2/2. Full 1회, InvalidHandler 1회. 11 처리 중 추가한 33은 대기 중인 22 뒤에 실행됐다. | 11→4,358 / 22→556 / 33→533. 처리기 1은 2회, 합계 4,891, 최대 4,358, 1틱 초과 2회. 처리기 0은 1회, 합계·최대 556, 초과 0회. |
| coop-single | 용량/최대 깊이 1/1. Full 1회, InvalidHandler 1회. 11을 꺼내 확보한 공간에 33을 추가해 다음에 실행했다. | 11→5,121 / 33→553. 처리기 0은 2회, 합계 5,674, 최대 5,121, 1틱 초과 2회. 미등록 행은 모두 0. |

각 실행에서 소유자는 반환 후 초과를 두 번 기록하고 계속 실행했다. 26워드 응용 관찰값에서 순서·완료별 카운트를 읽어 처리기별 합계·최댓값·초과 횟수를 재구성했다. 카운트는 호출을 감싼 측정으로 인터럽트 시간을 포함할 수 있다. 반환하지 않는 호출에는 종료 표본이 없다. 실보드 WCET와 제품 부하별 승인 한계는 별도다.

PM의 별도 호스트 회귀 2개가 통과했다. `handler_posts_to_capacity_and_budget_equality_is_accepted`와 `zero_slots_and_zero_registrations_are_safe`다.

## 원본 복원과 오프라인 재현

저장소 루트에서 아래 Python 3 코드를 실행한다. `events-01/`과 `single-01/`에 원본 UART, 예외 추적, 감사 메모리, 레지스터, 실행/QMP/종료 기록과 검증 결과가 있다. `symbol-inputs/`에는 동일 ELF에서 별도로 추출한 심벌과 SVC 명령이 있다. 원래 검증기는 Linux의 Python 3, AArch64 GNU nm/objdump와 두 정확한 ELF를 사용한다. 아래 디렉터리 배치에서 `python3 coop-fresh/verify.py`를 실행하면 게스트 없이 결과와 SHA256SUMS를 재생성한다.

```python
import base64, hashlib, io, json, zipfile
from pathlib import Path

record = json.loads(Path("docs/evidence/evd-036.json").read_text())
blob = base64.b64decode(record["zip_base64"], validate=True)
assert hashlib.sha256(blob).hexdigest() == record["zip_sha256"]
root = Path("coop-fresh")
root.mkdir(exist_ok=False)
with zipfile.ZipFile(io.BytesIO(blob)) as archive:
    assert set(archive.namelist()) == set(record["files"])
    for name, spec in record["files"].items():
        data = archive.read(name)
        assert len(data) == spec["size"]
        assert hashlib.sha256(data).hexdigest() == spec["sha256"]
        dest = root / name
        dest.parent.mkdir(parents=True, exist_ok=True)
        dest.write_bytes(data)
```
