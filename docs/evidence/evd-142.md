# EVD-142 · 네이티브 혼합 중요도 앱의 HI 전환과 세대 처리

CHG-142 / IMP-142 / POL-015 / [#347](https://github.com/Romanof123/JNOX/issues/347) / [#348](https://github.com/Romanof123/JNOX/pull/348)


최초 SDK 사전 점검에서는 C 앱 네 개가 모두 링크 전에 종료 1로 실패했다. 수정된 SDK는 네 AArch64 ELF와 2·4슬롯 패키지를 생성했다. 게스트를 실행한 커널은 f2b2cd724ff8e3d8e7e403c5cc6a6e819f5f4ff0이다. 이 문서의 통합 기준 main은 3373dcc6ce8230cc65240fe78f6500fb2798f6b6이다.

[First SDK preflight / 최초 SDK 점검](native-amc-first-preflight.en-ko.md) · [Corrected binaries / 수정 바이너리](native-amc-corrected-preflight.en-ko.md)

단일 Cortex-A72 QEMU virt/GICv2 기본 62.5 MHz에서 여섯 구성의 일반·추적 최초 부팅 12건 모두 종료 기록에 도달했고 구간·생명주기 행 손실은 없었다. 최초 공개 판독은 8건 충족, 2건 미완료, 2건 실패였다. normal-hi와 staggered 추적은 HI1/g0의 CPU 시계 SVC에서 전환했고 해당 세대의 PPI30은 0회였다. 실제 CVAL보다 각각 125·1,145틱 늦게 표본을 얻었다. 사설 앱은 커밋 뒤 다음 경계 전에 HI를 관측했지만 타이머 단독 전환 조건은 미충족이다. over-hi 추적은 실제 PPI30 전환을 기록했다. normal-hi에서 새 LO0/g1은 표본 8개·합 36을 냈고 생존 작업은 완료됐다. over-hi에서도 새 세대 산출물과 HI 예산 소진을 확인했다.

두 overlap 최초 실행의 LO0/g0은 의도한 마감보다 각각 2,875,851틱과 2,665,910틱 늦게 종료했다. 마감 결함과 중복 공개 거절 이후 기존 세대가 실제 종료까지 차감됐고 8/36과 종료 0을 남겼다. 최초 판독은 의도한 늦은 종료를 실패로 판정했다. 같은 원본을 재판독한 별도 검사에서는 10건 충족·2건 미완료였으나 결함과 거절을 25 ms 뒤로 옮긴 변조 두 건도 잘못 통과했다. bba5355의 추가 판독 수정은 독립 수용 대기 중이다.

실물 보드 시간, 실제 제품의 부하·예산·마감 및 위험 수용은 별도 판정 대상이다. #353과 POL-015의 미해결 범위를 추적한다.
