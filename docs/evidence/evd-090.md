# EVD-090 · 정적 ELF 메모리 측정

이 기록은 REQ-009의 정적 크기에 대한 VER-009 측정 근거다. 소스 `34454f955a30b0d3be0a4dfc73435a344f2dbff9`에서 최소 virt 이미지의 RX는 275 B, 정적 RAM은 20,496 B였다. 각각 상한을 포함한 256 KiB와 2 MiB 기준을 충족했다. 별도 상한이 없는 fixed-RR 비교 이미지는 각각 14,728 B와 115,056 B였다. 최초 판정기는 정렬되지 않은 BSS 끝을 허용하고 유효한 보존 전용 읽기 섹션을 거부했다. [최초 측정](evd-090-virt-static-first.md) · [색인](evd-090-virt-static-first.json) · [원래 ELF와 대조군](evd-090-virt-static-first.zip)

수정 소스 `812cfd80c62b8936bfd53e5ff4ffe185195375a3`에서 입력 역할·경계 검사 30건이 독립 ELF 계산과 일치했다. 별도 익명 대조에서도 입력 역할별 결과 20건이 모두 일치했다. 실행 중 스택·힙 최대 사용량, 기동 시간 및 실기 지연은 미결이다.
