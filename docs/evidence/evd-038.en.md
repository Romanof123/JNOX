**Direct observations.** Each external exception stream showed blocking SVC #2, sibling wake #3 returning to the blocked continuation, an IRQ preempting the first task, peer exit #1 to idle, an idle IRQ restoring the first task's exact interrupted instruction, first exit restoring the sibling after wake, and sibling exit returning to idle. UART identified the peer at the shared entry trampoline. Both diagnostic journals recorded elapsed service, charge, overrun, debt and a terminal compare of zero. Their stopped register snapshots located idle. The plain streams ended with an ERET into idle.

**Independent reconstruction.** The period P was 15,625,000 and the parent quota P/4 was 3,906,250. The verifier assigned elapsed time only along the outgoing owner's path and capped each node's credit at its quota on each fixed-grid refill. Positive balances in the table come from that reconstruction. Negative magnitudes matched journaled debts. The late parent needed three further refills before it regained positive credit and its two ready leaves became eligible. Each saved/restored frame mapped to its owner's distinct 16 KiB stack. All sample intervals were at most 8P, ordinary and idle reactions at most P/8, and late parent debt exceeded P/2.

**Scope.** The external trace identifies IRQ class. PPI30 attribution follows from the accepted GICC IAR check and timer configuration. Timer-control readback was outside the capture. These four trusted EL1 single-vCPU executions leave repeated delays, arithmetic extremes, physical worst-case timing, FTTI and product isolation open. PM separately reported five passing host tests and synthetic controls.

## Offline replay

From the repository root, run the Python 3 snippet, then run `python groups-replay/portable.py` and compare its output with `validation.txt`. The archive includes the original `validate.py` and the objdump/nm outputs it obtained from the identified ELFs. The portable version substitutes these two file inputs. Each boot log identifies the ELF SHA-256 and launch arguments.

```python
import base64, hashlib, io, json, zipfile
from pathlib import Path

record = json.loads(Path("docs/evidence/evd-038.json").read_text())
blob = base64.b64decode(record["zip_base64"], validate=True)
assert hashlib.sha256(blob).hexdigest() == record["zip_sha256"]
root = Path("groups-replay")
root.mkdir(exist_ok=False)
with zipfile.ZipFile(io.BytesIO(blob)) as archive:
    assert set(archive.namelist()) == set(record["files"])
    for name, spec in record["files"].items():
        data = archive.read(name)
        assert len(data) == spec["size"]
        assert hashlib.sha256(data).hexdigest() == spec["sha256"]
        dest = root / name
        dest.parent.mkdir(parents=True, exist_ok=True)
        dest.write_bytes(data)
```
