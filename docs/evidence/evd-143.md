# EVD-143 · 네이티브 평가기 정지 후 복구

최초 A/B 바이너리 검사는 두 입력을 모두 거부했다. 후속 소스 빌드 검사 두 건도 부팅 전에 Cortex-A53 정오표용 링커 옵션을 거부했다. 수정 판독기 f5b9df23은 2c4b0c22의 A와 B 각각에서 형식이 지정된 평가기 진입점과 신뢰 입력 순서, 적재 바이트를 독립 단독 빌드의 일반 ELF와 대조했다. 지정 QEMU Cortex-A72의 기존 일반 구성 12회, B 일반 구성 2회, 고장 주입 비활성·활성 구성 8회의 최초 부팅에서 셀 206개와 운영 종료 184건을 확인했다. 사설 RAM의 전압·온도·경보 산출물과 종료 코드 30·31·32가 일치했다.

PPI30이 평가기 전용 스택의 주입 루프를 중단했다. A k1에서는 한 셀 만에 미게시 거래를 취소했고 A k3에서는 세 셀 만에 워치독이 만료됐다. 두 경우 모두 온도 작업 슬롯 1을 선택했다. B k9에서는 정확히 두 셀 경계에서 만료되어 할당량 0으로 실제 EL1 유휴 상태에 진입했다. 예약 경보는 k8과 k11에서 실행됐다. 세 차단 관측은 D보다 각각 9,116·8,518·8,623틱 늦었다. 실행된 타이머 쓰기 명령의 피연산자는 예정 비교값과 일치했고 차단 시점에 CVAL=D와 CTL 하위 비트 5를 독립적으로 읽었다. 외부 및 게스트 ELR은 자기 분기 주소와 일치했다. 중단 직전 PSTATE는 관측됐으나 설정 순간의 타이머 재판독과 저장된 SPSR_EL1 직접 판독은 없었다.

고장 루프는 해석 및 게시 준비 전에 실행됐다. 정상 해석·게시 중 인터럽트와 오래된 생산자의 실제 게시 시도, 자발적 손실은 미관측이다. 판독기 판정은 지정 입력에 한정되며 PM 및 POL-018 계열 출시 판정은 미결이다.
