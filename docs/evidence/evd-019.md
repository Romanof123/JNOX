# EVD-019 · 다단계 큐의 작업 선택과 복귀

[English](evd-019.en.md) · [합격 기준](../m4-multilevel.md) · [#50](https://github.com/Romanof123/JNOX/issues/50)

첫 부팅에서 상위 작업 둘이 실제 타이머 인터럽트 네 번에 걸쳐 교대했다. 하위 작업은 모든 구간에서 준비 상태였고, 상위 작업 둘이 모두 차단된 뒤에야 실행됐다. 피드백 큐에서는 한 단위씩 소비한 두 번의 조기 양보에서 잔여량이 3→2→1로 줄었다. 세 번째 계상에서 작업이 강등되어 먼저 기다리던 CPU 중심 작업이 앞섰다. 누적 서비스 12단위에서 부스트 후 준비 순서가 보존됐고, 새로 깨어난 대화형 작업보다 CPU 중심 작업이 먼저 실행됐다.

신규 검증자가 두 사례의 작업 문맥 여섯 개에 걸친 17개 결정을 동결 ELF 및 IRQ 8회·SVC 9회의 예외 기록과 대조했다. 디스패치에서 예외까지 경과한 카운터를 틱당 2,500,000단위로 나눈 정수 몫을 허용량까지 계상했으며 모든 기록이 이 규칙과 일치했다. 관측 구간에는 디스패치 복귀와 예외 진입이 포함된다. [동일 실행의 UART·문맥·예외 기록](evd-019.json)

독립 큐 기준 5,850개 이력을 포함해 동결 소스의 Rust 호스트 시험 80개, Python 시험 14개, 추가 순차 게스트 부팅 11회가 통과했다. 이 프로파일에서는 미사용 공용 준비 큐 메서드 두 개에 대한 빌드 경고 한 건이 있었다. 실물 시간 상한과 제품 부하의 서비스 보장은 추적 중이다. [공통 회귀 기록](evd-019-020-regressions.json)
