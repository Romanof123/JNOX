# Pi 4 작업 이주 최초 관측 결과

[English](pi4-migration-first.en.md) · [판정 기준](../boards/pi4-smp-migration.md) · [원본 관측 자료 묶음](pi4-migration-first.zip)

raspi4b 모델을 처음 여섯 번 기동한 결과 한 번만 산술 루프 중단·복귀 기준을 충족했다. 정책별 최초 두 번 모두 충족해야 한다. 전역 0/2, 분할 1/2, 클러스터 0/2였다.

첫 소스 `ba212f67cd75564925a76be0dec8b85aa044fc38`에서는 Rust 1.95.0 릴리스 빌드 세 건 모두 smp_policy.rs:84에서 E0599(AffinityDomain::allows 누락)로 종료했다. 게스트 기동은 0회였다. 수정 소스 `6bb8ab9e451f314304b63820b769d4efe90d9183`에서는 세 빌드가 성공했다. 매번 새 4-vCPU raspi4b 프로세스에서 두 CPU를 온라인으로 설정하고 다중 스레드 TCG, 최대 30초, 종료 출력 후 1초 무출력 조건으로 수집했다. 아래 루프 주소는 시작을 포함하고 끝을 제외한다. 자료 묶음에 정책별 ELF, 링크 맵, 역어셈블리 및 스레드별 예외·복귀 로그가 있다.

| 정책·순번 | 산술 루프 | CPU0의 실제 ELR·명령 | 결과 |
|---|---|---|---|
| 전역 1 | 0x81e10–0x81e34 | 이주 IRQ 관측 없음 | M이 먼저 종료, UART 실패 코드 0x1d |
| 전역 2 | 0x81e10–0x81e34 | 0x81e80, ldp x2,x3,[sp] | 루프 반환 뒤 CPU1에서 M 재개 |
| 분할 1 | 0x81e14–0x81e38 | 0x81e14, ldr x8,[x21] | CPU0에서 루프 내부 재개 |
| 분할 2 | 0x81e14–0x81e38 | 0x81e98, ldr x8,[sp] | 루프 밖, MG END |
| 클러스터 1 | 0x81ec0–0x81ee4 | 0x81f44, ldr x8,[sp] | 루프 밖, MG END |
| 클러스터 2 | 0x81ec0–0x81ee4 | 0x81f44, ldr x8,[sp] | 루프 밖, MG END |

**전역 2회차.** CPU0이 EL1 IRQ를 받았을 때 SPSR은 0x60000345, ELR은 0x81e80이었다. 작업 프레임 주소는 593392, SP는 594224였다. CPU1은 유휴 상태의 0x80914에서 IRQ를 받고 0x81e80으로 복귀했다. 두 CPU의 Linux TID별 로그에서 이주가 확인되었으나 중단 위치는 판정 대상 루프 밖이었다. 인덱스 51328의 관측은 리스 1과 4에 걸쳤다. 51344에서는 양쪽 모두 리스 4였고 부분합은 1318128840이었다. CPU1에서 M이 최종합 2147516416을 한 번 기록했다. P0 결과는 528, P1 결과는 136과 392였다. UART의 M/P0/P1 로컬 서비스 합계는 65100/2039/23571틱이었다.

**분할 1회차.** CPU0이 0x81e14에서 복귀했다. CPU0에서 M의 리스 1과 5가 소비한 시간은 합계 59390틱이었다. P0과 P1은 62.5 MHz에서 각각 3976틱과 22222틱을 소비했다. 인덱스 48960은 리스 경계에 걸렸고, 48976은 리스 5에서 부분합 1199348776을 기록했다. M의 최종합은 2147516416이었다. 보존된 중간 관측은 일부 지점에 한정된다. 코어 간 경과 지연과 실물 보드 명령 이력은 미측정이다.

**오프라인 재생.** 자료 묶음을 풀고 측정 소스의 도구와 Python, pyelftools 0.32를 사용한다. 각 정책과 순번에 대해 해당 폴더의 session-1.digest 또는 session-2.digest를 읽고 `python3 tools/pi4_migration_replay.py <자료>/<정책> <순번> <해시>`를 실행한다. 미관측이면 종료 코드는 1이다. 처음에는 pyelftools 누락으로 MG END 다섯 건의 도구 판정이 중단됐고, 의존성을 설치한 뒤 동일한 자료를 재생했다. 공개 텍스트의 계정·작업 경로와 연쇄 해시는 정규화했다. provenance.json에 원본·공개본 SHA-256이 있다. ELF와 원시 이미지는 동결 당시와 같으며 UART, TID 맵, 예외 로그는 원본 바이트를 보존한다. ZIP SHA-256은 `75e2245186f24ae7f25e83729ad9358002fdace1aeddc2a7a811ff0c565fac08`이다.
