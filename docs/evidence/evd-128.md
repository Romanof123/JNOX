# EVD-128 · 두 마감 작업과 반복 서비스의 시간표

CHG-128 / IMP-128 / POL-005 / [#319](../native-deadline-recurring.en-ko.md) / [#320](https://github.com/Romanof123/JNOX/pull/320)

`0054957280b20ec958a96b6849daabc897ab5f35`

수용된 QEMU 부팅 5회에서 두 작업 모두 실제 마감 전에 끝났다. EDF·격자형 LLF는 각각 일반·추적에서 슬롯 1·3에 서비스를 실행했고 별도 EDF는 슬롯 2·4에 실행했다. 다섯 사례 모두 반열린 100 ms 이동 구간의 최대 소유자 전환 수는 3으로 설정 상한 6 이내였다. 남은 예약 시간은 유휴였다. 종료 RAM에서 A의 16블록 합 8,355,840, B의 표본 67,108,864개와 히스토그램 9개 빈, 서비스의 64표본 두 묶음 제곱합 89,440·617,824를 확인했다. 서비스가 복귀한 순번은 1이었고 A·B·서비스 종료값은 17·197·41이었다.

최초 시간표에서는 B가 슬롯 2·4에서 PC 0x40003c, SP 0x1010fa0로 복귀했다. 일반 부팅은 저널과 종료 RAM을 제공했다. 두 외부 추적에서는 각각 예외 9건과 실제 EL0 복귀 주소 전체가 일치했고 서비스 전후의 전용 진행량을 관측했다. 기록된 복귀 시각은 게스트 복귀 직전 표본이다. 두 정책 모두 상한 5는 사유 10, 잔여 공급 부족은 사유 8로 운영 타이머 설정과 EL0 진입 전에 거부했다. 기존 두 작업 패키지 두 개에서도 전용 산출물과 종료값을 확인했다.

부팅한 소스는 0054957이다. 최초 판독기는 성공한 5회의 첫 ARM 행을 거부했다. 판독기만 수정한 5efcf0b는 같은 파일을 통과시켰고 기존 거부 4회 판정도 유지했다. 호스트 해시 도구 오류로 통합 bindings.json 작성은 최초 EDF 일반 부팅 뒤에 이뤄졌다. 개별 매니페스트와 입력·명령은 부팅 전에 정해졌으며 최초 게스트를 다시 실행하지 않았다. 호스트 스케줄링 시험 177개가 통과했다. 변조 기록 4개의 거부는 오프라인 판독기 검사이며 런타임의 잘못된 호출이나 하드웨어 결함 주입은 수행하지 않았다. 검증 범위는 지정된 단일 CPU 가상 배포다. 다른 제품 부하·간섭 조건·실물 보드는 별도 판정 대상이다.
