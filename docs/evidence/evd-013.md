# EVD-013 · 타이머 도착 시 SJF·SRTF·HRRN의 실행 결정

[English](evd-013.en.md)

실행 중인 A의 잔여 추정량이 4일 때 추정량 2인 B가 도착했다. SJF는 A의 명령 `0x40201298`로 즉시 복귀했다. SRTF는 B를 실행하고 B가 종료하자 A의 같은 명령으로 복귀했다. HRRN은 과소 추정된 A를 종료까지 유지한 뒤 새로 도착한 짧은 C보다 열 틱 기다린 B를 먼저 실행했다.

독립 검증자는 소스와 예외 기록을 보기 전에 UART 301바이트와 관찰기 종료 코드 0을 기록했다. 같은 게스트에서 IRQ 3회와 완료 SVC 7회를 ELF에 대응시켰고 변형된 UART 입력 3개를 모두 거부했다. 호스트 시험 39개가 통과했다. 독립 틱 모델은 도착·ID·추정량·실제 실행량을 바꾼 9,720개 스케줄을 비교했다. 통합팀은 별도로 단독 및 조합 구성 11개를 부팅해 기존 프로필과 선택 순서를 확인했다. [UART / IRQ / SVC](evd-013.json) · [11 QEMU profiles](evd-013-regressions.json)

표의 시각은 작업이 제공한 논리 입력이다. 이 결과는 단일 에뮬레이션 코어에서 어떤 작업을 실행했는지, 비동기 중단과 원래 명령 복귀가 일어났는지를 확인한다. 레지스터와 스택 값은 게스트 내부에서 검사했다. 실제 서비스 시간·WCET 및 M4 배치 서비스 출시는 별도 검증 항목이다.
