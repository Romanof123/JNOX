# EVD-125 · Create and join a native worker thread

CHG-125 / IMP-125 / [#313](../native-joinable-threads.en-ko.md) / [#314](https://github.com/Romanof123/JNOX/pull/314)

`304667baa498d12f0c99774891f32a28ca287b0c`

Original source 304667b built both application ELFs and passed 169 host tests. Packaging the C and Rust kernels failed with three E0308 type errors. No guest booted on that source.

Corrected source `3d53da8b72a3f58e44e02d256af815fa3159adb9` passed 169 host tests. Thirteen cold boots on a single Cortex-A72 QEMU virt CPU comprised plain and external-trace runs of each application and nine lifecycle, error and compatibility controls. C exited 17 in both runs. All 256 entries in both shared calibration arrays matched; worker sums were 32,896 and 33,152, and main summed 32,640. Main blocked on the first join. While its worker slept, the idle CPU acknowledged PPI 30 and the worker woke after its deadline. The next worker explicitly exited before main joined, so that join returned immediately. Handles 3 and 5 identified distinct generations; the stale handle returned ESRCH. Rust exited 29 in both runs, verified all 256 squares (sum 5,559,680) and joined the shared result at 0x402004.

Physical process-memory reads and a page-table walk confirmed shared arrays under the same TTBR, distinct guarded stack ranges (initial SP 0x1010fb0 and 0x1009000) and separate TPIDRRO_EL0 errno cells at 0x1001000 and 0x1001004, containing 22 and 38. Both worker generations began with errno zero. The external trace matched all 28 C and eight Rust SVC entries and corresponding EL0 returns. Controls covered occupied and unjoined slots, self join, invalid wrapper inputs, discarded join results, main-thread exit, whole-process exit and singleton compatibility.

This evidence covers one cooperative process on CPU0. EL0-origin timer delivery, full FP/SIMD/TLS canaries, first-instruction stack scrubbing, SMP, physical-board timing and the broader POSIX API remain outside these runs.
