# EVD-044 · 일반 Rust 작업의 시간 분할

[English](evd-044.en.md) · [#99](https://github.com/Romanof123/JNOX/issues/99) · [#104](https://github.com/Romanof123/JNOX/pull/104)

v2의 새 정상 콜드 실행은 P 10/10, Q 13/13 경계에서 1 ms를 충족했다. v1은 P 9/10, Q 11/12 경계가 초과했고 Q가 준비된 B 구간을 건너뛰었다. 실제 지연 주입과 IRQ 마스킹은 미검증이다. [EVD-044 v2](evd-044-v2.md)

### 첫 실행 · v1

**부분 검증. 최초 일반 게스트 두 개 모두 1 ms 시간 기준에 실패했다.** P는 10개 경계 중 9개, Q는 12개 중 11개에서 한계를 넘었다. Q에서는 준비된 B의 실행 창 하나를 건너뛰었다. 독립 재현은 예외 PC, 전용 스택 연속성, 작업 체크섬과 타이머 비교값 읽기를 대조했다. 기존 어셈블리 시험도 PART FAIL을 출력했으며 원인은 미해결이다. 합성 사례 6개는 호스트 대조군이다. #99 및 #21 전체 릴리스는 미확정이다.
