# EVD-139 · 네이티브 배치 작업의 도착과 서비스 추정치

CHG-139 / IMP-139 / POL-003 / [#341](../native-batch-applications.en-ko.md) / [#342](https://github.com/Romanof123/JNOX/pull/342)

`25a41989368d4f76ec7151209e27a448b7b253e2`

14개 네이티브 최초 부팅에서 각 앱의 사설 산출물과 재생 결과가 일치했고 저널 손실은 없었다. 두 앱의 도착 실험에서는 SRTF가 실행 중인 앱을 선점해 짧은 앱을 실행한 뒤 원래 앱에 복귀했다. SJF와 HRRN은 기존 앱을 유지했다. 대기 시간 실험에서 HRRN은 B를 C보다 먼저 선택했고 SJF는 C를 먼저 선택했다. SJF 동순위 큐 최초 부팅에서는 첫 PPI가 E+5,442,243틱에 발생해 이미 세 앱 모두 공개 시각이 지났다. B 다음 C 순서는 확인했지만 A 실행 중 두 피어가 도착하는 장면은 이 부팅에서 관측되지 않았다.

도착 사례 6건에서 A는 각각 128 MiB를 처리해 합계 17,112,760,320과 종료값 17을, B는 8블록에서 경보 2,048개와 종료값 43을 남겼다. SRTF 원본에서 중단·복원된 PC, SP, 매핑 및 프레임과 최종 산출물을 확인했다. 중단 순간의 누적 블록 수나 정수 레지스터 전체에 대한 별도 스냅숏은 없었다. 노화 HRRN의 A 종료 결정은 E+10,124,297틱에서 B를 선택했고 SJF는 E+10,086,152틱에서 C를 선택했다.

기존 링크형 #211 텔레메트리 최초 6건의 순서는 모두 2,1,0이었고 실제 포화 거부 및 산출물을 확인했다. 이전 세 ELF의 적재 세그먼트가 달라 기존 일반 부팅 6건 및 저널 재생 3건의 결과를 별도 보존했다. 기본 시작 대조군은 37로 종료했다. 호스트 191/191, CLI 거부 13건, 직접 빌드 거부 11건, 직접 빌드 성공 2건을 기록했다. 최대 오프셋은 패키징 근거이며 오버플로 및 동시 기상·공개는 호스트 대조다. 고객 배포 용량과 실물 보드 WCET는 별도이며 출시 판정은 미결이다.
