# EVD-139 · Set arrival and service estimates for native batch jobs

CHG-139 / IMP-139 / POL-003 / [#341](../native-batch-applications.en-ko.md) / [#342](https://github.com/Romanof123/JNOX/pull/342)

`25a41989368d4f76ec7151209e27a448b7b253e2`

All 14 native first boots matched the private products and replay with zero journal loss. In the two-app arrival case SRTF interrupted the running app, ran the short app and resumed the interrupted one. SJF and HRRN retained the running app. With an aged queue HRRN chose B before C, while SJF chose C first. In the SJF equal-queue first the initial PPI at E+5,442,243 ticks found A, B and C already due. B then C was observed. Peer arrival during A execution was unobserved in that particular boot.

In each of six arrival boots A processed 128 MiB, produced sum 17,112,760,320 and exited 17. B processed eight blocks, counted 2,048 alarms and exited 43. The first SRTF evidence matched interrupted and restored PC, SP, mapping and frame, and verified completion. No separate snapshot of the numeric block count or all integer registers was taken at interruption. At A exit, aged HRRN selected B at E+10,124,297 ticks and SJF selected C at E+10,086,152.

All six linked #211 telemetry firsts produced order 2,1,0 with verified products and real saturation refusal. Three historical ELF load images differed. Six ordinary linked boots and three journal replays passed separately. The default startup control exited 37. Host results were 191/191, with 13 CLI rejections, 11 raw build rejections and two raw packaging positives. The maximum offset established packaging only. Overflow and coincident wake/release were host controls. Customer deployment capacity and physical-board WCET require separate evidence. Release disposition is pending.
