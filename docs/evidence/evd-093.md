# EVD-093 · 확장 정책의 일반 작업

2026-11-25 사후 색인에서 확장 정책의 일반 작업 변경에는 `CHG-093`을, 측정된 구현에는 `IMP-093`을 연결했다. POL-018 · [`3aec626ef802c990f1e977ab8308775c10d554fa`](https://github.com/Romanof123/JNOX/commit/3aec626ef802c990f1e977ab8308775c10d554fa) · [extension_normal_jobs.rs](../../kernel/src/extension_normal_jobs.rs).
