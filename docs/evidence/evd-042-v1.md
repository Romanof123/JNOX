# EVD-042 v1 · FS-M3-01 최초 가상 런타임 캡처

[English](evd-042-v1.en.md) · [#94](https://github.com/Romanof123/JNOX/issues/94) · [PR #97](https://github.com/Romanof123/JNOX/pull/97)

**부분 통과.** 서로 다른 이미지 23개가 QEMU 6.2.0의 가상 Cortex-A72 한 개, GICv2, 메모리 128 MiB에서 모두 CONTROL END에 도달했다. 첫 RM 정상 부팅은 초기 IRQ 지연 한계를 넘었다. 종료 표시에 도달한 것만으로 해당 사례가 통과하지는 않는다.

| 클록과 작업 | 최초 관측 결과 |
|---|---|
| 기본 클록, RM·DM 정상/손실/지연/수요 초과(8개) | 모두 활성화 전에 억제되어 장치 전이가 없었다. 시작 실패가 먼저 발생해 지연 IRQ나 수요 초과의 효과를 분리할 수 없었다. RM 손실은 슬롯 0을 건너뛰었다. 기본 클록의 송신 인계 부팅은 이 행렬에 없었다. |
| 결정론적 명령 계수, RM·DM 인계 정상/손실(4개) | 네 경우 모두 활성화 후 세대 1, 순번 3의 발행 권한을 일반 Rust 송신 작업에 인계했다. 각 실행에서 판정 26회를 확인했다. 정상은 활성 상태를 유지했고 손실에서는 하강 전이가 발생했다. |
| 결정론적 RM 상태 스크립트(9개) | 조기·만료·누락 명령, 허가 누락, 무효 입력, 무응답, 포화, 복구, 구세대 사례가 각 상태 검사를 충족했다. 복구는 활성/비활성/활성 전이를 보였다. |
| 결정론적 RM 정확 경계(2개) | 최악 간격 시험에서 완료 시각은 목표 2,658,828틱보다 늦은 2,658,830틱이었고 다음 간격은 312,500틱 대신 312,503틱이었다. 동률 시험에서 발행은 만료 판정 2,658,829틱보다 6틱 늦은 2,658,835틱이었다. 정확한 최악 배치 및 발행·만료 동시 사건은 입증되지 않았다. |

62.5 MHz에서 결정론적 주입기의 첫 두 허가 발행은 190,079·815,079틱, 명령은 1,127,579틱이었다. 활성 읽기 확인은 1,252,634틱, 송신 인계는 1,252,637틱이었다. 두 손실 시험에서 고장 표본은 2,065,089틱, 검출은 3,440,108틱, 하강 읽기 확인은 3,440,132틱이었다. 보수적 구간 상한은 검출까지 1,375,019틱, 검출에서 하강 읽기까지 25틱, 전체 1,375,043틱으로 해당 실행의 25/5/30 ms 한계 이내였다.

장치 상태는 게스트 안에서 에뮬레이션된 PL061 레지스터를 읽어 확인했다. 예외 추적은 제어 전달을 기록한다. 외부 전기 신호나 연속 인터럽트 마스크 관측은 없었다. 상태 스크립트는 제한된 입력을 사용했고 인계는 로컬 송신 작업으로 이뤄졌다. 안전 IPC 전송, 실물 보드 응답, 실측 예산 근거 및 일반 해석적 수용은 별도 검증 대상이다.
