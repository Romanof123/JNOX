# Independent native argv verification / 네이티브 인수 독립 검증

Guest source 1c45bee0cb37e13f1a53f8dab902bd0e7e9fec94. Independent verifier used one emulated Cortex-A72, QEMU virt/GICv2, TCG, 128 MiB. Each of six packages had a plain boot, a separate stock capture/replay, and a separate externally stopped boot. All 11 startup vectors passed direct comparison in the active EL0 mapping. All six stock replays passed. See e/observations.json and e/runs for register, RAM, raw byte, UART and exception observations.

단일 가상 Cortex-A72에서 패키지 6개를 일반 부팅, 기본 캡처·리플레이, 외부 중단점 관측으로 각각 확인했다. 실제 사용자 진입점에서 읽은 11개 인수 벡터와 스택의 포인터·NUL·패딩이 예상 바이트와 일치했다.

At _start the observer matched all absolute pointers and string bytes against a separately built vector. At each actual SDK yield and its successor the observer identified the active slot by its entire initialized tail and checked the in-function SP across return. At __jnox_exit it read user ELF symbols directly for count, lengths, label storage, arithmetic, successful returns and status. Cooperative dispatch alternated; FIFO high-priority yields reselected their owner. Stock replay independently checked the distinct physical stack pages. Default and probe live startup bytes additionally matched separate boots of preimplementation public b1be51a958ccc7bab7fcadd703ece4d353f0e12f byte-for-byte.

같은 ELF 두 개가 같은 가상 주소의 서로 다른 인수와 계산 결과를 보존했다. 협력형에서는 실제 슬롯 교대와 복귀를 확인했고, FIFO에서는 슬롯 1 또는 2가 먼저 시작했다. 기본 앱과 프로브는 이전 공개 커밋의 실제 부팅 결과와 80바이트 전체가 같았다.

Host packager controls covered all eight three-slot default/custom combinations, source input, literal newlines/quotes/spaces/Unicode, empty arguments, 15/16 argument boundary, 1024/1025 bytes including terminators, UTF-8 boundary, missing peers, probe refusal, inherited selector cleaning. Raw Cargo covered each published malformed class, omitted/00/one-empty, absent peer and probe. Changing only peer text rebuilt a cached Cargo target. Input ELFs remained identical and separate manifests/generated byte arrays matched each value.

호스트에서는 3슬롯 조합 8개, UTF-8·빈 문자열·리터럴 처리, 수량·바이트 한계, 원시 Cargo 입력 거부, 동일 ELF에서 동료 인수만 바꾼 재빌드를 확인했다.

The original standalone Rust unit harness failed at compile time with E0308, kernel/src/native_stack.rs line 105. The original diagnostic is e/unit-original.log. The separate public correction fffbb31d46c88670dd82485be4fdea1171b3a78b changed only an explicit slice type inside #[cfg(test)]. The complete commit-to-commit diff is e/correction.diff. All three corrected tests passed. Guest observations refer to the original commit; the production source is identical across the correction.

최초 커밋의 Rust 단위 테스트는 105행 타입 오류로 컴파일에 실패했다. 테스트 전용 한 줄 수정 후 3개가 모두 통과했다. 원래 진단과 수정 diff를 보존했다. 실행 대상은 QEMU 가상 머신이며 모든 원본과 도구·명령을 WSL ext4에 보관했다.
