# EVD-096 · 네이티브 P/Q 기능 브랜치의 연속 창 커서

`CHG-096` · `IMP-096` · `POL-006` · [#249](https://github.com/Romanof123/JNOX/issues/249) · [#251](https://github.com/Romanof123/JNOX/pull/251).

최초 짝지은 QEMU 40회에서 정상 창 460개와 부팅마다 EL0 종료 두 건을 검증했다. 연속 경로는 인덱스와 검사된 덧셈을 사용하며 불연속 입력은 나눗셈과 검색으로 복구한다. 수정 P의 기본 클록은 5회 중 3회에서 2세대가 원래 62,500틱 한도를 초과했고 최대 지연은 78,799틱이었다. 수정 Q 기본 클록과 두 결정론적 구성은 각각 5/5 통과했다. 기준판 기본 P와 Q의 미달은 각각 5/5와 3/5였다. 기능 브랜치의 시간 판정은 미결이다.
