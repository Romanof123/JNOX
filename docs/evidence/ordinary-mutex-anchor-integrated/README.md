# CHG-072 integrated first boots / 통합 최초 실행

The integrated source `e716871c7c9e25ad1b3fa28dc19f73af2944862c` qualified 3/4 rust-prepared, 2/4 rust-stages and 4/4 selected-return first boots independently. Rust-prepared PI traced and both rust-stages PI boots stopped with reason 16, zero chunks and no active protected work. Each plain/trace pair shared its ELF. All twelve had the original 6,250-tick compare, a complete footer and independent ownership, frame and task-data replay. Six traced boots also correlated exception entries and returns. Rust-prepared PI plain interrupted the store of its first computed partial result before publishing a chunk. The earlier staged source measured 3/4, 3/4 and 4/4. All six integrated optional PT_LOAD images matched their staged counterparts.

Only these twelve single-core virt/GICv2 Cortex-A72 boots ran. Comparison builds covered unset-anchor PI and ceiling (identical executable text, seven loadable read-only bytes changed in each against #149), legacy mutex-bench (identical load segments), and default virt, default Pi 4 and Pi 4 fixed-rr (identical load segments against the main first parent). Pi 4 directed-wake was neither built nor booted in this cohort. The six incompatible selector builds exited 101. The five host decoder cases and two policy cases passed. An initial build stopped before any guest because the local source export omitted arch/aarch64/target. The original log is retained. Restoring arch from the pinned commit allowed compilation to proceed. Product blocking bounds and physical timing remain open.

통합 소스 `e716871c7c9e25ad1b3fa28dc19f73af2944862c`의 첫 부팅에서 rust-prepared는 3/4, rust-stages는 2/4, selected-return은 4/4로 각각 독립 검증됐다. rust-prepared PI 추적과 rust-stages PI 일반·추적은 모두 사유 16, 청크 0, 보호 계산 미진입으로 끝났다. 일반·추적 쌍은 같은 ELF를 사용했다. 열두 건 모두 6,250틱 비교값과 완전한 푸터를 남겼고 소유권·프레임·작업 데이터를 독립 재생했다. 추적 여섯 건은 예외 진입과 복귀도 대조했다. rust-prepared PI 일반은 첫 청크를 게시하기 전 계산한 부분 결과를 저장하는 명령에서 중단됐다. 직전 소스의 결과는 3/4, 3/4, 4/4였다. 선택형 ELF 여섯 개의 적재 영역은 각각 직전 소스와 일치했다.

게스트 실행은 단일 코어 virt/GICv2 Cortex-A72 열두 건이었다. 비교 빌드에서 미설정 PI·천장은 #149와 실행 코드가 같고 읽기 전용 적재 바이트가 각각 7개 달랐다. 기존 mutex-bench는 적재 영역이 일치했다. 기본 virt, 기본 Pi 4 및 Pi 4 fixed-rr은 main 첫 부모와 적재 영역이 같았다. Pi 4 directed-wake는 이번에 빌드하거나 부팅하지 않았다. 비호환 선택자 여섯 건은 코드 101, 호스트 디코더 5건과 정책 2건은 통과였다. 첫 로컬 소스 추출에서 arch/aarch64/target이 빠져 게스트 실행 전에 빌드가 중단됐다. 최초 로그를 보존하고 같은 커밋에서 arch를 추출한 뒤 빌드했다. 제품 차단 시간 한계와 실물 타이밍은 미확인이다.
