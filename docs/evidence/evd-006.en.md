# EVD-006 · CPU budget depletion and replenishment

[한국어](evd-006.md) · English

**The CPU dispatched the idle task while both workers still had pending work and both budgets were exhausted.** On 2026-11-24 a fresh verifier captured nine UART lines, 112 bytes, on the first cold boot of one emulated Cortex-A72. The verifier then matched the exception addresses from that run to the linked ELF. [Acceptance contract](../m1-cbs.en.md) · [Source candidate](https://github.com/Romanof123/JNOX/commit/6ee2ebb48e78b60e3c46fd0f04f453c97d2eae71)

| 1 | A · `0x40201278` | B entry |
| 2 | B · `0x402012fc` | Idle entry |
| 3 | Idle · `0x40201380` | A resumes at `0x40201278` |

| 5 | B · `0x4020134c` | Timer disabled, CPU parked |

A received one slot per three and B one per four. Budget and server deadline determined the selected execution context. Five IRQs occurred without a voluntary yield. Timer compares shared one guest-counter epoch. The nominal slot was 50 ms. Physical-board latency bounds require separate evidence. The observer returned 0. All three malformed host transcripts were rejected. [Raw UART, exceptions and verdict](evd-006.json)

All 28 host tests passed. A separate test counted demanded slots in a 60-tick frame for 3,375 ordered triples of valid reservations with periods 1 through 5. Admission accepted all 81 within capacity and rejected the other 3,294. Each admitted triple ran backlogged through 120 logical ticks, checking service against quota in every period. Further cases checked exact capacity, marginal overload and representation limits. Admission assumes independent implicit-deadline servers on one processor with zero interference and overhead. [Host test output](evd-006-host.txt) · [Test inputs](../../tools/scheduling_tests.rs)

After changing the shared exception context code, the default boot, fixed-priority preemption, FIFO, round-robin and EDF images were rebuilt, then booted once each in sequence. All five observers passed. The all-features configuration also passed a compile check. [Per-profile hashes and UART](evd-006-regressions.json)

The ELF SHA-256 is `5e7c0098151706243d66fc0c41080888fdc2b074706450fee452bd49087b0e6c`. The verifier mapped instructions from the supplied ELF with the same digest as the launched image. No numeric register or counter dump was captured. The restoration and timing-window checks are supported by the executed guards and trace.
