# EVD-103 · 유한 복권 실행에서 모든 관측창의 최소 배정 횟수

CHG-103 · IMP-103 · POL-010 · [이슈 #269](https://github.com/Romanof123/JNOX/issues/269) · [PR #270](https://github.com/Romanof123/JNOX/pull/270) · [English](evd-103.en.md)

단일 Cortex-A72 QEMU CPU에서 계속 준비된 세 작업이 가중치 1·2·4로 경쟁하며 각자 패킷 스트림을 처리했다. 독립 검증자는 시드별 48회 배정에 포함된 **연속 24슬롯 관측창 25개 전체**에서 작업별 최솟값을 구했다. A는 바이트 합계, B는 하위 두 비트가 0인 바이트 수, C는 최댓값을 계산해 매 배정마다 결과 한 건을 게시했다. [사전 설계](../lottery-window-plan.en-ko.md) · [검증 소스 602b189](https://github.com/Romanof123/JNOX/tree/602b1896286b9eb25b956ca1d658732441e1b719)

| 콜드 실행 구성 | A/B/C 최소 배정 횟수 | 최초 판정 |
|---|---|---|
| 시드 1 | 5 / 3 / 11 | 수용, 패킷 결과 48건 |
| 시드 2 | 1 / 7 / 10 | 수용, 패킷 결과 48건 |
| 시드 1, A에 6회 요구 | 5 / 3 / 11 | [24,48) 창에서 A가 5회여서 기동 전 거부. 배정과 타이머 IRQ 모두 0회 |

수용 분석 전후 실제 추첨 상태는 같았다. 배정 횟수는 슬롯 점유를 나타내며, 타이머 비교값과 경과 카운터는 별도로 기록했다. 호스트 시험 139건을 통과했고 독립 비교 8,640건을 수행했다. 기존 구성 여섯 개는 각각 예상 동작을 재현했다. lottery-miss는 소스 행이 이동했지만 기존 한 틱 조건에서 두 틱을 관측해 거부했다. 어셈블리 벤치는 최초 선택자 오류를 보존한 뒤 올바른 기능 플래그로 실행했다. 기존 여섯 ELF의 해시가 모두 달라졌고, 평면 바이너리가 기준과 일치한 구성은 어셈블리 벤치뿐이었다. [최초 독립 검증 보고서](lottery-window-first.en-ko.md) · [원본 캡처](lottery-window-first.zip)
