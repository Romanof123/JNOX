# EVD-052 · 제어 서비스 마커의 독립 재생 및 손상 입력 검사

[CHG-053 / IMP-052](../control-service-plan.md) · [#124](https://github.com/Romanof123/JNOX/pull/124) · [EVD-051](evd-051.md) · [JSON](evd-052.json) · [ZIP](evd-052-marker-replay.zip)

원본과 수정 판독기는 EVD-051에서 보존한 실제 RAM 저널 4개, 위상 104개의 판정 구간 및 위상 대응에 동의했다. 원본은 RAM·UART 두 입력으로 당시 출력을 재현했고 모든 서비스 조각에서 서로 겹치지 않는 비용 합계가 일치했다. 수정 판독기는 외부 IRQ/SVC·ERET 순서도 대조했다. 02번 부팅의 마커 9는 시작 273778, 끝 275568, 위상 0으로 판정 비용 1790틱이었다. 원래 판독기가 실제 위상을 잘못 읽었다는 주장은 독립 정정문에서 철회됐다.

수정 판독기는 RAM과 UART를 함께 바꾼 역순 구간, 잘못된 위상, 누락·중복 데이터, 손상된 PC와 마지막 예외 기록을 거절했다. 원본별 실행 명령과 결과, 대조 조건 및 종료 상태는 ZIP에 있다. 마커 통합 소스는 기본·기술자·콜드·마커 단독 구성을 허용하고 콜드+기술자, 기술자+마커, 콜드+마커 조합을 거절했다. 통합 제어 이미지와 독립 참조는 배치와 명령이 일치했지만 적재 바이트 9~12개가 소스 줄 번호 메타데이터에서 달랐다.

통합 제어 부팅은 두 소스 합계 6회 모두 종료했고 운영 적격은 0/6이었다. 기술자 소스 RM·DM의 첫 실패는 각각 실제 전달과 재무장 간격이었다. 마커 소스의 마커 RM·DM은 실제 전달과 위상 시간 기준에서 각각 실패했다. 각 소스에서 한 번씩 실행한 고정 기준 무시험 IRQ 콜드 모드는 설정을 확인했으나 일반 점수 도구가 사건 48을 지원하지 않았다. 각 사례는 기본 시계 한 번의 관측이며 물리적 시간이나 건전 상태를 보장하지 않는다.

**원래 엄격 감사 판정은 HOLD였다.** 소스 ab14de0에서 POL-004의 IMP-052가 근거로 연결되지 않아 종료 1이었다. 이 기록은 실제 시험과 부분 검증 경로를 추가한다. 이 새 트리의 엄격 감사 결과는 아직 없다.
