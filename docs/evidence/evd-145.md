# EVD-145 · AMC 시계 페이지와 HI 예산 타이머 전환

CHG-145 / IMP-145 / POL-015 / [#353](../native-amc-clock-pair.en-ko.md) / [#354](https://github.com/Romanof123/JNOX/pull/354)


896518d8edcfc850dc16361dcde2d1edd87c0d4c에서 단일 CPU QEMU 최초 부팅 6건은 모두 종료 기록까지 도달했고 구간·생명주기·관측 행 유실이 없었다. 페이지를 사용한 normal-hi 일반·추적과 staggered 일반·추적은 모두 HI1의 실제 PPI30을 거쳤다. 예산 경계 b부터 첫 사설 앱 관측 x까지 각각 8.535760, 7.518816, 7.127168, 7.144624 ms로 사전 기준을 충족했다. 네 실행의 시계 SVC는 0회였다. 페이지를 끈 별도 normal-hi 추적에서는 폴백 995쌍, 시계 SVC 1,990회, b→x 18.683712 ms였다.

C·Rust 호환 대조군의 663쌍은 각자의 CPU·단조 시계 경계와 정확한 게시 구간 안에 있었다. 행 909의 실제 low/g0→high/g0 선점은 타이머 IRQ가 아닌 복귀 게이트에서 일어났다. 원래 low 프레임은 high 종료 뒤 복원됐고 새 low/g1은 서비스 0에서 시작해 표본 8개·합 36을 남겼다. 최초 공개 판독기는 IRQ 원인만 허용해 이 대조를 실패로 판정했다(6건 중 5건 충족).

#348의 기존 시계 시스템 호출 기반 normal-hi·staggered 추적 최초 실행에서는 해당 세대의 필수 PPI 전환 두 건이 관측되지 않았다. 이 별도 시계 페이지 실행은 그 판정을 바꾸지 않는다. 실물 보드 타이밍·M5·제품 위험 승인과 POL-015 전체 출시는 미결이다.

통합 리더 93488785는 잘못된 입력 여섯 개를 받아들여 보류됐다. 수정 리더 d01e7f30fc35e4a50e2cc81285bf5802387c6e9e는 동일한 원본 6건을 모두 충족으로 판독했다. 네 HI1/g0 전환은 실제 GICC_IAR 0x1e를 기록했다. 호환 대조에서 909행의 복귀 게이트가 선점했고 1515행에서 high 종료 후 원래 low가 복원됐다. 독립 재판독은 RAM 변조 29건, 기존 외부 추적 변조 4건, EL1 유휴 IRQ·EL0 IRQ·EL0 SVC의 벡터 목적지를 각각 누락하거나 바꾼 새 6건을 모두 거부했다(39/39). 이전 #348 원본 12건은 10건 충족·2건 미완료, 변조 26건은 모두 거부였다.

독립 공학 수용은 이 단일 vCPU 진단 구성의 판독기에 한정한다. 새 게스트 실행은 없었다. 독립 Release와 PM은 공학 검토 대상 커밋 `f89e58ea9cb9c737e9cc145599877559a17174c0`의 선택형 네이티브 시계 페이지 기능을 승인했다. PR #354가 병합되었고 이슈 #353은 종료되었다. 실물 보드 시간 측정, M5 심사 및 제품 승인이 남아 있어 POL-015는 미승인 상태이며 #21의 정책군 승인 수는 6/18이다.
