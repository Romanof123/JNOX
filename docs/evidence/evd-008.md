# EVD-008 · RM·DM 응답 시간 계산 검증

한국어 · [English](evd-008.en.md)

**같은 작업 집합에서 DM은 두 기한을 모두 충족하는 상한을 계산했고, RM에서는 urgent 작업의 계산값이 기한을 넘었다.** 2026-11-24 독립 검증자는 먼저 공개 문서와 예제로 기대값을 계산한 뒤 호스트 CLI를 실행했다. 첫 판정을 남긴 후 코드와 시험 묶음을 확인했다. [분석 가정과 사용법](../fp-response.md) · [동결한 계산 도구](https://github.com/Romanof123/JNOX/commit/c941c61da048eff87bf2b3c3fd27a2b099da9cbd)

| 입력 | 기대값과 실행 결과 |
| --- | --- |
| 공개 예제, DM | urgent 1틱, short 3틱. 종료 코드 0 |
| 같은 예제, RM | short 2틱. urgent의 반복값이 2틱 기한을 넘어 상한은 비어 있음. 종료 코드 1 |
| 검증자가 계산한 IRQ·지터·차단·디스패치 사례 | 상위 작업 4틱, 하위 작업 9틱. 하위 기한 9틱과 같아 통과 |
| 잘못된 중복 입력 / 반복 한도 소진 | 중복 입력을 거부하고, 정상 입력의 반복 한도 소진은 판정 보류로 반환. 두 실행의 종료 코드 2 |

Python 3.9.16에서 독립 인수 시험 8개가 통과했다. 여기에는 8개의 동기 도착 작업 집합에 대해 두 공통 반복주기 동안 틱 단위로 스케줄링하여 관측된 응답 시간을 계산 상한과 대조하는 시험이 포함된다. 공개 문서에 선택 입력 `iteration_limit`의 이름을 명시하라는 검증 의견을 반영했다. [재현 입력·CLI 반환값·시험 출력](evd-008.json)

결과 JSON에서는 호스트별 Python 실행 파일 경로를 `python`으로 표기했다. 원본 관측의 SHA-256은 `8fc5e8141d59f8c1a059839e97641c8d00a32a46188aa80edb7f98030b21244b`이다.
