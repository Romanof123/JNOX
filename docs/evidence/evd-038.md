# EVD-038 · 중첩 그룹의 지연 IRQ와 부채 회복

[English](evd-038.en.md) · [사전 계약](../ordinary-groups.md#한국어) · [독립 판정·원본·재현 자료](evd-038.json)

네 이미지(일반/지연 × 비계측/계측)는 각각 재시도 없이 최초 콜드 부팅을 통과했다. 지연 계측 부팅에서 첫 리프는 한 주기 경계를 지나 18,907,440틱을 실행했다. 독립 계산은 이 구간을 실행한 리프·자식·부모에 각각 한 번 차감했다. 다른 분기의 작업은 자기 구간 143,777틱만 부담했다.

| 계측 결과 (카운터 틱) | 일반 | 지연 |
|---|---:|---:|
| 첫 태스크를 선점한 IRQ까지의 해당 구간 차감 | 3,681,996 | 18,907,440 |
| 이전 비교 시각 초과 | 158,608 | 15,344,190 |
| 선점 시 부모 / 자식 / 리프 잔액 | −158,608 / 11,719,276 / 11,719,276 | −11,437,940 / 11,999,560 / 11,999,560 |
| 다른 분기 작업의 차감 | 139,378 | 143,777 |
| 유휴 경과 / 차감 | 11,567,187 / 0 | 43,296,693 / 0 |
| 유휴 회복 IRQ의 비교 시각 초과 | 146,423 | 190,910 |

**직접 관찰.** 네 외부 예외 기록에 차단 SVC #2, 형제의 깨움 #3과 차단 작업 복귀, 첫 작업을 선점한 IRQ, 다른 분기 작업 종료 #1과 idle 진입, idle IRQ와 첫 작업의 정확한 중단 명령 복귀, 첫 작업 종료와 형제의 깨움 직후 복귀, 형제 종료와 idle 복귀가 순서대로 있다. UART가 공통 진입 트램펄린의 작업을 식별한다. 두 계측 메모리는 경과·차감·초과·부채와 최종 비교값 0을 기록했고 정지 레지스터는 idle을 가리켰다. 비계측 기록은 idle로 향한 마지막 ERET까지 관찰했다.

**독립 재구성.** 기간 P=15,625,000, 부모 할당량 P/4=3,906,250이다. 검증자는 실제 실행 소유자의 경로에만 경과 시간을 적용하고 고정 경계마다 보충 후 잔액을 할당량으로 제한했다. 양수 잔액은 이 계산의 결과이며, 음수 크기는 저널 부채와 대조했다. 지연 부모는 추가 보충 세 번 후에야 양수가 되어 두 준비 리프가 다시 실행 가능했다. 모든 저장·복원 프레임은 해당 소유자의 16 KiB 전용 스택에 있었다. 모든 표본 간격은 8P 이하, 일반 및 유휴 반응은 P/8 이하였고 지연 부모 부채는 P/2를 넘었다.

**범위.** 외부 로그는 IRQ 종류를 보여 준다. PPI30 식별은 승인된 GICC IAR 검사와 타이머 설정에서 추론했다. 외부 타이머 제어 판독은 없다. 단일 가상 CPU의 신뢰된 EL1 실행이므로 반복 지연·산술 극한·실물 최악 시간·FTTI·제품 격리 승인은 남아 있다. PM은 독립 게스트 관찰과 별도로 호스트 테스트 5개 통과 및 합성 대조 검사를 보고했다.

## 오프라인 재현

저장소 루트에서 아래 Python 3 코드를 실행한 뒤 `python groups-replay/portable.py`로 복원된 기록을 재계산한다. 출력은 `validation.txt`와 비교한다. 원본 `validate.py`가 실행 때 읽던 objdump/nm 출력을 보존했고 휴대용 버전에서는 이 두 입력만 파일로 대체했다. 각 부팅 로그에는 ELF SHA-256과 실행 인자가 있다.

```python
import base64, hashlib, io, json, zipfile
from pathlib import Path

record = json.loads(Path("docs/evidence/evd-038.json").read_text())
blob = base64.b64decode(record["zip_base64"], validate=True)
assert hashlib.sha256(blob).hexdigest() == record["zip_sha256"]
root = Path("groups-replay")
root.mkdir(exist_ok=False)
with zipfile.ZipFile(io.BytesIO(blob)) as archive:
    assert set(archive.namelist()) == set(record["files"])
    for name, spec in record["files"].items():
        data = archive.read(name)
        assert len(data) == spec["size"]
        assert hashlib.sha256(data).hexdigest() == spec["sha256"]
        dest = root / name
        dest.parent.mkdir(parents=True, exist_ok=True)
        dest.write_bytes(data)
```
