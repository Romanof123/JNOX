# EVD-109 · 시간 제한 상속 후 남은 뮤텍스 대기자

CHG-109 / IMP-109 / POL-014 / [#284](../ordinary-mutex-surviving-waiters.en-ko.md) / [#295](https://github.com/Romanof123/JNOX/pull/295)

통합 소스 `0a7747fe1e254eccadb6ded40b3238944f6c957e`의 최초 일반 게스트는 두 구간 모두 사유 0으로 완료했다. PPI 30은 전체 16,384청크 중 각각 1,850·2,159청크에서 관측됐다. X를 잡은 보고 작업은 A→B 순서에서 4→41→412, B→A 순서에서 4→42→421을 기록했다.

생존 대기자 작업의 최초 일반·추적 부팅은 2/2 통과했다. 외부 추적 부팅에서는 1,418·1,520청크에서 PPI 30이 발생했다. 두 부팅 모두 각 구간에서 선택 20회와 어셈블리 복귀 20회를 재구성하고 각 작업의 스택, 저장된 획득 호출의 반환값과 보호 영역 쓰기를 확인했다. 외부 추적에서 예외 PC와 복귀 PC도 대조했다. HIGH가 시간 초과로 빠진 뒤 X에 남은 두 보고 작업은 각 구간의 도착 순서대로 X를 받았다.

비교 순번은 8회 중 6회 통과했다. 기존 연쇄 상속과 FIFO는 각각 2/2였다. 기존 PI와 천장 대조는 일반 부팅에서 통과했고 추적 부팅에서는 각각 사유 16으로 중단됐다(2/4). 같은 절대 경로와 옵션으로 깨끗하게 빌드한 부모 소스의 두 해당 이미지는 로드되는 모든 바이트, 세그먼트 헤더, 진입점, 실행 명령 워드, 심볼 주소와 크기가 일치했다. LLVM 지역 이름은 달랐다. 이 비교에서 부모 게스트는 실행하지 않았다. 두 추적 순번이 기준을 놓친 원인은 미확정이다.

호스트 시험 140개와 관련 검사 24개가 통과했고 잘못된 선택자 10개는 거부됐다. 실패한 두 추적 순번은 #49·#21에서 추적한다. 릴리스 검토는 두 실패 순번을 보존하는 조건으로 생존 대기자 작업의 병합을 지지했다. 실물 차단 상한 및 제품 승인은 남아 있다.
