# EVD-054 · 통합 게이트

통합 소스에서 고정된 32개 조건을 재실행했다. 운용 조건 20건 중 적격은 0건이었다. A0 세 건에서 각각 허가 7개를 수락했지만 첫 발행 간격이 짧았다. 최초 EVD-054의 32건은 별도 집단이다.

[JSON](evd-054-integration.json) · [ZIP](evd-054-integration.zip) · [#131](https://github.com/Romanof123/JNOX/pull/131) · [Source](https://github.com/Romanof123/JNOX/tree/2adccb563a525863e0f56c82703852082f5bc709)

| 조건 | 결과 |
|---|---|
| 운용 A0 기본 클록 4건 | 모두 관측 종료점 도달. RM 01-1, DM 01-1, DM 10-2는 7/7 수락. RM 10-2는 7회 발행, 수락 전 결함으로 0회 수락. 첫 간격은 각각 588087, 591691, 591544, 587136틱으로 모두 요구값 625000틱 미달. 출력 전이 0회. |
| 운용 A1/A2 16건 | 기본 클록 12건과 icount 4건 모두 마스크 4095로 타이머 비교 설정·작업자 실행 전에 거절. |
| OFF 기본 클록 8건 | 첫 발행 기회 전 종료. 제어 서비스 결함 103이 7건, RM 12-2는 IRQ 지연 101. |
| OFF icount 4건 | 각각 독립 수락 7회, 첫 발행 간격 625000틱, 기준+937500틱에 별도 명령, 가상 적격 4회, 모델 ON 0회. |

각 결정론적 OFF 부팅의 SVC3 양보 7회는 이후 IRQ를 거쳐 저장된 송신자 ELR에서 재개됐다. 부팅당 IRQ/SVC/ERET는 33/40/74였고, 복귀 직전 PC 74개와 실제 복귀 PC가 일치했다. 행 86의 DAIF는 게스트가 보류 인터럽트와 함께 표본화한 값이다. 마스킹 명령의 위치와 외부 예외 기록으로 측정에서 빠진 마스킹 끝 구간의 상한을 정할 수 없다.

호스트 감시기는 리셋부터 PL061 추적을 읽고 종료 후 남은 바이트를 검사했다. 합성 자식 프로세스에서 경보 감지 후 SIGSTOP/SIGKILL이 동작했다. 분할 행, 순간 ON, 마스크 주소 별칭, 방향 및 무관 비트, 잘못된 입력을 검사했다. 각 OFF 실행에서 0 쓰기 두 번과 초기 출력 0을 관측했고 실제 경보는 없었다. 호스트 폴링·버퍼 지연의 상한, 게스트 카운터와의 동기화, 실물 핀 상태 및 결함 반응 시간은 미확인이다.

위상 이미지 10개와 별도 회귀 이미지 17개가 빌드됐다. 잘못된 선택 8개와 표식·콜드 충돌 16개를 거절했다. 양 정책의 A0·운용·OFF 및 #124 제어 이미지에서 이전 로드와 달라진 바이트는 Rust 소스 행 정보였다. 파티션 이미지 9개는 PT_LOAD 전체가 일치했다.

#124 실제 8건이 종료점에 도달했다. 새 표식 저널 2개를 예외 기록과 대조했다. 과거 표식 4건은 재생 결과가 같았고 중복 차감 주입을 거절했다. 건강 조건 검사에서 RM 기본·표식·서술자는 위상 범위, DM 기본·표식은 전달, DM 서술자는 재무장 간격에 실패했다. 행 48은 일반 검사에서 거절됐으며 별도 콜드 검사에서 무탐침 2건을 확인했다. 모드 3 RM/DM은 각각 실제 탐침 1회 후 보류·활성 비트를 지우고 기준 시각을 유지했다.

파티션 수동 제어 2건이 허용 범위 안에서 STOP에 도달했다. 의도적으로 통지를 늦춘 4건은 해당 경계 후 복구됐고 다른 지연 경계는 발견되지 않았다. 기존 벤치와 진단을 통과했고 음성 대조는 예상한 guard 99와 PART FAIL을 냈다. 스케줄링 증거 감사, 파티션 회계 시험 9건과 Cargo 선택자 회귀를 통과했다.

형식 감사는 최초 32건의 순서·집계 자료형·원본 소스·ZIP·내부 tar·매니페스트와 ELF를 대조했다. v1 오프라인 재생은 원본 결과를 재생성했다. v2 합성 검사 19건을 통과했고 과거 모든 조건에서 결과 필드를 보존했다. IRQ 간격은 행 2의 절대 비교 시각과 행 3의 요청 인덱스를 사용하고 깨움을 별도로 처리해 확인했다. 실물 타이밍이나 운용 적격 판정까지 확장할 수 없다.
