# EVD-027 · 우선순위 복귀와 RR 잔여 실행량

[English](evd-027.en.md) · [승인 기준](../m1-priority-resume.md) · [#63](https://github.com/Romanof123/JNOX/issues/63)

설정 단계에서 다섯 번의 호출이 실패했고, 여섯 번째 호출에서 게스트가 처음 부팅됐다. 기록 21행에서 선점형 FIFO와 RR의 실행 순서는 A/A/HIGH/A/B/A/idle, 지연형 FIFO는 A/A/A/HIGH/B/A/idle이었다. 검증자는 IRQ 7회와 SVC 11회를 대조했다. RR은 1,662,259카운트와 1,650,670카운트를 차감해 최초 6,250,000카운트 중 2,937,071카운트를 남겼다. 만료 관측은 설정한 기한보다 102,071카운트 늦었으며 허용치 781,250카운트 이내였다.

이 판정 당시 공개 저널 명세는 불완전했다. 검증자는 소스를 열기 전에 승인 기준, 예외 추적, ELF와 감사 기록을 확인했다. 이번 가상 부팅의 범위는 우선순위 복귀 프로필이다. 기존 FIFO/RR 회귀와 실물 시간 특성에는 별도 근거가 필요하다.

ELF SHA-256 `b1d003f72b8aa7b06461313fa6577411bed287e2d8c4ec866d7146b3aae0c337`. [검증 소스](https://github.com/Romanof123/JNOX/commit/93c64c853c3d1bf3f6286da59d83d7dc8394f7b9) · [독립 판정과 원시 기록](evd-027.json)

동일 커널 리비전에서 Rust 테스트 120개와 Python 테스트 28개가 통과했다. 단일 구성 26개와 조합 구성 4개에서 게스트를 추가로 30회 순차 부팅했다. [회귀 기록](evd-027-029-regressions.json)

## 공개 저널 명세를 사용한 독립 재현

별도 콜드 부팅에서 동일한 ELF를 사용했고, 개정된 관측기가 Python으로 캡처 스크립트를 직접 호출했다. 독립 검증자는 21개 행마다 18개 필드를 모두 해석하고 예외 및 복귀 사건 36건을 발생 순서대로 대조했다. 이 실행에서 A가 재개됐을 때 RR 잔여 실행량은 2,875,451카운트였다. 만료 IRQ는 설정한 기한보다 137,104카운트 늦게 도착해 허용치 781,250카운트 이내였다. [공개 명세와 관측기 리비전](https://github.com/Romanof123/JNOX/commit/775ecb7426d57204091f3f1ffbecc2c0f8ec02c8) · [독립 재현, 호출 명령과 원시 기록](evd-027-schema.json)

최종 관찰기에서 Python 테스트와 주기·CBS 직접 수집 실행이 통과했다. 우선순위 프로파일은 독립 스키마 재생에서 같은 직접 실행 경로를 확인했다.
