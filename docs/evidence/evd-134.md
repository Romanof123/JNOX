# EVD-134 · EEVDF 텔레메트리 CPU 공급과 기상 응답

CHG-134 / IMP-134 / POL-012 / [#331](../eevdf-telemetry-deployment.en-ko.md) / [#332](https://github.com/Romanof123/JNOX/pull/332)

`6c22596f71e956c9db8b97548dc91de8d79e43cb`

단일 Cortex-A72 QEMU virt/GICv2 기본 시계에서 운영자 명령으로 게스트를 한 번 부팅했다. 링크된 EL1 작업 세 개는 각각 16 KiB 스택을 사용했다. 카운터 62.5 MHz에서 Q=625,000틱이며, 32Q 창 다섯 개의 실제 공급은 19,932,823~19,968,349틱으로 모두 28Q 이상이었다. 작업·창 조합 15개에서 이상적 공급과의 절대 오차는 모두 4Q 이내였다. PPI30 기상 8회 모두 기한부터 소비자 코드의 첫 작업까지 4Q 이내였다. 최대 770,390틱, IRQ 기상 수락부터 첫 작업까지 최대 766,597틱이었다.

다섯 번째 대기에서 B의 가중치·요청량이 1,Q에서 2,2Q로 바뀌었다. IRQ 73건, SVC 11건과 실제 ERET 84건이 복원된 PC/SP 결정과 일치했다. 두 배치 작업 모두 선점 후 재개했고 모든 작업이 종료됐다.
