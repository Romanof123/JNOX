# EVD-050 v1 · Paired cold-start timing on QEMU virt

[한국어](evd-050-v1.md) · [EVD-050](evd-050.en.md)

**No stock healthy run qualified (0/32); no diagnostic mode initialized (0/96).** All 128 matrix runs reached a terminal marker. Every phase in the stock runs met the IRQ envelope (832/832), but only 830/832 met the decision/return envelope. No stock run received a permit, issued a rearm command or observed device ON. This is a separate cold-start experiment under #109.

The single-core Cortex-A72 TCG guests used QEMU 6.2.0, virt/GICv2 and 128 MiB. Each policy and configuration had eight cold pairs, alternating OFF/ON and ON/OFF order for QEMU interrupt logging. Launch timeout was 10 host seconds and UART polling interval was 1 ms. The ELF, UART and interrupt logs used Linux-native temporary storage. The recorded host load and Windows power settings describe the environment; load was not controlled. Host launch/observation elapsed times and guest counter intervals are retained separately.

| Stock arm | Runs | First IRQ lateness range (ms) | Runs meeting every decision/return envelope |
|---|---:|---:|---:|
| RM, logging off | 8 | 0.136176–0.231072 | 7 |
| RM, logging on | 8 | 0.150944–0.267312 | 7 |
| DM, logging off | 8 | 0.136928–0.185904 | 8 |
| DM, logging on | 8 | 0.144032–0.191552 | 8 |

Mean paired logging-on minus logging-off first-IRQ lateness was +0.015590 ms for RM and +0.006996 ms for DM. Individual differences had both signs. Each stock run issued seven permits, but the first two issues were 8.607536–9.453680 ms apart against exactly 10 ms required. All control-job deadlines and decision-spacing checks passed. All 32 ended OFF; latch reason 3 occurred in 30 runs and reason 7 in two. These paired samples do not establish a general causal latency penalty.

Each diagnostic run used one of three requested modes: instrumented stock-style epoch selection, delayed phase zero without a probe, or delayed phase zero with a timer probe. All 96 instead reported the initialized sentinel 4294967295 in row 48, then row 60 reason 1 and output OFF. The separate generic ELF-loader attempt also returned the sentinel. This demonstrates failure of this mode-input procedure on the frozen executable. ELF initialization overwriting the input is consistent with the result; reset ordering was not observed. Reset-to-first-sample is blind. Calibration of initialization/cutoff, operational phase zero, probe IRQ/EOI/readback and warmup versus matched no-probe comparisons remains unassessed.

The matrix exercised only the virtual healthy workload. Loss budgets, negative controls, physical timing, product qualification and the causes of earlier failures remain outside this evidence.
