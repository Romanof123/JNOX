# EVD-010 · Static partition windows across two major frames

[한국어](evd-010.md)

The kernel reclaimed the CPU from non-yielding A at the end of its window. Idle ran on behalf of blocked B in the first frame and continued through the reserved idle window when B became ready. In the second frame A resumed at its interrupted PC, then B ran inside its own window.

The first independent boot produced 135 UART bytes, observer exit 0 and six IRQs. The verifier recorded the first verdict before inspecting exception returns from that same guest. Logical ticks are derived from the absolute timer setup in the source and linked ELF. Register and stack checks ran inside the guest. Board latency and memory isolation require separate evidence.
