# EVD-036 · Cooperative event order and handler time

[한국어](evd-036.md) · [Predeclared contract](../coop-runtime.en.md) · [Originals, symbols and independent verifier](evd-036.json)

An independent verifier cold-booted each ordinary image once on QEMU virt, one Cortex-A72, TCG, GICv2 and 128 MiB. In both first boots a timer IRQ interrupted the owner and returned to the same PC, `0x402013c4` for events and `0x402013c8` for single. Application memory recorded the timer disabled before voluntary yield.

Both external exception traces showed IRQ → SVC #0 (owner yield) → #1 (peer 2 exit) → #1 (peer 0 exit) → #1 (owner exit). Yield and the first exit returned to the entry trampoline at `0x4020124c`. The second exit restored the owner's saved `0x40201434`. The final exit returned to idle at `0x40201258`, with the stopped PC at `0x4020125c`. UART and application memory agreed on peer order 2 then 0.

| Profile | Queue and dispatch | Elapsed counts per completion and reaction |
|---|---|---|
| coop-events | Capacity/peak 2/2. One Full and one InvalidHandler refusal. Handler processing 11 appended 33 behind queued 22. | 11→4,358 / 22→556 / 33→533. Handler 1 completed twice, total 4,891, maximum 4,358, twice over its one-tick budget. Handler 0 completed once, total and maximum 556, zero overruns. |
| coop-single | Capacity/peak 1/1. One Full and one InvalidHandler refusal. Removing 11 freed the slot for 33, which ran next. | 11→5,121 / 33→553. Handler 0 completed twice, total 5,674, maximum 5,121, twice over its one-tick budget. Unregistered row was zero. |

The owner logged both overruns after return and continued in each boot. The verifier reconstructed each handler's totals, maximum and overrun count from dispatch order and individual elapsed counts in the 26-word application block. These samples span the call and can include interruptions. A nonreturning handler supplies no completion sample. Physical WCET and approved product workload bounds remain open.

PM separately reported two passing host regressions, `handler_posts_to_capacity_and_budget_equality_is_accepted` and `zero_slots_and_zero_registrations_are_safe`.

## Restore and replay offline

Run the Python 3 snippet from the repository root. The `events-01/` and `single-01/` directories contain original UART, exceptions, audit memory, registers, launch/QMP/exit records and verdicts. The `symbol-inputs/` directory holds supplemental symbol tables and SVC instructions extracted from the same ELFs. The original verifier requires Linux Python 3, AArch64 GNU nm/objdump and both exact ELFs. With the layout below, run `python3 coop-fresh/verify.py` to regenerate the reports and SHA256SUMS without a guest.

```python
import base64, hashlib, io, json, zipfile
from pathlib import Path

record = json.loads(Path("docs/evidence/evd-036.json").read_text())
blob = base64.b64decode(record["zip_base64"], validate=True)
assert hashlib.sha256(blob).hexdigest() == record["zip_sha256"]
root = Path("coop-fresh")
root.mkdir(exist_ok=False)
with zipfile.ZipFile(io.BytesIO(blob)) as archive:
    assert set(archive.namelist()) == set(record["files"])
    for name, spec in record["files"].items():
        data = archive.read(name)
        assert len(data) == spec["size"]
        assert hashlib.sha256(data).hexdigest() == spec["sha256"]
        dest = root / name
        dest.parent.mkdir(parents=True, exist_ok=True)
        dest.write_bytes(data)
```
