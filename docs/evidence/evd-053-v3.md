# EVD-053 v3 · 예약 첫 경계 인계

후보 일반 실행 8건 중 4건, 같은 실험의 선행 버전 8건 중 5건, 과거 선행 버전 8건 중 1건이 완료됐다. 후보와 동시 비교군은 각각 과부하 2건을 모두 거절했다. 전체 프로필 적격 판정은 보류한다.

[CHG-059](../reservation-compact-handoff-plan.md) · [#138](https://github.com/Romanof123/JNOX/pull/138) · [Rust](https://github.com/Romanof123/JNOX/tree/b9a247c68c3ab2544f18158c8dd13fc15cab6428/kernel) · [Python](https://github.com/Romanof123/JNOX/blob/54218be8e6e06382cd491bc2e3af9f61705d4f0c/tools/reservation_handoff.py) · [JSON](evd-053-v3.json) · [ZIP](evd-053-v3-captures.zip)

기본 QEMU 카운터와 15초 제한에서 한 쌍의 실행 순서를 번갈아 배정했다. 20건 모두 새 게스트의 첫 실행이다. W는 깨움, S는 포화 부하이다. 카운터는 62.5 MHz, 슬롯은 3,125,000틱이다. 표의 표식은 첫 Rust 실행 시각에서 해당 게스트의 기준 시각 E를 뺀 틱 수이고 —는 미관측이다.

상태 0/0은 정상 완료이다. 정렬 W 두 건은 슬롯 34까지 A/B 각 9회, 이웃 B는 슬롯 1, 5, 9, 14, 17, 21, 25, 29, 33에서 서비스를 받았다. 정렬 S 일반과 CBS S 추적은 슬롯 10까지 각 4회, B는 1, 3, 5, 7에서 실행했다. 각 기한의 누적 서비스 상한을 해당 할당량과 대조했다. 이 결과가 적용되는 범위는 완료한 슬롯과 구성이다.

2/5 세 건은 권한 뱅크 교체와 컷오프 설정 후 선택 전 경계 검사에서 멈췄다. 2/2인 CBS W 일반은 A 한 번이 E+63,524틱에 관측돼 1 ms(62,500틱)를 넘겼다. 네 실패 모두 이후 B 서비스를 확인할 수 없다. 1/2는 수요 9/8을 기준 시각·타이머 비교·프레임 준비 전에 거절한 경우이다. 종료 슬롯의 최댓값은 미설정 표식이다.

게스트 타이머는 PPI 30을 기록했다. QEMU 외부 IRQ/SVC/ERET 횟수는 정렬 W 추적 48/5/53, CBS S 추적 17/2/19, 선택 전 종료된 추적 두 건 각각 1/0/1이다. 추적에서 실제 복귀 PC를 ELF에 연결했다. 일반 실행은 게스트 벡터와 어셈블리 복귀 기록에 의존한다. 독립 분석은 832바이트 저장 프레임과 스택 상단, 작업자 진입 주소, 연산 진행량과 각 할당 기한별 서비스 상한을 대조했다.

후보 커밋 구간은 2,721–3,658틱, 동시 비교군은 4,921–6,669틱이었다. 후보 소스 읽기는 5,047–10,472틱, 마스킹부터 준비 표식까지는 39,587–45,583틱이었다. 표식은 마스크 해제 전에 찍혔다. 두 뱅크와 증빙·영수증은 128+128+264+184=704바이트였다. 구간에는 계측 자체 비용이 들어간다. 부팅 기준점은 커널의 첫 카운터 표본이며 호스트 시작 시간은 제외된다. 짧아진 커밋 구간만으로 경계 전체의 비용 개선을 입증할 수 없다.

기존 디코더는 부팅 및 종료 시점의 태그 24를 중복으로 해석해 후보 일반 8건에서 실패했다. 수정 도구는 원본 20건 모두에서 독립 분석과 일치했다. 뱅크 1·세대 1·소유자 A·권한값 3을 확인한 뒤 종료 시 출력된 31/32행을 해석했다. 이 행의 출력 시각은 실제 차감 시각을 나타내지 않는다. 두 도구 버전의 커널 트리는 같다. 원본 오류, 수정 디코더 제어 시험 4건과 모든 원자료는 ZIP에 있다. v3 지연 전용 시험은 수행하지 않았다. 실물 타이밍과 배포 환경 격리는 미검증이다.

JSON에 기재한 ZIP 해시를 확인하고 Linux에서 아래 명령으로 파일별 SHA-256을 검사한다. 복사본에서 Python 3 및 GNU aarch64-linux-gnu-nm으로 재분석한다.

```sh
unzip evd-053-v3-captures.zip
mkdir corpus
tar -xzf reservation-compact-fresh.tar.gz -C corpus
(cd corpus && sha256sum -c SHA256SUMS)
cp -R corpus replay-copy
(cd replay-copy && python3 audit.py)
```
