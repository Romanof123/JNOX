# EVD-057 · 일반 Rust 뮤텍스 계측

IMP-057 / POL-014. LOW와 HIGH가 보호 배치 데이터를 인계하고 MEDIUM은 실행 준비 상태를 유지한다. 실험 소스 47ea890의 기존 RAW1 최초 4회 중 3회가 충족됐다. PI 일반은 보호 작업 전에 사유 16으로 중단했다. 후속 사전 비교에서는 기본 PI 이미지의 소스 위치 여섯 곳 차이를 보존했다. [기존 최초 4회](ordinary-mutex-first/README.md) · [기본 이미지 비교](ordinary-mutex-anchor-preflight/README.md)

### 실험 브랜치 최초 실행

소스 da8005510e3d240660fc1f8f445161826852a291. 각 행은 사전에 정한 네 자리로 구성되며 셀은 게스트 사유와 IRQ 시점 완료 청크 수다. 최초 12회 모두 종료 기록을 남겼다. 실제 IRQ PC, 타이머 비교·판독, 소유자·복귀 및 시간 구간은 원본에 있다. [12회 상세 기록](ordinary-mutex-anchor-first/README.md) · [ELF·UART·외부 추적·재생 원본](ordinary-mutex-anchor-first/captures.zip)

실패한 두 PI 추적은 작업 진입 표시가 0이었다. 선택 복귀형 천장 추적은 링크된 입력 루프 직후, 첫 청크 게시 전에 IRQ를 받았다. 충족 사례는 256청크, 카운트 65,536, 보호 합계 557,056, MEDIUM 합계 32,896을 완료했다. 타이머 비교 간격은 62.5 MHz에서 6,250틱이다. 추적 ERET는 목적 PC를 알려준다. 정확한 복귀 사이클, 실물 최대 차단, WCET 및 배포 작업은 별도 측정이 필요하다. [앵커와 기록 형식](../ordinary-mutex-anchor.md)

### 통합 후보

통합 소스 검증은 대기 중이다. kernel/에서 Rust 1.95.0, cargo build --locked --release -j1, JNOX_BOARD=virt, JNOX_PROFILE=mutex, JNOX_APP=ordinary-pi 또는 ordinary-ceiling으로 빌드한다. 위 세 앵커를 JNOX_MUTEX_ANCHOR에 각각 지정한다. 앱마다 동일 ELF로 기본 시계 virt/GICv2 Cortex-A72 일반·예외 추적 첫 부팅을 각각 1회 수행한다. 실패를 포함해 통합 실행 원본을 새 순번으로 보존하고 작업·소유권·우선순위·인계·복귀와 결과를 재생한다. 정확한 병합 리비전과 ELF·맵·도구 해시를 기록한다. 앵커 미설정 RAW1 두 앱, 기존 mutex-bench, 잘못된 선택자, Pi 4 directed-wake와 기존 프로필 선택도 확인하고 기준별 이미지 차이를 보고한다.
