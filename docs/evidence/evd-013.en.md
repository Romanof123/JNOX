# EVD-013 · Timer arrivals under SJF, SRTF and HRRN

[한국어](evd-013.md)

The same four-versus-two remaining-service comparison produced opposite dispatches. SJF returned directly to A at `0x40201298`. SRTF dispatched B and restored A at that address when B completed. HRRN kept an underestimated A running, then selected the five-unit B, which had waited ten ticks, ahead of newly ready one-unit C.

The independent verifier recorded 301 exact UART bytes and observer exit 0 before reviewing source or trace. Three IRQs and seven completion SVCs were mapped against the same guest ELF. The observer rejected three altered transcripts. All 39 host tests passed, including an independent tick-by-tick comparison of 9,720 schedules with different arrival patterns, IDs, service estimates and actual durations. Integration separately booted 11 single and combined feature configurations to check precedence and earlier entry points. [UART / IRQ / SVC](evd-013.json) · [11 QEMU profiles](evd-013-regressions.json)

The workload supplies logical service timestamps. These observations establish dispatch identity, asynchronous interruption and saved-PC restoration on a single emulated Cortex-A72. The guest checks live register and stack witnesses. Physical service times, WCET and a released M4 batch service require separate evidence.
