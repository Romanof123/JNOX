# EVD-043 · FS-M3-01 제어 작업의 조건부 수용 분석

[English](evd-043.en.md) · [수용 분석 방법](../fs-m3-admission.md) · [#94](https://github.com/Romanof123/JNOX/issues/94) · [#96](https://github.com/Romanof123/JNOX/pull/96)

첫 호스트 검증은 **부분 통과**였다. 회귀 시험 14건, 반열린 구간의 도착 상한 검사 1,056건과 정책 비교 184건이 일치했다. 깊이 1,500의 중첩 입력에서 CLI가 RecursionError를 처리하지 못하고 종료 코드 1로 끝났으며 구조화된 결과가 없었다. 당시 명령, 예외 추적과 성공한 검사 기록을 보존했다. [최초 소스](https://github.com/Romanof123/JNOX/commit/0805534a39ca58b55a23c25aca6da17258e0a727) · [최초 검증 기록](evd-043-initial.json)

수정 후 호스트 검증은 **통과**했다. 독립 검증자는 정수 길이 구간을 순회해 최초로 간섭 수요를 수용하는 구간을 구하고 RM·DM 결과와 대조했다. 고정 우선순위 회귀 시험 8건과 FS-M3 회귀 시험 9건을 통과했다. CLI 결과 168건 중 조건부 수용 80건, 거부 64건, 미결정 24건이었다. 두 정책 모두 깊이 4,000의 중첩 입력에 구조화된 unknown과 종료 코드 2를 반환했다. 거부는 제공된 가정과 예산 상한으로 모든 한계를 증명할 수 없다는 뜻이다. 미결정은 입력이 무효·미지원이거나 계산으로 결론을 낼 수 없음을 뜻한다.

가상 예시에서 두 정책 모두 불확실성 포함 위상 A/B 완료 상한 185/285 µs, 송신 완료 상한 695 µs, 최대 판정 간격과 제어 작업 완료 상한 2,785 µs를 산출했다. 송신 경계 사례는 9,999 및 10,000 µs에서 조건부 수용, 10,001 µs에서 거부였다. 이는 계산한 상한이다.

분석은 처음 유휴 상태인 단일 코어, 조기 실행 없는 절대 위상 목표, 동일 작업의 B 위상 재개, 누락 없는 서비스 회계, 이전 구간에서 이월되는 간섭을 포함한 독립적이고 유한한 IRQ 상한을 가정한다. 두 호스트 검증의 범위에 실측 실행 예산 근거, 런타임 ELF, 게스트 추적, 실물 보드, 장치 상태 또는 제품 안전 검증은 포함되지 않는다.
