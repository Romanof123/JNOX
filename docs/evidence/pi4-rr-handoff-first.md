# CHG-073 RR 데이터 인계 최초 관측

소스 `702380d7797648cff740cc538bd301c442873e85`에서 Pi 4 모델의 일반 RR 부팅 두 건은 모두 124바이트 UART 검사를 통과했다. 계측 부팅 두 건은 모두 종료 코드 **2**였다. HIGH 선점, A 복귀와 연산값 증가를 확인했다. 이후 타이머로 B에서 A로 전환한 세대는 5였고 B는 세대 6에서 다시 실행됐다. 후반 연산 증가와 단일 세대 내 데이터 인계 기준은 모두 미관측이다.

| 고정 순서 | 결과 | 양수 페이로드 | A 구간(틱) | B 구간(틱) |
|---|---|---:|---:|---:|
| O1 일반 | 완료 | — | — | — |
| E1 계측 | 코드 2 | 1,820,706 | 649 | 23,211 |
| E2 계측 | 코드 2 | 1,871,585 | 642 | 20,488 |
| O2 일반 | 완료 | — | — | — |

A의 release 저장은 두 번 모두 세대 5 안에 있었다. B의 단일 acquire가 읽은 값은 매번 A가 저장한 값과 같았다. B의 측정 구간은 세대 4에서 6까지 걸쳤고 중간에 A가 실행됐다. 따라서 읽기 명령을 한 세대에 귀속할 수 없다. 독립 예외 기록은 계측 부팅별 일곱 세대와 일치했다. 실제 STLR 주소는 `0x82208`, 조건 분기와 관측값 양쪽에 쓰인 LDAR 주소는 `0x82178`이었다. 측정 시점의 스택 상단 대비 깊이는 A 0바이트, B 192바이트였다. 스택 최대 사용량과 실물 보드 타이밍은 미확인이다.

통합 v1 계측 이미지보다 코드가 452바이트, 읽기 전용 데이터가 1바이트, BSS가 176바이트 늘었다. BSS 증가량은 소유자별 셀 두 개와 커밋 워드 두 개에 해당한다. 데이터 및 예약 스택 크기는 같았다. 일반 원시 이미지는 통합본과 일치했다. 변조 복사본 여섯 건은 모두 코드 1이었다. 기존 v1 FIFO/RR 재생은 원본 0/0, 통합본 0/2였다. 새 부팅 네 건은 모두 시간 안에 끝났으며 재시도는 없었다. O1 실행 전에 로컬 소스 추출에서 boards/pi4/config.txt가 빠져 패키징이 중단됐다. 최초 준비 파일 세 개를 보존하고 같은 커밋에서 보드 파일을 추출해 패키징을 완료했다.
