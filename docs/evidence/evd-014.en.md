# EVD-014 · Physical timer preemption and exact return in the Pi 4 model

[한국어](evd-014.md)

The dedicated Pi 4 raw image ran on raspi4b. An IRQ interrupted LOW’s ADD at `0x812bc`, entered vector `0x80a80` and returned into HIGH at `0x8134c`. HIGH issued SVC #1 at `0x81388`, entered vector `0x80a00`, and returned to the exact LOW instruction at `0x812bc`. The guest checked PPI 30, frames, stack and progress. The external trace supplied the exception and return PCs.

The fresh verifier recorded 103 UART bytes, one second of silence after the final LF and observer exit 0 on the first guest. A shell argument preparation error preceded the observer launch. Five host controls rejected altered output. Two clean builds matched raw and ELF hashes. Integration separately booted the staged scheduler payload, the serial-only payload and the virt scheduler. The build rejected five unsupported Pi feature combinations. [UART / IRQ / SVC](evd-014.json) · [SD / SHA-256](evd-014-package.json)

This covers core zero on the QEMU 11.1.3 raspi4b model with 2 GiB RAM. Physical hardware depends on the secure firmware stub delegating the nonsecure timer interrupt. Two physical power cycles, on-board exception tracing, real-time latency and SMP require their own evidence.
