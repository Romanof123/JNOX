# EVD-050 v1 · QEMU virt 콜드 시작의 쌍대 시간 비교

[English](evd-050-v1.en.md) · [EVD-050](evd-050.md)

**일반 이미지 정상 판정은 0/32, 진단 모드 초기화 성공은 0/96이었다.** 행렬의 128회 모두 종료 표시를 남겼다. 일반 실행의 모든 위상은 IRQ 한계를 충족했지만(832/832), 판정·복귀 한계를 충족한 위상은 830/832였다. 허가 수신, 재무장 명령 또는 장치 ON 전이는 한 번도 관측되지 않았다. 이는 #109의 별도 콜드 시작 실험이다.

단일 Cortex-A72 TCG 게스트는 QEMU 6.2.0, virt/GICv2, 128 MiB를 사용했다. 정책·구성마다 콜드 실행 8쌍을 배치하고 QEMU 인터럽트 로깅 꺼짐/켜짐과 켜짐/꺼짐 순서를 번갈아 사용했다. 시작 제한은 호스트 시간 10초, UART 폴링 간격은 1 ms였다. ELF·UART·인터럽트 로그는 Linux 로컬 임시 저장소를 사용했다. 호스트 부하와 Windows 전원 설정은 기록했지만 부하를 통제하지 않았다. 호스트 시작·관측 경과 시간과 게스트 카운터 구간은 별도로 보존했다.

| 일반 이미지 구성 | 실행 수 | 첫 IRQ 지연 범위(ms) | 모든 판정·복귀 한계 충족 실행 수 |
|---|---:|---:|---:|
| RM, 로깅 꺼짐 | 8 | 0.136176~0.231072 | 7 |
| RM, 로깅 켜짐 | 8 | 0.150944~0.267312 | 7 |
| DM, 로깅 꺼짐 | 8 | 0.136928~0.185904 | 8 |
| DM, 로깅 켜짐 | 8 | 0.144032~0.191552 | 8 |

첫 IRQ 지연의 쌍별 차이(켜짐에서 꺼짐을 뺀 값)는 평균 RM +0.015590 ms, DM +0.006996 ms였다. 개별 차이에는 두 부호가 모두 있었다. 일반 이미지 실행마다 허가 7개를 발행했지만 첫 두 발행 사이 간격은 요구된 정확한 10 ms 대비 8.607536~9.453680 ms였다. 제어 작업의 마감과 판정 간격은 모두 충족했다. 32개 모두 OFF로 끝났으며 래치 원인은 30개에서 3, 2개에서 7이었다. 이 쌍대 표본으로 일반적인 로깅 지연의 인과 효과를 확정할 수 없다.

진단 실행은 계측된 일반형 기준 시각 선택, 프로브 없는 위상 0 지연, 타이머 프로브가 있는 위상 0 지연 중 하나를 요청했다. 그러나 96개 모두 행 48에 초기 센티널 4294967295, 행 60에 원인 1과 출력 OFF를 기록했다. 별도 일반 ELF 로더 시험에서도 센티널이 남았다. 이 실행 파일에서 해당 모드 전달 절차가 실패했음은 확인했다. ELF 데이터 초기화가 입력을 덮었다는 설명과 부합하지만 리셋 순서를 관측하지 못했다. 리셋부터 첫 표본까지는 관측 공백이다. 초기화·준비 마감·운영 위상 0, 프로브 IRQ·EOI·읽기, 워밍업과 대응 무프로브 비교는 평가할 수 없다.

이 행렬은 가상 정상 작업만 다뤘다. 손실 예산, 음성 대조군, 실물 타이밍, 제품 적격성과 과거 실패 원인은 이 근거의 범위 밖이다.
