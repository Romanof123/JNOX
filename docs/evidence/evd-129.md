# EVD-129 · Pi 4 모델에서 실행한 두 네이티브 소수 계산 앱

CHG-129 / IMP-129 / POL-002 / [#321](../pi4-native-fixed-applications.en-ko.md) / [#322](https://github.com/Romanof123/JNOX/pull/322)

첫 후보 `001dda0`은 지역 레이블 `.Lpark`가 중복 정의되어 어셈블에 실패했고 게스트 부팅까지 진행되지 않았다. 수정 후보 `d905d924a90ea1041821bac78919194852263fe5`는 C 및 Rust ELF를 우선순위 2로 패키징했다. 수정 후 모델 부팅 네 건에서 종료 상태 12와 77이 보고됐다.

FIFO 일반·추적 부팅의 동순위 타이머 전환은 각각 0회, RR은 각각 16회였다. RR은 어느 앱도 종료되기 전에 A→B→A로 전환했다. 62.5 MHz 카운터에서 퀀텀은 1,250,000틱이었다. 추적된 IRQ와 ERET의 PC·SP가 실행 중이던 계산 루프의 저장·복원 프레임과 일치했다. EL0 예외는 CPU0에서만 관측됐으며 CPU1–3의 마지막 PC는 0x310이었다.

네 부팅 모두 독립 페이지 테이블 순회에서 두 앱의 같은 VA 0x402000이 각각 PA 0x2036000과 0x244b000으로 연결됐다. 종료 시 커널 RAM에서 확인한 C·Rust 소수 개수는 78,498·70,435였고 종료 슬롯은 12·77이었다. 두 프로세스의 스택도 분리됐다.

고정 펌웨어 트리 2개 모두 해시와 원시 이미지 바이트가 일치했다. 각 8 MiB인 입력 ELF 두 개로 만든 이미지도 12·77로 종료됐다. C 소스와 센서 피어는 서로 다른 인자 목록을 받고 양보한 뒤 17·29로 종료됐다. 고정 ELF를 사용한 virt FIFO·RR 및 기존 Pi 링크형 FIFO 대조군도 완료됐다. 첫 호스트 아카이브의 CRLF·Git 메타데이터 문제와 링크형 대조군 래퍼의 실행 전 실패는 보고서에 보존됐다.

QEMU 11.1.3 raspi4b의 원시 직접 적재는 EEPROM·SD·VideoCore 펌웨어 실행을 건너뛴다. 실물 보드 전원 인가, UART, 보드 시간 측정 및 제품 승인은 별도 검증 대상으로 남는다.
