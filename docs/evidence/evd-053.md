# EVD-053 · 일반 Rust 예약 작업의 첫 콜드 실행

후보 일반 실행 8건 중 4건, 같은 실험의 선행 버전 8건 중 5건, 과거 선행 버전 8건 중 1건이 완료됐다. 후보와 동시 비교군은 각각 과부하 2건을 모두 거절했다. 전체 프로필 적격 판정은 보류한다. [EVD-053 v3](evd-053-v3.md)

v2는 정상 1/8, 거절 2/2, 비교 v1 정상 0/8이었다. CBS 포화 추적 1회만 완료했고 W 네 건 모두 B 실행권이 없었다. v2 지연 실행과 제품 적격 판정은 없다. [EVD-053 v2](evd-053-v2.md)

### 첫 기록 · v1

정상 8회 모두 첫 A 실행권의 슬롯 0 시간 기준에 실패했다. 거절 2회는 예상대로 동작했고 지연 2회는 명목 종료를 넘는 실제 진행을 기록했지만 더 이른 시작 결함 때문에 지정된 지연 판정을 충족하지 못했다. 기존 CBS 회귀 4회는 별도다. 동료 서비스 격리는 미검증이다.
