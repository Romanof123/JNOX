전용 선택기에서 ELF 하나와 모델 JSON을 묶는다. 두 코어 기동 후 CPU0에서 최초 한 번 판단하고 대상 코어만 EL0에 진입한다. 슬립 후에도 소유권을 유지한다. 무배치 결과도 두 코어 정지를 확인한다. 기존 정책은 그대로 사용한다.

Profile v1 declares integer work, minimum capacity, eligible CPU bitmask (0–3), relative deadline and protected reserve in model ticks; model tick is floor(CNTFRQ/10) counter ticks. Supply limits for CPU0/1 (available, thermal capacity, shared load, reserved capacity), zero to eight distinct (CPU, OPP ID, nominal capacity, energy/work, wake energy, wake ticks) points, and optionally one separately identified trusted fallback. Hash profile, argv and ELF into package provenance. Validate bounded integer types, finite cardinalities, units, mandatory fields and all conversions before dispatch; reject malformed input. An explicitly empty catalogue is valid. Never silently construct a capacity or fallback. Use the real bounded Rust selector with the actual point count; avoid dummy candidates. Calculate the absolute deadline once as E + deadline × tick. Pass ceil((decision−E)/tick) as model now to preserve the original origin and full protected reserve. Retain actual counter times at release, decision, dispatch, first user observation and exit. A returned late job reports its signed margin and miss, including solver, wake and execution costs. A model rejection is a separate disposition. [Shared placement and fallback semantics](../kernel/src/power_policy.rs)
