## Ordinary health / 운영 상태

Identity is one outstanding timer arm and its sequence. Classify the actual minimum when selecting the target. Score an idle **refill** only for idle owner, real GIC PPI30 and the outstanding original actionable fixed-grid refill due D. Record idle wake, active grant end, simultaneous wake/refill, horizon revisit, non-PPI, duplicate/stale and terminal separately; classify a genuine due refill coincident with a wake once and label both causes. Never use a wake-only or range checkpoint as its D. Keep each original IRQ reaction gate for the broader acceptance replay. An early arrival E<D is an explicit invalid/early outcome. A valid E≥D has checked lag E−D; equality at floor(P/8) passes, one tick above fails. P=15,625,000, limit=1,953,125, max consecutive observation gap 8P=125,000,000, F=62,500,000 Hz. Keep original charge, refill grid, dispatch and application exit behavior. No early guard, polling, timer shift or fabricated interrupt.

Maintain constant-size boot-lifetime state independent of journal allocation: version, checked arm/event identity and counts, scored refill count, early/invalid, late count, maximum scored lag, first violation (kind, sequence, D, E, lag when defined) and explicit counter overflow/incomplete flag. Preserve first and maximum across dropped detail rows; never wrap or report a clean verdict after accounting overflow. Zero observations is unobserved. A complete ordinary terminal UART summary and deterministic reader expose instrumentation validity, timing outcome, product status and detail completeness separately. Include total/stored/dropped rows and the first violation's arm/entry evidence in bounded storage. A truncated terminal record is incomplete. Reconcile every recoverable row, exact counts/max/first when detail is complete; on detail loss report the independently accumulated status and the limited replay scope.

실제 유휴 상태의 PPI30과 현재 설정한 고정 위상 재충전 시각을 일련번호로 결합한다. 수면 종료·실행권 만료·먼 미래 중간 점검·중복을 구분하며 동시 깨움·재충전은 한 번만 센다. 이른 진입은 명시적 오류다. 등호는 통과하고 한 틱 초과는 실패다. 상세 저널이 차도 총 관측 수, 최초 위반의 원인·행·비교·진입·레지스터, 최대 지연·누락 수를 고정 RAM에 남긴다. 일반 UART와 리더에서 앱 결과, 시간 결과, 자료 완전성을 각각 읽는다. 건수 오버플로·불완전한 종결과 관측 0회를 명시한다.

## Measurement boundaries / 관측 경계

Keep the original earliest ordered IRQ-vector sample unchanged. At arm bracket the existing CVAL/CTL writes with ordered counter reads, ISB and actual CVAL/CTL readback; record requested absolute D and target identity. At entry retain the earliest E, then sample CVAL, CTL (ENABLE, IMASK, ISTATUS when architecturally meaningful), counter, saved SPSR/ELR and IAR identity before reprogramming or EOI. Preserve the distinction between pre-exception mask in SPSR and IRQ-masked handler DAIF. Acknowledge the interrupt only once. Link arm and entry even on the first failure after trace saturation. The existing idle landing precedes DAIFClr. Where implemented, bracket the actual idle unmask/WFI boundary in assembly, label the last sample's instruction and any possible interrupt before WFI; keep WFI+4 and external exception/ERET evidence distinct from timestamped execution of those instructions. Record probe overhead in the existing cost brackets. [Native timer](../kernel/src/native_el0.rs) · [Weighted readback and idle vector precedent](../kernel/src/native_el0_vectors.S)

Wrong CVAL, disabled/masked CTL, or a late pre-idle sample can localize a guest-side discrepancy. A checked early arm, early unmasked idle and late vector entry still leave timer callback, GIC path, vCPU scheduling and other unobserved intervals unresolved. ISTATUS at entry reports current timer condition, not when it first changed. Use only the pinned executable's actual trace catalog/backend. Check for timer-expiry, GIC bestirq/line assertion/ack and exception events; record exactly which supply timer/PPI30, CPU0, order and timestamp. The [GIC model precedent](boards/pi4-mg2-gic-model.en-ko.md) identifies event names to check, not proof for this host. No log-text timestamp may silently stand for guest CNTPCT. Host attribution requires independently measured time mapping, resolution/error and matching events, e.g. identified QEMU thread IDs and correlated scheduler wake/switch records. If unavailable, report order/coverage and the remaining unknown interval.

설정 전후 실제 CVAL·CTL과 카운터를 읽고, 원래 벡터 최초 표본을 보존한 뒤 재설정·EOI 전의 레지스터와 이전 SPSR·ELR·IAR를 연결한다. 착지, 마스크 해제, WFI 직전, 실제 예외 및 복귀를 구분한다. CTL 상태는 이전의 선 상승 시각을 알려주지 않는다. 해당 QEMU 바이너리가 제공하는 이벤트만 사용하며, 호스트 스케줄링 원인 판정에는 스레드 식별과 별도 시계 정렬 오차가 필요하다.

## Frozen acquisition / 고정 실행 순서

1. On original WSL ext4 setup, cold saturated plain **original then candidate**, cold swap plain **original then candidate**. Original kernels are the byte-identical archived packages/saturated/kernel.elf and packages/swap/kernel.elf. Bind hashes from the public archive before launch. Candidate uses the same ordered user ELF bytes, topology, QEMU binary, CPU/clock, launch argv, QMP observation cadence, host settings and ordinary untraced mode; record every unavoidable difference. No provider or exception tracing in this pair. Preserve first failure, timeout or missing artifact.
2. Complete the candidate's other original positions in original relative order: saturated-trace, swap-trace, child-leaf plain/traced, wake plain/traced, single plain/traced. Keep original full [functional, isolation, cost, compatibility and product criteria](native-hierarchical-applications.en-ko.md). Preserve each first separately, including original linked #84/#212 and default native controls where the original qualification requires them. Assess the two comparison positions individually.
3. Separately freeze one saturated and one swap candidate cold launch with the passive providers available, in that order, retaining the same package/clock. Preserve catalog, enabled names, exact argv, tool/host identities, trace drop/termination and guest evidence. No guest-stopping probe or deliberate guest event. If a provider is unavailable, record that limitation rather than forcing the event. No new miss means natural recurrence unobserved; a subsequent pass cannot identify the earlier cause.
4. Arithmetic controls replay the two published misses exactly and cover zero, equality, limit+1, E<D, unrelated/duplicate causes, wake/refill tie, u64 boundaries, dropped rows before first violation and saturated summary counters. Require retained first and max to match offline arithmetic, and reader to reject malformed/truncated summaries. These are deterministic host controls. A remedy, if indicated, belongs at the measured layer and needs separate qualification against the unchanged gate. #333/#334/#21 retain their original dispositions pending explicit release review.

최초 대조는 포화 일반 원본→후보, 교환 일반 원본→후보 순서다. 원본은 공개 보관 ELF 바이트를 사용하고 앱·호스트·관측 주기와 기본 시계를 일치시킨다. 나머지 여덟 후보 위치 및 기존 대조의 최초 결과도 보존한다. 독립 수동 관측은 같은 후보의 포화→교환 두 실행으로 분리한다. 원본 초과량·등호·한 틱 초과·이른 진입·중복·저널 포화는 호스트 산술로 대조한다. 새 실행에서 자연 위반이 관측되지 않으면 그대로 기록한다. 제품 및 실보드 시간은 해당 배포 주체의 별도 판정이다.
