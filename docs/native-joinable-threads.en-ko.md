# Joinable threads within a native process / 네이티브 프로세스 안의 조인 가능 스레드

[#313](https://github.com/Romanof123/JNOX/issues/313) · CHG-125 / IMP-125 / EVD-125 · REQ-005, [#8](https://github.com/Romanof123/JNOX/issues/8), [#12](https://github.com/Romanof123/JNOX/issues/12), [#21](https://github.com/Romanof123/JNOX/issues/21). Prospective on `eb73c63a925aa9a17982bdc1a0d79b768ed03c5f`. One application can give a worker a pointer to shared samples, do other work on its main thread, and collect the worker's result by joining it. The second thread executes normal AArch64 EL0 code in the same process. [Native entry and dispatcher](../kernel/src/native_el0.rs) · [Exception frames](../kernel/src/native_el0_vectors.S) · [Current errno locator](../sdk/native-aarch64/io.c)

하나의 앱이 공유 표본 배열을 작업 스레드에 넘기고 메인 스레드에서 다른 계산을 한 뒤 조인으로 결과를 회수한다. 두 실행 문맥은 같은 프로세스의 EL0 주소 공간을 쓰며 각자의 스택·레지스터·errno를 가진다.

## Deployment and memory / 배포와 메모리

Package `--source app.c --threads 2` or `--elf app.elf --threads 2` with the normal output option. Raw Cargo equivalent: JNOX_NATIVE_THREADS=2. Accept exactly one ordinary ELF, optional existing primary argv, one CPU and the default cooperative policy. Reject other counts, duplicate switches, peers, startup-probe mode and scheduling-specific options in the CLI and raw build path. Record thread capacity and ELF digest. Omission preserves existing packages, stack maps, syscall behavior for existing services and the initial SP/pointers of #311. Threaded C/Rust apps link the updated SDK. An existing single-thread binary stays usable with its original package.

Within the existing 64 KiB stack reservation, map a writable user errno page at 0x01001000, leave [0x01002000,0x01003000) unmapped, give the worker [0x01003000,0x01009000), leave [0x01009000,0x0100a000) unmapped and give main [0x0100a000,0x01011000). Main's argv remains at the usual top; validate it against main's reduced bounds. Worker starts with aligned SP=0x01009000. Both stacks and errno page are user RW/NX. Update page installation, range/copy checks and per-thread saved-SP validation together so an unmapped gap fails even inside the old contiguous span. These are separate stack ranges within a shared address space; ordinary user pointers to shared data remain valid across a handoff.

Use aligned i32 cells at the errno page base + 0 (main) and + 4 (worker). Use TPIDRRO_EL0 as the SDK errno-cell locator: EL1 sets the correct pointer on **first** entry and frame restore; users can read it but cannot redirect the kernel through it. Keep TPIDR_EL0 independent and save/restore it in each full frame. The threaded startup path must not clear its locator in native_el0_enter. Initialize both errno cells to zero and clear the worker's cell and stack on safe slot reuse. New __jnox_errno_location reads TPIDRRO_EL0 and falls back to the current static int if zero, as it is in the existing singleton route. The kernel derives permitted cells/stacks from trusted slot metadata. No general dynamic TLS ABI is introduced. [Current private mappings and user copies](../kernel/src/native_el0_mmu.rs)

옵트인 패키지는 --threads 2인 단일 일반 ELF와 협력형 CPU0 실행으로 제한한다. 메인 argv는 기존 스택 꼭대기에 두고 아래쪽에 작업 스택과 비매핑 가드 페이지를 둔다. TPIDRRO_EL0는 스레드별 errno 셀을 가리키며 최초 진입과 복귀 모두에서 설정한다. 이전 단일 스레드 경로는 0 값과 기존 정적 errno를 유지한다.

## SDK calls and ownership / 호출 규약과 수명

Add native-v1 SVC 0x4a01 with x8=10 CREATE, 11 JOIN, 12 THREAD_EXIT. CREATE and JOIN return x0=0 or negative native errno; x1 carries a successful handle or an opaque full-width return value. C wrappers return **positive error numbers directly**, leave errno unchanged, and publish output only on success. The SDK stores into caller-owned objects in user mode; the kernel never dereferences the opaque callback argument, the returned value or a saved join-output pointer. Outside the profile the new raw services return −ENOTSUP. Keep x8=1 as whole-process exit. Provide <pthread.h> with uint64_t pthread_t, an opaque pthread_attr_t, pthread_create, pthread_join and noreturn pthread_exit.

- pthread_create(&handle,NULL,start,arg): reject NULL output or NULL routine with EINVAL and non-NULL attributes with ENOTSUP. The wrapper supplies x0=start, x1=arg, x2=SDK trampoline. Validate both code addresses against complete aligned four-byte instructions in the loaded ELF executable segment; readable data, stack, noncanonical addresses and page padding outside executable segment memory fail EINVAL. Atomically reserve the worker slot or return EAGAIN. Initialize a clean native frame at the validated trampoline with x0=start and x1=arg, worker SP, user PSTATE, its own locator, clean GPR/SIMD/FP state and no inherited continuation. The trampoline calls start(arg) and passes its returned x0 to THREAD_EXIT. Do not directly return from user code into an EL1 routine. Main receives the handle before the worker can run: create queues the worker and leaves the caller running.
- One generation-checked worker handle per creation, e.g. (generation << 1) | 1, generation starts at 1. Refuse counter exhaustion with EAGAIN before mutation. A live or exited-but-unjoined worker occupies the slot. JOIN x0=handle: unknown, zero, stale or already reaped → ESRCH; current worker joining itself → EDEADLK. Only main may claim a valid worker join. A live worker blocks main's saved post-SVC frame. A finished worker yields its stored result immediately. On handoff fill main's saved x0/x1, consume the claim once and reap. NULL result pointer discards the value. An ordinary non-NULL output pointer must denote a writable C object; no deferred kernel write to a user pointer. The worker may return NULL or any pointer-sized value, including an address in shared data. Do not use a pointer to an expired worker stack object as an application result.
- Worker pthread_exit(value) and normal callback return finish only the current worker. If main has not joined, retain its result until join. A main pthread_exit(value) ends main; continue any live worker, and terminate the process with status 0 when no live thread remains (discard uncollectable results). Returning from main or calling the original process EXIT immediately terminates all threads with the supplied signed status, cancels sleeps/join and timer, and prevents any later user restore. A new creator can reuse the worker slot only after successful reap. No cancellation, detach, arbitrary stack attributes or preemptive time slice in this profile.

C 호출은 실패 시 errno를 바꾸지 않고 양의 오류 번호를 직접 반환한다. 커널은 ELF의 실행 영역에서 시작 주소와 트램펄린을 검사하고, 결과는 저장된 레지스터로 전달한다. 메인은 작업 종료 전 조인하면 차단되고 종료 후 조인하면 즉시 결과를 받는다. 조인 전까지 슬롯을 보존하며 재사용 때에는 새 세대로 이전 핸들을 거부한다. 작업 함수 반환이나 pthread_exit는 해당 스레드를 끝내고 기존 프로세스 종료는 둘 다 끝낸다.

## Dispatch and evidence / 실행과 관측

Track CPU0's current process separately from its current thread. Keep one saved complete NativeFrame per thread (x0–x30, SP_EL0, ELR/SPSR, SIMD, FP status/control and thread registers). A same-process thread change must actually swap frames even when the address-space root remains identical. Stable ready FIFO: main starts alone, creation appends, yield appends the caller and selects the front (alone returns 0); a join waiter or future absolute sleeper is ineligible. Wake due sleepers once in deadline/slot order into the FIFO, without involuntarily replacing a running thread. Arm the earliest checked physical compare, idle only without ready work, and handle PPI30 from EL0 or idle. Preserve native error/elapsed sleep semantics. Worker exit makes an existing join waiter ready. Ordinary nonblocking calls preserve the current thread. Keep bounded, nonperturbing observations with lost-row totals: entry/exit samples, pid/tid/generation, ready/block/terminal state, SVC and result, timer target and observed IRQ, saved/restored SP/ELR, thread locator, private stack bounds, address-space root, join claim and actual return. No service benchmark follows from these records.

One frozen C application makes two sequential creations. Initialize shared arrays of 256 uint32_t values. Worker g=1,2 writes out[i]=i+g, yielding after each 64-element quarter; main computes an independent 0…255 checksum of 32,640. Use atomics for interleaved flags/counts; publish immutable inputs before creation and consume worker-written results only after join (SDK/compiler memory barriers at creation, exit and join). Worker 1 returns a pointer to its shared descriptor; verify all 256 outputs and sum 32,896 after a **blocking** join. Main then creates worker 2, which explicitly pthread_exit's a pointer to its second descriptor. Let worker 2 finish before joining; verify all outputs and sum 33,152, pointer identity, distinct handles and stale-handle ESRCH. Main returns 17. Exercise actual clock_gettime with a wrong clock ID for EINVAL on main; use close on an unsupported descriptor service for ENOSYS on the worker. Interleave yields, timed waits and joins and reread errno on each thread, demonstrating distinct cell addresses and values, including fresh zero on reuse. In a separate no_std Rust ELF, use the C ABI with extern "C" worker entry and static atomic data, and join before consuming its output. Keep any unsafe pointer lifetime and valid output-object obligations explicit.

Freeze source and SDK/ELF hashes, exact inputs, private symbols, stack-map addresses, original package commands and trace capacity on an ext4 build/capture volume before first guest launch. Preserve first plain then external exception-traced cold boots on one Cortex-A72 QEMU virt/GICv2, 128 MiB, default clock, C then Rust. Verify the common TTBR, pointers and physical backing, distinct SP/ELR and errno cells, restored worker continuation, result pointer and full arrays. Exercise both runnable handoffs and a case with main blocked in join and worker sleeping to an actual future SDK deadline (e.g. now+20 ms), then real idle wake and success. Separate controls cover zombie capacity/EAGAIN before reap, self join, invalid code, stale handle, NULL result, main pthread_exit, early process exit with live worker, and unchanged singleton/probe argv/errno plus unsupported raw calls. Reconcile actual EL0-origin exceptions and user returns against the journal; a host check or pre-ERET stamp alone cannot establish the restored instruction. Retain any failed first positions independently of later fixes.

CPU0는 프로세스와 스레드의 현재 ID를 별도로 추적한다. 같은 페이지 테이블이어도 스레드가 바뀌면 전체 문맥을 교환한다. 생성·양보·조인·절대 대기·종료를 실제 준비 큐와 타이머로 처리한다. 검증 앱은 작업자를 두 번 순차 생성해 각각 종료 전·후 조인하고, 256개 출력 전체와 합계 32,896 및 33,152, 결과 포인터, 과거 핸들의 거부와 스레드별 errno를 확인한다. ext4에서 입력과 바이너리를 동결하고 일반·외부 추적 최초 부팅을 보존한다. 물리 보드와 다른 정책의 스레드 지원은 별도 범위다.
