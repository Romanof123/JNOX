## Change and acceptance

At `ca0b3dd3f87f0f459449271d957af1eb8e77d2cd` the healthy descriptor worker masks IRQ, reads the counter twice and restores DAIF solely to read `Runtime.missed` at the start of each of two phases. Between this precheck and its second check under the actual decision guard it only selects immutable register arguments. The build admits the descriptor only for healthy RM/DM. In all workers the existing second check can enter the nonreturning `final_check` inside the outer guard. Its SVC then precedes the outer guard's exit observation and DAIF restore. The missed-index producer disables the timer and marks the affected execution for a single final evaluation. [Worker and exception paths](../kernel/src/control_runtime.rs) · [Prior control design](control-service-plan.md)

Consume a pending missed index in the actual decision guard. Under that mask perform the final freshness evaluation on the worker stack using the actual counter and the missed index's original target, record phase completion and mark stopping. Exit the guard before SVC #2. If there is no miss, perform the usual check with the descriptor, original phase envelope and SVC sequence. Keep the stock worker's early check before its job reconstruction and optional demand loop. A late IRQ between the evaluation and the next SVC still uses the original handler redirect. Preserve DAIF restoration, mask measurements for actual regions, all slice debit, the 5 ms job and inter-check bounds, the 250 µs control limit, 0.5 ms IRQ and 1 ms phase, sender admission, rearm and independent PL061 readback. No new input value or timing allowance is introduced.

## 변경 및 합격 기준

기준 커밋의 healthy 디스크립터 작업은 각 위상의 실제 판정 직전에 누락 여부만 읽기 위해 IRQ 마스킹·카운터 읽기 두 번·DAIF 복원을 한 번 더 수행한다. 두 검사 사이에는 레지스터로 받은 위상 인자 선택만 있다. 기존 작업은 실제 판정 보호 구간 안에서 누락을 발견하면 내부에서 복귀하지 않는 최종 검사를 호출하여 바깥 구간의 마스크 종료 관측·복원 전에 SVC에 진입할 수 있다.

실제 판정 구간에서 누락 인덱스를 한 번 소비한다. 누락 시 작업자 스택에서 실제 시각으로 신선도를 평가하고 해당 인덱스의 원래 목표와 종료를 기록한 뒤 정지 표시를 설정한다. 마스크를 복원한 뒤 SVC #2를 실행한다. 정상 시 원래 디스크립터와 시간 한도를 사용한다. 기존 비디스크립터 작업의 작업 복원·수요 루프 전 검사와 판정 이후 IRQ가 들어올 때의 SVC 재진입 처리는 보존한다. 실제 구간의 마스크 측정, 슬라이스 과금, 작업·신선도 5 ms, 제어 250 µs, IRQ 0.5 ms, 위상 1 ms, 송신 수용 및 PL061 독립 판독 기준을 그대로 적용한다.

앞선 저장 경로 32회, 서비스 24회, 게시·수용 실험과 OFF 관측 16회를 보존한다. OFF 관측에서는 송신 기회 112건 모두 시도 전 종료했고 최초 제어 서비스가 모두 15,625틱을 넘었다. 이번 변경의 절감 시간이나 정확한 허가 간격은 미측정이다. 같은 QEMU 6.2·GICv2·A72 단일 CPU·128 MiB, NIC 없음·ext4·10초 타임아웃에서 RM 이후 DM 각각 A0의 기준→후보, 후보→기준 순서로 최초 8회를 동결한다. 계측 조건을 맞춰 모든 최초 원본, 과금·위상·발행·수신·명령·출력의 실제 상태를 기록하며 전체 정상 판정과 쌍별 차이를 구분한다.

추가 12회는 RM 이후 DM, 각 정책에서 기본 운영 거부→기본 OFF→기존 icount OFF, 각 항목에서 A1 다음 A2 순서다. 운영 진입 전 누락 마스크 4095, 실제 OFF 정지·완주와 독립 출력 관측을 확인한다. 연결된 코드에서 위상별 판정 마스킹 한 번, 누락 시 DAIF 복원 후 SVC, 판정 이후 누락의 기존 재진입을 확인한다. 저장 상태로 진입 전·판정 후 누락을 별도 검증하고 실제 부팅 관측과 구별한다. 기존 healthy·cold·marker 이미지의 적재 데이터를 대조하고 달라진 구성은 첫 부팅 대조도 수행한다. 실제 비용 상한이 공급되기 전 A1/A2 운영 수용은 계속 거부한다. 제품 판정에는 실물·제품별 근거가 필요하다.
